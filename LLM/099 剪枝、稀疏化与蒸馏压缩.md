[[099 剪枝、稀疏化与蒸馏压缩|剪枝、稀疏化与蒸馏压缩]] 是和量化并列的另一类模型压缩:**剪枝**删掉不重要的权重(非结构化置零单权重 / 结构化整删行列头层),**稀疏化**让权重矩阵大量为零以省算省存,**知识蒸馏**让小学生模型模仿大教师的**软标签**学到"暗知识",从而以更小的模型逼近大模型的效果。

## 直觉

三条路,目标都是"更小更快、尽量不掉点":

- **非结构化剪枝**:把幅值最小的单个权重直接**置零**。删得最狠(稀疏度可很高),但留下的是**不规则稀疏矩阵**——通用 GPU 还是按稠密算,**省了显存但难提速**,除非专用稀疏核或 2:4 结构稀疏。
- **结构化剪枝**:成块地删——整个**注意力头、FFN 通道、甚至整层**。矩阵真的变小,**通用硬件直接提速**;代价是粒度粗,掉点风险大,通常要**剪后再微调**找回精度。
- **知识蒸馏**:不动结构,换个训法。让小模型(学生)去拟合大模型(教师)输出的**软概率分布**(带温度 $T$),而不是只看 one-hot 硬标签。软标签里藏着"猫和虎很像、和汽车不像"这种**类间结构**(Hinton 称之为"暗知识"),信息量远大于硬标签,小模型因此学得更好。

一句话:**剪枝/稀疏是"砍",蒸馏是"教";砍要么砍得碎(难加速)要么砍得整(易掉点),教则用软标签把大模型的隐性知识传给小模型。**

## 例子

**剪枝**。某 FFN 权重行 `[0.8, 0.02, -0.7, 0.01, 0.9, -0.03]`,设 50% 稀疏:

- **非结构化**:按幅值排序,置零最小的 3 个(`0.02, 0.01, -0.03`)→ `[0.8, 0, -0.7, 0, 0.9, 0]`。保了大权重,但这一行还是 6 维,矩阵形状没变,**GPU 仍当稠密算**。
- **结构化(2:4)**:每 4 个里强制留 2 个最大的,对上 NVIDIA Ampere 稀疏 Tensor Core,**真能约 2× 提速**——这是结构稀疏的折中。

![[quant-2to4结构稀疏.png]]

**蒸馏(温度暴露暗知识)**。教师对一张猫图的 logits 经 softmax:

- 硬 one-hot:`猫 1.0 | 虎 0.0 | 汽车 0.0`(只说"是猫")。
- 教师软标签($T=1$):`猫 0.90 | 虎 0.09 | 汽车 0.01`。
- 升温 $T=4$ 后变平:`猫 0.55 | 虎 0.40 | 汽车 0.05`——"猫像虎、不像车"的相对关系被**放大暴露**出来。学生用同样 $T$ 拟合这个平滑分布,学到 one-hot 给不了的类间相似度。

![[quant-剪枝稀疏与蒸馏.png]]

## 原理

**剪枝判据(幅值剪枝)**。给定稀疏率 $p$,取阈值 $\tau$ 为权重绝对值的 $p$ 分位数,掩码

$$
m_{ij} = \mathbb 1\big[\,|w_{ij}| > \tau\,\big],\qquad \hat w_{ij} = m_{ij}\, w_{ij}
$$

非结构化对单个 $w_{ij}$;结构化则对**整组**(一个头/一个通道的 $\|\cdot\|_2$)排序删除。更高级的判据用二阶信息(如 OBS/SparseGPT 的 Hessian 近似)衡量"删掉它对 loss 的影响"。剪后常需**再训练/微调**恢复精度。

**为什么纯幅值剪枝在 LLM 上不够好,SparseGPT/Wanda 怎么改进**。幅值剪枝假设「小权重 = 不重要」,但**乘了大激活的小权重照样重要**(贡献 $w\cdot x$)——和 [[096 AWQ 与 SmoothQuant|AWQ]] 的洞察同源。所以 LLM 剪枝改用**激活感知判据**:① **Wanda**(2023)直接用 $|w_{ij}|\cdot\|x_j\|$ 当重要性(权重幅值 × 对应激活范数),一次性剪枝、无需再训,极轻量;② **SparseGPT**(2023)沿用 [[095 GPTQ|GPTQ]] 的逐层 Hessian 框架:把「剪枝」当成「量化到 0」的特例,剪掉一个权重后用 $H^{-1}$ 把误差补偿进剩余权重,一次性剪到 50%+ 稀疏几乎不掉点。这两者把「LLM 剪枝必须重训」变成「一次性 PTQ 式剪枝」,是工程主流。

**知识蒸馏损失**。带温度的 softmax:$p_i^{(T)}=\dfrac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$(见 [[27 Softmax 与温度|温度]])。学生总损失是软目标 KL 与硬标签 CE 的加权:

$$
\mathcal L = \alpha\, T^2 \cdot \mathrm{KL}\big(p_{\text{teacher}}^{(T)}\,\Vert\, p_{\text{student}}^{(T)}\big) \;+\; (1-\alpha)\,\mathrm{CE}\big(y_{\text{hard}},\, p_{\text{student}}^{(1)}\big)
$$

- **温度 $T>1$** 让分布变平,**放大非目标类的相对概率**(暗知识);训练用 $T$、推理用 $T=1$。
- 系数 **$T^2$** 是因为软标签项的梯度量级 $\propto 1/T^2$,乘回来让两项梯度尺度可比(Hinton 2015 的关键技巧)。**为什么是 $1/T^2$**:softmax 的 logits 先除以 $T$,反传时这一步带一个 $\frac1T$ 因子;软目标 KL 对学生 logits 的梯度里,「软化」和「对 logits 求导」各贡献一个 $\frac1T$,合起来梯度 $\propto\frac1{T^2}$。所以高温下软项梯度被压得很小,乘 $T^2$ 补回来,才不会被硬标签项盖过。这是 Hinton 论文里不显眼但极关键的一行。
- LLM 里有两类蒸馏:**白盒**(对齐 logits/中间层,需教师可访问)与**黑盒/序列级**(只用教师生成的文本当 SFT 数据,即"蒸馏数据")。RLHF/对齐里也常拿强模型的偏好或回答蒸馏给小模型(可与 [[090 RLAIF、宪法 AI 与过程奖励 PRM|RLAIF]] 中的 AI 反馈思路结合)。

## 代码

```python
import torch, torch.nn.functional as F

# ---- 非结构化幅值剪枝 ----
def magnitude_prune(W, sparsity=0.5):
    tau = W.abs().flatten().kthvalue(int(sparsity * W.numel())).values  # p 分位阈值
    mask = (W.abs() > tau).float()
    return W * mask, mask                         # 形状不变,只是大量置零

# ❌ 蒸馏常见错:① 用硬标签做 KL ② 忘了 T^2 缩放 ③ 训练/推理温度不一致
def distill_loss_bad(student_logits, teacher_logits, y, T=4.0):
    p_s = F.softmax(student_logits, -1)           # 没除以 T
    p_t = F.softmax(teacher_logits, -1)           # 没除以 T,软标签被浪费
    return F.kl_div(p_s.log(), p_t)               # 还漏了 T^2 与硬标签项

# ✅ 正确:温度软化 + T^2 缩放 + 软硬加权
def distill_loss(student_logits, teacher_logits, y, T=4.0, alpha=0.9):
    soft = F.kl_div(
        F.log_softmax(student_logits / T, dim=-1),
        F.softmax(teacher_logits / T, dim=-1),
        reduction="batchmean",
    ) * (T * T)                                   # 关键:补回 T^2
    hard = F.cross_entropy(student_logits, y)     # 硬标签项用 T=1
    return alpha * soft + (1 - alpha) * hard

sl = torch.randn(8, 1000, requires_grad=True)
tl = torch.randn(8, 1000)
y  = torch.randint(0, 1000, (8,))
print("蒸馏 loss:", distill_loss(sl, tl, y).item())
```

## 面试高频

- **非结构化 vs 结构化剪枝,差别和取舍?** 非结构化置零单权重,稀疏度高但不规则、通用 GPU 难加速(省显存不省时);结构化整删头/通道/层,矩阵真变小、硬件直接提速,但粒度粗易掉点,需剪后微调。
- **为什么剪枝在通用 GPU 上常不提速?** 稀疏矩阵元素位置不规则,稠密 GEMM 核照样算所有元素;要提速得靠专用稀疏核或 2:4 结构稀疏(Ampere 起的稀疏 Tensor Core)。
- **知识蒸馏的"暗知识"是什么?温度起什么作用?** 软标签里非目标类的相对概率(类间相似结构)。温度 $T>1$ 让分布变平、放大这些信息;训练用高 $T$、推理用 $T=1$。
- **蒸馏损失里为什么要乘 $T^2$?** softmax 除以 $T$ 后,软目标项梯度量级约缩小 $T^2$ 倍;乘回 $T^2$ 让它和硬标签项梯度尺度可比,保证两项都有效。
- **LLM 时代怎么蒸馏?** 多用**序列级/黑盒蒸馏**:拿强教师生成的高质量文本当 SFT 语料训小模型(如各种 "distilled" 小模型);也有白盒对齐 logits/中间层。
- **剪枝、量化、蒸馏能叠加吗?** 能,且常组合:先剪/蒸得到小模型,再 [[097 NF4 与 QLoRA 4-bit|量化]]部署,进一步省显存提吞吐。
- **为什么乘 $T^2$ 而不是别的?** softmax 除 $T$ + 对 logits 求导各带一个 $\frac1T$,软项梯度 $\propto\frac1{T^2}$;乘 $T^2$ 补回,使软/硬两项梯度尺度可比、软项不被淹没。高温时尤其关键。
- **LLM 怎么做激活感知剪枝?** Wanda 用 $|w|\cdot\|x\|$(权重幅值 × 激活范数)一次性剪、免重训;SparseGPT 用 GPTQ 式逐层 Hessian 把剪枝当「量化到 0」并补偿误差,一次性剪到 50%+ 几乎不掉点。比纯幅值剪枝强,因为「小权重 × 大激活」也重要。
- **2:4 结构稀疏为什么能真加速?** 每 4 个权重固定保留 2 个,稀疏模式规整、可被 NVIDIA Ampere 稀疏 Tensor Core 直接支持,约 2× 加速;非结构化稀疏位置不规则,稠密 GEMM 核照算全部元素,通用 GPU 不提速。
- **LLM 蒸馏是白盒还是黑盒?** 多为**黑盒/序列级**:拿强教师生成的高质量文本当 SFT 语料训学生(无需教师 logits/权重),如各种 distilled 小模型、用 R1 长 CoT 蒸推理(见 [[089 推理模型与 RL：o1、R1 的长 CoT 与自我反思|R1 蒸馏]]);白盒(对齐 logits/中间层)需教师可访问。

## 关键事实

- 知识蒸馏出自 Hinton, Vinyals, Dean《Distilling the Knowledge in a Neural Network》(2015,arXiv:1503.02531);核心是带温度的软标签 + 软硬损失加权,软项乘 $T^2$。
- "暗知识(dark knowledge)"指软标签中非目标类的相对概率所携带的类间相似信息;论文建议 $T$ 取 1–10。
- 非结构化剪枝稀疏度可很高但通用硬件难加速;**2:4 结构稀疏**(每 4 选 2)对上 NVIDIA Ampere 稀疏 Tensor Core 可约 2× 提速。
- LLM 后训练剪枝代表:SparseGPT(Frantar & Alistarh 2023,arXiv:2301.00774,GPTQ 式逐层 Hessian 补偿)、Wanda(Sun et al. 2023,arXiv:2306.11695,$|w|\cdot\|x\|$ 一次性免重训);蒸馏代表:DistilBERT(2019)、以及大量用强模型输出做 SFT 的"序列级蒸馏"。
- 压缩三件套——**量化(降位宽)、剪枝/稀疏(删参数)、蒸馏(换小模型)**——常组合使用,目标都是更低显存与更高吞吐。
