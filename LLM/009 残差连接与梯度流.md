[[009 残差连接与梯度流]]:每个子层的输出不是 $\text{Sublayer}(x)$,而是 $x+\text{Sublayer}(x)$——这条**恒等跳连**给反向传播修了一条不衰减的"梯度高速路",让几十上百层的 Transformer 也能训得动。

## ① 直觉:让网络"学增量"而不是"学全部"

深网络有个老毛病:层数一多,梯度在反向传播时层层相乘,容易越乘越小([[44 梯度消失、爆炸与梯度裁剪|梯度消失]])直到趋近 0,前面的层几乎收不到学习信号。

残差连接(residual / skip connection)的办法很反直觉:**别让子层直接输出结果,而是输出"在输入基础上的修改量"**。原本要学映射 $H(x)$,改成让子层只学残差 $F(x)=H(x)-x$,最终输出 $x+F(x)$。

- 如果这一层"什么都不用改"最好,子层只要学会输出 0 即可(比学一个恒等映射容易得多)。
- 那条 $+x$ 的跳连像一条**高速路**:信息和梯度都能"原样"直达,绕过子层的衰减。

这就是 [[52 残差连接与深度可训练性|残差连接]]在 ResNet(2015)里让上百层 CNN 可训练的同一招,Transformer 直接借用。

## ② 例子:看那个 "+1" 怎么救梯度

设某子层对输入 $x$ 的雅可比([[17 雅可比与 Hessian|雅可比]])为 $\dfrac{\partial F}{\partial x}=0.1$(很小,典型的衰减情形)。上游传来梯度 $g$。

**无残差**:输出 $y=F(x)$,回传到 $x$ 的梯度 $=g\cdot 0.1$。堆 10 层,梯度 $\approx g\cdot 0.1^{10}=g\cdot10^{-10}$——几乎归零,前层练不动。

**有残差**:输出 $y=x+F(x)$,对 $x$ 求导:

$$
\frac{\partial y}{\partial x}=\underbrace{1}_{\text{跳连}}+\underbrace{\frac{\partial F}{\partial x}}_{\text{子层}}=1+0.1=1.1
$$

回传梯度 $=g\cdot 1.1$。堆 10 层 $\approx g\cdot 1.1^{10}\approx g\cdot 2.6$——非但不消失,还略放大。**关键就在那个 "1"**:即使子层项趋近 0,跳连提供的"1"也保证梯度有一条不被压扁的通路。

## ③ 原理:链式法则下的梯度直通

一个残差块 $y=x+F(x)$。反向传播用 [[16 链式法则|链式法则]],设损失为 $L$,则:

$$
\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\cdot\frac{\partial y}{\partial x}=\frac{\partial L}{\partial y}\Big(1+\frac{\partial F}{\partial x}\Big)=\underbrace{\frac{\partial L}{\partial y}}_{\text{原样直达}}+\underbrace{\frac{\partial L}{\partial y}\frac{\partial F}{\partial x}}_{\text{经子层}}
$$

把它推广到 $L$ 个堆叠的残差块,设第 $\ell$ 层输出 $x_{\ell+1}=x_\ell+F_\ell(x_\ell)$,则从深层 $x_{L}$ 到浅层 $x_\ell$ 的梯度:

$$
\frac{\partial L}{\partial x_\ell}=\frac{\partial L}{\partial x_{L}}\prod_{i=\ell}^{L-1}\Big(1+\frac{\partial F_i}{\partial x_i}\Big)
$$

展开这个连乘,会出现一项 $\dfrac{\partial L}{\partial x_{L}}\cdot 1\cdot 1\cdots 1=\dfrac{\partial L}{\partial x_{L}}$——**纯由跳连构成、完全不衰减**的项始终存在。对比没有残差时梯度是 $\prod \dfrac{\partial F_i}{\partial x_i}$,只要每项 $<1$ 就指数衰减。这就是残差缓解 [[44 梯度消失、爆炸与梯度裁剪|梯度消失]]的数学本质。

**把连乘完全展开看清楚**。$\prod_{i}(1+\frac{\partial F_i}{\partial x_i})$ 展开是一堆项之和:
$$\underbrace{1}_{\text{纯跳连}}+\underbrace{\sum_i\tfrac{\partial F_i}{\partial x_i}}_{\text{只过一个子层}}+\underbrace{\sum_{i<j}\tfrac{\partial F_i}{\partial x_i}\tfrac{\partial F_j}{\partial x_j}}_{\text{过两个}}+\cdots$$
**第一项恒为 1**,与深度无关、永不衰减——这是梯度的"保底通道"。即使所有子层项都很小,这个 1 也保证浅层能收到信号。这也对应 He et al.《Identity Mappings》(2016)的洞见:**残差路要保持"干净恒等"**(中间别插非线性/缩放),那个 1 才纯。Pre-LN 之所以比 Post-LN 稳,正因为它把 LN 移出残差主干,让这条保底通道更干净(见 010)。

**ResNet 的"退化问题"动机(为什么发明残差)**。He et al. 观察到一个反常现象:56 层 CNN 的训练误差**反而比 20 层更高**——不是过拟合(训练误差就更高),而是**深网络更难优化**。理论上深网至少能学成"浅网 + 若干恒等层"不该更差,但 SGD 学不出恒等映射。残差直接把恒等"焊死"在结构里($x+F(x)$,要恒等只需 $F=0$),让"加层不变差"成为默认。Transformer 直接继承这一设计,才敢堆几十上百层。

残差在 Transformer 里总是和 [[010 层归一化：Pre-LN 与 Post-LN|LayerNorm]] 搭配:

- **Post-LN**(原版):$\text{LN}(x+\text{Sublayer}(x))$
- **Pre-LN**(现代主流):$x+\text{Sublayer}(\text{LN}(x))$ —— 残差路是"干净"的恒等,梯度更稳,详见 [[010 层归一化：Pre-LN 与 Post-LN]]。

## ④ 代码:有无残差,看深层梯度差多少

```python
import numpy as np

np.random.seed(0)
def sublayer(x, W):          # 一个会衰减梯度的子层(乘个小权重)
    return np.tanh(x @ W)

L, d = 30, 8                 # 30 层深
Ws = [np.random.randn(d, d)*0.3 for _ in range(L)]
x0 = np.random.randn(1, d)

# ❌ 无残差:逐层覆盖,梯度连乘衰减
x = x0.copy()
for W in Ws:
    x = sublayer(x, W)
# 数值估计第 0 层输入的梯度范数(扰动法)
def fwd(x0, residual):
    x = x0.copy()
    for W in Ws:
        x = (x + sublayer(x, W)) if residual else sublayer(x, W)
    return x.sum()
eps = 1e-5
g_no  = (fwd(x0+eps, False) - fwd(x0-eps, False)) / (2*eps)
g_yes = (fwd(x0+eps, True ) - fwd(x0-eps, True )) / (2*eps)
print(f"无残差梯度≈{g_no:.2e}   有残差梯度≈{g_yes:.2e}")
# 无残差 ~1e-8 量级(几乎消失);有残差 ~1e0 量级(健康)
```

PyTorch 里一个 Pre-LN block:

```python
def block(x, attn, ffn, ln1, ln2):
    x = x + attn(ln1(x))    # ✅ 残差包住注意力
    x = x + ffn(ln2(x))     # ✅ 残差包住 FFN
    return x
# ❌ 别写成 x = attn(ln1(x)):丢掉 +x,深层就练不动
```

## 面试高频

- **Q:残差为什么能缓解梯度消失?** 因为 $\frac{\partial(x+F)}{\partial x}=1+\frac{\partial F}{\partial x}$,那个 "1" 让梯度有一条不衰减的直通路;多层连乘里始终存在一项恒等通路。
- **Q:残差和恒等映射什么关系?** 残差让网络"默认恒等、只学增量",学 $F=0$ 比学 $H=x$ 容易,所以加层不会变差(至少不更差)。
- **Q:残差要求什么维度条件?** $x$ 和 $\text{Sublayer}(x)$ 维度必须相同才能相加,所以 Transformer 全程保持 $d_{model}$ 不变(FFN 升维后又降回 $d$ 正是为此)。
- **Q:Transformer 里残差和 LayerNorm 怎么配合?** Post-LN 把 LN 放在相加之后,Pre-LN 放在子层之前;Pre-LN 让残差通路保持干净恒等,梯度更稳、更易训深,是现代默认。
- **Q:没有残差会怎样?** 几十层的 Transformer 几乎无法收敛,这是它能"做深"的地基。
- **Q:ResNet 当初为什么要发明残差?** 解决"退化问题"——深网络训练误差反而比浅网络高(非过拟合),因为 SGD 学不出恒等映射;残差把恒等焊进结构($F=0$ 即恒等),让加层不变差。
- **Q:为什么残差路要"干净"(别插东西)?** 那个不衰减的 $+1$ 项要纯,残差主干上插非线性/缩放会破坏它;这正是 Pre-LN(LN 在子层内、残差路干净)比 Post-LN 稳的原因(He et al. 2016《Identity Mappings》)。
- **Q:残差会不会让激活方差越加越大?怎么治?** 会——每层 $x+f(x)$ 使方差约线性增长 $O(N)$;治法是残差缩放(乘 $\sim1/\sqrt{N}$,GPT-2 做法)或 Pre-LN(每子层输入先归一吸收膨胀),详见 [[015 Transformer 训练稳定性|训练稳定性]]。
- **Q:残差和 Dropout 怎么配合?** Dropout 只能加在子层产出上(`x + dropout(f(x))`),绝不能丢残差主干,否则切断恒等捷径(见 017)。

## 关键事实

- 残差连接出自《Deep Residual Learning for Image Recognition》(He et al., 2015,ResNet),让 152 层 CNN 可训练。
- Transformer 的每个子层都用残差 + LayerNorm:原文写作 $\text{LayerNorm}(x+\text{Sublayer}(x))$(Vaswani et al., 2017,Post-LN)。
- 梯度直通的本质是 $\frac{\partial}{\partial x}(x+F(x))=1+\frac{\partial F}{\partial x}$,深层连乘中恒存在不衰减的恒等项(参见 He et al.《Identity Mappings in Deep Residual Networks》, 2016 对"干净恒等路"的分析)。
