[[004 缩放点积注意力(为何除以根号 dk)|缩放点积]] —— 在 Softmax 之前把打分 $q\cdot k$ 除以 $\sqrt{d_k}$;因为高维点积的**方差随 $d_k$ 线性增大**,不缩放会让分数量级过大、把 [[27 Softmax 与温度|Softmax]] 推入饱和区(输出近似 one-hot、梯度近 0),除以 $\sqrt{d_k}$ 正好把方差拉回 1,保持训练可学。

## 直觉
Softmax 像一个"对比度旋钮"。输入分数差距越大,它越倾向于把全部概率压到最大那一项上(变成接近 one-hot),此时其余项的梯度几乎为 0——模型"学不动"了。

问题在于:**维度越高,点积自然就越大**。$q\cdot k=\sum_{i=1}^{d_k} q_i k_i$ 是 $d_k$ 个随机项相加,项数越多、和的波动越大,分数动辄飙到几十。这就像把对比度旋钮拧到底,softmax 一上来就饱和。

$\sqrt{d_k}$ 是个"自动调对比度"的归一化常数:不管维度多高,都把分数的波动(标准差)拉回到 1 附近,让 softmax 工作在"既能区分、又有梯度"的甜区。它本质上是把 [[27 Softmax 与温度|温度]] 固定成一个随维度自适应的值。

## 例子
设 $q,k$ 各分量独立、均值 0、方差 1。

**点积的方差**:$q\cdot k=\sum_{i=1}^{d_k} q_i k_i$。每项 $q_ik_i$ 均值 0、方差 1(因 $q_i,k_i$ 独立),$d_k$ 项独立相加:
$$\text{Var}(q\cdot k)=\sum_{i=1}^{d_k}\text{Var}(q_ik_i)=d_k$$
所以标准差是 $\sqrt{d_k}$。取原文 $d_k=64$:标准差 $=8$,分数轻松落在 $\pm16$ 范围。

**看 softmax 怎样饱和**:假设 3 个 token 的打分是 $[16,8,0]$(典型 $d_k=64$ 未缩放量级)。
$$\text{softmax}([16,8,0])\approx[0.9997,\ 0.00034,\ 0.0000001]$$
几乎是 one-hot。对非最大项,$\partial\text{softmax}/\partial s\approx p(1-p)\approx 0$,梯度消失。

**除以 $\sqrt{d_k}=8$ 后**:分数变 $[2,1,0]$。
$$\text{softmax}([2,1,0])\approx[0.665,\ 0.245,\ 0.090]$$
分布平滑、各项都有非平凡梯度,训练正常。方差也回到 $\text{Var}(q\cdot k/\sqrt{d_k})=d_k/d_k=1$。

**多走一个变体:如果除以 $d_k$(而非 $\sqrt{d_k}$)会怎样?** 同样 $[16,8,0]$ 除以 $d_k=64$ 得 $[0.25,0.125,0]$:
$$\text{softmax}([0.25,0.125,0])\approx[0.375,\ 0.331,\ 0.294]$$
分布**几乎均匀**——区分度太低,注意力退化成"对谁都差不多关注",等于没在挑重点。方差也被压成 $d_k/d_k^2=1/64\ll1$。所以 $\sqrt{d_k}$ 是"刚刚好":既不让 softmax 饱和成 one-hot(除太小),也不让它平成均匀(除太大)。

**另一个变体:除以 $\sqrt{d_k}$ 等价于把温度设成 $\sqrt{d_k}$**。回忆带温度的 softmax $\text{softmax}(s/T)$(见 [[27 Softmax 与温度|温度]]):缩放因子就是温度 $T=\sqrt{d_k}$。$T$ 越大分布越平、越软;$T$ 越小越尖、越接近 one-hot。$\sqrt{d_k}$ 是一个随维度自适应、把"软硬度"钉在甜区的温度常数。

## 原理
**为何是 $\sqrt{d_k}$ 而非 $d_k$ 或别的**:我们要归一化的是分数的**尺度(标准差)**,不是方差本身。

设 $q_i,k_i$ i.i.d.,$\mathbb{E}[q_i]=\mathbb{E}[k_i]=0$,$\text{Var}(q_i)=\text{Var}(k_i)=1$。则
$$\mathbb{E}[q\cdot k]=\sum_i\mathbb{E}[q_ik_i]=\sum_i\mathbb{E}[q_i]\mathbb{E}[k_i]=0$$
$$\text{Var}(q\cdot k)=\sum_i\text{Var}(q_ik_i)=\sum_i\big(\mathbb{E}[q_i^2]\mathbb{E}[k_i^2]-0\big)=\sum_i 1\cdot1=d_k$$
(用到独立性:$\mathbb{E}[q_i^2 k_i^2]=\mathbb{E}[q_i^2]\mathbb{E}[k_i^2]$,且 $\mathbb{E}[q_ik_i]=0$。)

于是缩放后:
$$\text{Var}\!\left(\frac{q\cdot k}{\sqrt{d_k}}\right)=\frac{\text{Var}(q\cdot k)}{(\sqrt{d_k})^2}=\frac{d_k}{d_k}=1$$

方差被精确拉回 1,与 $d_k$ 无关。这就是论文那句"For large values of $d_k$, the dot products grow large in magnitude, pushing the softmax into regions where it has extremely small gradients"的数学根据。

**与梯度的联系**:softmax 在 logits 大时进入饱和区,雅可比 $\text{diag}(p)-pp^\top$ 的元素 $\to 0$,反传梯度被掐断。把 logits 尺度稳定在 $O(1)$,避免一开始就饱和,深层网络才训得起来(配合 [[52 残差连接与深度可训练性|残差]] 与 [[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|归一化]])。

完整公式:
$$\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

注意缩放用的是 $d_k$(Q、K 的维度),不是 $d_v$;多头时 $d_k=d/h$,所以多头里缩放因子是 $\sqrt{d/h}$(见 005)。

**为什么 softmax 饱和=梯度消失(逐步推)**。softmax 输出 $p=\text{softmax}(s)$,其雅可比 $J=\text{diag}(p)-pp^\top$,元素 $\partial p_i/\partial s_j=p_i(\delta_{ij}-p_j)$。当某个 $p_k\to1$(其余 $\to0$)时,对角项 $p_k(1-p_k)\to0$、非对角项 $-p_ip_j\to0$——**整个雅可比趋零**。反向传播经过这个雅可比的梯度被掐断,前面的 Q、K 投影几乎收不到信号。缩放把 logits 尺度稳在 $O(1)$,让 $p$ 不至于一上来就 one-hot,雅可比保持非零,梯度能流。

**点积 vs 加性注意力**。早期有两派:
- **加性(Bahdanau)注意力**:$s_{ij}=v^\top\tanh(W_q q_i+W_k k_j)$,用一个小 MLP 算分。$d_k$ 大时它对尺度不敏感,**不需要缩放**。
- **点积注意力**:$s_{ij}=q_i\cdot k_j$,可直接用高度优化的矩阵乘,**快得多**,但 $d_k$ 大时分数量级失控。
缩放 $1/\sqrt{d_k}$ 正是点积派为了"既要速度又要稳定"打的补丁——补上后点积派精度追平加性派,而速度优势保留,从此成为标准。这是"为何是缩放**点积**注意力"这个名字的来历。

**前提假设别忘**:方差推导假设 Q、K 各分量均值 0、方差 1、互相独立。训练初期靠合适初始化(见 [[41 权重初始化(Xavier、He、正交)|初始化]])满足;训练中靠 [[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|LayerNorm]] 维持。若这些统计被破坏(如 logits 漂移),现代实践会额外加 **QK-Norm**(对 Q、K 做归一)来强制约束,防注意力 logits 爆(见 [[015 Transformer 训练稳定性|训练稳定性]])。

## 代码
```python
import numpy as np

def softmax(x):
    x = x - x.max(-1, keepdims=True)
    e = np.exp(x); return e / e.sum(-1, keepdims=True)

dk = 64
q = np.random.randn(dk); k = np.random.randn(dk)
# 经验方差 ≈ dk
print(np.var([np.random.randn(dk) @ np.random.randn(dk) for _ in range(10000)]))  # ≈ 64

# ❌ 朴素:不缩放 → softmax 饱和,梯度趋零
def attn_no_scale(Q, K, V):
    return softmax(Q @ K.T) @ V

# ✅ 正确:除以 √dk → 方差归一
def attn_scaled(Q, K, V):
    return softmax(Q @ K.T / np.sqrt(K.shape[-1])) @ V

L = 3
Q = np.random.randn(L, dk); K = np.random.randn(L, dk)
print("无缩放 logits 量级:", (Q @ K.T).std())            # ≈ 8
print("缩放后 logits 量级:", (Q @ K.T / np.sqrt(dk)).std()) # ≈ 1
# 无缩放时 softmax 接近 one-hot,熵极低:
A_no = softmax(Q @ K.T); A_ok = softmax(Q @ K.T / np.sqrt(dk))
print("无缩放熵:", -(A_no*np.log(A_no+1e-9)).sum(1).mean())
print("缩放后熵:", -(A_ok*np.log(A_ok+1e-9)).sum(1).mean())  # 明显更大(更平滑)
```

## 面试高频
- **Q:为什么除以 $\sqrt{d_k}$ 而不是 $d_k$?** A:目标是把分数的**标准差**归一化。点积方差是 $d_k$、标准差是 $\sqrt{d_k}$;除以 $\sqrt{d_k}$ 使方差变 1。除以 $d_k$ 会过度压缩(方差变 $1/d_k$),分数太平、softmax 几乎均匀,也不好。
- **Q:不缩放会怎样?** A:$d_k$ 大时点积量级大,softmax 饱和成近 one-hot,非最大项梯度≈0,训练几乎停滞。
- **Q:缩放因子用 $d_k$ 还是 $d_v$?** A:用 $d_k$(参与点积的维度);$d_v$ 不影响打分尺度。
- **Q:除以 $d_k$(而非根号)会怎样?** A:方差被压成 $1/d_k$,分数太平,softmax 近似均匀,注意力失去区分度,等于不挑重点。$\sqrt{d_k}$ 是既不饱和也不均匀的甜区。
- **Q:缩放和温度是什么关系?** A:除以 $\sqrt{d_k}$ 就是把 softmax 温度设为 $T=\sqrt{d_k}$;温度大→分布软,小→分布尖。它是个随维度自适应的固定温度。
- **Q:为什么加性注意力不需要缩放,点积注意力需要?** A:加性注意力用 MLP 算分,对 $d_k$ 不敏感;点积注意力的分数是 $d_k$ 项相加,方差随 $d_k$ 线性涨,必须缩放。缩放是点积派为追平加性派精度、同时保住矩阵乘速度而打的补丁。
- **Q:softmax 饱和为什么导致梯度消失?** A:softmax 雅可比 $\text{diag}(p)-pp^\top$,当 $p$ 接近 one-hot 时所有元素趋零,反传梯度被掐断,Q/K 投影学不动。
- **Q:LayerNorm 和这个缩放有什么联系?** A:缩放推导假设 Q、K 分量均值 0、方差 1;LayerNorm 帮忙维持这个统计,二者配合才让缩放真正有效。
- **陷阱**:这里的 $d_k$ 在多头里是**每头**维度 $d/h$,不是 $d_{model}$;别用整层维度去缩放。另外推导前提是 Q、K 分量近似均值 0 方差 1——这正是 [[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|LayerNorm]] 帮忙维持的统计。别把"除以 $\sqrt{d_k}$"误记成"除以 $\sqrt{d_{model}}$"或"除以 $d_k$"。

## 关键事实
- 缩放因子 $1/\sqrt{d_k}$ 出自 Vaswani et al. 2017(arXiv:1706.03762)第 3.2.1 节,原文 $d_k=64$。
- 论文原话:dot products "grow large in magnitude" for large $d_k$,"pushing the softmax function into regions where it has extremely small gradients",故乘 $1/\sqrt{d_k}$。
- 方差推导假设 Q、K 各分量独立、均值 0、方差 1,则 $\text{Var}(q\cdot k)=d_k$;缩放后为 1。
- 这是"加性注意力"(Bahdanau)与"点积注意力"之争中,点积派为追上加性派精度而引入的关键修正——点积更快(可用高度优化的矩阵乘),缩放后精度也不输。
