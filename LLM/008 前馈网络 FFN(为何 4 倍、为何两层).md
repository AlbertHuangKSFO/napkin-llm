[[008 前馈网络 FFN(为何 4 倍、为何两层)]]:Transformer 每个 block 里跟在注意力之后的**逐位置两层 MLP**——先用 $W_1$ 把维度从 $d$ 升到 $4d$、过非线性激活,再用 $W_2$ 降回 $d$;它逐 token 独立处理,占了模型约 2/3 的参数,是"知识"的主存储。

## ① 直觉:注意力负责"混信息",FFN 负责"加工信息"

一个 Transformer block 有两个子层:[[005 多头注意力 Multi-Head|多头注意力]]让每个词去**看别的词**、把上下文混进来;但混完之后,每个词还需要一步**只对自己**的非线性变换,去做更复杂的特征加工——这就是 FFN(Feed-Forward Network,又叫 position-wise FFN)。

"逐位置(position-wise)"是关键:FFN 对序列里每个 token **各自独立**地过同一套权重,token 之间在这一层**不交互**(交互全交给注意力)。所以它本质就是一个对每个位置广播的两层 MLP(见 [[34 MLP 与万能逼近|MLP]])。

为什么要"升维再降维"?把信息投到更宽的 $4d$ 空间,等于给非线性变换腾出更多"工作维度",能拟合更复杂的函数;算完再压回 $d$,好让残差和下一层维度对齐。

## ② 例子:小数字走一遍

设 $d=4$(实际是 512/768/4096…),扩张倍数 4,则隐藏维 $4d=16$。某个 token 向量 $x=[1,0,-1,2]$。

- 升维:$h=W_1 x+b_1$,$W_1$ 是 $16\times 4$ 矩阵,得到 16 维向量,比如某一维 $h_5 = 0.3\cdot1 + (-0.5)\cdot0 + 0.2\cdot(-1) + 0.4\cdot2 = 0.9$。
- 激活:[[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]],以 ReLU 为例 $\text{ReLU}(0.9)=0.9$;若某维是 $-0.7$ 则被置 0(GELU 会保留一点负值)。
- 降维:$y=W_2\,\text{act}(h)+b_2$,$W_2$ 是 $4\times 16$,把 16 维压回 4 维。

参数量直觉:两层权重共 $4d\cdot d + d\cdot 4d = 8d^2$。当 $d=512$ 时约 $2.1\text{M}$/层;而注意力的 4 个投影矩阵共约 $4d^2\approx 1.05\text{M}$。所以**单个 block 里 FFN 比注意力参数还多一倍**,整模型里 FFN 约占 $2/3$ 参数。

**用真实模型核一下"2/3"**:每层 FFN 参 $8d^2$,注意力(QKVO)参 $4d^2$,比值 $8:4=2:1$,所以 FFN 占 $\frac{8}{8+4}=\frac{2}{3}$、注意力占 $\frac13$。这个"2/3"对任何用 $4\times$ FFN 的标准 Transformer 都成立,与 $d$ 无关。计算量(FLOPs)同样约 2/3 在 FFN。

## ③ 原理:公式与"为什么必须有非线性"

标准 FFN(原版,ReLU):

$$
\text{FFN}(x)=W_2\,\max(0,\;W_1 x+b_1)+b_2,\qquad W_1\in\mathbb{R}^{4d\times d},\;W_2\in\mathbb{R}^{d\times 4d}
$$

**为什么必须有激活?** 若去掉 $\max(0,\cdot)$,则 $\text{FFN}(x)=W_2 W_1 x + (\dots)$,而 $W_2 W_1$ 是一个 $d\times d$ 矩阵,两层线性会**塌缩成一层线性**,模型表达力没有任何提升——等于白加。非线性激活打破这种塌缩,才让"升维加工"有意义,也是 [[34 MLP 与万能逼近|万能逼近]]成立的前提。

**为什么是 4 倍?** 这是经验最优,《Attention Is All You Need》取 $d_{model}=512,\,d_{ff}=2048$,即 $4\times$。更宽更强但更贵;太窄则加工能力不足。后续大量模型沿用 4×。

**激活函数的演进**:ReLU(2017 原版)→ GELU(BERT/GPT-2,更平滑、负区不硬截断)→ SwiGLU(PaLM/LLaMA)。SwiGLU 是门控变体:

$$
\text{SwiGLU}(x)=\big(\text{Swish}(W_1 x)\odot (V x)\big)\,W_2
$$

它用了**三个**权重矩阵($W_1,V,W_2$)。为了让总参数量和普通 FFN 持平,SwiGLU 把隐藏维从 $4d$ 降到约 $\tfrac{8}{3}d\approx 2.67d$(PaLM 设为标准 FFN 的 2/3)。

**SwiGLU 的参数量为什么要缩到 8/3·d(逐步算)**。普通 FFN 两个矩阵,参数 $2\cdot d\cdot(4d)=8d^2$。SwiGLU 三个矩阵($W_1,V$ 各 $d\times d_{ff}$,$W_2$ 是 $d_{ff}\times d$),参数 $3\cdot d\cdot d_{ff}$。要让 $3d\cdot d_{ff}=8d^2$,解出 $d_{ff}=\frac{8}{3}d\approx2.67d$。这就是 LLaMA 把隐藏维设成 $\frac{2}{3}\cdot4d=\frac{8}{3}d$ 的来历——**多一个门控矩阵,就把每个矩阵缩窄,保持总参数和算力不变**。(已 WebSearch 核实:GLU 变体有三个权重矩阵 $W,V,W_2$,LLaMA 用 $d_{ff}=\frac23\cdot4d$ 对齐参数。)

**门控(gating)到底在干嘛**。GLU = Gated Linear Unit:$\text{GLU}(x)=(W_1x)\odot\sigma(Vx)$,一条路当"内容"、另一条路过激活当"开关",逐元素相乘。SwiGLU 把开关激活换成 Swish/SiLU:$\text{SwiGLU}(x)=\big(\text{Swish}(W_1x)\odot(Vx)\big)W_2$。直觉:门控让每个隐藏单元有一个"是否放行"的可学习闸门,比"一刀切的 ReLU"更柔、更有表达力。Shazeer(2020)实验里 GEGLU/SwiGLU 困惑度最优。

**激活函数演进对比(为什么从 ReLU 一路换到 SwiGLU)**:

| 激活 | 公式 | 特点 | 用在 |
|---|---|---|---|
| ReLU | $\max(0,x)$ | 负区硬截断为 0,简单快;但"死神经元"(负区梯度 0,单元可能永久失活) | 原版 Transformer 2017 |
| GELU | $x\cdot\Phi(x)$($\Phi$=标准正态 CDF) | 平滑、负区保留一点信号,可导处处非零 | BERT、GPT-2/3 |
| Swish/SiLU | $x\cdot\sigma(x)$ | 类似 GELU,平滑非单调 | EfficientNet、SwiGLU 的门 |
| SwiGLU | $(\text{Swish}(W_1x)\odot Vx)W_2$ | 门控,表达力强,需缩窄隐藏维对齐参数 | PaLM、LLaMA、Qwen |

趋势:从"硬截断"走向"平滑 + 门控"。详见 [[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]]。

**FFN 为什么是"知识"的主存储(key-value memory 视角)**。Geva et al.(2021)指出:FFN 可看成一个 **key-value 记忆**——第一层 $W_1$ 的每一行是一个"key"(检测某种输入模式),激活后第二层 $W_2$ 的对应列是"value"(该模式触发时要写入的内容)。某个 token 命中某些 key,就把对应 value 加进它的表示。这解释了为什么很多可解释性工作能把"事实记忆"(如"巴黎是法国首都")定位到具体某些 FFN 神经元,以及为什么 FFN 占 2/3 参数却是模型"记住事实"的地方。注意力负责"路由/搬运",FFN 负责"存储/加工"。

**为什么是"两层"而不是一层或三层**。一层线性无非线性、无加工能力;两层(升维→激活→降维)是能引入非线性又保持输入输出同维($d\to d$,满足残差对齐)的最小结构;三层及以上会增加深度内的深度、训练更难且收益不明显——把"深"留给堆 block 更划算。所以 FFN 固定两层,靠堆 $N$ 个 block 做深。

## ④ 代码:numpy / PyTorch 两版 FFN

```python
import numpy as np

def gelu(x):  # tanh 近似版
    return 0.5*x*(1+np.tanh(np.sqrt(2/np.pi)*(x+0.044715*x**3)))

d, dff = 4, 16
W1 = np.random.randn(dff, d)*0.1; b1 = np.zeros(dff)
W2 = np.random.randn(d, dff)*0.1; b2 = np.zeros(d)
x = np.random.randn(3, d)        # 3 个 token,各自独立

# ❌ 错:两层都线性,没激活 → 等价于单层线性,白扩维
h = x @ W1.T + b1
y_bad = h @ W2.T + b2            # = x @ (W2@W1).T + ...,塌成一层

# ✅ 对:中间插非线性,逐位置独立
h = gelu(x @ W1.T + b1)         # 升维 d→4d 再激活
y_good = h @ W2.T + b2          # 降维 4d→d
print(y_good.shape)             # (3, 4):每个 token 各过同一套 W,互不影响
```

PyTorch:

```python
import torch.nn as nn
class FFN(nn.Module):
    def __init__(self, d, mult=4):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d, mult*d),   # 升维
            nn.GELU(),              # 非线性(原版是 ReLU)
            nn.Linear(mult*d, d),   # 降维
        )
    def forward(self, x):           # x: (batch, seq, d)
        return self.net(x)          # 对最后一维作用 → 天然 position-wise
```

## 面试高频

- **Q:FFN 为什么叫 "position-wise"?** 因为它对序列每个位置**独立**应用同一组权重,token 之间不交互;交互全由注意力负责。实现上就是 `nn.Linear` 作用在最后一维。
- **Q:为什么扩张到 4 倍?** 经验值,给非线性加工腾"工作维度",表达力与成本的折中;原论文 512→2048。
- **Q:为什么 FFN 必须有非线性激活?** 否则两层线性塌成一层,白白增加参数却不增加表达力。
- **Q:FFN 占多少参数?** 约 2/3,是 Transformer 主要的参数与"知识"存储位置(很多可解释性工作把事实记忆定位到 FFN)。
- **Q:SwiGLU 为什么把隐藏维改成 ~2.7d 而不是 4d?** 它多了一个门控矩阵 $V$,缩窄隐藏维是为了让总参数量与普通 FFN 对齐(PaLM 用 8/3·d)。
- **Q:ReLU、GELU、SwiGLU 各用在哪?** ReLU=原版/早期;GELU=BERT、GPT-2/3;SwiGLU=PaLM、LLaMA 等现代 LLM。详见 [[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]]。
- **Q:SwiGLU 为什么有三个矩阵?门控是什么?** 门控 GLU 把输入分两路:一路当内容、一路过激活当"开关",逐元素相乘,故多一个矩阵 $V$。Swish 当门激活;门控比 ReLU 一刀切更柔、表达力更强(Shazeer 2020 困惑度最优)。
- **Q:为什么说 FFN 是模型的"知识库"?** Geva et al.(2021)把 FFN 解读为 key-value 记忆:$W_1$ 行=检测模式的 key,$W_2$ 列=触发时写入的 value;事实知识常能定位到具体 FFN 神经元。注意力搬运、FFN 存储。
- **Q:为什么 FFN 是两层不是三层?** 两层是"能引入非线性 + 输入输出同维(残差对齐)"的最小结构;要更深就堆 block,不在 FFN 内加层。
- **Q:GELU 和 ReLU 区别,为什么 BERT 换 GELU?** GELU 平滑、负区保留少量信号、处处可导,避免 ReLU 的"死神经元",经验上略好。

## 关键事实

- position-wise FFN、$d_{ff}=4\,d_{model}$、ReLU 激活均出自《Attention Is All You Need》(Vaswani et al., 2017,$d_{model}=512,\,d_{ff}=2048$)。
- GELU 出自《Gaussian Error Linear Units》(Hendrycks & Gimpel, 2016),被 BERT(2018)、GPT-2(2019)采用。
- SwiGLU 出自《GLU Variants Improve Transformer》(Shazeer, 2020);PaLM(2022)与 LLaMA(2023)采用,并将隐藏维设为标准 FFN 的 2/3(≈ 8/3·d)以对齐参数量。
- FFN 约占 Transformer 总参数的 2/3,是大量"事实知识"的存储位置(见 transformer-circuits 等可解释性研究)。
