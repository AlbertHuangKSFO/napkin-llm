[[006 注意力的矩阵形式与张量形状|注意力矩阵形式]] —— 把 002–005 的逐 token 描述统一成一行矩阵运算 $\text{softmax}(QK^\top/\sqrt{d_k})\,V$,并逐步标注每个张量的形状 $(B,L,d)$;理解这套形状是读懂任何 Transformer 实现、估算显存与算力(见 014)的基础。

## 直觉
前面讲自注意力时是"站在某一个 token 的视角"逐个算。但 GPU 不喜欢"逐个",喜欢"一锅端"。矩阵形式就是把"L 个 token 各自的 query/key/value"**叠成矩阵**,用两次矩阵乘一次性算完所有 token、所有 batch:

- 第一次矩阵乘 $QK^\top$:一口气算出**所有 token 对所有 token**的打分(一张 $L\times L$ 的"互相关注表")。
- 第二次矩阵乘 $A V$:一口气把每个 token 该取的 value **加权求和**出来。

只要把形状对齐,framework 自动并行。所以"看懂形状"几乎等价于"看懂注意力怎么跑在硬件上"。

## 例子
$L=3$ token,$d_k=d_v=2$(单头)。把 002 里逐 token 的算法写成矩阵:

设
$$Q=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad K=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad V=\begin{bmatrix}10&0\\0&10\\5&5\end{bmatrix}$$

**① $QK^\top$**($3\times2$ 乘 $2\times3$ = $3\times3$ 打分矩阵):
$$QK^\top=\begin{bmatrix}1&0&1\\0&1&1\\1&1&2\end{bmatrix}$$
(例如第 3 行第 3 列 $=q_3\cdot k_3=[1,1]\cdot[1,1]=2$。)

**② 缩放 $\div\sqrt{2}\approx1.414$**:
$$\frac{QK^\top}{\sqrt2}=\begin{bmatrix}0.71&0&0.71\\0&0.71&0.71\\0.71&0.71&1.41\end{bmatrix}$$

**③ 行 softmax**(看第 3 行 $[0.71,0.71,1.41]$,$e^{0.71}=2.03,e^{1.41}=4.10$,和 $=8.16$):
$$A_{3,:}=[0.249,\ 0.249,\ 0.502]$$

**④ $AV$**:第 3 个 token 输出
$$z_3=0.249[10,0]+0.249[0,10]+0.502[5,5]=[2.49+2.51,\ 2.49+2.51]=[5.0,\ 5.0]$$

每行 $A$ 和为 1,$Z=AV\in\mathbb{R}^{3\times2}$。这就是 002 手算的矩阵版——一次算完三行。

## 原理
**单头、无 batch**($X\in\mathbb{R}^{L\times d}$):

| 步骤 | 运算 | 形状 |
|---|---|---|
| 投影 | $Q=XW^Q,\ K=XW^K,\ V=XW^V$ | $Q,K:(L,d_k)$, $V:(L,d_v)$ |
| 打分 | $S=QK^\top$ | $(L,L)$ |
| 缩放 | $S/\sqrt{d_k}$ | $(L,L)$ |
| (掩码) | $+M$,屏蔽位 $-\infty$(见 007) | $(L,L)$ |
| 归一 | $A=\text{softmax}(\cdot)$ 按行 | $(L,L)$,每行和 1 |
| 取值 | $Z=AV$ | $(L,d_v)$ |

$$\boxed{\ Z=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V\ }$$

**加上 batch 与多头**(实现里真正的形状):

| 张量 | 形状 | 说明 |
|---|---|---|
| 输入 $X$ | $(B,L,d)$ | B=batch, L=序列长, d=模型维 |
| $Q,K,V$ reshape 后 | $(B,H,L,d/H)$ | 头维提到第 2 维并行(见 005) |
| 打分 $QK^\top$ | $(B,H,L,L)$ | 缩放 $\sqrt{d/H}$ |
| 权重 $A$ | $(B,H,L,L)$ | 行 softmax |
| $AV$ | $(B,H,L,d/H)$ | 加权求和 |
| concat 回 | $(B,L,d)$ | transpose+reshape |
| $\times W^O$ | $(B,L,d)$ | 输出投影 |

**形状里读出的事实**:
- 打分/权重矩阵是 $(B,H,L,L)$,显存与算力都随 $L^2$ 增长——这就是 [[014 注意力复杂度 O(n²) 与瓶颈|O(n²) 瓶颈]] 的来源。
- 输入输出同形 $(B,L,d)$,所以注意力子层能直接套 [[52 残差连接与深度可训练性|残差]]($x+\text{Attn}(x)$)并堆叠 N 层(见 013)。
- 广播规则(见 [[13 张量、广播与维度对齐|张量广播]]):掩码 $M$ 常是 $(1,1,L,L)$ 或 $(B,1,L,L)$,靠广播加到 $(B,H,L,L)$ 上。

矩阵形式的两次大矩阵乘($QK^\top$ 与 $AV$)是注意力的主算力;它们能跑满 GPU,正是 Transformer 相对 [[54 RNN 原理与 BPTT|RNN]] 可并行的根本(见 001)。

**逐运算 FLOPs 账(便于估算成本)**。设单头、序列 $L$、维度 $d$(略去 batch):

| 运算 | 输出形状 | FLOPs(乘加) |
|---|---|---|
| 投影 $XW^Q$(及 K、V、O 共 4 个) | $(L,d)$ | $4\cdot L d^2$ |
| $QK^\top$ | $(L,L)$ | $L^2 d$ |
| softmax | $(L,L)$ | $\sim L^2$(指数+归一) |
| $AV$ | $(L,d)$ | $L^2 d$ |

总计 $\approx 4Ld^2 + 2L^2 d$。**两项的较量**:投影项 $4Ld^2$ 对 $L$ 线性、对 $d$ 平方;注意力项 $2L^2d$ 对 $L$ 平方。当 $L\ll d$,投影是大头;当 $L\gg d$,$L^2$ 项主导(见 014)。这解释了为什么短序列时注意力其实不贵、长序列才暴雷。

**einsum 写法(读实现常见)**。打分和取值用爱因斯坦求和记号最清楚:
- 打分:`scores = einsum('bhqd,bhkd->bhqk', Q, K)` —— q、k 是两个序列位置维,d 被求和(点积)。
- 取值:`out = einsum('bhqk,bhkd->bhqd', A, V)` —— k 被求和(加权)。
读懂这两行就读懂了注意力的所有形状变换。

**广播规则细节(常踩的坑)**。掩码 $M$ 通常不是 $(B,H,L,L)$ 全量存,而是靠[[13 张量、广播与维度对齐|广播]]:
- 因果掩码:$(1,1,L,L)$,对所有 batch、所有头相同 → 广播到 $(B,H,L,L)$。
- padding 掩码:$(B,1,1,L)$,每个样本一行、对所有头和所有 query 位置相同 → 广播。
两者相加(逻辑取交集)再广播加到 scores 上,省显存。广播维度对不齐是新手最常见的 shape bug。

## 代码
```python
import torch, torch.nn.functional as F

def attention(Q, K, V, mask=None):
    # Q,K,V: (B, H, L, dh)
    dh = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / dh**0.5     # (B,H,L,L)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))  # 掩码在 softmax 前
    A = F.softmax(scores, dim=-1)                  # 按最后一维(key 维)
    return A @ V, A                                # (B,H,L,dh), (B,H,L,L)

B, H, L, dh = 2, 4, 5, 16
Q = K = V = torch.randn(B, H, L, dh)
out, A = attention(Q, K, V)
print(out.shape, A.shape)                # (2,4,5,16) (2,4,5,5)
print(A.sum(-1)[0,0])                    # 全 1:每行是概率分布

# ❌ 朴素错误:对 dim=-2 做 softmax(在 query 维归一)→ 含义反了,每"列"和为1
# ❌ 朴素错误:把 mask 乘到 A 之后再 renormalize → 数值不等价,且梯度路径不对
# ✅ 正确:mask 在 softmax 前置 -inf;softmax 在 key 维(dim=-1)
```

PyTorch 内置的 `F.scaled_dot_product_attention(Q,K,V,attn_mask=...)` 就是这套逻辑的融合高效实现(底层走 FlashAttention,降 $L^2$ 显存)。

```python
# 形状对照速查:从 token id 到注意力输出,每一步形状怎么变
# ids        (B, L)             token id
# x = emb    (B, L, d)          嵌入
# Q,K,V      (B, L, d)          三个投影
# reshape    (B, H, L, d/H)     拆头:把 d 切成 H 段并把 H 提前
# QK^T       (B, H, L, L)       打分(L×L 方阵,显存大头)
# softmax    (B, H, L, L)       行归一,每行和 1
# A@V        (B, H, L, d/H)     加权求和
# merge      (B, L, d)          合头(transpose+reshape)
# @ W_O      (B, L, d)          输出投影,形状回到 (B,L,d)
```

注意整条链上**唯一随 $L$ 平方膨胀的是 $(B,H,L,L)$ 那两步**(打分和权重);其余都是 $(B,L,d)$ 或 $(B,H,L,d/H)$,对 $L$ 线性。一眼盯住 $L\times L$ 就抓住了显存瓶颈。

## 面试高频
- **Q:写出注意力的矩阵公式并标形状。** A:$Z=\text{softmax}(QK^\top/\sqrt{d_k})V$;$Q,K:(L,d_k)$,$V:(L,d_v)$,打分 $(L,L)$,输出 $(L,d_v)$;带 batch/多头是 $(B,H,L,d/H)$,打分 $(B,H,L,L)$。
- **Q:softmax 沿哪个维度?为什么?** A:沿 key 维(实现里是最后一维 $L$),使每个 query 对所有 key 的注意力和为 1。
- **Q:从形状看,注意力的瓶颈在哪?** A:打分矩阵 $(B,H,L,L)$ 随 $L^2$ 增长,长序列时显存与算力都爆,这是 $O(n^2)$ 瓶颈(见 014),催生 FlashAttention、线性注意力等。
- **Q:注意力的 FLOPs 怎么估?投影和注意力哪个大?** A:投影 $4Ld^2$(对 $L$ 线性),注意力 $2L^2d$(对 $L$ 平方);$L\ll d$ 投影大、$L\gg d$ 注意力大。
- **Q:掩码张量为什么常是 $(1,1,L,L)$ 或 $(B,1,1,L)$ 而不是全量?** A:靠广播省显存——因果掩码对所有 batch/头相同,padding 掩码对所有头/query 位置相同,广播到 $(B,H,L,L)$ 即可。
- **Q:交叉注意力的打分矩阵是什么形状?** A:$(B,H,n,m)$,目标长 $n$ × 源长 $m$,长方形而非方阵(见 012);自注意力才是方阵 $(B,H,L,L)$。
- **陷阱**:掩码必须加在 softmax **之前**(置 $-\infty$),不能 softmax 之后再乘 0;别把 softmax 维度搞反(沿 key 维 dim=-1);多头缩放用 $d/H$ 不是 $d$;reshape 拆头后必须 transpose 把 $H$ 提到第 2 维,否则头和序列维搅混。

## 关键事实
- 矩阵形式 $\text{softmax}(QK^\top/\sqrt{d_k})V$ 出自 Vaswani et al. 2017(arXiv:1706.03762),论文强调点积形式可用"highly optimized matrix multiplication code"实现,这是其相对加性注意力的速度优势。
- 标准张量布局 $(B,H,L,d/H)$、打分 $(B,H,L,L)$ 是 PyTorch / HuggingFace 等实现的通用约定。
- $L^2$ 的打分矩阵是显存与算力主因;FlashAttention(Dao et al. 2022, arXiv:2205.14135)通过分块、不显式落地完整 $(L,L)$ 矩阵,把显存降到线性,同时数值等价。
