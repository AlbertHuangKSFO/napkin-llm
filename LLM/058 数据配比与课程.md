[[058 数据配比与课程|数据配比与课程]] 讲的是干净语料备齐后,**各领域(网页、代码、书、数学、学术)各喂多少(配比 / 混合权重),以及按什么顺序喂(课程 / 分阶段)**。配比影响远大于顺序,本质是在固定算力预算下,对各项能力做的取舍分配。

## 直觉

清洗去重后(见 [[057 数据：清洗、去重与质量过滤|数据清洗]]),你手里有一堆来自不同领域的语料。现在两个问题:

1. **配比(各占多少)**:不是按「有多少给多少」,而是按「**对下游多有用**」调。网页量最大但质量参差;代码、数学占比小却对推理/编码能力极重要,常被**上采样**(重复多看几遍)。配比就是混合权重。
2. **课程(什么顺序)**:像上学先易后难。常见做法是**末段退火(anneal)**——训练后期把高质量/教科书数据上采样,配合低学习率「精修」;以及**分阶段扩上下文长度**(先短窗省算力,后期再扩长)。

直觉上配比像「配营养餐」:主食(网页)管饱,但要补蛋白质(代码)、维生素(数学/学术),比例失衡模型某项能力就弱。顺序则像「复习安排」,影响有限但非零。

一句话:**配比 = 给各能力分配数据预算;课程 = 安排喂的顺序与阶段;配比比顺序更要紧。**

## 例子

**配比的取舍。** 某模型预算 1T token,粗配比:
```
网页 50%  |  代码 22%  |  书 15%  |  学术/数学 13%
```
注意代码只占语料总量的一小部分,却被特意拉到 22%——因为代码对逻辑/结构化推理帮助大。若把代码砍到 5%,模型编程能力明显下降,但通用闲聊几乎不变:**配比是在「编码能力」和「其他」之间分蛋糕**。

**DoReMi:用小模型自动找配比。** 人工调配比靠经验、很贵。DoReMi 的做法:先用一个 **280M 的代理模型**跑 Group-DRO(分布鲁棒优化),自动产出各领域权重;再用这套权重重采样数据去训 **8B 大模型**(大 30 倍)。结果在 The Pile 上**下游平均准确率 +6.5%,达到基线只需 1/2.6 的训练步**。有趣的是它**上调通用网页(Pile-CC 0.11→0.61)、下调专精领域**(ArXiv、PubMed),说明「多看专精数据」未必最优。

![[train-数据配比与课程.png]]

**课程 / 退火。** 现代配方常分阶段:
```
主预训练(海量通用网页) → 退火 anneal(末段高质数据 + 低 LR) → 长上下文(扩窗续训)
```
退火阶段把教科书、精选指令样本上采样,用最后的低学习率「定型」,实测能稳定提分;长上下文阶段才把窗口从 4k 扩到 32k/128k,前期短窗省了大量算力。

## 原理

**1. 配比的形式化。** 设领域 $i$ 的混合权重 $w_i$($\sum_i w_i=1$),训练时按 $w_i$ 的概率从领域 $i$ 采样 batch。总损失是各领域损失的加权:

$$\mathcal{L}=\sum_i w_i\,\mathcal{L}_i$$

调高 $w_i$ → 领域 $i$ 困惑度下降,但通常**牺牲其他领域**(此消彼长)。配比就是在这个权衡面上选点。

**2. DoReMi(Group-DRO 找权重)。** 不针对单一领域优化,而是**最小化最差领域的超额损失**:

$$\min_{\theta}\ \max_{w\in\Delta}\ \sum_i w_i\big(\mathcal{L}_i(\theta)-\mathcal{L}_i^{\text{ref}}\big)$$

$\mathcal{L}_i^{\text{ref}}$ 是参考模型在领域 $i$ 的损失。对抗地给「相对最难/收益最大」的领域加权,得到鲁棒的混合权重。用小代理模型求权重只花约 8% 的大模型算力,却让大模型训练更快更好。

**3. 课程学习与退火。** 把训练看成在 loss 面上走,**数据顺序影响走的轨迹**。退火:末段降学习率(见 [[40 学习率调度与 warmup、cosine|学习率调度]])时若同时切到高质量数据,相当于在最敏感的收尾阶段「精修」到更好的盆地。分阶段扩上下文:短窗预训练用 $O(L^2)$ 的小 $L$ 省算力,后期再用长窗 + [[032 RoPE 外推：NTK-aware、位置插值、YaRN|RoPE 外推]] 扩展位置。

**4. 重复 epoch 的天花板。** 高质数据有限,不得不重复多轮(epoch)。但重复收益递减:约 **4 个 epoch 后**重复数据近似于「无效新增」,再多甚至退化(记忆/过拟合)。所以上采样某领域有上限,不能无脑重复。这也约束了 [[079 Scaling Law 与 Chinchilla 最优|Chinchilla 最优]]——数据不够时,加参数不如加(去重后的)新数据。

**5. 配比 vs 顺序的相对重要性。** 经验上**配比(看了什么、各多少)影响远大于顺序(先看什么)**:打乱顺序对最终效果影响有限,但改配比会显著改变各能力分布。所以工程精力主要花在配比与退火上,纯顺序课程收益较小。

**6. 多语言的温度采样(temperature sampling)。** 语料里高资源语言(英语)token 量是低资源语言的成百上千倍。若按自然占比采样,小语种几乎学不到。做法:对语言 $i$ 的自然占比 $p_i$ 做幂次「软化」,采样权重 $q_i\propto p_i^{1/T}$($T>1$,如 mBERT/XLM-R 用 $T\approx3.3$ 即 $\alpha=0.3$)。$T\to\infty$ 趋于均匀(过度上采样小语种、伤大语种);$T=1$ 退回自然占比。这是「给小语种配额」的标准旋钮,直接缓解 [[055 分词的坑：数字、代码、多语言与 token 攻击面|fertility]] 在小语种上的劣势。

![[tok-温度采样配比.png]]

**7. 在线配比 vs 离线配比。** ① **离线**:训练前一次性按权重把各域数据混好、打散成固定数据集(最常见,简单可复现)。② **在线**:训练中**动态**调权重——DoReMi 用代理模型预先求权重属离线优化;而 **Online Data Mixing / RegMix**(2024)用训练中的反馈(各域 loss 下降速率)实时调,试图把「配比搜索」并进训练。在线法省了反复试跑,但实现复杂、易不稳。

**8. 续训/领域适配里的灾难性遗忘与 replay。** 拿通用底座做领域续训(如全喂医疗/代码)时,模型会**遗忘**通用能力(catastrophic forgetting)。对策是 **replay**:领域续训时**掺回一定比例的原始预训练数据**(如 5–30%),让旧分布不被冲掉。这是配比思想在 [[067 长上下文训练与续训|续训]]场景的延伸——配比不只在从头预训练时重要,续训同样靠它平衡新旧能力。

**9. 重复 epoch 的等效数据量(把账算细)。** Muennighoff 等给出:重复一遍数据的「有效价值」随重复次数指数衰减。粗略地,前 ~4 个 epoch 重复数据 $\approx$ 等量新数据;到第 4 epoch 后,新增一遍重复数据的有效贡献跌到约新数据的几分之一,继续重复甚至因过拟合/记忆使验证 loss 回升。所以「数据不够时」的最优解是:先把去重做彻底、再适度重复高质域(≤4 epoch),而非无脑堆 epoch——这正是 [[079 Scaling Law 与 Chinchilla 最优|Chinchilla]]「数据受限」分支的实操含义。

## 代码

```python
import numpy as np

# —— 按配比从各领域采样 batch ——
domains = ["web", "code", "book", "academic"]
weights = np.array([0.50, 0.22, 0.15, 0.13])   # 混合权重，和为 1
assert abs(weights.sum() - 1.0) < 1e-9

def sample_domain(rng):
    return domains[rng.choice(len(domains), p=weights)]   # ✅ 按权重采样

rng = np.random.default_rng(0)
from collections import Counter
print(Counter(sample_domain(rng) for _ in range(10000)))
# 约 {'web':5000,'code':2200,'book':1500,'academic':1300}  ← 经验配比落地

# —— 退火：末段切高质数据 + 降学习率 ——
def lr_and_mix(step, total, anneal_frac=0.1):
    if step < total * (1 - anneal_frac):
        return 3e-4, weights                       # 主阶段：通用配比
    else:
        high_quality = np.array([0.30, 0.25, 0.25, 0.20])  # 退火：上采样书/学术
        return 3e-5, high_quality                  # ✅ 低 LR + 高质配比「精修」
```

```python
# ❌ 错：按「语料里有多少给多少」配比 —— 网页淹没一切，代码/数学被稀释，推理变弱
# ❌ 错：把稀缺高质数据无限重复 —— 约 4 个 epoch 后收益递减甚至退化
# ❌ 错：一上来就用长上下文训全程 —— O(L²) 烧光算力；应先短窗、后扩窗
# ✅ 对：配比按下游收益调（可用 DoReMi 小模型自动找），末段退火 + 分阶段扩窗
```

```python
import numpy as np
# —— 多语言温度采样:给小语种配额(p^(1/T) 软化) ——
langs = ["en", "zh", "sw"]                 # sw=斯瓦希里语(低资源)
nat   = np.array([0.90, 0.099, 0.001])     # 自然 token 占比
def temp_sample(p, T):
    q = p ** (1.0 / T); return q / q.sum()
for T in [1.0, 3.3, 10.0]:
    print(f"T={T}: ", temp_sample(nat, T).round(4))
# T=1 退回自然占比(小语种几乎学不到);T 越大越接近均匀(过度上采样、伤大语种)
# 经验 T≈3.3(α=0.3),给低资源语言显著配额又不淹没高资源

# —— 续训 replay:掺回原分布防遗忘 ——
def continued_pretrain_mix(domain_frac=0.8, replay_frac=0.2):
    assert abs(domain_frac + replay_frac - 1) < 1e-9
    return {"new_domain": domain_frac, "pretrain_replay": replay_frac}
print(continued_pretrain_mix())   # ❌ replay=0 → 灾难性遗忘;✅ 掺 5~30% 原数据
```

## 面试高频

- **Q:预训练数据配比怎么定?** A:按「对下游能力的贡献」而非「语料里有多少」调混合权重;代码/数学常被上采样。本质是固定算力下对各能力分配数据预算,各领域此消彼长。
- **Q:DoReMi 是什么?解决什么?** A:用 280M 小代理模型跑 Group-DRO 自动找各领域权重,再训 8B 大模型;The Pile 上下游 +6.5%、达基线只需 1/2.6 步,且只花约 8% 额外算力。它常上调通用网页、下调专精领域。
- **Q:什么是课程学习 / 退火?** A:按顺序/分阶段喂数据。退火指训练末段把高质数据上采样并配低学习率「精修」;还常分阶段扩上下文长度(先短窗省算力)。
- **Q:配比和顺序哪个更重要?** A:配比(看了什么、各多少)影响远大于顺序;打乱顺序影响有限,改配比显著改变能力分布。
- **Q:为什么不能无限重复高质数据?** A:重复 epoch 收益递减,约 4 个 epoch 后近似无效新增,再多可能过拟合/记忆;这约束了上采样上限,也呼应 Chinchilla(数据不足时加参数不如加新数据)。
- **Q:多语言怎么给小语种配额?** A:温度采样,权重 $\propto p_i^{1/T}$($T>1$ 上采样小语种,经验 $T\approx3.3$);$T=1$ 退回自然占比、小语种学不到,$T$ 过大又伤大语种。直接缓解小语种 fertility 劣势。
- **Q:在线配比和离线配比区别?** A:离线=训练前一次性混好固定数据集(DoReMi 也属离线优化权重);在线=训练中按各域 loss 反馈动态调权(Online Data Mixing/RegMix),省试跑但实现复杂易不稳。
- **Q:领域续训怎么防灾难性遗忘?** A:replay——续训时掺回 5–30% 原始预训练数据,让旧分布不被冲掉。配比思想在续训场景的延伸。
- **Q:数据不够时该堆 epoch 还是加参数?** A:先把去重做彻底,再适度重复高质域(≤4 epoch,之后收益骤降甚至过拟合);呼应 Chinchilla 数据受限分支——加新数据优于加参数,无新数据则适度重复。
- **陷阱**:上采样某领域会牺牲其他领域;长上下文别全程开,$O(L^2)$ 烧算力;多语言温度别设太大(伤大语种);续训漏 replay 会遗忘通用能力。

## 关键事实

- 自动配比:**DoReMi(Xie et al., arXiv:2305.10429, NeurIPS 2023)**——280M 代理模型 Group-DRO 求领域权重训 8B(大 30 倍);The Pile 下游平均 +6.5%、达基线 2.6× 更少步;权重优化仅花约 8% 大模型算力。
- 重复 epoch 收益:**Muennighoff et al.《Scaling Data-Constrained Language Models》(arXiv:2305.16264, NeurIPS 2023)**——约 4 个 epoch 内重复数据近似等价新数据,之后收益快速衰减。
- 配比 > 顺序:多数实证表明数据混合权重对最终性能的影响显著大于样本顺序;纯顺序课程收益有限。
- 上采样实践:LLaMA(Touvron et al. 2023)、The Pile(Gao et al. 2020)等对代码、学术、维基等高价值领域上采样。
