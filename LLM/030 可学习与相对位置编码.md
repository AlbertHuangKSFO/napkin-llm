[[030 可学习与相对位置编码|可学习与相对位置编码]]:**可学习绝对编码**用一张可训练查表给每个位置一个向量(灵活但表长定死、不能外推);**相对位置编码**(Shaw 2018)不给绝对坐标,而在注意力打分时按"两 token 距离 $i-j$"加偏置(平移不变、外推更好),是 [[031 RoPE 旋转位置编码(推导与实现)|RoPE]]、[[033 ALiBi 与 NoPE|ALiBi]] 的源头。

## 直觉:两种思路——"我在第几位"vs"我离你多远"
[[029 正弦余弦位置编码(推导)|正弦编码]] 是固定公式算出来的绝对位置。两个自然的改进方向:

**① 既然要给绝对位置一个向量,何不让模型自己学?** 这就是**可学习绝对位置编码**:维护一张 $\text{max\_len}\times d$ 的可训练表,位置 $i$ 取第 $i$ 行加到词嵌入。BERT、GPT 都用它——简单、灵活、短上下文表现常优于正弦。代价:表只有 max_len 行,**超出长度就没有对应行**,无法外推;且每个绝对位置独立学,样本少的远位置学不充分。

**② 语言其实更在乎"相对距离"而非"绝对坐标"。** "形容词修饰它右边第一个名词"这种规律,和这对词在句首还是句尾无关,只和它们**相距多远**有关。于是 **Shaw 2018** 提出相对位置编码:不给绝对坐标,而在注意力打分时,根据 query 与 key 的**相对距离 $i-j$** 加一个可学习偏置。同一距离共享同一向量 → **平移不变**,换个位置规律照用,外推也更稳。

类比:绝对编码像给每个座位贴死号码("3 排 5 座");相对编码像只关心"你在我左边还是右边、隔几个人"——后者换个会议室照样适用。

## 例子:相对偏置如何改打分
标准注意力打分 $e_{ij}=\dfrac{q_i^\top k_j}{\sqrt d}$,完全不含位置。Shaw 给 key 加一个相对项 $a^K_{i-j}$:
$$e_{ij}=\frac{q_i^\top(k_j+a^K_{i-j})}{\sqrt d}$$
$a^K_{i-j}$ 是一张**按相对距离索引**的可学习向量表。设窗口裁剪 $k=2$,相对距离取值 $\{-2,-1,0,+1,+2\}$(超出截断到边界),只需 $2k+1=5$ 个向量,被所有位置对共享。

具体:位置对 $(i,j)=(5,3)$ 和 $(10,8)$ 相对距离都是 $+2$,**用同一个 $a^K_{+2}$**——绝对位置不同但相对关系相同,打分受到一致的位置修正。这就是"平移不变":把整句平移,相对距离不变,注意力行为不变。

**T5 分桶手算(为什么远距离粗粒度)。** T5 把相对距离 $i-j$ 映射到有限个"桶",每个桶一个标量偏置 $b$。近距离一对一精细分桶,远距离对数压缩:设 32 个桶、最大距离 128,典型映射类似——距离 0,1,2,…,15 各占一桶(精细);16–23、24–31、32–47…按对数合并(越远桶越宽)。直觉:**"差 1 个词"和"差 2 个词"语义差别大,要分清;"差 100"和"差 101"几乎没区别,合一个桶就行**。这样既覆盖任意长距离、桶数又固定(可外推),还省参数。打分变成 $e_{ij}=q_i^\top k_j/\sqrt d + b_{\text{bucket}(i-j)}$,$b$ 是按头学的标量,不与 $q$ 相乘、不改 value——比 Shaw 更省。

## 原理:三类对照与演进
**可学习绝对编码。** 位置嵌入 $p_i\in\mathbb{R}^d$ 来自可训练表 $P\in\mathbb{R}^{L\times d}$,加到词嵌入:$x_i=e_i+p_i$。参数量 $L\times d$。优点:端到端学、灵活;缺点:① 表长 $L$ 定死 → 序列超 $L$ 无编码、不能外推;② 远位置训练样本少、学不透;③ 不显式建模相对距离。

**Shaw 相对位置编码。** 把位置信息从"输入相加"挪到"注意力打分内部"。完整形式不仅给打分加相对项,也给 value 加(原文同时改 key 与 value):
$$e_{ij}=\frac{q_i^\top k_j + q_i^\top a^K_{\text{clip}(i-j)}}{\sqrt d},\qquad o_i=\sum_j \alpha_{ij}\,(v_j+a^V_{\text{clip}(i-j)})$$
其中 $\text{clip}(i-j)=\max(-k,\min(k,i-j))$ 把相对距离裁到窗口 $[-k,k]$,使表大小固定为 $2k+1$,与序列长无关。优点:**平移不变、外推更好、参数少**(只随窗口 $k$ 不随 $L$)。

**演进主线(面试爱问):**
- **正弦绝对**(Vaswani 2017):无参数、固定、加输入。
- **可学习绝对**(BERT/GPT):有参数、加输入、不可外推。
- **Shaw 相对**(2018):打分加相对偏置、平移不变。
- **T5 相对偏置**(2020):简化成一个**标量** bucket 偏置直接加到打分($e_{ij}\mathrel{+}=b_{\text{bucket}(i-j)}$),按距离分桶,远距离粗粒度。
- **[[031 RoPE 旋转位置编码(推导与实现)|RoPE]]**(2021):把 $q,k$ 按位置**旋转**,内积自动只依赖相对角度——主流。
- **[[033 ALiBi 与 NoPE|ALiBi]]**(2021):按距离给打分加**线性衰减**惩罚 $-m\cdot|i-j|$,零参数、外推极好。

可以看到:**位置编码从"加在输入的绝对向量"逐步走向"作用在注意力打分的相对量"**,因为相对量平移不变、外推更稳——这正是长上下文时代的默认选择。

## 代码:可学习绝对 vs Shaw 相对
```python
import torch, torch.nn as nn, torch.nn.functional as F

# ✅ 可学习绝对位置编码:一张可训练表,加到词嵌入
class LearnedAbsPE(nn.Module):
    def __init__(self, max_len, d):
        super().__init__()
        self.table = nn.Embedding(max_len, d)        # L×d 可训练表
    def forward(self, x):                            # x:(n,d)
        pos = torch.arange(x.size(0), device=x.device)
        return x + self.table(pos)                   # 相加
        # ❌ 序列长度 > max_len 时 self.table 越界 → 无法外推,必须重训扩表

# ✅ Shaw 相对位置编码:打分时按 clip(i-j) 取相对向量加偏置
class ShawRelAttn(nn.Module):
    def __init__(self, d, k=2):                      # k=相对窗口
        super().__init__()
        self.k, self.d = k, d
        self.rel = nn.Embedding(2 * k + 1, d)        # 只 (2k+1) 个,与序列长无关!
    def forward(self, Q, K, V):                      # (n,d)
        n = Q.size(0)
        idx = torch.arange(n)
        rel = (idx[:, None] - idx[None, :]).clamp(-self.k, self.k) + self.k  # (n,n) 相对距离→桶
        a_K = self.rel(rel)                          # (n,n,d) 每对一个相对向量(共享)
        content = Q @ K.T                            # (n,n) 内容打分
        position = torch.einsum('id,ijd->ij', Q, a_K)  # (n,n) 相对位置打分
        A = F.softmax((content + position) / self.d ** 0.5, dim=-1)
        return A @ V
# ❌ 易错:相对表大小写成 n 或 max_len —— 应是 (2k+1),靠 clip 共享才平移不变、可外推。
```

## 面试高频
- **可学习绝对位置编码的最大缺点?** 表长 $L$ 固定 → **不能外推**(超 $L$ 没编码);远位置样本少学不透;不显式建模相对距离。BERT/GPT 用它。
- **相对位置编码(Shaw)核心思想?** 不给绝对坐标,在注意力打分时按相对距离 $i-j$(裁到窗口 $k$)加可学习偏置,**同一距离共享** → 平移不变、外推更好、参数只随 $k$。
- **绝对 vs 相对一句话区别?** 绝对答"我在第几位"(加在输入),相对答"我离你多远"(作用在打分)。语言更依赖相对距离。
- **演进顺序?** 正弦绝对 → 可学习绝对 → Shaw 相对 → T5 相对偏置(标量分桶)→ [[031 RoPE 旋转位置编码(推导与实现)|RoPE]](旋转)→ [[033 ALiBi 与 NoPE|ALiBi]](线性衰减)。趋势:从输入绝对量走向打分相对量。
- **T5 相对偏置比 Shaw 简化在哪?** T5 把相对项简化成一个**标量** bucket 偏置直接加到打分(不与 $q$ 相乘、也不改 value),按距离分桶、远距离粗粒度,更省。
- **为什么相对编码外推更好?** 平移不变:同一相对距离用同一参数,训练见过的距离规律可直接用到更长序列上;绝对编码的新位置则从未训练过。
- **[[031 RoPE 旋转位置编码(推导与实现)|RoPE]] 算绝对还是相对?** 它对 $q,k$ 施加绝对位置的旋转,但内积只依赖**相对**角度差 → 兼具二者、是相对编码的主流实现。
- **T5 分桶为什么远距离粗、近距离细?** 近距离语义差别大(差 1 词 vs 差 2 词关系迥异),要精细分桶;远距离差别可忽略(差 100 vs 101 几乎一样),对数合并成宽桶。桶数固定 → 任意长度可外推、又省参数。
- **可学习绝对编码为什么"远位置学不透"?** 训练语料里长序列少,大位置索引(如第 3000 位)出现次数远少于小位置,其对应表行更新少、欠拟合;相对编码因"同距离共享",任何长度的样本都在更新同一批相对参数,数据效率高得多。
- **BERT 用可学习绝对、外推差,实际怎么处理超长输入?** 截断或滑动窗口;要真正变长须扩表 + 继续训练。这正是后来模型转向 RoPE/ALiBi 的动机之一。
- **Shaw 相对编码为什么也改 value(加 $a^V$)?** 原文认为位置不仅影响"看谁"(打分),也该影响"取到什么"(value);但后续 T5/RoPE 发现只改打分已足够且更省,故主流简化为只在打分注入。

## 关键事实
- 可学习绝对位置编码:在 BERT(Devlin et al. 2018)、GPT 等中广泛使用,可训练表 $L\times d$,加到词嵌入;不可外推。
- Peter Shaw、Jakob Uszkoreit、Ashish Vaswani,*Self-Attention with Relative Position Representations*,2018,arXiv:1803.02155(NAACL 2018)。在打分与 value 上加按相对距离裁剪的可学习项;WMT14 En-De 较绝对位置 +1.3 BLEU。
- 关键设计:相对距离裁剪到窗口 $[-k,k]$,表大小 $2k+1$ 与序列长无关 → 平移不变、可外推。
- T5 相对偏置:Raffel et al.,*Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*,2020,arXiv:1910.10683,用标量分桶偏置直接加到打分,进一步简化。
