[[057 数据：清洗、去重与质量过滤|数据清洗]] 讲的是把 PB 级原始网页(CommonCrawl)变成可训练语料的工程管线:**抽正文、语言识别、启发式过滤、精确+近似去重(MinHash)、质量分类、去测试集污染**。核心信念:**数据质量常比加参数更决定模型上限**。

## 直觉

LLM 的「燃料」是文本,但原始网页脏得离谱:导航栏、广告、乱码、色情垃圾、海量转载重复。直接喂进去,模型会学坏、过拟合、记住隐私、还浪费算力。所以预训练前要跑一条**清洗管线**,像炼油一样把原油提纯:

1. **抽正文 + 语言识别**:从 HTML 里抽出正文,去掉样板(导航/页脚),识别语言只留目标语种。
2. **启发式过滤**:用简单规则筛掉垃圾——文档太短/太长、符号比例异常、停用词太少、含黑名单词(NSFW)。
3. **去重(两层)**:精确去重删 byte 级重复;**近似去重**用 MinHash 估相似度,删「换汤不换药」的近重复(模板页、转载)。
4. **质量分类**:训一个分类器,给文档打「像不像维基/书」的分,留高分的。
5. **去测试集污染(decontaminate)**:删掉与评测基准重叠的文档,否则评测虚高(这是一种 [[09 数据与模型投毒|数据问题]],也关联 [[057 数据：清洗、去重与质量过滤|数据]] 的诚信)。

一句话:**清洗去掉脏的,去重去掉重的,质量过滤留下好的,去污染保证评测可信。**

## 例子

**去重为什么有用(小数字直觉)。** 假设语料里某段「订阅我们的 newsletter」出现了 10000 次(各网站页脚转载)。不去重,模型会把这段**背下来**,并在生成时无端复读;且这 10000 份占了算力却没带来新信息。去重后只留 1 份,腾出的预算可换真正多样的数据。实测:**去重比多加 5% 的数据更能提升泛化**(Lee et al. 2022)。RedPajama 中约 **50% 的文档是精确重复**,可见原始网页冗余之高。

**精确 vs 近似去重。** 两段文本:
```
A: "今天天气很好，我们去公园散步。"
B: "今天天气很好，我们去公园里散步。"   ← 只差一个「里」字
```
精确去重(整段哈希)认为 A≠B,留着;但它们几乎是重复。**MinHash** 把每段表示成一组 shingle(如字符 n-gram)的集合,用多个哈希取最小值得到**签名**,签名相似度无偏估计两集合的 **Jaccard 相似度**;再用 LSH 把签名分桶,只比同桶的,近似找出 A、B 这种近重复并删一份。

![[train-数据清洗管线.svg]]

**质量分类的直觉。** 拿「已知高质量」文本(维基、书、被点赞的 Reddit 链接指向的网页)当正例,随机 CommonCrawl 当负例,训一个轻量分类器(逻辑回归 / fastText)。给每个网页打分,只留高分的。GPT-3、LLaMA 等都用过类似做法。**RefinedWeb 证明:只靠清洗+去重网页(不掺精选语料),就能训出追平甚至超过用精选语料模型的效果**——数据工程本身就是核心竞争力。

## 原理

**1. MinHash 估 Jaccard。** 两文档的 shingle 集合 $A,B$,Jaccard 相似度

$$J(A,B)=\frac{|A\cap B|}{|A\cup B|}$$

精确算要两两求交,$O(N^2)$ 不可行。MinHash:取一个随机哈希 $h$,定义 $\min h(A)=\min_{a\in A}h(a)$。关键性质——

$$\Pr[\min h(A)=\min h(B)]=J(A,B)$$

用 $k$ 个独立哈希,签名里相等位的比例就是 $J$ 的无偏估计,把每个文档压成长度 $k$ 的紧凑签名。

**2. LSH 把近似搜索降到近线性。** 把 $k$ 维签名切成 $b$ 个 band(每 band $r$ 行,$k=br$),对每个 band 哈希分桶。两文档**至少一个 band 完全相同**才进同桶、才比较。某 band 全等的概率是 $J^r$,「至少一个 band 命中」的概率

$$P_{\text{hit}}=1-(1-J^{r})^{b}$$

是个 S 形曲线:相似度高于阈值的几乎必命中,低于的几乎被滤掉。于是只需比较同桶对,从 $O(N^2)$ 降到近 $O(N)$,能在万亿 token 规模做近似去重。

**3. 启发式过滤是「精确率换召回率」。** 规则(长度、符号比、重复行比、困惑度阈值)简单、可大规模并行,但会误删一些好文档、漏掉一些坏文档。工程上接受这种粗筛,把精细判断交给后面的质量分类器。

**4. 去污染的必要性。** 若评测基准(如 MMLU、GSM8K)的题目出现在训练集,模型是「背过答案」,评测分数虚高、不反映泛化。去污染按 n-gram 重叠删除与基准重合的训练文档。这与 [[09 数据与模型投毒|数据投毒]] 是一体两面:无意污染抬虚分,恶意投毒则是攻击。

**5. 为什么数据质量决定上限。** [[079 Scaling Law 与 Chinchilla 最优|Scaling Law]] 在「干净数据」上才成立;脏数据让等效数据量缩水、困惑度虚高、并引入记忆与偏见。在固定算力下,**提升数据质量往往比加参数更划算**——这也是 2023 年后开源竞赛的主战场从「堆参数」转向「炼数据」的原因。

**6. MinHash + LSH 参数怎么算(手推 S 曲线)。** 设 $k=128$ 个哈希、分 $b=16$ band、每 band $r=8$ 行($br=128$)。两文档 Jaccard $J$ 时,某 band 全等概率 $J^r=J^8$,至少一个 band 命中(进同桶被比较)概率 $P_{\text{hit}}=1-(1-J^8)^{16}$。代入:$J=0.9$ 时 $0.9^8\approx0.43$,$P_{\text{hit}}=1-(1-0.43)^{16}\approx1.0$(几乎必抓);$J=0.5$ 时 $0.5^8\approx0.0039$,$P_{\text{hit}}\approx1-(0.9961)^{16}\approx0.06$(基本放过)。曲线的「拐点」近似在 $J^\star\approx(1/b)^{1/r}=(1/16)^{1/8}\approx0.71$。**调 $b,r$ 就是调这个去重阈值**:$r$ 大→曲线更陡、阈值更高(更保守、漏删近重复);$b$ 大→召回更高但误删风险升。

**7. 精确去重的可扩展实现:后缀数组 / 子串去重。** 整段 SHA256 只能删「逐字节完全相同的文档」,删不了「一篇文章里嵌了另一篇的一长段」。Lee 等(2022)的 **ExactSubstr** 用**后缀数组**找出语料中所有长度 ≥50 token 的重复子串并删除,粒度细到「子串级」,比文档级哈希更彻底;MinHash 则补「整体高度相似但非逐字」的近重复。三层叠加(文档哈希 + 子串去重 + MinHash)才算干净。

**8. 质量过滤的两条路线:启发式 vs 模型分类器。** ① **启发式**(C4/Gopher rules):停用词比例、平均行长、符号/词比、重复 n-gram 比、含 `{` 比例(防 JS 垃圾)等几十条规则,快但粗。② **模型分类器**:轻量(fastText/逻辑回归)用「高质 vs 随机网页」二分类打分(GPT-3/LLaMA);更新的 **FineWeb-Edu**(2024)用 LLM 标注「教育价值」分数训一个分类器筛网页,显著提升下游推理。③ **困惑度过滤**:用一个在高质语料上训的小 LM 给文档打 PPL,PPL 过高(像乱码)或过低(像模板/重复)都筛掉。

**9. PII 与记忆风险。** 网页含大量个人信息(邮箱、电话、地址)。不处理,模型会**逐字背下并可在生成时吐出**(训练数据提取攻击)。去重本身能大幅降低记忆(重复越多越易被背),此外要做 PII 检测/脱敏;这与隐私、[[09 数据与模型投毒|数据投毒]]都相关。**去重 = 隐私防御的第一步**:Lee(2022)证明被记忆的样本绝大多数是高重复样本。

## 代码

```python
from datasketch import MinHash, MinHashLSH

def shingles(text, k=5):                      # 字符 5-gram 作为 shingle
    return {text[i:i+k] for i in range(len(text)-k+1)}

def make_minhash(text, num_perm=128):
    m = MinHash(num_perm=num_perm)
    for s in shingles(text):
        m.update(s.encode("utf-8"))
    return m

docs = {
    "d1": "今天天气很好，我们去公园散步。",
    "d2": "今天天气很好，我们去公园里散步。",   # d1 的近重复
    "d3": "量子计算利用叠加与纠缠并行计算。",   # 无关
}

# LSH：阈值 0.7，自动把近重复分到同桶
lsh = MinHashLSH(threshold=0.7, num_perm=128)
mh = {k: make_minhash(v) for k, v in docs.items()}
kept = []
for name, m in mh.items():
    if lsh.query(m):                          # 已有近重复 → 丢弃
        print(f"丢弃近重复: {name}")
    else:
        lsh.insert(name, m); kept.append(name)   # 保留代表
print("保留:", kept)        # 例如保留 d1、d3，丢弃 d2

# —— 精确去重：整段哈希 ——
import hashlib
seen, exact_kept = set(), []
for name, text in docs.items():
    h = hashlib.sha256(text.encode()).hexdigest()
    if h not in seen:
        seen.add(h); exact_kept.append(name)   # 精确去重看不出 d1≈d2，需 MinHash 补
```

```python
# ❌ 错：只做精确去重就以为干净了 —— 近重复（转载、模板）漏一大片
# ❌ 错：先训模型再发现测试集污染 —— 评测分虚高、白跑
# ✅ 对：管线顺序 抽正文→语言→启发式→精确去重→MinHash 近似去重→质量分类→去污染
# ✅ 对：质量分类器用「已知高质量 vs 随机网页」当正负例训轻量模型打分
```

```python
# —— LSH 的 S 曲线:band/row 如何决定去重阈值(手算) ——
def p_hit(J, b, r):                 # 至少一个 band 命中 → 进同桶被比较
    return 1 - (1 - J**r)**b
b, r = 16, 8                        # k=128 个哈希
for J in [0.9, 0.8, 0.71, 0.6, 0.5]:
    print(f"J={J}:  P_hit={p_hit(J,b,r):.3f}")
# 拐点 ≈ (1/b)**(1/r)
print("阈值拐点 ≈", (1/b)**(1/r))   # ≈0.71;r↑曲线更陡(更保守),b↑召回更高
# ❌ 直接两两比 O(N²) 不可行;✅ 分桶后只比同桶对,近 O(N)

# —— 启发式过滤的几条典型规则(Gopher/C4 风格) ——
def heuristic_keep(text):
    words = text.split()
    if not (50 <= len(words) <= 100000): return False          # 太短/太长
    sym_ratio = sum(c in "#{}[]<>" for c in text) / max(len(text),1)
    if sym_ratio > 0.1: return False                            # 符号过多(像代码垃圾)
    stop = {"the","of","and","to","是","的","了"}
    if sum(w.lower() in stop for w in words) / len(words) < 0.05: return False  # 停用词太少→非自然语言
    return True
# 启发式是「宁可错杀」的粗筛;精细判断交给质量分类器/PPL 过滤
```

## 面试高频

- **Q:LLM 预训练数据清洗管线有哪些步骤?** A:抽正文+去样板 → 语言识别 → 启发式过滤(长度/符号比/黑名单) → 精确去重 → MinHash 近似去重 → 质量分类打分 → 去测试集污染。
- **Q:精确去重和近似去重区别?为什么都要?** A:精确去重删 byte 级完全相同的;近似去重用 MinHash+LSH 删「只差几个字」的近重复(转载、模板)。光精确去重会漏掉大量近重复。
- **Q:MinHash 怎么估相似度?** A:$\Pr[\min h(A)=\min h(B)]=J(A,B)$,用 $k$ 个哈希的签名里相等位比例无偏估计 Jaccard;LSH 分 band 分桶把两两比较降到近线性。
- **Q:去重为什么提升模型?** A:重复样本导致过拟合、记忆隐私、复读、浪费算力;去重比多加 5% 数据更能提升泛化(Lee 2022)。RedPajama 约半数文档是精确重复。
- **Q:什么是数据污染(decontamination),为什么重要?** A:评测基准的题目混进训练集会让评测虚高,不反映真实泛化;去污染按 n-gram 重叠删与基准重合的训练文档。
- **Q:数据质量真比参数重要吗?** A:RefinedWeb 证明只靠清洗+去重网页就能追平用精选语料的模型;固定算力下提升数据质量常比加参数更划算。
- **Q:LSH 的 band/row 怎么定去重阈值?** A:$k=br$,某 band 全等概率 $J^r$,命中概率 $1-(1-J^r)^b$,拐点 $\approx(1/b)^{1/r}$;$r$ 大→曲线更陡阈值更高(保守、易漏近重复),$b$ 大→召回更高但误删风险升。
- **Q:整段哈希去重够吗?** A:不够,只能删逐字节相同的文档,删不了「嵌入了另一篇一长段」。需用后缀数组做**子串级**精确去重(Lee 2022 的 ExactSubstr,删 ≥50 token 重复子串)+ MinHash 删非逐字近重复,三层叠加。
- **Q:除了启发式和分类器,还有什么质量过滤?** A:困惑度过滤(小 LM 给 PPL,过高像乱码、过低像模板都删);以及用 LLM 标「教育价值」训分类器(FineWeb-Edu 2024)显著提升下游推理。
- **Q:数据清洗和隐私/记忆什么关系?** A:模型会逐字背高重复样本并在生成时吐出(训练数据提取攻击);去重是隐私防御第一步(被记忆样本多为高重复),还需 PII 检测脱敏。
- **陷阱**:启发式过滤是粗筛(会误删/漏判),精细判断交给质量分类器;去重要在近似层面做,别只信整段哈希;子串级重复需后缀数组;LSH 阈值由 band/row 隐式决定,别忘了调。

## 关键事实

- 去重提升泛化:**Lee et al.《Deduplicating Training Data Makes Language Models Better》(arXiv:2107.06499, ACL 2022)**——去重减少记忆、提升效果,去重比加数据更有效。
- 近似去重方法:**MinHash(Broder 1997)** 估 Jaccard + **LSH** 分桶;工业界普遍用于万亿 token 规模(如 RedPajama、RefinedWeb)。
- 数据工程即竞争力:**RefinedWeb / Falcon(Penedo et al., arXiv:2306.01116, 2023)**——仅靠大规模清洗+去重 CommonCrawl,不掺精选语料,即可训出 SOTA 级模型;清洗后约 2.8TB 干净文本。
- 冗余之高:RedPajama 中约 50% 文档为精确重复;原始网页极度冗余。
- 质量分类:GPT-3(Brown et al. 2020)、LLaMA(Touvron et al. 2023)用「高质量 vs 随机网页」分类器筛选 CommonCrawl。
