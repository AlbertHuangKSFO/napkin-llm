[[029 正弦余弦位置编码(推导)|正弦余弦位置编码]]:把每个位置编成一串**不同频率的 sin/cos 值**,偶数维用 $\sin$、奇数维用 $\cos$,频率从高到低几何递减——无参数、每个位置唯一,且 $PE(pos+k)$ 可由 $PE(pos)$ 经一个只依赖 $k$ 的**线性旋转**表出(便于学相对位置),理论上可外推到训练没见过的长度。

## 直觉:用一组不同快慢的"指针"标位置
要给位置 $pos$ 一个唯一指纹,最朴素是写它的二进制:$0,1,10,11,\dots$——每一位以不同频率翻转(最低位每步翻、次低位每两步翻……)。正弦编码是这个想法的**连续光滑版**:用一组**频率不同的正弦波**,每个维度一条波,高频维区分相邻位置、低频维编码全局位置,组合起来每个 $pos$ 唯一。

类比:钟表用秒针(高频)、分针(中频)、时针(低频)三根不同快慢的指针,组合就能唯一表示一天里任一时刻。正弦编码是 $d$ 根"指针",频率呈几何级数铺开,把位置编进一个 $d$ 维向量。

为什么非要 sin/cos 而不直接用整数 $pos$?① 整数无界,长序列数值爆炸、不利训练;sin/cos 恒在 $[-1,1]$ 有界。② sin/cos 的和角公式让"相对位移"能被线性地表达——这才是它真正的妙处(见原理)。

## 例子:手算几个位置
取 $d=4$,基数 10000。维度对 $i=0,1$,频率 $\omega_i=1/10000^{2i/d}$:$\omega_0=1$,$\omega_1=1/10000^{0.5}=0.01$。
$$PE(pos)=[\sin(\omega_0 pos),\ \cos(\omega_0 pos),\ \sin(\omega_1 pos),\ \cos(\omega_1 pos)]$$
- $pos=0$:$[\sin0,\cos0,\sin0,\cos0]=[0,1,0,1]$
- $pos=1$:$[\sin1,\cos1,\sin0.01,\cos0.01]\approx[0.841,0.540,0.010,1.000]$
- $pos=2$:$[\sin2,\cos2,\sin0.02,\cos0.02]\approx[0.909,-0.416,0.020,1.000]$

看维 0(高频 $\omega_0=1$):从 $pos$ 0→1→2 变化明显(0→0.841→0.909),擅长**区分近邻**;维 2(低频 $\omega_1=0.01$):几乎不动(0→0.010→0.020),它只在**很大跨度**上才显著变化,负责**全局位置**。两者组合 → 每个 $pos$ 一个唯一向量。

**波长表(频率几何铺开,$d=8$, base=10000)。** 维度对 $i=0,1,2,3$,$\omega_i=10000^{-2i/8}=10000^{-i/4}$,波长 $\lambda_i=2\pi/\omega_i$:

| $i$ | $\omega_i$ | 波长 $\lambda_i$ | 角色 |
|---|---|---|---|
| 0 | $1$ | $2\pi\approx6.3$ | 最高频,区分相邻 token |
| 1 | $0.1$ | $\approx63$ | 中高频 |
| 2 | $0.01$ | $\approx628$ | 中低频 |
| 3 | $0.001$ | $\approx6283$ | 最低频,编码全局位置 |

波长从 $2\pi$ 几何增长到约 $2\pi\cdot10000$——**像一组从"秒针"到"年历"的不同刻度同时计时**,任意位置在这组刻度上的读数组合唯一。$d$ 越大,刻度越密、可无歧义表示的位置范围越长。

**与二进制计数的对应。** 二进制里位置 $pos$ 的最低位每 +1 翻转一次(周期 2)、次低位每 +2 翻转(周期 4)、再上一位周期 8……正弦编码就是它的连续版:维 0 周期 $2\pi$(最快翻)对应最低位,维 $d/2-1$ 周期最长对应最高位。区别是 sin/cos 平滑有界、相邻位置编码相似(利于泛化),而二进制相邻位可能差很多位(如 7→8 是 0111→1000)。

## 原理:公式 + 为何相对位置可线性表出
**编码公式**(Vaswani 2017),$pos$ 是位置,$i$ 是维度对索引,$d$ 是模型维:
$$PE(pos,2i)=\sin\!\Big(\frac{pos}{10000^{2i/d}}\Big),\qquad PE(pos,2i+1)=\cos\!\Big(\frac{pos}{10000^{2i/d}}\Big)$$
记 $\omega_i=10000^{-2i/d}$,则波长(周期 $2\pi/\omega_i$)从 $2\pi$(高频,$i=0$)几何增长到约 $2\pi\cdot10000$(低频,$i=d/2-1$)。$i$ 越大频率越低。

**核心性质:相对位移是固定线性变换。** 对任一维度对,$PE$ 由 $(\sin\omega_i pos,\cos\omega_i pos)$ 组成。用和角公式:
$$\begin{bmatrix}\sin\omega_i(pos+k)\\ \cos\omega_i(pos+k)\end{bmatrix}
=\underbrace{\begin{bmatrix}\cos\omega_i k & \sin\omega_i k\\ -\sin\omega_i k & \cos\omega_i k\end{bmatrix}}_{R_k:\ \text{只依赖 }k}
\begin{bmatrix}\sin\omega_i pos\\ \cos\omega_i pos\end{bmatrix}$$
即 $PE(pos+k)=R_k\,PE(pos)$,$R_k$ 是个**只依赖偏移 $k$、与 $pos$ 无关的旋转矩阵**。所以模型用一个线性层就能从"某位置的编码"推出"它前/后 $k$ 步的编码"——**相对位置关系天然可被线性建模**。这正是后来 [[031 RoPE 旋转位置编码(推导与实现)|RoPE]] 的灵感:RoPE 把这个旋转直接作用到 $q,k$ 上,让注意力内积**只依赖相对距离**。

**和角公式逐步验证(为什么 $R_k$ 与 $pos$ 无关)。** 取 $\sin\omega(pos+k)=\sin\omega pos\cos\omega k+\cos\omega pos\sin\omega k$,$\cos\omega(pos+k)=\cos\omega pos\cos\omega k-\sin\omega pos\sin\omega k$。把 $(\sin\omega pos,\cos\omega pos)$ 当未知量,系数矩阵正是 $\begin{bmatrix}\cos\omega k&\sin\omega k\\-\sin\omega k&\cos\omega k\end{bmatrix}$——里面**只有 $k$,没有 $pos$**。这就是关键:同一个偏移 $k$,不论作用在句首还是句尾的位置,旋转矩阵完全相同 → 模型学一次"前进 $k$ 步"的线性映射就到处可用。这是正弦编码"可表示相对位置"的数学本质,也直接催生了 RoPE。

**为何用相加而非拼接?** 实践中 $PE$ 直接**加**到词嵌入:$x_i=e_i+PE(i)$。相加不增维、且高层可通过学习把位置子空间与语义子空间近似解耦;Vaswani 实验显示加 vs 拼接效果相当,加更省。

**为何能外推?** $PE$ 是**确定性函数**,对任意 $pos$(哪怕训练时没见过的更长位置)都能直接算出,无需训练参数——理论上可外推。但实践中纯正弦编码外推一般,真正长上下文外推靠 [[032 RoPE 外推：NTK-aware、位置插值、YaRN|位置插值/NTK/YaRN]]。

## 代码:几行写出整张位置表
```python
import torch, math

# ✅ 正弦余弦位置编码:无参数,直接由公式算出
def sinusoidal_pe(max_len, d):
    pe = torch.zeros(max_len, d)
    pos = torch.arange(max_len).unsqueeze(1).float()          # (max_len, 1)
    # 频率项 ω_i = 1 / 10000^(2i/d);用 exp(log) 数值稳定
    div = torch.exp(torch.arange(0, d, 2).float() * (-math.log(10000.0) / d))
    pe[:, 0::2] = torch.sin(pos * div)                        # 偶数维 sin
    pe[:, 1::2] = torch.cos(pos * div)                        # 奇数维 cos
    return pe                                                 # (max_len, d)

pe = sinusoidal_pe(50, 16)
x = torch.randn(50, 16)
x = x + pe                                                    # 加到词嵌入,不是拼接

# ❌ 易错:用 pos / 10000**(2i/d) 直接幂运算,长序列/大 d 易溢出 → 用 exp-log 形式
# ❌ 易错:把 sin 放奇数维、cos 放偶数维(顺序反了)——与论文约定不符,虽不致命但不一致
# ❌ 易错:以为 PE 要训练 —— 正弦编码是固定的,可学习版见 030
```

## 面试高频
- **正弦编码公式?** $PE(pos,2i)=\sin(pos/10000^{2i/d})$,$PE(pos,2i+1)=\cos(\cdot)$。偶 sin 奇 cos,频率随维度几何递减。
- **为什么用多个频率?** 高频维区分相邻、低频维编码全局,组合让每个位置唯一(类比秒/分/时针)。
- **它最妙的性质是什么?** $PE(pos+k)=R_k\,PE(pos)$,$R_k$ 是只依赖偏移 $k$ 的旋转 → **相对位置可被线性表出**,模型易学距离关系。这是 [[031 RoPE 旋转位置编码(推导与实现)|RoPE]] 的前身思想。
- **为什么是相加不是拼接?** 不增维、效果相当且更省;高层可学着把位置/语义子空间解耦。
- **能外推吗?** 因是确定性函数,理论上任意长度可算 → 可外推;但实测纯正弦外推一般,长上下文靠 [[032 RoPE 外推：NTK-aware、位置插值、YaRN|插值/NTK/YaRN]]。
- **和 [[030 可学习与相对位置编码|可学习位置编码]] 比?** 正弦无参数、可外推但固定;可学习有参数、灵活但表长定死。BERT/GPT 多用可学习,原始 Transformer 用正弦。
- **基数为什么是 10000?** 经验取值,决定最低频波长 $\approx2\pi\cdot10000$,覆盖足够长的位置范围;改基数会改外推行为(NTK 思路即调此基)。
- **为什么不直接用整数 $pos$ 当位置编码?** ① 整数无界,长序列数值爆炸、与有界的词嵌入量纲不匹配,训练不稳;② 无法天然表达"相对位移可线性表示"这一性质。sin/cos 有界且满足 $PE(pos+k)=R_k PE(pos)$,两个问题都解决。
- **正弦编码和二进制计数什么关系?** 是其连续光滑版:维 0(高频)≈ 最低位(每步翻),低频维 ≈ 高位(慢翻)。但 sin/cos 相邻位置编码相似、利于泛化,二进制相邻位可能差很多位。
- **偶 sin 奇 cos 放反了会怎样?** 只是维度置换,信息不丢、不致命,但与论文/主流实现约定不符,迁移权重时易出错——保持一致即可。
- **正弦编码每层都加吗?** 不。它只在**输入嵌入**加一次,后续靠模型携带;对比 [[031 RoPE 旋转位置编码(推导与实现)|RoPE]]/[[033 ALiBi 与 NoPE|ALiBi]] 在每层注意力都重新注入。

## 关键事实
- Ashish Vaswani et al.,*Attention Is All You Need*,2017,arXiv:1706.03762,3.5 节提出正弦余弦位置编码。
- 公式:$PE(pos,2i)=\sin(pos/10000^{2i/d})$,$PE(pos,2i+1)=\cos(pos/10000^{2i/d})$;波长从 $2\pi$ 几何增长到 $2\pi\cdot10000$。
- 关键性质:$PE(pos+k)=R_k\,PE(pos)$,$R_k$ 为仅依赖 $k$ 的旋转矩阵 → 相对位置线性可表;启发 [[031 RoPE 旋转位置编码(推导与实现)|RoPE]]。
- 使用:与词嵌入**相加**(非拼接);无可训练参数,确定性、理论可外推。
- 定位:[[028 位置编码总览：为何 Transformer 需要|位置编码]] 的开山方案(绝对、固定),对照 [[030 可学习与相对位置编码|可学习/相对编码]];外推增强见 [[032 RoPE 外推：NTK-aware、位置插值、YaRN|032]]。
