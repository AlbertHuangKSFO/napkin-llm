[[084 策略梯度与 PPO 基础]]:策略梯度直接对「策略」求梯度上升以最大化期望奖励,但方差大、易一步走崩;PPO(Proximal Policy Optimization,Schulman 2017,arXiv 1707.06347)用 **clip 截断的代理目标 + actor-critic + 优势函数**把更新「拴住」,稳定又好实现,是 [[085 RLHF 全流程与 KL 约束、奖励黑客|RLHF]] 优化策略的默认算法。

## 直觉:奖励高的动作,下次多做一点

[[083 奖励模型 RM|奖励模型]] 给了「奖励数字」,现在要让模型(策略 $\pi_\theta$)生成的回答**奖励更高**。最朴素的想法:**奖励高的回答,就提高它出现的概率;奖励低的,降低**。这就是**策略梯度**。

但它有两个老毛病:

1. **方差大**:全程奖励是个随机数,梯度噪声极大,训练抖。→ 用**基线(baseline)**减方差:不看「绝对奖励」,看「比平均好多少」,这个差额叫**优势(advantage)**。
2. **一步走太远会崩**:策略更新太猛,新策略和旧策略差太多,采的数据就失效了(off-policy 失配),直接训飞。→ PPO 的 **clip** 把「新旧策略概率比」截断,**不许一步偏离太多**。

把这两点装好,就是 PPO:**actor**(策略)负责生成、**critic**(价值网络)估基线算优势、**clip 目标**保证小步快跑。

## 例子:优势与 clip 的小数字

一个 token 处,优势 $A=+2$(这个动作比平均好),新旧策略概率比 $r=\pi_\theta/\pi_{\text{old}}$。

- 若 $r=1.1$(新策略略微更爱这个动作):未截断项 $r\cdot A=2.2$。在 $\varepsilon=0.2$ 下,clip 区间 $[0.8,1.2]$,$1.1$ 没出界 → 取 $\min(2.2,\ 1.1\times2)=2.2$,正常给奖励。
- 若 $r=1.5$(新策略**过度**偏爱):未截断 $r\cdot A=3.0$,但 clip 把 $r$ 压到 $1.2$ → $\min(3.0,\ 1.2\times2)=\min(3.0,2.4)=2.4$。**多出来的不给了**——不鼓励一步走太远。

反过来 $A=-2$(动作不好,想降概率):如果新策略反而更爱它($r=1.5$),clip 不挡;但如果新策略已经把它压得很低($r=0.5<0.8$),clip 截断,**不再追加惩罚**,防止把概率压到 0 这种过度更新。

一句话:**clip 永远取「悲观的那一侧」**,挡住对当前批数据的过度优化。

## 原理:从策略梯度到 PPO-clip

**1)目标**。最大化期望奖励 $J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}[R(\tau)]$。

**2)策略梯度定理(REINFORCE)**:

$$
\nabla_\theta J=\mathbb{E}_{\tau\sim\pi_\theta}\Big[\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\;\cdot\; R_t\Big]
$$

直觉:每个动作的 $\log$ 概率梯度,按它带来的回报 $R_t$ 加权——回报正就提概率,负就降。

**3)用优势替回报(减方差)**。把 $R_t$ 换成**优势** $A_t=Q(s_t,a_t)-V(s_t)$——「这个动作比该状态平均好多少」。$V(s_t)$ 是 critic 估的**基线**,减它不改变梯度期望,但**大幅降方差**。实践用 [[31 KL 散度与 JS 散度|GAE]](广义优势估计)平滑偏差-方差。

**4)重要性采样比**。为复用旧策略采的数据(一批数据多更新几步),引入概率比:

$$
r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)},\qquad
L^{\text{IS}}=\mathbb{E}[\,r_t(\theta)\,A_t\,]
$$

但 $r_t$ 失控时这个目标会爆。

**5)PPO 的 clip 目标(核心)**:

$$
L^{\text{CLIP}}(\theta)=\mathbb{E}_t\Big[\ \min\big(\,r_t A_t,\ \ \mathrm{clip}(r_t,\,1-\varepsilon,\,1+\varepsilon)\,A_t\,\big)\Big],\quad \varepsilon\approx0.2
$$

取「未截断」与「截断」的 $\min$ → 永远是真实目标的**悲观下界**,从而**不鼓励 $r_t$ 偏离 1 太远**。这等价于近似一个信赖域约束(TRPO 的二阶约束的廉价替代),却只用一阶梯度,**好实现、够稳**。

**6)完整 PPO 损失** = 策略项 + 价值项 + 熵正则:

$$
L=\underbrace{-L^{\text{CLIP}}}_{\text{actor}}+\ c_1\underbrace{\|V_\phi(s_t)-R_t\|^2}_{\text{critic 回归}}-\ c_2\underbrace{\mathcal{H}[\pi_\theta]}_{\text{熵(鼓励探索)}}
$$

![[post-ppo-actor-critic.png]]

**在 RLHF 里**:状态=已生成的前缀,动作=下一个 token,奖励= [[083 奖励模型 RM|RM]] 给整段的分(序列末尾)再减去逐 token 的 KL 惩罚 $-\beta\log\frac{\pi_\theta}{\pi_{\text{ref}}}$(把策略拴在 [[081 指令微调 SFT 与数据构造|SFT]] 参考策略附近,防奖励黑客)。显存上要同时放 **actor、critic、RM、ref** 四份模型,这是 PPO 贵的原因,也是 [[086 DPO 直接偏好优化(推导)|DPO]] 想省掉它的动机。

## GAE 完整推导:在偏差与方差间调一个旋钮

优势 $A_t=Q(s_t,a_t)-V(s_t)$ 的样本估计有两个极端:
- **蒙特卡洛**($A_t=\sum_{k\ge0}\gamma^k r_{t+k}-V(s_t)$):无偏,但用了整条轨迹的随机回报 → **方差极大**。
- **单步 TD**($A_t=\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$):方差小,但依赖不准的 $V$ → **有偏**。

**GAE(广义优势估计,Schulman 2015)**用 $\lambda$ 在两者间插值。定义 TD 残差 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$,则
$$A_t^{\text{GAE}(\gamma,\lambda)}=\sum_{l=0}^{\infty}(\gamma\lambda)^l\,\delta_{t+l}.$$
- $\lambda=0$:$A_t=\delta_t$(单步 TD,低方差高偏差)。
- $\lambda=1$:$A_t=\sum\gamma^l\delta_{t+l}=$ 蒙特卡洛优势(无偏高方差)。
- $0<\lambda<1$:指数加权,**近期 $\delta$ 权重大、远期衰减**,在偏差-方差间平滑取舍。RLHF 常用 $\lambda\approx0.95$、$\gamma\approx1.0$(序列短、不太需要折现)。

实现上**从后往前递推**:$A_t=\delta_t+\gamma\lambda A_{t+1}$,一遍 $O(T)$ 算完。

## 重要性采样比为什么必要,以及它的失控

PPO 想用旧策略 $\pi_{\text{old}}$ 采的一批数据**多更新几步**(样本效率),但目标 $J(\theta)=\mathbb{E}_{a\sim\pi_\theta}[\cdot]$ 的期望是在**新策略**下的。重要性采样把期望换到旧策略下:
$$\mathbb{E}_{a\sim\pi_\theta}[A]=\mathbb{E}_{a\sim\pi_{\text{old}}}\Big[\underbrace{\tfrac{\pi_\theta(a)}{\pi_{\text{old}}(a)}}_{r_t(\theta)}A\Big].$$
$r_t$ 就是概率比。但当 $\pi_\theta$ 更新得离 $\pi_{\text{old}}$ 远时,$r_t$ 可能爆到很大/很小,$r_tA$ 方差失控、目标被个别样本主导 → 训飞。这正是 **clip 要把 $r_t$ 拴在 $[1-\varepsilon,1+\varepsilon]$** 的动机:近似一个信赖域,不让一批数据被过度优化。

## KL 散度怎么算:Schulman 的 k1/k2/k3 估计

RLHF 的 KL 惩罚(见 [[085 RLHF 全流程与 KL 约束、奖励黑客|RLHF]])要在采样里估 $\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})$,但只有采样、没有完整分布。设 $\log\text{-ratio}\ \ell=\log\frac{\pi_\theta}{\pi_{\text{ref}}}$:
- **k1**:$\hat{\mathrm{KL}}=\ell$。无偏,但**方差大、可能为负**(KL 应 ≥0)。
- **k2**:$\hat{\mathrm{KL}}=\frac12\ell^2$。低方差但有偏。
- **k3**:$\hat{\mathrm{KL}}=(e^{-\ell}-1)+\ell$。**无偏且恒非负、低方差**——Schulman 推荐的估计,现代 RLHF 实现常用它算 KL 惩罚/监控。
记 k3 这个形式(面试问"RLHF 里 KL 怎么从采样估"能答),它是 $e^x-1-x\ge0$ 的应用。

**三式代数手算**(取 $\ell=0.7$,某个采样点的 log-ratio):
- k1 $=\ell=0.7$;
- k2 $=\tfrac12\ell^2=\tfrac12\times0.49=0.245$;
- k3 $=e^{-0.7}-1+0.7=0.4966-1+0.7=0.1966$。
三者差出一截,但**真正的差异在 $\ell<0$ 时暴露**:取 $\ell=-0.7$,k1 $=-0.7$(KL 估成**负数**,荒谬);k2 仍 $=0.245$;k3 $=e^{0.7}-1-0.7=2.0138-1.7=0.3138$(恒 $\ge0$)。可见 k1 单点可为负、噪声大,k2 恒非负但有偏,**只有 k3 既无偏又恒非负**——这就是现代 RLHF 默认用 k3 估逐 token KL 惩罚的原因。

## value clipping 与 PPO 实战技巧

完整 PPO 还有一堆"让它真能训起来"的细节(面试问"PPO 调不动怎么办"):
- **value clipping**:critic 的回归目标也 clip,防 $V$ 一步更新过大:$L^V=\max[(V-R)^2,(\text{clip}(V,V_{\text{old}}\pm\varepsilon)-R)^2]$。
- **优势标准化**:每个 batch 对 $A_t$ 做 $(A-\mu)/\sigma$,稳定梯度尺度(③ 已提)。
- **多个 epoch / minibatch**:一批 rollout 数据重复更新 K 个 epoch(典型 1-4),这正是引入 $r_t$ 的目的;太多 epoch 会让 $r_t$ 偏太远。
- **熵正则 $c_2$**:鼓励探索,防过早收敛到确定性策略(RLHF 里防多样性塌缩)。
- **学习率 / KL 早停**:KL 超目标值就早停这批更新(防训飞),或用自适应 KL 系数。
- **梯度裁剪**:global norm clip 防梯度爆炸。

**ratio 失控 debug**:若 loss/KL 突然爆,常见原因——优势没标准化、学率太大、$\varepsilon$ 太大、一批 epoch 太多、reward 尺度没归一(见 [[083 奖励模型 RM|RM]])。

## 代码:PPO-clip 目标(❌ vs ✅)

```python
import torch

def ppo_clip_loss(logp_new, logp_old, adv, eps=0.2):
    ratio = torch.exp(logp_new - logp_old)        # r_t = π_θ / π_old(在 log 空间算更稳)

    # ❌ 误区:直接用 ratio * adv 做目标 —— ratio 失控时一步训飞
    # return -(ratio * adv).mean()

    # ✅ PPO:取「未截断」与「截断」的 min,做悲观下界
    unclipped = ratio * adv
    clipped   = torch.clamp(ratio, 1 - eps, 1 + eps) * adv
    return -torch.min(unclipped, clipped).mean()   # 负号:loss 最小化 = 目标最大化

# 优势用 critic 当基线(减方差),实际用 GAE 平滑
# adv = returns - values   # A = Q - V 的样本估计
```

要点:概率比在 **log 空间**算(`exp(logp_new - logp_old)`)更数值稳定;`min` 不能漏(漏了就退化成会训飞的 IS 目标);优势通常**标准化**(减均值除标准差)再用。

## 面试高频

- **PPO 解决了策略梯度的什么问题?** 两个:高方差(用 critic 基线 + 优势)和一步更新过大导致训飞(clip 概率比近似信赖域)。让一批数据能安全地多更新几步,样本效率与稳定性兼得。
- **clip 的 min 为什么必须有?** $\min$ 让目标变成悲观下界:$A>0$ 时 $r$ 超过 $1+\varepsilon$ 不再给额外奖励,$A<0$ 时 $r$ 低于 $1-\varepsilon$ 不再加额外惩罚——双向都挡住过度优化。少了 min 就是普通重要性采样,会爆。
- **actor-critic 里两者分别是什么?** actor=策略 $\pi_\theta$(决定动作);critic=价值 $V_\phi$(估状态预期回报,当基线算优势)。RLHF 里它们常共享骨干、分两个头。
- **优势函数为什么减基线?** $A=Q-V$ 去掉与动作无关的「状态本身好坏」,只留「这个动作相对平均的增量」,期望不变但方差大降。GAE 在偏差-方差间调 $\lambda$。
- **PPO 在 RLHF 里和纯 RL 有何不同?** 奖励来自 RM(非环境),且逐 token 加 KL 惩罚把策略拴在 SFT 附近(防奖励黑客);要同时载 actor/critic/RM/ref 四模型,显存大。
- **GAE 的 $\lambda$ 调什么?** 偏差-方差。$\lambda$=0 是单步 TD(低方差高偏差),$\lambda$=1 是蒙特卡洛(无偏高方差),中间指数加权 TD 残差 $A_t=\sum(\gamma\lambda)^l\delta_{t+l}$,从后往前递推 $A_t=\delta_t+\gamma\lambda A_{t+1}$。RLHF 常 $\lambda$≈0.95、$\gamma$≈1。
- **为什么要重要性采样比 $r_t$?** 想用旧策略采的数据多更新几步(样本效率),但目标期望在新策略下,用 $r_t=\pi_\theta/\pi_{\text{old}}$ 把期望换到旧策略下。$r_t$ 失控会训飞,所以 clip 拴住它。
- **RLHF 里 KL 怎么从采样估?** 用 Schulman 的 k3:$\hat{\mathrm{KL}}=(e^{-\ell}-1)+\ell$($\ell=\log\frac{\pi_\theta}{\pi_{\text{ref}}}$),无偏、恒非负、低方差;k1=$\ell$ 无偏但可能为负,k2=$\frac12\ell^2$ 有偏。
- **PPO 训不稳怎么调?** 优势标准化、value clipping、KL 早停/自适应 KL、梯度裁剪、熵正则、降学率、减每批 epoch、reward 归一。ratio 爆常因优势没标准化或学率太大。
- **PPO vs DPO?** [[086 DPO 直接偏好优化(推导)|DPO]] 把 RM+PPO 合并成一个对偏好对的监督损失,**无需 critic/RM/采样**,更稳更省显存;但 PPO 仍在「在线探索、可验证奖励」(如代码/数学 RL)场景占优,见 [[32 Agentic RL 与训练|Agentic RL]]。

## 关键事实

- Schulman et al.(OpenAI), *Proximal Policy Optimization Algorithms*, 2017,arXiv **1707.06347**:提出 clip 代理目标,默认 $\varepsilon=0.2$;是 TRPO(二阶信赖域)的一阶廉价替代。
- 策略梯度定理:Sutton et al. 2000;REINFORCE:Williams 1992;GAE:Schulman et al. 2015(arXiv 1506.02438)。
- RLHF 用法:状态=前缀,动作=token,奖励=RM 分(末尾)− 逐 token KL;同载 actor/critic/RM/ref 四模型。
- PPO 完整损失 = clip 策略项 + 价值回归项($c_1$) + 熵正则($c_2$,鼓励探索)。
- GAE(Schulman et al., 2015, arXiv:1506.02438):$A_t^{(\gamma,\lambda)}=\sum_l(\gamma\lambda)^l\delta_{t+l}$,$\lambda$ 调偏差-方差;从后往前递推。
- KL 采样估计 k1/k2/k3(Schulman, "Approximating KL Divergence" 博客):k3=$(e^{-\ell}-1)+\ell$ 无偏非负低方差,现代 RLHF 实现常用。
- PPO 实战细节:value clipping、优势标准化、每批多 epoch/minibatch、熵正则($c_2$)、自适应 KL / KL 早停、梯度裁剪;TRL/OpenRLHF 等库内置。
