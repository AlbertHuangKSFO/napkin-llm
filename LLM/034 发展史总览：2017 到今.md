[[034 发展史总览：2017 到今]]:一条从 2017 年 Transformer 到今天推理大模型的主线——理解(BERT 系)与生成(GPT 系)两条路线如何分叉、规模化(Scaling)如何让生成式 decoder-only 最终一统江湖。

## 直觉:一句话串起七年

2017 年 Transformer 用「纯注意力 + 可并行」取代了 RNN,所有后来者都站在它肩上。接着分成两条路:**BERT 用编码器做「理解」**(完形填空式预训练),**GPT 用解码器做「生成」**(接龙式预训练)。一开始 BERT 在刷榜上更亮眼,但 GPT 路线靠**把模型和数据一起放大**,在 GPT-3 上涌现出「看几个例子就会做新任务」的 in-context learning,再叠加 RLHF 对齐变成 ChatGPT,彻底引爆。2023 年起开源浪潮(LLaMA 等)让人人能训,RoPE+RMSNorm+SwiGLU 成为标配;2024 年后进入多模态、长上下文、推理模型时代。

## 例子:同一句话,两条路线怎么学

输入「猫坐在垫子上」:

- **BERT(理解 / 完形填空)**:遮住一个词「猫坐在 [MASK] 上」,让模型用**左右两边**的上下文猜出「垫子」。详见 [[035 BERT：双向编码与 MLM|BERT]]。学到的是双向理解,擅长分类、抽取、检索。
- **GPT(生成 / 接龙)**:给「猫坐在垫子」,让模型**只看左边**预测下一个字「上」。详见 [[036 GPT 系列：自回归与规模化|GPT 系列]]。学到的是逐词生成,擅长写作、对话、推理。

差别就这么简单:**遮中间双向猜 vs 接下一个单向写**。这对应 [[011 Encoder-Decoder、Decoder-Only 与 Encoder-Only|架构三类]] 里的 encoder-only 与 decoder-only,以及 [[056 预训练目标：自回归、掩码与去噪|预训练目标]] 里的掩码 vs 自回归。

**为什么"接龙"最终赢过"完形填空"(样本效率视角)。** 同一句 $L$ 个 token:
- BERT 的 MLM 只遮约 **15%** 的 token、只在被遮处算 loss → 一句话约 $0.15L$ 个监督信号;还要造 `[MASK]`,带来"预训练见 `[MASK]`、微调见不到"的分布不一致。
- GPT 的自回归对**每个**位置都预测下一词 → 一句话约 $L$ 个监督信号,样本效率约高 **6–7 倍**,且训练/推理目标一致(都是续写)。

更高的样本效率 + 天然适配生成与 in-context learning + 规模化收益更大,三者叠加,让 decoder-only 路线在 scaling 时代胜出。BERT 路线没有消失,而是退到 embedding、检索、分类等"只需理解不需生成"的子任务。

## 原理:时间线上的关键节点

**2017 — Transformer**(Vaswani et al.,《Attention Is All You Need》)。抛弃 RNN 的串行递归,用 [[002 自注意力 Self-Attention|自注意力]] 让序列内任意两词直接交互,且整段可并行训练。引入 [[028 位置编码总览：为何 Transformer 需要|位置编码]] 补回顺序信息(原版用 [[029 正弦余弦位置编码(推导)|正弦余弦]])。这是 LLM 一切的地基。

**2018 — 路线分叉**。
- **BERT**(Devlin et al.,arXiv 1810.04805):编码器 + [[035 BERT：双向编码与 MLM|MLM+NSP]],双向、判别式,刷爆 GLUE 等理解任务。
- **GPT-1**(Radford et al.):解码器 + 自回归,生成式预训练 + 下游微调,首次证明「无监督预训练 + 有监督微调」范式。

**2019 — 规模初显**。GPT-2(1.5B)展示 zero-shot 生成;[[037 T5 与 BART：去噪 encoder-decoder|T5]] 把一切任务统一成 text-to-text;RoBERTa 调优 BERT。

**2020 — GPT-3 与 Scaling Law**。GPT-3(175B,arXiv 2005.14165)涌现 **in-context learning**:不更新权重,仅凭提示里的几个示例就能做新任务。同年 Kaplan et al. 提出 [[079 Scaling Law 与 Chinchilla 最优|Scaling Law]],把「更大 = 更强」量化成幂律。

**2022 — 对齐与出圈**。InstructGPT 用 RLHF 让模型听懂指令;ChatGPT(2022 年 11 月)引爆全民关注;DeepMind 的 Chinchilla 修正 Scaling Law,指出多数大模型「训练数据喂得太少」。

**2023 — 开源浪潮**。Meta 的 [[038 LLaMA 架构解剖|LLaMA]] 开源,催生 Alpaca/Vicuna 等;Mistral、Qwen 跟进;GPT-4 发布。架构上 **[[031 RoPE 旋转位置编码(推导与实现)|RoPE]] + RMSNorm + SwiGLU** 成为 decoder-only 标配。

**2024+ — 新维度**。多模态(GPT-4o)、[[107 长上下文推理：YaRN、位置插值与 StreamingLLM|长上下文]](百万 token)、推理模型(o1 等的测试时计算)、MoE 稀疏化、Agent。

**一页时间线速查表(年份背诵用)。**

| 年 | 里程碑 | 一句话意义 |
|---|---|---|
| 2017 | Transformer | 注意力替代 RNN,可并行 + 长程,地基 |
| 2018 | BERT / GPT-1 | 理解(MLM)与生成(自回归)两条路线分叉 |
| 2019 | GPT-2 / T5 / RoBERTa | 规模初显;text-to-text 统一任务 |
| 2020 | GPT-3 / Scaling Law | in-context learning 涌现;幂律量化"更大更强" |
| 2021 | RoPE / ALiBi / Gopher | 相对位置编码成熟;继续 scaling |
| 2022 | InstructGPT / Chinchilla / ChatGPT | RLHF 对齐;数据该喂更多;全民出圈 |
| 2023 | LLaMA / GPT-4 / Mistral / Mamba | 开源浪潮;RoPE+RMSNorm+SwiGLU 标配;SSM 复兴 |

> 一个反直觉的总结:**架构七年没大变**(还是 2017 的 Transformer),真正的飞跃来自规模、数据、对齐和位置编码这些「外围」的持续打磨。

**Scaling Law → Chinchilla 的关键修正(高频考点)。** Kaplan(2020)给出 loss 随参数 $N$、数据 $D$、算力 $C$ 的幂律,并暗示"模型越大越好、数据其次"。Hoffmann 等的 **Chinchilla**(2022)用更系统的实验修正:**在固定算力下,$N$ 和 $D$ 应大致等比例增长**,经验法则约 **每个参数配 ~20 个训练 token**。结论:GPT-3(175B,300B token)其实"参数过大、数据喂太少",而 Chinchilla(70B,1.4T token)用更小模型 + 更多数据反而更强。这直接改变了后续(LLaMA 等)"中等参数 + 海量数据"的训练配方。

## 代码:两条路线的训练目标对照

```python
import torch, torch.nn.functional as F

# ❌ 混淆：用「预测下一个词」的方式去训 BERT，或用「完形填空」去训 GPT —— 目标搞反
# 两者的本质区别只在「能看到哪些位置」和「预测哪些位置」

# ✅ GPT 路线（自回归）：因果掩码，预测每个位置的下一个 token
def gpt_loss(logits, tokens):
    # logits: (B, L, V)；预测位置 t 的目标是 token t+1
    return F.cross_entropy(logits[:, :-1].reshape(-1, logits.size(-1)),
                           tokens[:, 1:].reshape(-1))

# ✅ BERT 路线（掩码）：双向可见，只在被 [MASK] 的位置算 loss
def bert_mlm_loss(logits, tokens, mask_positions):
    # mask_positions: 布尔张量 (B, L)，标记哪些位置被遮
    sel_logits = logits[mask_positions]            # 只取被遮位置
    sel_targets = tokens[mask_positions]
    return F.cross_entropy(sel_logits, sel_targets)

# 同一个 Transformer 主干，换 (掩码策略 + loss 位置) 就在两条路线间切换
```

## 面试高频

- **为什么生成式 decoder-only 赢了?** ① 自回归目标对所有 token 都算 loss,样本效率高;② 天然适配生成、对话、in-context learning;③ 规模化收益更大(Scaling Law),GPT-3 涌现新能力;④ RLHF 对齐让它直接可用。BERT 路线强在理解但不会生成,逐渐退居 embedding/分类等子任务。
- **Transformer 哪点最关键?** 用注意力替代递归 → **可并行 + 长程依赖**,使大规模预训练在工程上可行;没有它就没有后续一切。
- **in-context learning 是什么时候、怎么来的?** GPT-3(2020)涌现,本质是规模化的副产物——不更新权重,靠提示里的示例临时「学会」任务。
- **ChatGPT 相比 GPT-3 多了什么?** 主要是 **RLHF 对齐**(InstructGPT 路线):指令微调 + 人类反馈强化学习,让模型听懂指令、更安全有用,而非单纯更大。
- **现代开源 decoder-only 的「新三件套」?** RoPE(位置)+ RMSNorm(归一化)+ SwiGLU(激活),由 LLaMA 普及。
- **Kaplan 与 Chinchilla scaling law 的核心区别?** Kaplan(2020)偏向"参数优先";Chinchilla(2022)修正为"固定算力下参数与数据等比例增长,约每参数 20 token",指出多数大模型数据喂太少。LLaMA 等据此走"中等参数 + 海量数据"。
- **为什么 BERT 样本效率低于 GPT?** MLM 只遮 15% 且仅在被遮处算 loss(约 $0.15L$ 信号),还有 `[MASK]` 的预训练/微调不一致;自回归对每个位置都算 loss(约 $L$ 信号),目标也与生成一致。
- **架构层面 2017 到今真正变了什么?** 主干没变(还是 Transformer);变的是:位置编码(正弦→RoPE)、归一化(LayerNorm→RMSNorm、Post-LN→Pre-LN)、激活(ReLU/GELU→SwiGLU)、注意力效率(MHA→GQA/MLA + FlashAttention)、稀疏化(Dense→MoE)。
- **推理模型(o1 类)新在哪?** 把算力从"训练时"挪一部分到"测试时"(让模型生成更长的思维链再作答),是继 scaling 参数/数据之后的"第三个 scaling 维度"——测试时计算(test-time compute)。

## 关键事实

- Transformer:Vaswani et al., 2017,《Attention Is All You Need》(NeurIPS 2017,arXiv 1706.03762)。
- BERT:Devlin et al., 2018,arXiv 1810.04805(双向编码器,MLM+NSP)。
- GPT-1:Radford et al., 2018(OpenAI,生成式预训练);GPT-2:2019(1.5B);GPT-3:Brown et al., 2020,arXiv 2005.14165(175B,in-context learning)。
- T5:Raffel et al., 2019/2020(text-to-text);Scaling Law:Kaplan et al., 2020;Chinchilla:Hoffmann et al., 2022。
- InstructGPT:Ouyang et al., 2022(RLHF);ChatGPT 发布 2022 年 11 月。
- LLaMA:Touvron et al., 2023(Meta,开源,普及 RoPE+RMSNorm+SwiGLU)。
- 主线:架构稳定(仍是 2017 Transformer),突破来自规模 + 数据 + 对齐 + 位置编码,生成式 [[011 Encoder-Decoder、Decoder-Only 与 Encoder-Only|decoder-only]] 路线最终主导。
