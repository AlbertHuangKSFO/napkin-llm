[[056 预训练目标：自回归、掩码与去噪|预训练目标]] 讲的是预训练时「让模型做什么填空题」的三大流派:**自回归(预测下一个词,GPT)、掩码(完形填空,BERT)、去噪(还原被损坏的连续片段,T5)**。目标不同,决定了模型擅长生成还是理解、样本效率高低,以及今天为何 LLM 几乎清一色走自回归。

## 直觉

预训练就是给模型设计一道**自监督填空题**:从无标注文本里自动造出「输入—答案」,让模型反复猜。三种造法:

1. **自回归(GPT)**:把句子从左到右,**每个位置都预测它的下一个词**。用 [[007 因果掩码与 padding 掩码|因果掩码]] 保证只看左边,看不到右边。天生适合生成(预测对了接上去,继续预测)。见 [[036 GPT 系列：自回归与规模化|GPT]]。
2. **掩码(BERT)**:随机遮住约 15% 的词,让模型**用双向上下文**还原被遮的。像做完形填空,理解能力强,但**不直接会生成**(它不建模逐词生成概率)。见 [[035 BERT：双向编码与 MLM|BERT]]。
3. **去噪 / span 损坏(T5)**:遮住的不是单个词,而是**连续的一段**(span),用一个哨兵 token 占位,让解码端**自回归地还原整段**。介于前两者之间:编码器双向看输入,解码器自回归生成被损坏的片段。见 [[037 T5 与 BART：去噪 encoder-decoder|T5、BART]]。

一句话:**自回归=接龙(会生成)、掩码=完形填空(会理解)、去噪=补整段(seq2seq 转换)。**

## 例子

用同一句「猫坐在垫上」演示三种目标喂给模型的样子。

**① 自回归(GPT)**——整体左移一位对齐:
```
输入：  猫  坐  在  垫
目标：  坐  在  垫  上
```
每个位置都有监督信号(4 个),只能看左侧。生成时把上一步输出接回输入循环。

**② 掩码(BERT)**——随机遮 15%:
```
输入：  猫 [MASK] 在 [MASK] 上
目标：     坐         垫
```
只有被遮的 2 个位置算 loss,但能用左右双向上下文还原。

**③ 去噪(T5)**——遮整段、哨兵占位:
```
输入：  猫 <X> 垫 <Y>             （两个连续 span 各用一个唯一哨兵）
目标：  <X> 坐 在 <Y> 上 <Z>       （依序恢复两个 span；<Z> 是结束哨兵）
```
这里 `<X>`、`<Y>` 不可复用为同一个 token:它们标出两个不同 span 的边界。`<Z>` 对应最后一个空边界,让目标有可解析的终点(随后仍可接模型的 EOS)。目标序列只含损坏片段及边界,span 平均长约 3。

![[train-三种预训练目标.png]]

**一个关键数字对比**:同样一段 $T$ 个 token 的文本,GPT 对**每个**位置都算 loss($T$ 个监督信号),BERT 只对 15% 被遮位算($0.15T$ 个)。所以**同样的数据,自回归提供约 6 倍的监督信号** → 样本效率更高。这是大规模下生成式路线更划算的关键原因之一。

## 原理

**1. 自回归(因果 LM)。** 用链式法则把整句联合概率拆成逐词条件,最大化似然 = 最小化 [[30 交叉熵与负对数似然|交叉熵]]:

$$p(x_1,\dots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t}),\qquad \mathcal{L}_{\text{AR}}=-\sum_{t=1}^{T}\log p(x_t\mid x_{<t})$$

每个 $t$ 都贡献一项 loss(实现细节见 [[060 训练目标与 loss 实现|loss 实现]])。

**2. 掩码 LM(MLM)。** 设遮罩位置集合 $M$(约 15%),只在这些位上算 loss,且**双向**可见:

$$\mathcal{L}_{\text{MLM}}=-\sum_{t\in M}\log p(x_t\mid x_{\setminus M})$$

代价:① 只 15% 位贡献监督 → 样本效率低;② 训练时见 `[MASK]`、推理时见不到,造成**预训练—微调不匹配**(BERT 用 80/10/10 策略缓解);③ 各遮位**独立预测**,无法建模被遮 token 之间的依赖。

**3. 去噪 / span 损坏(T5)。** 设按原文顺序的被遮 span 为 $s_0,\ldots,s_{m-1}$,为每个 span 分配不同哨兵 $z_0,\ldots,z_{m-1}$,再额外保留结束哨兵 $z_m$。输入以 $z_i$ 替换 $s_i$,目标是自回归地还原:

$$y=z_0\Vert s_0\Vert z_1\Vert s_1\Vert\cdots\Vert z_{m-1}\Vert s_{m-1}\Vert z_m$$

$$\mathcal{L}_{\text{T5}}=-\sum_{t=1}^{|y|}\log p(y_t\mid y_{<t},\tilde{x})$$

例如原 token 为 $[10,11,12,13,14]$,遮 $s_0=[11,12]$ 与 $s_1=[14]$,取 $z_0=32000,z_1=31999,z_2=31998$。则 $\tilde{x}=[10,z_0,13,z_1]$,而 $y=[z_0,11,12,z_1,14,z_2]$。其中每个 span 都有自己的锚点,最后的 $z_2$ 明确结束 span 列表。它让 span 内 token 自回归生成(有 intra-span 依赖)、目标只含损坏片段(序列短);同时保留编码器的双向理解。

**4. 为什么现代 LLM 几乎都选自回归?**
- **样本效率**:每步全 token 算 loss(≈6 倍监督)。
- **天生会生成**:推理即「预测下一个词」,无缝对接对话/续写。
- **规模化涌现**:在自回归 decoder-only 上放大,会涌现 in-context learning(见 [[036 GPT 系列：自回归与规模化|GPT]]、[[079 Scaling Law 与 Chinchilla 最优|Scaling Law]])。
- **无预训练—推理不匹配**:不像 MLM 训练见 `[MASK]`、推理见不到。

理解任务(分类、检索)BERT 类双向编码仍有优势;转换任务(翻译、摘要)T5/BART 仍常用。但**通用大模型**=自回归。

**5. 6 倍监督信号从哪来(把数字推一遍)。** 一段 $T$ token 的文本:GPT 对位置 $1..T-1$ 每个都算一项 loss,有效监督 $\approx T$;BERT 只遮 15%,其中真正替换成 `[MASK]` 的是 $0.8\times0.15T=0.12T$、随机替换 $0.015T$、保持不变 $0.015T$,但**只有这 $0.15T$ 个位置进 loss**,且每个位还得用上下文「猜一个」。所以 GPT/BERT 的监督密度比 $\approx T/(0.15T)\approx6.7$。这意味着同样烧完一遍语料,自回归从每个 token 都学到信号,MLM 浪费了 85% 的位置——大规模下这是巨大的效率差。

**6. BERT 的 80/10/10 为什么这么设。** 被选中的 15% 里:**80% 换 `[MASK]`**(主任务)、**10% 换随机词**、**10% 保持原词不变**。后两者是为缓解「训练见 `[MASK]`、推理见不到」的不匹配:若 100% 都换 `[MASK]`,模型会**只在看到 `[MASK]` 时才努力**、对非掩码位的表示偷懒;掺入「随机词」逼它对每个 token 都保持怀疑(可能是被改过的)、掺入「不变」让它对正常 token 也产生有用表示。这是 MLM 的工程补丁,不是理论必然。

**7. PrefixLM 与 UL2:统一两端。** 自回归(因果)和双向不是非此即彼。**PrefixLM**(前缀语言模型):序列前一段(prefix/上下文)用**双向**注意力,后一段(待生成)用**因果**——既能双向理解输入,又能自回归生成输出,T5 的解码其实接近这种思路。**UL2**(Tay 等 2022)更进一步,把「不同长度/比例的去噪」混成一组任务(R/S/X-denoiser),用 mode token 切换,试图一个模型同时擅长理解与生成。它们说明:目标设计是个连续谱,不止三个点。

**8. FIM(Fill-in-the-Middle):自回归也能「中间填空」。** 代码补全要根据**上下文两侧**填中间,但自回归只看左边。FIM(OpenAI 2022)的技巧:训练时把文档随机切成 `prefix / middle / suffix` 三段,重排成 `<PRE> prefix <SUF> suffix <MID> middle` 再做**普通自回归**——模型在 `<MID>` 后生成 middle 时,prefix 和 suffix 都已在左侧上下文里。于是**不改自回归架构**就获得了「看两侧填中间」的能力,Code Llama、StarCoder 等都用。这是「用数据重排扩展目标能力」的经典案例。

## 代码

```python
import torch, torch.nn.functional as F

# ① 自回归 loss：每个位置都算，左移对齐（GPT）
def ar_loss(logits, tokens):                 # logits:(B,L,V)  tokens:(B,L)
    shift_logits = logits[:, :-1, :].reshape(-1, logits.size(-1))
    shift_labels = tokens[:, 1:].reshape(-1)  # 目标是「下一个」token
    return F.cross_entropy(shift_logits, shift_labels)   # 全部位置贡献 loss

# ② MLM loss：只对被遮位置算（BERT），其余用 -100 屏蔽
def mlm_loss(logits, labels):                # labels 里非遮位设为 -100
    return F.cross_entropy(logits.reshape(-1, logits.size(-1)),
                           labels.reshape(-1), ignore_index=-100)  # 仅 ~15% 位有效

# ③ span 损坏：构造 T5 风格的 (输入, 目标)
# spans 是已采样、已排序且互不重叠的 [start, end)；采样策略与序列化分开，便于测试。
def make_span_corruption(token_ids, spans, sentinel_base=32000):
    inp, tgt, cursor = [], [], 0
    for k, (start, end) in enumerate(spans):
        assert cursor <= start < end <= len(token_ids)
        sentinel = sentinel_base - k                  # 每个连续 span 一个 unique sentinel
        inp.extend(token_ids[cursor:start]); inp.append(sentinel)
        tgt.append(sentinel); tgt.extend(token_ids[start:end])
        cursor = end
    inp.extend(token_ids[cursor:])
    tgt.append(sentinel_base - len(spans))            # 结束 sentinel：空的最后边界
    return inp, tgt

inp, tgt = make_span_corruption([10, 11, 12, 13, 14], [(1, 3), (4, 5)])
assert inp == [10, 32000, 13, 31999]
assert tgt == [32000, 11, 12, 31999, 14, 31998]
```

```python
#    MLM 各遮位独立预测，不建模逐词生成概率，硬采样会前后矛盾
# ❌ 误区二：以为三者样本效率一样
#    GPT 每步全 token、MLM 仅 15%、T5 仅损坏片段 → 监督信号密度差很大
# ✅ 经验：要生成/通用 → 自回归；要理解/分类 → 掩码；要转换/seq2seq → 去噪
```

```python
# —— FIM:用数据重排让自回归学会「看两侧填中间」(PSM 模式) ——
import random
PRE, SUF, MID = "<PRE>", "<SUF>", "<MID>"
def make_fim(doc_tokens, p=0.5):
    if random.random() > p:
        return doc_tokens                      # 一半样本保持普通自回归
    n = len(doc_tokens)
    a, b = sorted(random.sample(range(n), 2))  # 随机两个切点
    prefix, middle, suffix = doc_tokens[:a], doc_tokens[a:b], doc_tokens[b:]
    # PSM 重排:模型在 <MID> 后生成 middle 时,prefix+suffix 都在左侧上下文
    return [PRE]+prefix + [SUF]+suffix + [MID]+middle

doc = list("def add(a,b): return a+b")
print("".join(make_fim(doc, p=1.0)))
# ❌ 误以为要换双向架构才能中间填空;✅ 仅重排数据 + 普通自回归即可(Code Llama/StarCoder)

# —— 监督密度对比(手算 6 倍) ——
T = 1000
print("GPT 有效 loss 位 ≈", T-1)          # 每个位置都算
print("BERT 有效 loss 位 ≈", int(0.15*T)) # 只 15%
print("监督密度比 ≈", round((T-1)/(0.15*T), 1))  # ≈6.7
```

## 面试高频

- **Q:三种预训练目标各是什么、各擅长什么?** A:自回归(GPT)预测下一个词、因果掩码、天生会生成,擅长生成/对话;掩码(BERT)双向还原被遮 15%,擅长理解/分类;去噪(T5)还原被损坏的连续 span、encoder 双向+decoder 自回归,擅长翻译/摘要等转换。
- **Q:自回归 vs MLM 的样本效率差别从哪来?** A:GPT 对每个 token 都算 loss,BERT 只对 15% 被遮位算 → 同样数据 GPT 监督信号约 6 倍,大规模下更划算。
- **Q:MLM 有什么缺点?** A:① 仅 15% 位贡献 loss(效率低);② 训练见 `[MASK]`、推理见不到(预训练—微调不匹配);③ 各遮位独立预测,不建模被遮 token 间依赖。
- **Q:T5 的 span corruption 比 MLM 好在哪?** A:遮整段并让解码端自回归还原 → 有 span 内依赖、目标序列短(只含损坏片段、算力省),同时保留 encoder 双向理解,介于 BERT 与 GPT 之间。
- **Q:T5 的 sentinel 为什么必须唯一、为什么目标还要一个结束 sentinel?** A:第 $i$ 个唯一 sentinel 把输入中被遮的第 $i$ 个连续 span 与目标中的恢复片段对齐；目标末尾再给一个未承载文本的 sentinel,使 span 列表有无歧义终点。复用同一个 sentinel 会丢掉“这一段对应哪一处”的边界信息。
- **Q:为什么今天的大模型几乎都用自回归?** A:样本效率高(全 token 算 loss)+ 天生会生成 + 规模化下涌现 in-context learning + 无预训练-推理不匹配 → 通用性最强。理解类任务 BERT 仍有用武之地。
- **Q:BERT 的 80/10/10 掩码策略为什么不全用 `[MASK]`?** A:全用 `[MASK]` 会让模型只在看到掩码时努力、对正常 token 偷懒,且加剧训练-推理不匹配(推理无 `[MASK]`);掺 10% 随机词逼它怀疑每个 token、10% 不变让它对正常词也学有用表示。
- **Q:PrefixLM、UL2 是什么?** A:PrefixLM 让前缀双向、生成段因果,兼顾理解与生成;UL2 把不同比例/长度的去噪混成一组任务(R/S/X)用 mode token 切换,想一个模型同时强于理解与生成。说明目标是连续谱,不止三点。
- **Q:自回归模型怎么做代码「中间填空」?** A:FIM——训练时把文档切成 prefix/middle/suffix 三段重排成 `<PRE>p<SUF>s<MID>m` 再做普通自回归,生成 middle 时两侧上下文都在左边。不改架构,仅靠数据重排;Code Llama、StarCoder 采用。
- **陷阱**:别把 BERT 当生成器;别以为「双向」一定更强——双向换来理解、牺牲生成与样本效率;FIM 只是数据重排、不是新架构;BERT 各遮位独立预测,别指望它建模被遮 token 间依赖。

## 关键事实

- 自回归预训练:GPT 系列(Radford et al. 2018/2019;Brown et al. 2020, arXiv:2005.14165),目标 $\prod_t p(x_t\mid x_{<t})$,见 [[036 GPT 系列：自回归与规模化|GPT]]。
- 掩码语言模型(MLM):**BERT(Devlin et al. 2018, arXiv:1810.04805)**,随机遮 15%(80% `[MASK]`/10% 随机词/10% 不变),双向编码,见 [[035 BERT：双向编码与 MLM|BERT]]。
- 去噪 / span 损坏:**T5(Raffel et al. 2019, arXiv:1910.10683; JMLR 2020, Table 2)**,连续 span 在每个样本内由不同 sentinel 替换；目标按 span 顺序串联“sentinel + 原 span”,并以额外 sentinel 结束。其默认实验设遮约 15%、平均 span 长 3;**BART(Lewis et al. 2019, arXiv:1910.13461)** 用 text infilling 等多种噪声。见 [[037 T5 与 BART：去噪 encoder-decoder|T5、BART]]。
- 样本效率:自回归每步全 token 算 loss,约为 MLM(仅 15%)的 6 倍监督信号密度,是生成式路线大规模胜出的原因之一。
- 规模化涌现:自回归 decoder-only 放大后涌现 in-context learning(GPT-3),见 [[079 Scaling Law 与 Chinchilla 最优|Scaling Law]]。
- 损失度量统一为 [[30 交叉熵与负对数似然|交叉熵 / 负对数似然]],评估用 [[32 困惑度 Perplexity|困惑度]];实现细节见 [[060 训练目标与 loss 实现|loss 实现]]。
