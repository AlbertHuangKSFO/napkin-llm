[[075 参数量逐层手算(GPT 全拆)]]:把一个 GPT 的参数量**逐层拆开手算**——嵌入 = V·d,每层注意力 ≈ 4d²、FFN ≈ 8d²,单层 ≈ 12d²,全模型 ≈ 12·L·d² + 嵌入;这是 MLE 面试的高频"白板题",拆得清楚才能进一步算显存与算力。

## ① 直觉:参数就藏在几个矩阵里,数清矩阵的行×列就行

"这个模型有多少参数"听起来玄,其实参数就是**那几个权重矩阵里的数**,数清每个矩阵的形状(行 × 列),全加起来就是答案。GPT(decoder-only,见 [[036 GPT 系列：自回归与规模化]])的参数只来自三类地方:

1. **嵌入层**:把 token id 查成 d 维向量的查找表,大小 = 词表 V × 维度 d;还有位置嵌入(若用可学习位置编码)n_ctx × d。
2. **每个 Transformer 层**里的两块:**注意力**的 Q、K、V、O 四个投影矩阵,和 **FFN** 的两个矩阵(升维 + 降维)。
3. 一些**零头**:LayerNorm 的 γ、β,各种偏置 bias——量很小,估算时常忽略。

记住三个"魔法数",白板题就能秒答:

- 每层**注意力** ≈ **4d²**(Q、K、V、O 四个 $d\times d$ 矩阵)。
- 每层 **FFN** ≈ **8d²**(升维 $d\to 4d$ 再降维 $4d\to d$,即 $4d^2+4d^2$,见 [[008 前馈网络 FFN(为何 4 倍、为何两层)]])。
- 单层合计 ≈ **12d²**,L 层就是 **12·L·d²**,再加嵌入 V·d。

## ② 例子:手算 GPT-2 small(L=12,d=768,V=50257)

逐项算,单位百万(M):

**嵌入(只算一次,不随层数变)**
- token 嵌入:$V\cdot d = 50257\times 768 = 38{,}597{,}376 \approx 38.6\text{M}$
- 位置嵌入:$n_{ctx}\cdot d = 1024\times 768 = 786{,}432 \approx 0.79\text{M}$

**每一层(×12)**
- 注意力 QKVO:$4d^2 = 4\times 768^2 = 4\times 589{,}824 = 2{,}359{,}296 \approx 2.36\text{M}$
- FFN:$8d^2 = 8\times 589{,}824 = 4{,}718{,}592 \approx 4.72\text{M}$
- 2 个 LayerNorm + 偏置:约 $6d \approx 0.005\text{M}$(忽略级)
- **单层合计** $\approx 12d^2 = 12\times 589{,}824 = 7{,}077{,}888 \approx 7.08\text{M}$

**汇总**
- 12 层:$12\times 7.08 = 84.9\text{M}$(非嵌入参数)
- 加 token + 位置嵌入:$84.9 + 38.6 + 0.79 \approx 124.3\text{M}$

得到 **≈ 124M**,与官方 GPT-2 small 的 124M 完全吻合(早期口径 117M 是漏算了一部分)。

注意一个易错点:GPT-2 用 [[016 输出层、tied embedding 与 logits|tied embedding]](weight tying),输出层 lm_head 直接**复用** token 嵌入矩阵,**不额外占参数**——否则会多算一份 38.6M。

![[param-GPT2参数逐层表.svg]]

**为什么大模型几乎只看 12·L·d²**:嵌入 V·d 是**线性**于 d,而每层是**平方**于 d。GPT-2(d=768)嵌入占 31%;到了 LLaMA-7B(d=4096),嵌入 $32000\times4096\approx131\text{M}$ 只占 1.9%,12·L·d² 主导一切。

![[param-参数堆叠饼图.svg]]

## ③ 原理:每个矩阵形状的来历,以及偏置/LN 的零头

**注意力 4d² 怎么来**。多头注意力(见 [[005 多头注意力 Multi-Head]])里 Q、K、V 三个投影把输入 $d$ 维分别映到 $d$ 维(所有头拼起来仍是 d),输出投影 O 再从 $d$ 映回 $d$。四个矩阵都是 $d\times d$:

$$
P_{\text{attn}} = \underbrace{d^2}_{W_Q}+\underbrace{d^2}_{W_K}+\underbrace{d^2}_{W_V}+\underbrace{d^2}_{W_O} = 4d^2
$$

(GQA/MQA 会让 K、V 投影变小,见 [[019 GQA 分组查询注意力]],此处按标准 MHA 算。)

**FFN 8d² 怎么来**。两层:升维 $W_1\in\mathbb{R}^{4d\times d}$、降维 $W_2\in\mathbb{R}^{d\times 4d}$:

$$
P_{\text{ffn}} = 4d\cdot d + d\cdot 4d = 8d^2
$$

(SwiGLU 多一个门控矩阵但把隐藏维收窄到 ≈8/3·d 以对齐参数,仍约 8d²。)

**单层与全模型**:

$$
P_{\text{layer}} \approx 4d^2 + 8d^2 = 12d^2,\qquad
P_{\text{total}} \approx \underbrace{12\,L\,d^2}_{\text{非嵌入}} + \underbrace{V\,d}_{\text{嵌入}}
$$

**零头(精确版要加)**:每层 2 个 LayerNorm 各贡献 $2d$(γ、β),偏置若开则注意力 $4d$、FFN $5d$(含 $4d$ 的中间偏置 + $d$),共约 $6d\sim13d$/层;末端还有一个 final LayerNorm $2d$。这些都是 $O(d)$,相对 $O(d^2)$ 可忽略,但白板题被追问"还漏了啥"时要能答出来。

**验证 12·L·d² 的威力**:GPT-3 175B(L=96,d=12288)→ $12\times96\times12288^2 = 1.74\times10^{11} = 174\text{B}$,几乎就是 175B(差的是嵌入和零头)。这个公式直接喂给 [[077 训练 FLOPs 与 6ND 法则]] 和 [[076 显存占用估算(参数、梯度、优化器、激活、KV)]]。

## ⑤ 复现 GPT-2 全系列与 LLaMA-7B(把公式用到底)

**GPT-2 四个尺寸**(都用 V=50257, n_ctx=1024, tied embedding,非嵌入 ≈ 12Ld²):

| 型号 | L | d | 非嵌入 12Ld² | token 嵌入 Vd | 位置嵌入 | 合计 | 官方 |
|---|---|---|---|---|---|---|---|
| small | 12 | 768 | 84.9M | 38.6M | 0.79M | **124.3M** | 124M |
| medium | 24 | 1024 | 302M | 51.5M | 1.05M | **354M** | 355M |
| large | 36 | 1280 | 708M | 64.3M | 1.31M | **774M** | 774M |
| xl | 48 | 1600 | 1.475B | 80.4M | 1.64M | **1.557B** | 1.5B |

四个尺寸全部用 `12Ld² + Vd + n_ctx·d` 复现到 1% 以内——这就是这套公式的威力。

**LLaMA-7B 逐层手算**(L=32, d=4096, V=32000,RoPE 无位置嵌入,SwiGLU,GQA 此处按 MHA 近似):
- 注意力 QKVO:$4d^2=4\times4096^2=67.1$M/层。
- FFN(SwiGLU 三矩阵,中间维 $d_{ff}=11008$):$3\times d\times d_{ff}=3\times4096\times11008=135$M/层(SwiGLU 用 gate+up+down 三个矩阵,中间维收窄到约 $\frac{8}{3}d$ 以对齐 2 矩阵的 8d²;LLaMA 实际取 11008)。
- 单层 $\approx 67+135=202$M;×32 层 $=6.47$B(非嵌入)。
- token 嵌入 $Vd=32000\times4096=131$M(占 2%);无位置嵌入。
- **合计 $\approx 6.47+0.13=6.6$B**,贴近官方 6.7B(差的是 LayerNorm 零头 + GQA 让 KV 投影更小)。

注意 LLaMA 的 FFN 比"8d²"略大,因为 SwiGLU 用三个矩阵;但社区仍粗略用"非嵌入 ≈ 12Ld²"做量级估算,精确值要按 $d_{ff}$ 实算。

## ⑥ GQA/MQA、SwiGLU、MoE 的精确修正

把"4d²/8d²/12d²"按现代架构修正,面试追问"LLaMA 不是标准 Transformer,公式还成立吗"时用:

- **GQA/MQA**(见 [[019 GQA 分组查询注意力]]):Q 投影仍 $d^2$,但 K、V 投影只到 $n_{kv}$ 组的维度。设 Q 头 $n_h$、KV 组 $n_{kv}$、头维 $d_h=d/n_h$,则 KV 投影各 $d\times(n_{kv}d_h)$。注意力参数 $=\underbrace{d^2}_{Q}+\underbrace{2\,d\,n_{kv}d_h}_{K,V}+\underbrace{d^2}_{O}$。MQA($n_{kv}=1$)把 KV 投影砍到 $2d\cdot d_h$,远小于标准的 $2d^2$。
- **SwiGLU**(见 [[008 前馈网络 FFN(为何 4 倍、为何两层)]]):三个矩阵(gate、up 各 $d\times d_{ff}$,down $d_{ff}\times d$),$P_{\text{ffn}}=3\,d\,d_{ff}$。为对齐标准 FFN 的 8d² 参数量,$d_{ff}$ 收窄到 $\approx\frac{8}{3}d\approx2.67d$(故 LLaMA $d_{ff}=11008\approx2.7\times4096$)。
- **MoE**(见 [[049 专家并行 EP 与 MoE 部署]]):总参数 = 共享部分 + $E$ 个专家 FFN($E\times 8d^2$),但**激活参数**只算 top-k 个专家($k\times 8d^2$)。所以 MoE"总参数大、激活参数小":Mixtral-8×7B 总参 **46.7B**,每 token 只激活 **≈12.9B**(top-2 专家,Jiang 等,2024,arXiv:2401.04088)——6ND 算力按**激活参数**算,显存按**总参数**算,这是 MoE 的核心账(易错点)。

## ④ 代码:一行公式估算 + 逐层精确累加

```python
def gpt_params(V, d, L, n_ctx, ffn_mult=4, tie_emb=True, with_bias=True):
    tok_emb = V * d                       # token 嵌入查找表
    pos_emb = n_ctx * d                   # 可学习位置嵌入(RoPE 则为 0)
    attn = 4 * d * d                      # 每层 Q,K,V,O 四个 d×d
    ffn  = 2 * ffn_mult * d * d           # 每层 升维+降维 = 8d²(mult=4)
    ln   = 2 * (2 * d)                    # 每层 2 个 LayerNorm 的 γ,β
    bias = (4 * d + ffn_mult * d + d) if with_bias else 0
    per_layer = attn + ffn + ln + bias
    total = tok_emb + pos_emb + L * per_layer + 2 * d   # +末端 final LN
    if not tie_emb:                       # 不绑定则 lm_head 再占一份 V·d
        total += V * d
    return total

# ❌ 错:只用嵌入估全模型,或忘了 FFN 是注意力的两倍
wrong = 12 * 12 * 768 * 768               # 漏了嵌入 → 84.9M,少了 1/3
print(f"只数层(漏嵌入): {wrong/1e6:.1f}M")

# ✅ 对:逐项精确累加
n = gpt_params(V=50257, d=768, L=12, n_ctx=1024)
print(f"GPT-2 small: {n/1e6:.1f}M")       # ≈ 124.4M,与官方 124M 吻合

# 快速心算法:非嵌入 ≈ 12·L·d²,大模型直接用这个
quick = 12 * 12 * 768**2 + 50257*768 + 1024*768
print(f"快算: {quick/1e6:.1f}M")          # ≈ 124.3M
```

## 面试高频

- **Q:手推 Transformer 单层参数量。** 注意力 Q/K/V/O 各 $d\times d$ = 4d²;FFN 升维降维 = 8d²;合计 ≈ 12d²(LN、偏置是 $O(d)$ 零头)。
- **Q:GPT-2 small 多少参数,怎么算的?** 12 层 × 12d²(d=768)= 84.9M 非嵌入,加 token 嵌入 V·d=38.6M、位置嵌入 0.79M ≈ 124M。
- **Q:为什么大模型里嵌入占比可忽略?** 嵌入 V·d 线性于 d,层参数 12·L·d² 平方于 d;d 越大,$Vd/(12Ld^2)\propto V/(12Ld)$ 越小,GPT-2 占 31%、7B 仅 1.9%。
- **Q:FFN 和注意力哪个参数多?** FFN(8d²)是注意力(4d²)的 2 倍,约占每层 2/3,是模型主要的"知识"存储(见 [[008 前馈网络 FFN(为何 4 倍、为何两层)]])。
- **Q:tied embedding 影响参数量吗?** 输出层复用输入嵌入矩阵,省一份 V·d;若不绑定,GPT-2 会多 38.6M。
- **Q:GQA/MQA、SwiGLU 会改变这个估算吗?** GQA/MQA 缩小 K、V 投影(注意力 < 4d²);SwiGLU 多一矩阵但收窄隐藏维,总量仍 ≈ 8d²/层——量级不变,精确值要按实际配置调。
- **Q:手算 LLaMA-7B 参数量。** L=32, d=4096:注意力 4d²=67M/层,SwiGLU FFN $3\times4096\times11008=135$M/层,单层 202M,×32=6.47B 非嵌入;加 token 嵌入 $32000\times4096=131$M、无位置嵌入,合计 ≈6.6B,贴近官方 6.7B。
- **Q:MoE 的参数量怎么算,算力和显存分别按哪个?** 总参 = 共享 + $E\times$专家FFN;激活参 = 共享 + top-k 专家。Mixtral-8×7B 总 46.7B、激活 ≈12.9B。**6ND 算力按激活参数,显存按总参数**——这是 MoE"省算力不省显存"的根本。
- **Q:SwiGLU 为什么仍约 8d²?** 三个矩阵(gate/up/down)共 $3d\cdot d_{ff}$,把 $d_{ff}$ 从 4d 收窄到 ≈8/3·d 以对齐标准 FFN 的 8d²(LLaMA 取 11008≈2.7×4096),量级不变。

## 关键事实

- 参数公式 注意力 4d²、FFN 8d²、单层 ≈ 12d²、全模型 ≈ 12·L·d² + Vd,是社区标准估算口径(Kaplan et al., 2020, arXiv:2001.08361 用非嵌入参数 N ≈ 12·L·d² 定义 scaling law)。
- GPT-2 small 官方 124M(L=12, d=768, V=50257, n_ctx=1024);GPT-2 系列还有 medium 355M、large 774M、xl 1.5B,均可用本公式复现(Radford et al., 2019,《Language Models are Unsupervised Multitask Learners》)。
- GPT-2 使用 weight tying / tied embedding(Press & Wolf, 2017, arXiv:1608.05859),lm_head 复用 token 嵌入矩阵,省一份 V·d。
- 标准 FFN 升维倍数 4×、隐藏维 d_ff=4d 出自《Attention Is All You Need》(Vaswani et al., 2017);SwiGLU 把隐藏维设为 ≈8/3·d 以对齐参数(Shazeer, 2020, arXiv:2002.05202)。
- 验证:12·L·d² 套 GPT-3(L=96, d=12288)得 174B,贴近官方 175B 总参数(Brown et al., 2020, arXiv:2005.14165)。
- GPT-2 全系列(small 124M / medium 355M / large 774M / xl 1.5B)均可用 12Ld²+Vd 复现到 1% 以内(L,d 依次 12/768、24/1024、36/1280、48/1600)。
- LLaMA-7B:L=32, d=4096, V=32000, $d_{ff}$=11008, SwiGLU, RoPE(无位置嵌入),官方 6.7B(Touvron et al., 2023, arXiv:2302.13971)。
- Mixtral-8×7B:8 专家 top-2,总参 46.7B、激活参 ≈12.9B(Jiang et al., 2024, arXiv:2401.04088);MoE 算力按激活参、显存按总参。
- SwiGLU 三矩阵 $3d\cdot d_{ff}$、$d_{ff}\approx\frac{8}{3}d$ 对齐 8d²(Shazeer, 2020, arXiv:2002.05202);GQA/MQA 缩小 KV 投影(Ainslie et al., 2023, arXiv:2305.13245)。
