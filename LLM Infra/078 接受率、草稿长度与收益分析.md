[[078 接受率、草稿长度与收益分析|投机解码的收益分析]] 是把 [[073 投机解码系统：draft-verify 全流程|draft-verify]] 的加速量化成两个旋钮的函数:**逐位接受率** $\alpha$ 和**草稿长** $k$。核心结论:每轮 draft-verify 的期望接受 token 数 $\frac{1-\alpha^{k+1}}{1-\alpha}$ 随 $k$ **饱和于上限** $\frac{1}{1-\alpha}$;而草稿成本随 $k$ **线性增长**。两者博弈出一个**最优草稿长 $k^\*$**:$\alpha$ 高时 $k^\*$ 大、收益高;$\alpha$ 低时 $k^\*$ 小(2–4),开长草稿纯亏。这套分析还必须接上 [[004 算力 vs 带宽：Roofline 与算术强度|roofline]]:投机解码本质是把 [[014 Decode 阶段：访存受限|访存受限]] 时**闲置的算力**用起来——验证 k 个 token 几乎不增量搬权重。所以收益不只取决于 $\alpha$、$k$,还取决于**当前是否有闲置算力**(小 batch 才有,见 [[079 投机解码与连续批、前缀缓存的兼容|与连续批兼容]])。它统一解释了 [[074 EAGLE-3：工业标准投机解码|EAGLE]]、[[075 Medusa 与多头草稿|Medusa]]、[[077 多 token 预测 MTP(DeepSeek)|MTP]] 为何收益不同——都是 $\alpha$ 与草稿成本之差。

## 直觉

**生活类比**:实习生草稿的单句**采纳率 70%**。但被采纳要"前面全对":第 1 句中 **70%**,连中前 2 句 **0.7×0.7=49%**,前 3 句 **34%**,前 4 句 **24%**,前 5 句只剩 **17%**——**写越长越容易中途翻车**。所以"平均能省几趟"有个**天花板 = 1 ÷ (1 − 采纳率)**:采纳率 50% 天花板才 **2 趟**(写再长也白搭),70% 约 **3.3 趟**,90% 高达 **10 趟**(才值得让实习生写长)。另一头,实习生每多写一句都花时间(成本线性涨,不饱和)。两边一算账:采纳率 70% 写 **4 句**左右最划算,采纳率 50% 只写 **2 句**、再多纯亏——采纳率高才值得开长草稿。

![[spec-078类比草稿越长越翻车.png]]

把一轮 draft-verify 想成"实习生连写 k 个词,主编从左往右核对,碰到第一个错就停"。接受到第 $i$ 个词需要前 $i$ 个词全对,概率 $\alpha^i$——所以**越往后越难连对**,期望接受长度是个**衰减几何级数**,加得再多也逼近一个天花板 $\frac{1}{1-\alpha}$。

天花板由 $\alpha$ 决定:$\alpha=0.5$ 时天花板只有 2(开再长草稿也白搭);$\alpha=0.9$ 时天花板高达 10(值得开长草稿)。

![[spec-078接受截断.png]]

另一头,实习生每多写一个词都要花时间(草稿成本随 $k$ 线性涨)。所以最优草稿长 $k^\*$ 是"**收益曲线斜率 = 成本斜率**"的那一点——再往后,多写一个词带来的期望接受增量已经盖不住它的成本。$\alpha$ 越高,收益曲线在更大的 $k$ 才转平,$k^\*$ 越大。

## 例子

期望接受 token 数 $g(k)=\frac{1-\alpha^{k+1}}{1-\alpha}$:

| $\alpha$ | $k{=}1$ | $k{=}2$ | $k{=}4$ | $k{=}8$ | 上限 $\frac{1}{1-\alpha}$ |
|---|---|---|---|---|---|
| 0.5 | 1.50 | 1.75 | 1.94 | 2.00 | **2.0** |
| 0.7 | 1.70 | 2.19 | 2.80 | 3.27 | **3.33** |
| 0.9 | 1.90 | 2.71 | 4.10 | 6.13 | **10.0** |

读法:$\alpha=0.5$ 时从 $k{=}4$ 到 $k{=}8$ 只多 0.06 个 token,却把草稿成本翻倍——**纯亏**,$k^\*\approx 2$。$\alpha=0.9$ 时 $k{=}8$ 还能涨到 6.13,值得开长草稿。这解释了:独立小草稿($\alpha\approx 0.6$)只配短草稿;EAGLE-3($\alpha$ 高、$\tau\approx 4{-}7$)才值得开长草稿 / 宽树。

## 原理

**收益模型**。设大模型一次前向耗时 $T$,草稿器出一个 token 耗时 $cT$($c\ll 1$)。一轮:草稿 $k$ 步($kcT$)+ 大模型验证一次($T$),期望产出 $g(k)$ 个 token。每 token 平均耗时与净加速:

$$
\text{加速} \;=\; \frac{g(k)\cdot T_\text{base}}{T + k c T} \;\approx\; \frac{g(k)}{1+kc},\qquad g(k)=\frac{1-\alpha^{k+1}}{1-\alpha}
$$

分子饱和、分母线性增 → 存在最优 $k^\*$。对 $k$ 求导置零可得近似:$\alpha$ 越接近 1、$c$ 越小,$k^\*$ 越大。

**roofline 视角(为何验证"几乎免费")**。decode 算术强度 $I=\frac{\text{FLOP}}{\text{Byte}}$ 极低(每 token 搬一遍权重只算一次 GEMV),点远在算力屋顶之下、**算力闲置**。验证 $k$ 个 token 把同一批权重复用 $k$ 次,$I$ 提高 ~$k$ 倍、把点推向屋顶,**额外 FLOP 由闲置算力吸收,几乎不增耗时**——这就是"以算力换步数"的物理基础。但一旦 batch 增大,$I$ 本就接近屋顶,闲置算力消失,投机收益随之蒸发(见 [[079 投机解码与连续批、前缀缓存的兼容|与连续批兼容]])。

**接受率从哪来**。$\alpha=\mathbb{E}_{x\sim q}[\min(1,p/q)]$,$q$(草稿分布)越接近 $p$(目标),$\alpha$ 越高。这就是 EAGLE(吃特征)、MTP(同源)接受率高、独立小草稿低的根因。

## 代码

```python
# ✅ 用收益模型估算最优草稿长 k*（给定 α 和草稿成本比 c）
def best_k(alpha, c, kmax=12):
    def speedup(k):
        g = (1 - alpha**(k+1)) / (1 - alpha)   # 期望接受 token 数
        return g / (1 + k * c)                  # 净加速 ≈ g/(1+kc)
    return max(range(1, kmax+1), key=speedup)

print(best_k(alpha=0.9, c=0.05))   # 高接受率 → k* 偏大
print(best_k(alpha=0.5, c=0.05))   # 低接受率 → k* 偏小(2~3)
```

```python
# ❌ 反例：不看 α 一律把草稿长开满
"num_speculative_tokens": 10   # α=0.5 时收益早已饱和在 2，多算 8 步草稿纯亏
# ✅ 正解：先量测该模型/任务的实际接受率，再据收益模型挑 k；高接受率才开长草稿
```

`❌` 草稿长拍脑袋开满 = 低接受率下纯烧草稿算力;`✅` 先测 $\alpha$/$\tau$ 再定 $k$,且记得**大 batch 下要把 $k$ 调小甚至关闭**(闲置算力没了)。现代框架(vLLM/SGLang)支持 num_steps/topk 自动调优,本质就是在线估 $\alpha$ 找 $k^\*$。

## 面试高频

- **Q:投机解码期望加速怎么算?** 每轮期望产出 $g(k)=\frac{1-\alpha^{k+1}}{1-\alpha}$ 个 token,净加速 $\approx\frac{g(k)}{1+kc}$($c$ 为草稿成本比);分子饱和、分母线性,存在最优 $k^\*$。
- **Q:接受率上限和草稿长什么关系?** $g(k)$ 随 $k$ 饱和于 $\frac{1}{1-\alpha}$;$\alpha=0.5$ 上限仅 2,$\alpha=0.9$ 上限 10。低 $\alpha$ 开长草稿纯亏。
- **Q:为什么验证 k 个 token 几乎不增耗时?** decode 访存受限、算力闲置;验证复用同批权重把算术强度提 $k$ 倍,额外 FLOP 被闲置算力吸收(roofline 视角)。
- **Q:接受率 $\alpha$ 由什么决定?** $\alpha=\mathbb{E}_{x\sim q}[\min(1,p/q)]$,草稿分布 $q$ 越接近目标 $p$ 越高;EAGLE 吃特征、MTP 同源,故 $\alpha$ 高。
- **Q:什么时候投机解码反而变慢?** 接受率低 + 草稿长过大(纯烧草稿算力),或 batch 大(闲置算力消失、验证不再免费)。

## 关键事实

- 期望接受 token 数 $\frac{1-\alpha^{k+1}}{1-\alpha}$,上限 $\frac{1}{1-\alpha}$(Leviathan 2023 给出该几何级数收益模型)。
- 衡量草稿器质量的两个等价量:逐位接受率 $\alpha$、平均接受长度 $\tau=g(k)$;EAGLE-3 的 $\tau\approx 4{-}7$,独立小草稿 $\tau\approx 2{-}3$,DeepSeek MTP1 $\alpha>0.8$。
- 净加速 $\approx\frac{g(k)}{1+kc}$,最优 $k^\*$ 随 $\alpha\uparrow$、草稿成本 $c\downarrow$ 而增大。
- **roofline 约束**:收益依赖 decode 的闲置算力;**大 batch 时投机收益显著下降**(算力受限,验证不再"白嫖"),这是部署关键取舍(见 [[079 投机解码与连续批、前缀缓存的兼容|与连续批兼容]])。
