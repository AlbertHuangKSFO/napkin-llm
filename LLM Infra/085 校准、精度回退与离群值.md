[[085 校准、精度回退与离群值|校准、精度回退与离群值]]回答部署量化时**最务实的三个问题**:量化前要不要校准(怎么选校准集)?激活的**离群值通道**怎么处理?量化后掉点了怎么**逐级回退**?机理回链 [[LLM/094 LLM.int8 与离群值|LLM.int8 与离群值]]、[[LLM/096 AWQ 与 SmoothQuant|SmoothQuant]];这里讲**部署侧的操作与权衡**。这是 [[081 W8A8 与 W4A16：权重激活精度组合|W8A8]] 能不能用、[[084 引擎里的量化集成：AWQ、GPTQ、FP8 加载|量化集成]]能不能稳的前提。

## 直觉

量化的本质是把一段数值范围塞进有限刻度。麻烦在于 LLM 的**激活里有少数"离群值通道"**:绝大多数值落在 ±1,但某几个通道能飙到几十甚至上百(见图)。用一把 [[LLM/092 量化基础：对称非对称、per-tensor、per-channel、per-group|per-tensor]] 的尺子,scale 被这几个离群值撑大,**正常值全被压成 0**——这就是 INT8 激活量化掉点的元凶。三个对策:① **校准**——在一小撮代表性数据上前向跑一遍,统计真实极值来定 scale(而不是瞎猜);② **细粒度 scale**——per-channel/per-group,让离群通道单独用一把尺子;③ **离群迁移**——SmoothQuant 把离群从激活"挪"到权重(权重静态、好量),或干脆让敏感层保高精度。FP8 因指数位天然耐离群,这套麻烦轻很多(见 [[082 FP8 服务：H100、Blackwell 原生|FP8 服务]])。

## 例子

校准与回退的真实操作:

- **校准集**:选 **100–512 条** prompt,分布**贴近线上**(同领域、同典型上下文长);GPTQ/AWQ/SmoothQuant 都靠它定 scale。校准集偏了(比如全用英文校准、线上跑中文)→ 掉点放大。
- **掉点回退**(实测阶梯):W4A4 per-tensor 掉 3–5% → 换 **per-group(group_size=128)** 掉到 1–2% → 敏感层(`lm_head`、attention 输出)留 **FP8/BF16** 掉到 <1% → 实在不行**退回 W8A8 FP8 或仅权重 W4A16**(近无损)。
- **数字感**:FP8 W8A8 基本无损;INT8 W8A8 配 SmoothQuant 通常掉 <1%;W4A16 AWQ <0.5%;W4A4 风险最高,需 QAT/蒸馏回收(NVFP4 用蒸馏可把 DeepSeek-R1 [[LLM/110 下游基准：MMLU、GSM8K、HumanEval、MT-Bench|MMLU]] 掉点压到 ~0.1%)。

## 原理

离群值为什么毁 per-tensor:scale 取全张量极值,

$$
s=\frac{\max|x|}{q_\max}\xrightarrow{\text{离群值很大}}s\ \text{很大}\ \Rightarrow\ \text{正常值}\ \frac{x}{s}\approx 0
$$

**SmoothQuant** 的迁移:引入逐通道平滑因子 $d_j$,把激活离群"借"给权重——

$$
Y = (X\,\mathrm{diag}(d)^{-1})\,(\mathrm{diag}(d)\,W),\qquad d_j=\frac{\max|X_j|^{\alpha}}{\max|W_j|^{1-\alpha}}
$$

激活变平滑(好量),权重吸收离群(权重本就静态、per-channel 易量),数学等价。

![[quant-smoothquant迁移.png]]
**校准**就是用小集合估计 $\max|X_j|$ 这些统计量。**回退阶梯**(见图):从激进(W4A4/per-tensor)逐级加保守——加细粒度 scale → 混合精度(敏感层保高精度)→ 退回 W8A8/W only,每步都跑评测([[LLM/109 语言模型评估：困惑度与 bits-per-byte|困惑度]] + 下游任务指标),直到掉点可接受。核心纪律:**量化必须配评测**,不评测不上线。

## 代码

```python
# LLM Compressor:带校准集做 W8A8 INT8 + SmoothQuant(压离群)
from llmcompressor.transformers import oneshot
from llmcompressor.modifiers.quantization import GPTQModifier
from llmcompressor.modifiers.smoothquant import SmoothQuantModifier

oneshot(
    model="meta-llama/Llama-3-70B",
    dataset="open_platypus",        # 代表性校准集
    num_calibration_samples=512,
    recipe=[
        SmoothQuantModifier(smoothing_strength=0.8),   # 离群迁移
        GPTQModifier(scheme="W8A8", targets="Linear",
                     ignore=["lm_head"]),              # 敏感层保高精度
    ],
)
```

❌ 误区:量化完看一眼能输出就上线;或随便抓一批数据当校准集。
✅ 正解:① 校准集要**贴近线上分布**且覆盖典型上下文长;② 量化后**必跑评测**(perplexity + 下游任务);③ 掉点就**逐级回退**(细粒度 → 混合精度 → 退回更保守方案),别硬扛。

## 面试高频

- **Q:激活量化为什么比权重难?** 激活有动态**离群值通道**,per-tensor scale 被拉爆;权重分布静态、可离线 per-channel 精细量化。
- **Q:SmoothQuant 在做什么?** 用逐通道平滑因子把激活离群"迁移"到权重,使激活好量、权重吸收离群,数学等价。
- **Q:校准集怎么选?** 100–512 条、分布贴近线上、覆盖典型上下文长;偏了会放大掉点。
- **Q:量化掉点了的回退顺序?** 加细粒度 scale(per-group)→ 敏感层混合精度 → 退回 W8A8/FP8 或仅权重 → 必要时 QAT/蒸馏回收。

## 关键事实

- 2025:校准集典型 **100–512 条**;SmoothQuant + GPTQ/AWQ 可在 LLM Compressor 一次 oneshot 组合应用。
- FP8 因浮点指数位**天然耐离群**,校准/离群处理负担远轻于 INT8;这是 FP8 工程上更省心的关键原因。
- 极低比特(W4A4/NVFP4)需 **QAT 或量化感知蒸馏**回收精度;NVIDIA 报告蒸馏可把 NVFP4 掉点压到 <1%。
- 铁律:**量化必配评测**(perplexity + 下游任务),敏感层(`lm_head`、部分 attention)常保高精度。
