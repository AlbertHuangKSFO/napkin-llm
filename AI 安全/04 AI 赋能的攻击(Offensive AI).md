[[04 AI 赋能的攻击(Offensive AI)|Offensive AI]] 翻转了整个本域的视角:前面所有篇把 AI 当**被保护的对象**(怎么防它被攻击),这篇把 AI 当**武器**(攻击者怎么拿它打别人)。这是与本域正交的另一根轴——[[01 AI 安全总览与三层栈|总览]] 里列的两根轴之一。核心逻辑只有一个词:**dual-use(双刃)**——同一份能力,防守方用来加固,攻击方用来进攻;AI 真正改变的,是**拉平了攻防双方的技能门槛**。

## 全景:AI 作为能力放大器

![[sec-OffensiveAI全景.png]]

AI 对攻击者的价值不是「发明新攻击」,而是**放大旧攻击的规模、降低执行的门槛**:不会写地道英文的人能发出以假乱真的钓鱼邮件,不懂编程的人能拿到可用的恶意脚本初稿。四大类:

## ① 自动化漏洞发现与利用

- LLM 辅助代码审计、自动定位漏洞、辅助写 exploit。
- 规模化扫描、自适应 fuzzing,大幅压缩「发现漏洞 → 武器化」的时间窗。
- **双刃**:同样的能力,防守方用来自动找 bug、自动打补丁——这是攻防对称的典型。

## ② 规模化社工 / 钓鱼

- **鱼叉钓鱼(spear phishing)**:个性化、语法地道、批量生成,把过去「一封封手写」变成「成千上万封定制」。
- **深伪(deepfake)**:合成视频/图像冒充高管下达指令(典型如冒充 CFO 让财务转账)。
- **语音克隆(voice cloning)**:几秒样本即可仿声,用于电话诈骗、绕过声纹验证。
- 直接后果:**BEC(商业邮件诈骗)** 的成功率与规模一起抬升。

## ③ 恶意 / 越狱模型(Dark LLMs)

把对齐(见 [[03 内容安全与对齐边界|对齐边界]])整个去掉或绕过,造出专为犯罪服务的模型:

- **WormGPT**:基于开源 **GPT-J**,2023 年在 HackForums 上以约 $110/月兜售(另有 $5,400 私有版),主打钓鱼与恶意代码生成。原版作者于 **2023-08-08 关停**并撇清关系。
- **FraudGPT**:暗网/犯罪论坛兜售,化名「CanadianKingpin12」推广,定位 WormGPT 的「后继者」,主打钓鱼邮件、恶意代码、攻击教程。
- **演变**:如今「WormGPT」已成为**任意越狱犯罪 LLM 的统称**;实际手法多是**劫持主流 LLM API(如 Grok、Mixtral)+ 越狱 prompt** 来复活,而非自训模型。这把它和本域的 [[06 Jailbreak 越狱|越狱]] 直接接上了——offensive AI 的「弹药」常来自对正规模型的越狱。

## ④ Slopsquatting:AI 幻觉喂出的供应链攻击

这是 offensive AI 里最精巧、最「AI 原生」的一类,值得单独讲:

- **机制**:LLM 在写代码时会**幻觉出不存在的依赖包名**(plausible 但查无此包)。研究测得约 **19.7% 的 LLM 推荐包不存在**;开源模型幻觉率(均值 21.7%)远高于闭源(5.2%),某些模型超 1/3 输出含幻觉名;跨模型共观测到 20 万+ 个独特幻觉包名。
- **攻击**:攻击者**抢注**这些高频幻觉包名,塞进恶意代码。开发者(或 [[15 Tool Misuse 与意外代码执行|coding agent]])照抄 LLM 给的 `pip install`,就把后门装进环境。
- **为何可行**:幻觉名**复现率高、可预测**——重跑同一 prompt 十次,43% 的幻觉名每次都出现,61% 在多次出现。攻击者可批量「跑 prompt → 收集高频幻觉名 → 抢注」。
- **命名出处**:2025-04 由 Python 软件基金会驻场开发者、安全研究员 **Seth Larson** 命名(AI slop + typosquatting 的合成词),Andrew Nesbitt 在 Mastodon 推广。更早的先兆是 2023 年 Bar Lanyado 发现 LLM 幻觉出 `huggingface-cli`,他上传空包占位,3 个月被下载 3 万+ 次。

Slopsquatting 把 offensive AI 和 [[10 供应链安全(静态)|供应链安全]]、[[20 Agentic 供应链与 MCP 安全|Agentic 供应链]] 缝在了一起:**AI 的缺陷(幻觉)直接变成了攻击者的供应链入口**。

## 对比表

| 类别 | AI 改变了什么 | 双刃的另一面(防守也能用) |
|---|---|---|
| 自动化漏洞利用 | 压缩「发现→武器化」时间窗 | 自动找 bug / 自动打补丁 |
| 规模化社工 | 个性化 + 批量,质量与规模齐升 | AI 反钓鱼检测、深伪识别 |
| Dark LLMs | 去对齐,降低犯罪技能门槛 | 红队用同类模型测自身防线 |
| Slopsquatting | 把 AI 幻觉变成供应链入口 | 依赖校验、幻觉包检测工具 |

## 防御

- **针对社工/深伪**:多因子 + 带外验证(电话转账走二次人工确认)、对「语音/视频」本身不再当作身份凭证。
- **针对 slopsquatting**:依赖锁定与校验(lockfile + 哈希)、安装前核验包是否真实存在/有合理下载历史、用幻觉包检测工具;coding agent 装包前过 [[24 沙箱、最小权限与人审闸门|人审闸门]]。
- **针对 Dark LLMs**:这本质是对抗「越狱」与「滥用」,防线在 [[03 内容安全与对齐边界|对齐]]、[[21 Guardrails 与输入输出防护|Guardrails]]、平台层滥用监测;但要清醒——开源权重一旦放出,去对齐不可逆,只能在下游(投递、执行)设防。
- **整体心态**:offensive AI 是**对称军备**,防守方必须假设攻击方已用上同代 AI,把检测/响应([[25 监控、可观测与事件响应|监控]])也自动化、规模化。

## 何时用 / 坑

- **坑①**:以为「我们不用 AI 就不受 offensive AI 影响」——攻击方用不用 AI 不由你决定,这是被动暴露面。
- **坑②**:把 deepfake/语音克隆当小概率——它已是 BEC 主流手法,身份验证流程必须假设音视频可伪造。
- **坑③**:信任 LLM 给的依赖清单——slopsquatting 让「照抄 AI 的 import」成了新的高危习惯。

## 关键事实(含核验出处)

- **WormGPT**:基于 GPT-J,2023 年 HackForums 兜售(~$110/月),原作者 2023-08-08 关停;现为「越狱犯罪 LLM」统称,多靠劫持 Grok/Mixtral 等 API + 越狱复活。来源:CSO Online、Rapid7、SocRadar 等多方报道。
- **FraudGPT**:犯罪论坛兜售,化名「CanadianKingpin12」推广,定位 WormGPT 后继。来源:LevelBlue/SpiderLabs、Palo Alto Unit 42。
- **Slopsquatting**:Seth Larson 于 2025-04 命名(AI slop + typosquatting),Andrew Nesbitt 推广;学术论文《We Have a Package for You!》(2025-05)测得 ~19.7% 推荐包不存在、开源 21.7% vs 闭源 5.2%、20 万+ 独特幻觉名;USENIX Security 2025 跨 16 模型 57.6 万样本,幻觉名复现率 43%(十次全中)。先兆:2023 年 Bar Lanyado 的 `huggingface-cli` 占位包,3 个月 3 万+ 下载。来源:Wikipedia「Slopsquatting」、Snyk、Socket.dev、CSA。
- **Dual-use**:offensive AI 的统摄概念,见 Palo Alto Unit 42《The Dual-Use Dilemma of AI: Malicious LLMs》。

## 工业界实践

防 offensive AI 的工业逻辑是「**对称军备**」——假设攻击方已用上同代 AI,防守方必须把检测/响应同样自动化、规模化。按四大类分别落地:

### 针对深伪/语音克隆/BEC

- **流程硬控**(最有效,不依赖检测技术):转账/改收款账户走**带外多因子验证**——电话回拨已知号码、二次人工审批、对「音视频」本身**不再当作身份凭证**。这是 Arup 案的直接教训。
- **检测产品**:深伪检测(Intel FakeCatcher、Reality Defender、微软 Video Authenticator 类)、邮件安全网关的 AI 钓鱼检测(Abnormal Security、Proofpoint)、内容溯源标准 **C2PA / Content Credentials**(给真实媒体加可验证签名,反向证伪)。
- **真实事件——必背案例**:**Arup 深伪诈骗(2024)**,香港分部一名财务在一场「CFO + 多名同事」全是 AI 深伪的视频会上被说服,单日做了 **15 笔转账共 2,560 万美元(2 亿港元)**;在场无一真人,深伪由公开视频音频合成。它把「音视频可伪造」从理论变成 2,560 万美元的现实,身份验证流程必须假设音视频可造假。

### 针对 Dark LLMs / 越狱犯罪模型

- 本质是对抗「越狱 + 滥用」:防线在 [[03 内容安全与对齐边界|对齐]]、平台层**滥用监测**(异常 API 调用模式、批量钓鱼内容生成的指纹)、以及对劫持的正规 API(Grok/Mixtral 等)做速率限制 + 越狱检测。
- **清醒认知**:开源权重一旦放出,**去对齐不可逆**——只能在下游(投递、执行)设防,不能指望「召回模型」。

### 针对 Slopsquatting(AI 幻觉供应链)

工业界把它当**新型供应链威胁**纳入软件成分分析(SCA)流程:

```bash
# 防御要点:别盲信 LLM 给的 import,装包前自动核验
# ① 锁定 + 哈希校验(pip 用 hash-pinned requirements)
pip install --require-hashes -r requirements.txt
# ② 安装前核验包是否真实存在 + 有合理历史(下载量/首次发布时间/维护者)
#    可疑信号:全新包 + 零下载历史 + 名字恰好是高频幻觉名
```

```python
# coding agent 装包前过一道闸:拦"查无此包"或"可疑新包",转人审(见 24 篇)
def guard_install(pkg):
    meta = registry.lookup(pkg)              # PyPI/npm 元数据
    if meta is None:                          # LLM 幻觉出的不存在包
        return human_review(f"{pkg} 查无此包,疑似 slopsquatting")
    if meta.age_days < 30 and meta.downloads < 50:
        return human_review(f"{pkg} 新且冷门,核实是否抢注")
    return ALLOW
```

工具:**Socket.dev**、**Snyk**、GitHub Dependabot 等已开始标记可疑新包/幻觉包;CI 里强制 lockfile + 签名(接 [[10 供应链安全(静态)|供应链安全]])。

### 防守侧也用 AI(双刃的另一面)

- 自动找 bug / 自动打补丁、AI 反钓鱼、深伪识别、红队用同类模型测自身防线(**PyRIT/garak/Promptfoo**,见 [[22 AI 红队与对抗测试|AI 红队]])。把 [[25 监控、可观测与事件响应|检测与响应]] 也自动化,才跟得上攻击方的规模。

## 面试高频

- **Q:AI 给攻击者带来的最大改变是什么?**
  标准答:**不是发明新攻击,而是放大旧攻击的规模、拉平攻防双方的技能门槛**——不会写地道英文的人能发以假乱真的钓鱼邮件,不懂编程的人能拿到可用恶意脚本初稿。关键词 **dual-use(双刃)**:同一份能力,防守加固、攻击进攻。**追问**「那防守方怎么办?」——对称军备:假设攻击方已用上同代 AI,把检测响应同样自动化规模化。
- **Q:什么是 Slopsquatting?和 typosquatting 有何不同?**
  Slopsquatting = 攻击者**抢注 LLM 幻觉出的不存在包名**,等开发者/coding agent 照抄 `pip install` 就中招;typosquatting 抢的是**拼写相近**的名(如 `requstes`)。Slopsquatting 之所以可行,是因为幻觉名**复现率高、可预测**(同一 prompt 重跑,43% 幻觉名十次全中),攻击者可批量「跑 prompt → 收高频幻觉名 → 抢注」。**陷阱**:它把 AI 的缺陷(幻觉)直接变成供应链入口,缝合了 offensive AI 与 [[10 供应链安全(静态)|供应链安全]]。
- **Q:为什么 deepfake 不能当小概率忽略?** 已是 BEC 主流手法(Arup 案 2,560 万美元)。身份验证流程必须假设音视频可伪造,转账走带外二次确认。
- **陷阱题:「我们不用 AI,是不是就不受 offensive AI 影响?」** 错。攻击方用不用 AI 不由你决定,这是**被动暴露面**——你不用 AI 也照样会收到 AI 生成的钓鱼邮件、被深伪冒充。

## 知识拓展

- **Offensive AI 的框架坐标**:**MITRE ATLAS** 把「用 AI 发起攻击」与「攻击 AI 系统」都收录;OWASP **LLM Top 10** 里 **LLM03 供应链** 直接覆盖 slopsquatting,**LLM09 Misinformation** 是幻觉被武器化的根。
- **AI 自主攻击的前沿**:从「AI 辅助」走向「AI 自主」——学术与厂商红队已在测 **LLM agent 自主发现并利用真实 CVE**、自主完成多步入侵链。这把 offensive AI 从「放大器」推向「自动化攻击者」,防守的时间窗进一步压缩。
- **Dark LLM 的演化路径**:WormGPT/FraudGPT 已从「自训去对齐模型」退化为「**劫持主流 API + 越狱 prompt**」的运营模式——因为自训成本高、效果差,不如直接越狱正规强模型。所以打 Dark LLM 的现实抓手其实是**打越狱**(见 [[06 Jailbreak 越狱|越狱]])和**平台滥用监测**,而非追查某个犯罪模型。
- **对抗演化与边界**:深伪检测与生成是持续军备竞赛,**检测永远滞后于生成**——所以工业界主防线落在**流程**(带外验证)而非**检测技术**;媒体溯源(C2PA)走「证真」而非「验伪」路线,长期更可持续。整体心态见正文「对称军备」。
