[[33 感知机与人工神经元]]:**人工神经元是"加权求和 + 偏置 + 激活"$a=\sigma(w^\top x+b)$ 的最小计算单元**;最早的感知机只是它的线性二分类版本,而它学不会 XOR,正是逼出多层网络([[34 MLP 与万能逼近]])的经典坑。

## 直觉

把生物神经元抽象成三步:

1. **收集输入**:每根树突收一个数 $x_i$,各自有重要性(权重 $w_i$)。
2. **加权求和**:$z=\sum_i w_i x_i+b$。$b$ 是偏置——相当于"不管输入是啥,先有个起跑线/阈值"。
3. **激活/发放**:把 $z$ 喂进非线性 $\sigma$,得到输出 $a$。早期感知机用硬阈值($z>0$ 输出 1,否则 0),现代用平滑的 [[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]]。

权重 $w$ 决定"这条特征往哪个方向、多大力气影响决策";偏置 $b$ 平移决策边界。**几何上,单个神经元就是一条直线(高维是超平面)把空间切两半**——这既是它的能力,也是它的天花板。

## 例子

**例 1:神经元手算。** 输入 $x=[1,2]$,权重 $w=[0.5,-1]$,偏置 $b=0.3$:

$$z=0.5\times 1+(-1)\times 2+0.3=0.5-2+0.3=-1.2$$

过 sigmoid:$\sigma(-1.2)=\dfrac{1}{1+e^{1.2}}=0.231$。这个神经元对该输入"轻微反对"(输出 < 0.5)。

**例 2:感知机实现 AND。** 让 $w=[1,1],\ b=-1.5$,硬阈值"$z>0\Rightarrow 1$":

| $x_1$ | $x_2$ | $z=x_1+x_2-1.5$ | 输出 |
|---|---|---|---|
| 0 | 0 | $-1.5$ | 0 |
| 0 | 1 | $-0.5$ | 0 |
| 1 | 0 | $-0.5$ | 0 |
| 1 | 1 | $+0.5$ | **1** |

一条直线就分开了"全 1"和其余——AND/OR 都线性可分,单个神经元够用。

**例 3:感知机学习规则走两步(看权重怎么更新)**。学 OR,初始 $w=[0,0],b=0$,学习率 $\eta=1$,阶跃"$z>0\Rightarrow1$"。
- 样本 $(1,0)\to1$:$z=0$,预测 0(因 $z>0$ 才输出 1),错。更新 $w\leftarrow w+\eta(y-\hat y)x=[0,0]+1\cdot[1,0]=[1,0]$,$b\leftarrow0+1=1$。
- 样本 $(0,0)\to0$:$z=b=1>0$,预测 1,错。更新 $b\leftarrow1+1\cdot(0-1)=0$,$w$ 不变(因 $x=[0,0]$)。

每次"分错就把权重往正确方向推一点",反复扫数据直到全对。**只要线性可分,感知机收敛定理保证有限步停下**(步数上界与"间隔/数据范数"有关)。

**例 4:XOR 卡死。** 真值表要求 $(0,0)\to0,\ (1,1)\to0,\ (0,1)\to1,\ (1,0)\to1$。两个"该输出 0"的点 $(0,0)$ 和 $(1,1)$ 在对角,两个"该输出 1"的点也在另一条对角——**没有任何一条直线能把它们分开**。单层感知机对 XOR 无解。

## 原理

**人工神经元的前向计算:**

$$z=w^\top x+b=\sum_{i=1}^{d}w_i x_i+b,\qquad a=\sigma(z)$$

- $w\in\mathbb{R}^d$:权重向量,$w^\top x$ 是 [[03 点积、范数与相似度|点积]],衡量输入与权重方向的对齐程度。
- $b\in\mathbb{R}$:偏置,平移决策边界(没有它,边界被迫过原点)。
- $\sigma$:激活函数,提供**非线性**;若 $\sigma$ 是恒等映射,神经元退化为线性回归。

**感知机(Perceptron)** 是 $\sigma=\text{阶跃函数}$ 的特例,做线性二分类。Rosenblatt 的**感知机学习算法**:对每个分错的样本,$w\leftarrow w+\eta(y-\hat y)x$,$b\leftarrow b+\eta(y-\hat y)$。**感知机收敛定理**保证:只要数据**线性可分**,该算法有限步内必收敛到一个完美分界面。

**XOR 不可分的本质:** 单神经元的决策边界是**一个超平面** $w^\top x+b=0$,只能切出"两个半空间"。XOR 的两类点互相穿插(异或 = 不在同侧),不存在线性边界。

**破解:加一层隐藏层。** 用两个隐藏神经元先把输入**非线性地重新表示**(例如一个算 OR、一个算 NAND),输出层再对这两个新特征做 AND,XOR 就在新空间里线性可分了(因为 $\text{XOR}=\text{OR AND NAND}$)。这正是 [[34 MLP 与万能逼近|MLP]] 的起点。**注意:多层但全线性(无 $\sigma$)仍然只能表达线性函数,非线性激活才是关键。**

**感知机 vs 逻辑回归(同一个神经元,两种训法)**。把激活从阶跃换成 sigmoid、损失用 [[30 交叉熵与负对数似然|交叉熵]],神经元就变成**逻辑回归**:输出 $\sigma(w^\top x+b)$ 是概率、处处可导、可用梯度下降、还自带 [[25 最大似然估计 MLE|MLE]] 解释。区别一表:

| | 经典感知机 | 逻辑回归 |
|---|---|---|
| 激活 | 阶跃(硬) | sigmoid(软) |
| 输出 | 0/1 标签 | 概率 $\in(0,1)$ |
| 损失 | 误分类驱动 | 交叉熵(可导) |
| 优化 | 感知机规则 | 梯度下降 |
| 收敛 | 仅线性可分时 | 总能优化(凸) |

**几何:间隔(margin)**。决策面 $w^\top x+b=0$ 到最近样本的距离是 $\frac{|w^\top x+b|}{\|w\|}$。感知机只要分对就停(任意一条线),不关心间隔大小;**SVM** 则专门最大化这个间隔(更鲁棒的分界面)——这是从"能分"到"分得好"的关键升级。

## 代码

```python
import numpy as np

def neuron(x, w, b, act=lambda z: 1/(1+np.exp(-z))):
    return act(w @ x + b)                      # w·x + b 再激活

print(neuron(np.array([1, 2]), np.array([0.5, -1.0]), 0.3))   # 0.231

# ❌ 错:想用单层感知机学 XOR —— 数据线性不可分,算法永不收敛(死循环)
def perceptron_train(X, y, epochs=100, lr=0.1):
    w, b = np.zeros(X.shape[1]), 0.0
    for _ in range(epochs):
        for xi, yi in zip(X, y):
            pred = 1 if w @ xi + b > 0 else 0
            w += lr * (yi - pred) * xi          # XOR 上永远有错分,w 反复震荡
            b += lr * (yi - pred)
    return w, b

X = np.array([[0,0],[0,1],[1,0],[1,1]])
y_xor = np.array([0, 1, 1, 0])
w, b = perceptron_train(X, y_xor)
preds = [1 if w @ xi + b > 0 else 0 for xi in X]
print("单层 XOR:", preds, "≠", list(y_xor))      # 必有错,学不会

# ✅ 对:AND 线性可分,感知机能学会
y_and = np.array([0, 0, 0, 1])
w, b = perceptron_train(X, y_and)
print("单层 AND:", [1 if w @ xi + b > 0 else 0 for xi in X])   # [0,0,0,1] ✅
```

## 面试高频

- **"画一个人工神经元并写出公式。"** $a=\sigma(w^\top x+b)$,会标出权重、偏置、激活三部分。
- **"偏置 $b$ 的作用?"** 平移决策边界 / 设定激活阈值;没有它边界被迫过原点,表达力受限。
- **"感知机为什么学不会 XOR?"** 单神经元只能画一条线性边界,XOR 的两类点线性不可分;这导致 1969 年 Minsky & Papert 的批评,贡献了"AI 寒冬"。
- **"怎么解决 XOR?"** 加隐藏层(MLP)+ 非线性激活,把输入映到可分的新空间。强调:多层但缺非线性会塌缩成单层线性。
- **"感知机和逻辑回归区别?"** 逻辑回归 = 神经元用 sigmoid + 交叉熵、输出概率、可微可梯度下降、有 MLE 解释;经典感知机用硬阈值、靠误分类驱动更新、不输出概率、仅线性可分时收敛。
- **"感知机收敛定理说什么?"** 数据线性可分时,感知机学习规则有限步内收敛到一个完美分界面;步数上界与间隔和数据范数有关。线性不可分则永不收敛(震荡)。
- **"什么是 margin?感知机关心吗?"** 决策面到最近点的距离 $\frac{|w^\top x+b|}{\|w\|}$;感知机只要分对就停、不关心 margin,SVM 才最大化它(更鲁棒)。
- **"为什么单神经元 = 一条超平面?"** $w^\top x+b=0$ 是超平面方程;神经元按它把空间切两半,这既是能力也是天花板(只能线性可分)。

## 关键事实

- 感知机由 Rosenblatt 1958 提出;感知机收敛定理保证线性可分数据上有限步收敛(Novikoff 1962)。
- McCulloch & Pitts 1943 提出最早的阈值逻辑神经元模型,是人工神经元的源头。
- Minsky & Papert《Perceptrons》1969 指出单层感知机无法表示 XOR 等非线性可分函数,推动了对多层网络的研究。
- 现代神经元 = 线性变换 $w^\top x+b$ + 非线性激活,缺非线性时多层会退化为单层线性(Goodfellow《Deep Learning》2016,第 6 章)。
