[[38 反向传播在网络中的实现|反向传播的实现]]是把 [[20 反向传播的数学推导|反向传播的数学]] 落到一个真实小网络上:用具体权重数字走一遍前向 + 反向,算出**每个参数的梯度**,再交给 [[37 梯度下降：BGD、SGD、Mini-batch|梯度下降]] 更新。本篇用一个 2 层 MLP 手算到底,并给可运行的 numpy 手写反传。

## 直觉

[[34 MLP 与万能逼近|前向传播]] 是"输入一路算到损失";反向传播就是把这条路**倒着走一遍**,沿途回答:"损失对**这一层**的输入/参数敏感多少?"

核心机制只有三个动作,反复套用([[16 链式法则|链式法则]]):
1. **前向**:存下每层的中间值(线性输出 $z$、激活输出 $a$)——反向时要用。
2. **反向**:从损失出发,逐层把"上游梯度" $\delta$ 往回传。每层做两件事:① 用 $\delta$ 和**本层缓存的输入**算出**参数梯度**;② 把 $\delta$ 乘上**本层的本地导数**(权重转置、激活导数)传给下一层。
3. **更新**:$\theta\leftarrow\theta-\eta\,\nabla_\theta\mathcal L$。

一句话:**前向存值,反向传 $\delta$,沿途顺手把参数梯度摘下来**。线性层的权重梯度永远是 $\delta\cdot(\text{输入})^T$ 这种"误差外积输入"的形态(见 [[12 矩阵求导|矩阵求导]])。

## 例子

**一个能手算的 2 层 MLP**。结构:输入 2 维 → 隐层 2 神经元([[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|sigmoid]])→ 输出 1 神经元(sigmoid)→ 二元交叉熵损失。

**给定数字**(无偏置,简化):
$$W_1=\begin{bmatrix}0.1&0.2\\0.3&0.4\end{bmatrix},\quad W_2=\begin{bmatrix}0.5&0.6\end{bmatrix},\quad x=\begin{bmatrix}1\\1\end{bmatrix},\quad y=1$$

**前向**(记 $\sigma(t)=1/(1+e^{-t})$):
- $z_1=W_1x=\begin{bmatrix}0.1+0.2\\0.3+0.4\end{bmatrix}=\begin{bmatrix}0.3\\0.7\end{bmatrix}$
- $a_1=\sigma(z_1)=\begin{bmatrix}\sigma(0.3)\\\sigma(0.7)\end{bmatrix}=\begin{bmatrix}0.5744\\0.6682\end{bmatrix}$
- $z_2=W_2a_1=0.5\cdot0.5744+0.6\cdot0.6682=0.2872+0.4009=0.6881$
- $\hat y=a_2=\sigma(0.6881)=0.6655$
- 损失 $\mathcal L=-\ln \hat y=-\ln 0.6655=0.4073$

**反向**。关键事实:**sigmoid 输出 + 二元交叉熵**,损失对输出 logit $z_2$ 的梯度直接是 $\hat y-y$(和 [[36 损失函数(MSE、交叉熵、对比、Focal)|softmax+CE]] 同款简洁):
$$\delta_2=\frac{\partial\mathcal L}{\partial z_2}=\hat y-y=0.6655-1=-0.3345$$

**输出层权重梯度** $\dfrac{\partial\mathcal L}{\partial W_2}=\delta_2\,a_1^T$:
$$\frac{\partial\mathcal L}{\partial W_2}=-0.3345\cdot[0.5744,\ 0.6682]=[-0.1922,\ -0.2235]$$

**回传到隐层**。先穿过 $W_2$:$\dfrac{\partial\mathcal L}{\partial a_1}=W_2^T\delta_2=\begin{bmatrix}0.5\\0.6\end{bmatrix}(-0.3345)=\begin{bmatrix}-0.1672\\-0.2007\end{bmatrix}$。

再乘 sigmoid 本地导数 $\sigma'(z_1)=a_1(1-a_1)$:
- $\sigma'(z_{1,1})=0.5744\cdot0.4256=0.2445$,$\sigma'(z_{1,2})=0.6682\cdot0.3318=0.2217$
$$\delta_1=\frac{\partial\mathcal L}{\partial z_1}=\frac{\partial\mathcal L}{\partial a_1}\odot\sigma'(z_1)=\begin{bmatrix}-0.1672\cdot0.2445\\-0.2007\cdot0.2217\end{bmatrix}=\begin{bmatrix}-0.0409\\-0.0445\end{bmatrix}$$

**隐层权重梯度** $\dfrac{\partial\mathcal L}{\partial W_1}=\delta_1\,x^T$:
$$\frac{\partial\mathcal L}{\partial W_1}=\begin{bmatrix}-0.0409\\-0.0445\end{bmatrix}[1,\ 1]=\begin{bmatrix}-0.0409&-0.0409\\-0.0445&-0.0445\end{bmatrix}$$

**所有参数梯度齐了**,下一步用 $\eta$ 更新即可。

**用学习率走一步(把闭环补上)**。取 $\eta=0.5$ 更新 $W_2$:
$$W_2\leftarrow W_2-\eta\frac{\partial\mathcal L}{\partial W_2}=[0.5,0.6]-0.5\times[-0.1922,-0.2235]=[0.5961,0.7118]$$
权重朝"让真类输出更大"的方向挪了一点。重复"前向→反向→更新"就是训练。若有偏置,$b$ 的梯度就是 $\delta$ 本身($\partial\mathcal L/\partial b_2=\delta_2=-0.3345$),按同样方式更新。

## 原理

把上面的手算抽象成**通用反传公式**(逐层)。前向 $z_\ell=W_\ell a_{\ell-1}$,$a_\ell=g(z_\ell)$,$a_0=x$。

**反向递推**(从输出层 $L$ 起):
$$\delta_L=\frac{\partial\mathcal L}{\partial z_L}\quad(\text{分类时常等于 }\hat y-y)$$
$$\boxed{\ \delta_\ell=\big(W_{\ell+1}^{T}\,\delta_{\ell+1}\big)\odot g'(z_\ell)\ }$$
$$\boxed{\ \frac{\partial\mathcal L}{\partial W_\ell}=\delta_\ell\,a_{\ell-1}^{T},\qquad \frac{\partial\mathcal L}{\partial b_\ell}=\delta_\ell\ }$$

读这三个框:
- $\delta_\ell$:**先穿过下一层权重**($W_{\ell+1}^T$ 把误差从下游拉回本层),**再点乘本层激活的导数** $g'(z_\ell)$。这就是 [[16 链式法则|链式法则]] 在矩阵上的形态。
- 权重梯度 $=\delta_\ell a_{\ell-1}^T$:**误差外积输入**,与 $W_\ell$ 同形(见 [[12 矩阵求导|矩阵求导]])。偏置梯度就是 $\delta_\ell$ 本身。
- $g'(z_\ell)$ 是激活的本地导数:sigmoid 为 $a(1-a)$,ReLU 为 $\mathbb 1[z>0]$。**激活导数会乘进每一层**——若它总 $<1$(如 sigmoid 峰值 0.25),多层连乘后 $\delta$ 指数衰减,这就是 [[44 梯度消失、爆炸与梯度裁剪|梯度消失]] 的来源,也是 ReLU 流行的原因(导数为 1,不衰减)。

**与计算图的关系**:这套递推就是在 [[18 计算图(前向)|计算图]] 上做 [[19 自动微分：前向 vs 反向模式|反向模式自动微分]]——每个算子知道自己的本地导数(VJP,向量-雅可比积),框架按拓扑逆序自动连乘,无需手推。

![[nn-反传delta流.png]]

**批量(mini-batch)下的形态**。把单样本列向量换成 $B$ 列的矩阵 $A_{\ell-1}\in\mathbb R^{d\times B}$,则
$$\frac{\partial\mathcal L}{\partial W_\ell}=\frac1B\,\delta_\ell A_{\ell-1}^\top,\qquad \frac{\partial\mathcal L}{\partial b_\ell}=\frac1B\sum_{\text{batch}}\delta_\ell$$
权重梯度是整批"误差外积输入"再**对 batch 求和/平均**;偏置梯度是 $\delta$ 沿 batch 维求和。这就是框架里 `dW = delta @ A.T / B` 的来历——一次矩阵乘把整批梯度算完(GPU 友好)。

**梯度消失/爆炸的数值画面**。$L$ 层连乘,$\delta$ 每层乘一次 $W^\top$ 和一次 $g'$。粗略地,若每层"等效乘子"幅度为 $\gamma$,则底层梯度 $\sim\gamma^L$:$\gamma<1$(如 sigmoid 的 $0.25$)→ 指数消失;$\gamma>1$(初始化过大)→ 指数爆炸。这把 [[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活选择]]、[[41 权重初始化(Xavier、He、正交)|初始化]]、残差连接/归一化都串成"控制每层乘子 $\approx1$"这一个目标(见 [[44 梯度消失、爆炸与梯度裁剪]])。

**复杂度**:反向和前向**同阶**(都是几次矩阵乘),只是多存了中间激活值($O$(激活大小) 的显存)。这就是为什么 backprop 让深度网络训练变得可行。**激活检查点(activation/gradient checkpointing)**:不缓存全部中间激活,反向时按需重算,用约 $1.3\times$ 算力换大幅省显存——训大模型的标准技巧。

## 代码

```python
import numpy as np

# ===== 手写两层 MLP 的前向 + 反传,复现上面的手算 =====
sig  = lambda z: 1 / (1 + np.exp(-z))
W1 = np.array([[0.1, 0.2], [0.3, 0.4]])
W2 = np.array([[0.5, 0.6]])
x  = np.array([[1.], [1.]])      # 列向量 (2,1)
y  = 1.0

# --- 前向(缓存中间值)---
z1 = W1 @ x;          a1 = sig(z1)          # (2,1)
z2 = W2 @ a1;         yhat = sig(z2)        # (1,1)
loss = -np.log(yhat[0, 0])
print("yhat=%.4f  loss=%.4f" % (yhat[0, 0], loss))   # 0.6655 / 0.4073

# --- 反向 ---
d2 = (yhat - y)                       # δ2 = ŷ - y  = -0.3345
dW2 = d2 @ a1.T                       # δ2 · a1ᵀ
da1 = W2.T @ d2                       # 穿过 W2
d1 = da1 * (a1 * (1 - a1))            # ⊙ sigmoid'(z1)
dW1 = d1 @ x.T                        # δ1 · xᵀ
print("dW2 =", dW2.round(4))          # [[-0.1922 -0.2235]]
print("dW1 =\n", dW1.round(4))        # [[-0.0409 -0.0409][-0.0445 -0.0445]]

# ===== 梯度检验:数值梯度 vs 反传(见 笔记21)=====
def forward_loss(W1, W2):
    a1 = sig(W1 @ x); yh = sig(W2 @ a1)
    return -np.log(yh[0, 0])

def num_grad(W, which):
    g = np.zeros_like(W); eps = 1e-5
    for i in np.ndindex(W.shape):
        Wp = W.copy(); Wm = W.copy(); Wp[i] += eps; Wm[i] -= eps
        if which == 1: g[i] = (forward_loss(Wp, W2) - forward_loss(Wm, W2)) / (2*eps)
        else:          g[i] = (forward_loss(W1, Wp) - forward_loss(W1, Wm)) / (2*eps)
    return g

print("dW1 数值检验最大误差:", np.abs(num_grad(W1, 1) - dW1).max())   # ~1e-9 ✅
print("dW2 数值检验最大误差:", np.abs(num_grad(W2, 2) - dW2).max())   # ~1e-9 ✅
```

```python
# 常见反传 bug 清单(都能被梯度检验抓出):
# ❌ 1. 漏乘激活导数:  d1 = W2.T @ d2            # 忘了 ⊙ g'(z1)
# ❌ 2. 用 a 而非 z 的导数,或激活用错层
# ❌ 3. 转置写反:      dW = a @ delta.T 而非 delta @ a.T → 形状/值错
# ❌ 4. 用更新后的权重回传:必须用前向时的 W、缓存的激活,别先 step 再 backward
# ❌ 5. batch 维忘了求和/除以 B
# ✅ 正确:每穿过一层激活必乘其本地导数 g'(z);dW=δaᵀ;偏置 db=δ(沿 batch 求和)
```

手算对照:代码输出 `yhat=0.6655, loss=0.4073`、`dW2=[-0.1922,-0.2235]`、`dW1` 两行各为 $-0.0409,-0.0445$,与上面例子逐位吻合;数值梯度检验最大误差约 $10^{-9}$,确认反传公式实现正确(这正是 [[21 数值梯度检验与调试|梯度检验]] 的用途)。

## 面试高频

- **"手推/手写两层网络的反向传播。"** 高频实操题。记牢三框:$\delta_\ell=(W_{\ell+1}^T\delta_{\ell+1})\odot g'(z_\ell)$、$\partial\mathcal L/\partial W_\ell=\delta_\ell a_{\ell-1}^T$、$\partial\mathcal L/\partial b_\ell=\delta_\ell$。能就着具体数字走一遍最稳。
- **"反向为什么要缓存前向的中间激活?"** 权重梯度 $\delta_\ell a_{\ell-1}^T$ 需要前向的 $a_{\ell-1}$;激活导数 $g'(z_\ell)$ 需要 $z_\ell$ 或 $a_\ell$。所以前向必须存值,这也是训练比推理更费显存的原因(梯度检查点 / activation checkpointing 就是用算力换显存)。
- **"为什么 sigmoid 深层会梯度消失,ReLU 不会?"** 每层 $\delta$ 都乘 $g'(z)$;sigmoid 导数 $\le0.25$,多层连乘指数衰减;ReLU 正区导数为 1,梯度不缩水。
- **"softmax+交叉熵 / sigmoid+BCE 的输出层梯度为什么是 $\hat y-y$?"** softmax(或 sigmoid)的雅可比和 log 的导数在求 $\partial\mathcal L/\partial z$ 时刚好约掉,留下干净的 $p-y$。这也是框架把两者融成一个层的原因。
- **"反向传播复杂度?"** 与前向同阶(常数倍),额外开销是存中间激活的显存。
- **"batch 下权重梯度怎么算?"** $\frac1B\delta A^\top$(误差外积输入再对 batch 求和/平均);偏置 $\frac1B\sum\delta$。一次矩阵乘搞定整批。
- **"梯度消失/爆炸的数值根源?"** $L$ 层连乘,底层梯度 $\sim\gamma^L$;每层等效乘子 $\gamma<1$ 消失、$>1$ 爆炸。靠 ReLU/残差/归一化/合适初始化把 $\gamma$ 拉回 $\approx1$。
- **"activation checkpointing 是什么?"** 反向不缓存全部激活、按需重算,约 $1.3\times$ 算力换显存,训大模型必备。
- **"反传和自动微分什么关系?"** 反传 = 计算图上的反向模式自动微分,适合"少量输出(损失)对海量参数求导"的场景。

## 关键事实

- 反向传播算法:Rumelhart, Hinton & Williams, *Learning representations by back-propagating errors*(Nature, 1986)——把它推广为训练多层网络的通用方法。
- 逐层递推公式 $\delta_\ell=(W_{\ell+1}^T\delta_{\ell+1})\odot g'(z_\ell)$ 与权重梯度 $\delta a^T$,见 Goodfellow, Bengio & Courville《Deep Learning》(2016)第 6.5 节,及 Nielsen《Neural Networks and Deep Learning》第 2 章四大反传方程。
- 反向模式自动微分的现代实现(VJP / 计算图逆序),见 PyTorch autograd / JAX 文档,以及 CS231n 课程讲义。
