[[24 常见分布(高斯、伯努利、类别)|常见分布]]里,**高斯分布**描述连续的"钟形"噪声(身高、误差、权重),**伯努利分布**描述一次"是/否"二选一,**类别分布**(Categorical)描述一次 $K$ 选一——它们分别对应回归、二分类、多分类损失的概率假设,是 [[25 最大似然估计 MLE|MLE]] 推损失的起点。

## 直觉

**高斯(正态)分布**:大量独立小因素叠加,结果就长成对称钟形——中间最密、两侧迅速变稀(中心极限定理)。两个旋钮:均值 $\mu$ 决定钟峰在哪,标准差 $\sigma$ 决定钟有多胖。神经网络的初始化、噪声、连续输出几乎默认它。

**伯努利分布**:抛一次偏心硬币,正面概率 $p$、反面 $1-p$。是"二分类一个样本"的概率模型——sigmoid 输出的就是这个 $p$。

**类别分布**:掷一次偏心骰子,$K$ 个面各有概率 $p_1,\dots,p_K$($\sum p_k=1$)。是"多分类一个样本"的模型——[[27 Softmax 与温度|softmax]] 输出的正是这组 $p_k$。把伯努利推广到 $K$ 类就是它。

(注意:多次重复的次数分布分别叫二项分布、多项分布;这里讲的是"一次"的伯努利/类别。)

**离散/连续分布速查(零基础先建地图)**:

| 分布 | 描述什么 | 参数 | 期望 | 方差 | DL 里对应 |
|---|---|---|---|---|---|
| 伯努利 | 一次"是/否" | $p$ | $p$ | $p(1-p)$ | 二分类(sigmoid) |
| 二项 | $n$ 次是/否里成功几次 | $n,p$ | $np$ | $np(1-p)$ | — |
| 类别 | 一次 $K$ 选一 | $\boldsymbol p$ | — | — | 多分类(softmax) |
| 多项 | $n$ 次 $K$ 选一的计数 | $n,\boldsymbol p$ | $np_k$ | — | 词频/计数 |
| 均匀 $U(a,b)$ | 区间内等可能 | $a,b$ | $\frac{a+b}2$ | $\frac{(b-a)^2}{12}$ | 初始化、逆变换采样 |
| 高斯 | 连续钟形噪声 | $\mu,\sigma^2$ | $\mu$ | $\sigma^2$ | 回归(MSE)、初始化 |
| 拉普拉斯 | 尖峰重尾 | $\mu,b$ | $\mu$ | $2b^2$ | L1 先验(见 [[26 最大后验 MAP 与正则化的概率解释|MAP]]) |
| 指数 | 等待时间 | $\lambda$ | $1/\lambda$ | $1/\lambda^2$ | 逆变换采样例(见 [[28 采样方法(逆变换、Gumbel-Softmax、重参数化)|采样]]) |
| 泊松 | 单位时间稀有事件计数 | $\lambda$ | $\lambda$ | $\lambda$ | 计数数据 |

## 例子

**高斯密度手算**。标准正态 $\mu=0,\sigma=1$,峰值在 $x=0$:

$$f(0)=\frac{1}{\sqrt{2\pi}}e^{0}=\frac{1}{\sqrt{2\pi}}\approx0.399$$

$1\sigma$ 处 $x=1$:$f(1)=\frac{1}{\sqrt{2\pi}}e^{-1/2}\approx0.399\times0.6065\approx0.242$,比峰值矮约 $40\%$。记住"68–95–99.7":落在 $\mu\pm1\sigma/2\sigma/3\sigma$ 内的概率约 $68\%/95\%/99.7\%$。

**z 分数(标准化)手算**。一般高斯 $\mathcal N(\mu,\sigma^2)$ 通过 $z=\frac{x-\mu}{\sigma}$ 化成标准正态。例:$\mu=170,\sigma=10$ 的身高,$x=185$ 的 z 分数 $=\frac{185-170}{10}=1.5$,即"高于均值 1.5 个标准差",查表约处于 $93.3$ 百分位。所有"标准化/白化/BatchNorm"做的就是把数据减均值除标准差,挪到 $z$ 尺度。

**非标准高斯密度手算**。$\mu=170,\sigma=10$ 在 $x=185$:$f(185)=\frac{1}{\sqrt{2\pi}\cdot10}e^{-1.5^2/2}=\frac{1}{25.07}\times e^{-1.125}\approx0.0399\times0.3247\approx0.01296$。注意密度随 $\sigma$ 放大而整体压低($\frac1\sigma$ 因子),曲线变胖变矮但积分恒为 1。

**伯努利**。$p=0.7$,则 $P(X=1)=0.7,P(X=0)=0.3$。期望 $E[X]=p=0.7$,方差 $\text{Var}=p(1-p)=0.7\times0.3=0.21$。注意 $p=0.5$ 时方差最大($0.25$),最"不确定"。

**类别**。三类预测概率 $(0.1,0.3,0.6)$。一次抽样落到第 3 类的概率 $0.6$。若真实标签是第 3 类,这个样本的似然就是 $0.6$,负对数似然 $-\ln0.6\approx0.51$——这正是 [[27 Softmax 与温度|softmax]] 之后交叉熵要算的东西。

## 原理

**高斯(一维)**。密度

$$\mathcal N(x\mid\mu,\sigma^2)=\frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\Big(-\frac{(x-\mu)^2}{2\sigma^2}\Big),\quad E[X]=\mu,\ \text{Var}=\sigma^2$$

多维:$\mathcal N(x\mid\mu,\Sigma)\propto\exp\!\big(-\tfrac12(x-\mu)^T\Sigma^{-1}(x-\mu)\big)$,形状由 [[23 随机变量、期望、方差、协方差|协方差矩阵]] $\Sigma$ 决定。指数里的二次型 $(x-\mu)^2$ 是后面 [[26 最大后验 MAP 与正则化的概率解释|L2 正则 = 高斯先验]] 的来源。

**伯努利**。$P(X=x)=p^x(1-p)^{1-x},\ x\in\{0,1\}$。$E[X]=p,\ \text{Var}=p(1-p)$。一个样本的负对数似然

$$-\ln P=-\big[x\ln p+(1-x)\ln(1-p)\big]$$

正是**二元交叉熵**(BCE)。所以"sigmoid + BCE"不是凑出来的,是"假设标签服从伯努利,做 MLE"的必然结果。

**类别(Categorical)**。用 one-hot $y\in\{0,1\}^K$($\sum y_k=1$)表示标签,概率 $\boldsymbol p=(p_1,\dots,p_K),\sum p_k=1$:

$$P(y\mid\boldsymbol p)=\prod_{k=1}^K p_k^{\,y_k},\qquad -\ln P=-\sum_k y_k\ln p_k$$

右边就是**多类交叉熵**。把 logits 经 softmax 变成 $\boldsymbol p$、再套这个负对数似然,就是分类网络的标准损失。三者关系一句话:**伯努利是 $K=2$ 的类别分布,类别分布是高斯的离散对应物**;在 [[25 最大似然估计 MLE|MLE]] 框架下它们各自生出 MSE / BCE / 交叉熵。

**高斯的对数密度(为何 NLL = MSE,逐项拆)**。单样本负对数似然:
$$-\ln\mathcal N(x\mid\mu,\sigma^2)=\frac{(x-\mu)^2}{2\sigma^2}+\frac12\ln(2\pi\sigma^2)$$
固定 $\sigma$,第二项是常数,对 $\mu$ 求最小只剩 $\frac{(x-\mu)^2}{2\sigma^2}$ → **正比于平方误差**。把全体样本相加就是 MSE,这就是"回归用 MSE = 高斯噪声下的 MLE"的逐项来源(详见 [[25 最大似然估计 MLE|MLE]])。若让网络同时输出 $\mu$ 和 $\sigma$(异方差回归),则两项都参与,损失里会出现 $\ln\sigma$ 项——这是不确定性估计的入门形态。

**二项 / 多项分布(多次重复)**。$n$ 次独立伯努利里成功 $k$ 次的概率 $P(k)=\binom{n}{k}p^k(1-p)^{n-k}$,$E=np,\text{Var}=np(1-p)$。多项是它的 $K$ 类推广。与伯努利/类别的区别只是"一次 vs $n$ 次"——面试爱考这个辨析。

**指数族视角(进阶)**。高斯、伯努利、类别、二项、泊松、指数都属**指数族**,可写成统一形式 $p(x\mid\eta)=h(x)\exp\!\big(\eta^\top T(x)-A(\eta)\big)$,共享充分统计量 $T(x)$、自然参数 $\eta$、对数配分函数 $A(\eta)$ 与共轭先验结构,这解释了为何它们的 MLE 都有干净的闭式或凸优化形式。softmax 其实就是类别分布的自然参数(logits)到概率的映射,这给了 "logits → softmax" 一个指数族解释。

## 代码

```python
import numpy as np
rng = np.random.default_rng(0)

# 高斯:68-95-99.7 验证
x = rng.normal(0, 1, 1_000_000)
for k in (1, 2, 3):
    print(f"|x|<{k}σ 占比:", round((np.abs(x) < k).mean(), 3))
# ≈ 0.683 / 0.954 / 0.997

# 伯努利:p=0.7,均值≈0.7,方差≈0.21
b = (rng.random(1_000_000) < 0.7).astype(float)
print("Bernoulli 均值/方差:", round(b.mean(),3), round(b.var(),3))  # 0.700 0.210

# ❌ 类别采样:手写 argmax 概率最大类,丢了随机性
p = np.array([0.1, 0.3, 0.6])
wrong = p.argmax()                       # 永远输出 2,不是采样!
# ✅ 按概率采样
samples = rng.choice(3, size=100_000, p=p)
freq = np.bincount(samples, minlength=3) / 100_000
print("✅ 类别采样频率:", freq.round(3))  # ≈ [0.1 0.3 0.6]
print("第3类负对数似然 -ln0.6:", round(-np.log(0.6), 3))  # 0.511
```

`❌` 用 `argmax` 当"采样"会永远只出最大概率那一类、丢掉随机性;`✅` 用 `rng.choice(..., p=p)` 才是真正按类别分布采样,频率收敛到 $(0.1,0.3,0.6)$。负对数似然 $-\ln0.6\approx0.51$ 即该样本的交叉熵。

```python
# 中心极限定理:大量独立均匀变量之和趋于高斯
import numpy as np
rng = np.random.default_rng(0)
sums = rng.uniform(0, 1, (200_000, 12)).sum(axis=1)   # 12 个 U(0,1) 之和
print("均值≈6:", round(sums.mean(), 3), " 方差≈1:", round(sums.var(), 3))
# 12 个 U(0,1) 之和 ~ N(6,1)(老式生成标准正态的 trick)

# 高斯 NLL 拆成 MSE + 常数:固定 σ 时最小化 NLL = 最小化平方误差
x = np.array([2., 4., 6.]); sigma = 1.0
def gauss_nll(mu):
    return np.sum((x - mu)**2 / (2*sigma**2) + 0.5*np.log(2*np.pi*sigma**2))
mus = np.linspace(0, 8, 801)
print("argmin NLL 的 μ:", round(mus[np.argmin([gauss_nll(m) for m in mus])], 2))  # 4.0 = 样本均值
```

12 个均匀变量之和近似 $\mathcal N(6,1)$,印证中心极限定理(也是早期生成正态数的经典 trick);高斯 NLL 的最小值在样本均值,印证 NLL = MSE + 常数。

## 面试高频

- **"为什么回归用 MSE、分类用交叉熵?"** 回归假设噪声高斯 → MLE 得 MSE;分类假设标签伯努利/类别 → MLE 得 BCE/交叉熵。能从分布推损失是高分答案。
- **"伯努利方差什么时候最大?"** $p=0.5$ 时 $p(1-p)=0.25$ 最大,最不确定。
- **"高斯的 68-95-99.7 规则?"** $\mu\pm1/2/3\sigma$ 内概率约 $68\%/95\%/99.7\%$。
- **"类别分布和多项分布区别?"** 类别是一次试验($n=1$)的多项分布;多项是 $n$ 次重复的计数分布。面试常混。
- **"softmax 输出是什么分布?"** 类别分布的参数 $\boldsymbol p$。这把 [[27 Softmax 与温度|softmax]] 和交叉熵串成一条线。
- **"为什么处处都假设高斯?"** 中心极限定理:大量独立小因素之和趋于正态;在给定均值方差下高斯是最大熵分布(信息假设最少);且数学最好处理(线性运算下封闭、共轭)。
- **"z 分数 / 标准化是什么?"** $z=(x-\mu)/\sigma$,把任意高斯挪到标准正态;BatchNorm、特征缩放、白化都在做这件事。
- **"MSE 假设的噪声是什么?重尾数据怎么办?"** 等方差高斯;数据有重尾/离群点时换拉普拉斯假设 → MAE,或 Huber(见 [[36 损失函数(MSE、交叉熵、对比、Focal)|损失函数]])。
- **"伯努利、二项、类别、多项怎么区分?"** 一次是/否=伯努利,$n$ 次是/否计数=二项;一次 $K$ 选一=类别,$n$ 次 $K$ 选一计数=多项。"一次 vs 多次""二元 vs 多元"两条轴。
- **陷阱:概率密度 $f(x)$ 可以大于 1。** 连续分布是密度不是概率(如窄高斯峰值远大于 1),只有积分才是概率;单点概率为 0。

## 关键事实

- 高斯、伯努利、类别/多项分布及其性质见 Bishop《Pattern Recognition and Machine Learning》(2006)第 2 章(概率分布)。
- 中心极限定理解释高斯的普遍性:大量独立同分布变量之和趋于正态,见 Casella & Berger《Statistical Inference》(2002)第 5 章。
- 这三类分布同属指数族,统一了充分统计量与共轭先验,见 Murphy《Machine Learning: A Probabilistic Perspective》(2012)第 9 章。
