[[50 特征图、步幅、填充与感受野|特征图]]是卷积层的输出(一张张「某种特征在各位置的强度图」);**步幅**控制核每次滑多远、**填充**在边缘补 0 以保住尺寸,二者一起决定输出尺寸 $\big\lfloor\frac{W-K+2P}{S}\big\rfloor+1$;而**感受野**是输出某点回溯到原图能「看见」多大一块——层越深,看得越宽。

## 直觉

[[49 卷积运算与卷积核|卷积]]每个核扫一遍输入,产出一张二维图,叫**特征图**(feature map):图上每个数表示「这个核检测的特征(如竖直边)在该位置有多强」。一层有 $C_{\text{out}}$ 个核就出 $C_{\text{out}}$ 张特征图。

三个旋钮控制特征图怎么生成、长多大:
- **步幅 $S$**:核每次滑动几格。$S=1$ 逐格扫(输出大);$S=2$ 跳一格扫(**下采样**,输出近似减半)。
- **填充 $P$**:在输入四周补几圈 0。不补($P=0$,valid)时输出会缩小、且边缘像素「当不了中心」被欠采样;补 $P=\frac{K-1}{2}$(same)能让**输出尺寸 = 输入尺寸**,深网络才不会层层缩到没。
- **感受野** receptive field:输出图上一个点,是由原图多大一块算出来的。浅层只看几像素(局部边角),深层回溯一大片(整只猫)——这是 CNN 能从「局部纹理」长出「整体语义」的关键。

## 例子

**输出尺寸:5×5 输入、3×3 核,试三组参数。** 公式 $\big\lfloor\frac{W-K+2P}{S}\big\rfloor+1$。

- $S=1,P=0$:$\lfloor(5-3+0)/1\rfloor+1=2+1=\mathbf 3$ → 输出 3×3。
- $S=2,P=0$:$\lfloor(5-3+0)/2\rfloor+1=\lfloor1\rfloor+1=\mathbf 2$ → 输出 2×2(下采样)。
- $S=1,P=1$:$\lfloor(5-3+2)/1\rfloor+1=4+1=\mathbf 5$ → 输出 5×5(same,尺寸不变)。

![[cnn-步幅填充.svg]]

**一条小 CNN 的尺寸全程追踪(把公式连起来用)**。输入 $32\times32$,依次过:
- conv1:$3\times3,S{=}1,P{=}1$(same)→ $\lfloor(32-3+2)/1\rfloor+1=32$,尺寸不变。
- pool1:$2\times2,S{=}2$(等价 $K{=}2,P{=}0$)→ $\lfloor(32-2)/2\rfloor+1=16$,减半。
- conv2:$3\times3,S{=}1,P{=}1$ → 仍 16。
- pool2:$2\times2,S{=}2$ → 8。
- conv3:$5\times5,S{=}1,P{=}0$(valid)→ $\lfloor(8-5)/1\rfloor+1=4$。
$32\to32\to16\to16\to8\to4$:卷积(same)保尺寸、池化/stride 减半、valid 卷积缩一点。这套"算尺寸"是 CNN 调试最常用的基本功,接全连接前必须心算出最后的 $H\times W\times C$。

**感受野:堆两层 3×3($S=1$)。**
- conv1 后,每个点看输入 $3$ 个(1 维)→ 感受野 $r_1=3$。
- conv2 再叠一层 3×3,它的每个点看 conv1 的 3 个点,而那 3 个点又各看输入 3 个、彼此错开 1 → 合并后看输入 $3+2=5$ 个 → $r_2=5$。
- 再叠 conv3 → $r_3=7$。规律:**每多一层 $3\times3$($S=1$),感受野 +2**。

这解释了 [[51 池化与经典 CNN(LeNet→AlexNet→VGG→ResNet)|VGG]] 的核心 trick:**两层 3×3 的感受野 = 一层 5×5(都是 5),但参数更少($2\times3^2=18$ vs $5^2=25$)、非线性更多。**

**带下采样的感受野手算(步幅怎么放大感受野)**。堆三层:conv1(3×3, $S{=}1$)→ conv2(3×3, $S{=}2$ 下采样)→ conv3(3×3, $S{=}1$)。用递推 $r_\ell=r_{\ell-1}+(K_\ell-1)j_{\ell-1}$、$j_\ell=j_{\ell-1}S_\ell$,$r_0{=}1,j_0{=}1$:
- conv1:$r_1=1+(3-1)\cdot1=3$,$j_1=1\cdot1=1$。
- conv2:$r_2=3+(3-1)\cdot1=5$,$j_2=1\cdot2=2$(累计步幅翻倍)。
- conv3:$r_3=5+(3-1)\cdot j_2=5+2\cdot2=9$,$j_3=2\cdot1=2$。
对比全 $S{=}1$ 三层只有 $r=7$,加一个 stride2 后变成 9——**下采样让后续每层的"每一格"在原图上跨度更大,感受野增长加速**。若再多几个 stride2(像真实 CNN 那样),累计步幅指数翻倍,感受野迅速覆盖整图。

## 原理

**输出尺寸公式。** 一维方向,输入长 $W$、核 $K$、填充 $P$(两侧各 $P$)、步幅 $S$:
$$O=\Big\lfloor\frac{W-K+2P}{S}\Big\rfloor+1$$
取整(向下取整)对应「窗口放不满最后一步就丢弃」。二维就在高、宽两个方向各算一次。

**几种常用填充。**
- **valid**:$P=0$,不补,输出 $=\lfloor(W-K)/S\rfloor+1$,尺寸缩小。
- **same**($S=1$):令输出 $=W$,需 $P=\frac{K-1}{2}$(奇数核才整除;$K=3\Rightarrow P=1$,$K=5\Rightarrow P=2$)。
- $S>1$ 的 same 指「输出 $=\lceil W/S\rceil$」,需要的 $P$ 由该式反解。

**为什么要填充。** 不填充时,每过一层尺寸 $-(K-1)$,几十层后特征图会缩没;且**边缘像素被卷到的次数远少于中心**(信息欠采样)。补 0 让边缘也能当窗口中心,既保尺寸又均衡边缘。

**感受野递推。** 记第 $\ell$ 层感受野 $r_\ell$、累计步幅 $j_\ell=\prod_{i\le\ell}S_i$,核 $K_\ell$:
$$r_\ell=r_{\ell-1}+(K_\ell-1)\cdot j_{\ell-1},\qquad j_\ell=j_{\ell-1}\cdot S_\ell,\quad r_0=1,\ j_0=1$$
- 全 $S=1$、核 $K$ 的 $L$ 层:$r_L=1+L(K-1)$。3×3 堆 $L$ 层 → $r=1+2L$(线性增长)。
- 加入 $S=2$ 的下采样(或 [[51 池化与经典 CNN(LeNet→AlexNet→VGG→ResNet)|池化]])会让 $j$ 翻倍,**感受野指数级变宽**——这是深 CNN 高效覆盖整图的真正原因。

**步幅卷积 vs 池化。** 两者都做下采样;$S{=}2$ 卷积是「带可学习权重的下采样」,池化是「无参数的固定下采样」。现代网络(如 ResNet)常用 $S{=}2$ 卷积替代部分池化。

**有效感受野 ≠ 理论感受野(进阶但常被问)。** 上面算的是「理论上能看到多大一块」,但 Luo et al.(2016)发现:理论感受野内,**中心像素的贡献远大于边缘**,实际起作用的「有效感受野」呈近似高斯分布,直径只有理论值的约 $1/\sqrt L$(随层数 $L$)。含义:① 网络实际「看」的范围比公式算的小;② 想真正扩大有效感受野,加深、加下采样、加空洞卷积都有用,但别指望理论感受野那么满。

**空洞/膨胀卷积扩感受野(不下采样的办法)。** 膨胀率 $d$ 让 $k\times k$ 核的等效大小变成 $k+(k-1)(d-1)$:$3\times3$ 核 $d{=}2$ 时等效 $5\times5$、$d{=}4$ 时等效 $9\times9$,**参数仍是 9 个、空间分辨率不变**。语义分割(DeepLab)堆几个不同 $d$ 的空洞卷积,既保住分辨率又拿到大感受野,正是为了避开「下采样丢空间细节」的代价。

**特征图的内存账(工程视角)。** 一张特征图占内存 $\approx N\times C\times H\times W\times 4$ 字节(float32)。浅层 $H,W$ 大、$C$ 小;深层下采样后 $H,W$ 小、$C$ 大。前向激活要全部缓存供反向用,所以**显存峰值常卡在浅层的大特征图**——这也是为什么早早下采样、用 stride/池化缩空间能省显存。

## 代码

```python
import numpy as np

def out_size(W, K, P, S):
    return (W - K + 2*P) // S + 1

for (P, S) in [(0,1),(0,2),(1,1)]:
    print(f"P={P} S={S} -> {out_size(5,3,P,S)}")   # 3, 2, 5  ← 与手算一致 ✅

def receptive_field(layers):
    """layers: [(K, S), ...] 从输入侧到输出侧,返回最终感受野。"""
    r, j = 1, 1
    for (K, S) in layers:
        r = r + (K - 1) * j     # 感受野递推
        j = j * S               # 累计步幅
    return r

print(receptive_field([(3,1),(3,1)]))        # 5   两层3x3 = 一层5x5 的感受野
print(receptive_field([(3,1),(3,1),(3,1)]))  # 7
print(receptive_field([(3,2),(3,1)]))        # 加入 stride2 后,后层感受野按步幅放大
print(receptive_field([(3,1),(3,2),(3,1)]))  # 9  对照全 stride1 的 7,下采样让它更大

# 空洞卷积:膨胀率 d 让 k×k 核等效成 k+(k-1)(d-1),参数不变却扩感受野
def dilated_eff_k(k, d):
    return k + (k - 1) * (d - 1)
print("3x3 d=2 等效:", dilated_eff_k(3, 2), " d=4 等效:", dilated_eff_k(3, 4))  # 5, 9

# ❌ 误区:深网络一路 valid(P=0),特征图层层缩小,几十层后空间维变 0
# 32 -> 30 -> 28 -> ... 报错或信息耗尽

# ✅ PyTorch:用 padding 保尺寸 + stride 做下采样
import torch, torch.nn as nn
x = torch.randn(1, 3, 5, 5)
print(nn.Conv2d(3,8,3,stride=1,padding=0)(x).shape)  # [1,8,3,3]  valid
print(nn.Conv2d(3,8,3,stride=2,padding=0)(x).shape)  # [1,8,2,2]  下采样
print(nn.Conv2d(3,8,3,stride=1,padding=1)(x).shape)  # [1,8,5,5]  same ✅
```

## 面试高频

- **「卷积输出尺寸公式?」** $\big\lfloor\frac{W-K+2P}{S}\big\rfloor+1$。会代数:5×5 输入 3×3 核,$P{=}0,S{=}1$ 出 3;$S{=}2$ 出 2;$P{=}1,S{=}1$ 出 5(same)。
- **「same padding 怎么算?」** $S{=}1$ 时令输出 $=$ 输入,需 $P=\frac{K-1}{2}$(奇数核);$K{=}3\Rightarrow P{=}1$。
- **「为什么要 padding?」** 保住特征图尺寸(深网络不被层层缩没)+ 让边缘像素也能当窗口中心,避免边缘信息欠采样。
- **「感受野是什么,怎么变大?」** 输出一点回溯到原图能看见的范围。每堆一层 3×3($S{=}1$)+2;下采样($S{=}2$/池化)让它**成倍**扩大。深层大感受野 → 捕捉全局语义。
- **「为什么 VGG 用两层 3×3 代替一层 5×5?」** 感受野相同(都 5),但参数更少($18<25$)、多一次非线性、表达力更强。
- **「stride 卷积和池化都做下采样,区别?」** stride 卷积有可学权重,池化无参数固定规则;现代网络常用 stride2 卷积替代部分池化。
- **「理论感受野和有效感受野有什么不同?」** 理论是「能看到多大」,有效是「实际有多大贡献」。Luo 2016 发现有效感受野呈高斯分布、中心权重大,直径约理论值的 $1/\sqrt L$,所以网络实际看的范围比公式小。
- **「空洞卷积怎么扩感受野?代价?」** 膨胀率 $d$ 让 $k\times k$ 等效成 $k+(k-1)(d-1)$,参数和分辨率不变;代价是「网格效应」(采样有空洞),需多个 $d$ 错开缓解。
- **「为什么 stride 比池化更能放大感受野?」** stride>1 让累计步幅 $j$ 翻倍,后续每层每格在原图跨度成倍增大,感受野增长从线性变指数。
- **「显存峰值为什么常在浅层?」** 浅层特征图空间大($H,W$ 大),激活要缓存供反向用,占内存 $\propto NCHW$;早下采样能显著省显存。

## 关键事实

- 输出尺寸公式 $\lfloor(W-K+2P)/S\rfloor+1$、valid/same 填充约定,见 Dumoulin & Visin, *A guide to convolution arithmetic for deep learning*(arXiv:1603.07285, 2016)——卷积算术的权威小册。
- 「两层 3×3 = 一层 5×5 感受野,但参数更少、非线性更多」是 VGG 的核心论点,见 Simonyan & Zisserman, *Very Deep Convolutional Networks for Large-Scale Image Recognition*(VGG, ICLR 2015)。
- 感受野递推公式与可视化,见 Araujo et al., *Computing Receptive Fields of Convolutional Neural Networks*(Distill, 2019)。
- **有效感受野**:Luo, Li, Urtasun & Zemel, *Understanding the Effective Receptive Field in Deep CNNs*(NeurIPS 2016)——有效感受野呈高斯、远小于理论值。
- **空洞卷积**:Yu & Koltun, *Multi-Scale Context Aggregation by Dilated Convolutions*(ICLR 2016);DeepLab 系列(Chen et al., 2017–2018)用 ASPP 多尺度空洞。
- 特征图、填充、步幅的基础定义,见 Goodfellow, Bengio & Courville《Deep Learning》(2016)第 9.1–9.5 节。
