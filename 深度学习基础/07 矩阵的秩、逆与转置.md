[[07 矩阵的秩、逆与转置|秩]]是一个矩阵作为线性变换后"输出空间还剩几维",[[07 矩阵的秩、逆与转置|逆]]是把这个变换原样撤销的反向操作,[[07 矩阵的秩、逆与转置|转置]]则是把矩阵沿主对角线翻折、行列互换。这三个量一起回答了"这个 [[05 矩阵与线性变换(可视化)|线性变换]] 丢没丢信息、能不能复原、怎么换个角度看它"。

## 直觉

把矩阵想成一台**揉面机**。

- **秩**:面团本来是三维的(一团),机器压完后如果还是一团,秩=3,信息全在;如果压成一张饼(二维),秩=2,塌了一维;压成一根面条(一维),秩=1。秩就是"压完后还剩几维"。
- **逆**:如果机器只是把面团旋转、拉伸但没压扁(满秩),那存在一台"反向机器"能精确还原——这就是逆矩阵。一旦压成饼,被压没的那一维信息永远找不回来,就没有逆。
- **转置**:把矩阵这张数字表格沿对角线翻一下,横着读的变竖着读。它本身不"揉面",但在点积、协方差、反向传播里到处都是它。

## 例子

**手算秩**。看这个 $3\times3$ 矩阵:

$$A=\begin{bmatrix}1&2&3\\2&4&6\\1&1&1\end{bmatrix}$$

第二行 $=2\times$ 第一行,它俩线性相关([[04 向量空间、基与维度|线性相关]]),只能算一个独立方向。第三行 $(1,1,1)$ 不是第一行的倍数,独立。所以**独立行数 = 2**,$\text{rank}(A)=2$。这个 $3\times3$ 矩阵把三维空间压成了二维平面。

**手算逆($2\times2$)**。对 $A=\begin{bmatrix}a&b\\c&d\end{bmatrix}$,公式是

$$A^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$$

取 $A=\begin{bmatrix}2&1\\1&1\end{bmatrix}$,行列式 $ad-bc=2\cdot1-1\cdot1=1$,于是

$$A^{-1}=\frac{1}{1}\begin{bmatrix}1&-1\\-1&2\end{bmatrix}=\begin{bmatrix}1&-1\\-1&2\end{bmatrix}$$

验证:$A A^{-1}=\begin{bmatrix}2&1\\1&1\end{bmatrix}\begin{bmatrix}1&-1\\-1&2\end{bmatrix}=\begin{bmatrix}1&0\\0&1\end{bmatrix}=I$。对上了。

**再手算一个满秩 $3\times3$ 的秩**。$B=\begin{bmatrix}1&2&3\\0&1&4\\0&0&1\end{bmatrix}$ 是上三角且对角线全非零,三行没有谁是别人的组合(逐行消元也消不掉),所以 $\text{rank}(B)=3$,满秩、可逆。**速记:上/下三角矩阵的秩 ≥ 非零对角元个数;对角线全非零 ⇒ 满秩。**

**手算 $2\times2$ 逆的另一例 + 不可逆的反例**。$C=\begin{bmatrix}3&2\\1&4\end{bmatrix}$,$\det=3\cdot4-2\cdot1=10\ne0$,

$$C^{-1}=\frac{1}{10}\begin{bmatrix}4&-2\\-1&3\end{bmatrix}=\begin{bmatrix}0.4&-0.2\\-0.1&0.3\end{bmatrix}$$

验证 $CC^{-1}=\begin{bmatrix}3\cdot0.4+2\cdot(-0.1) & 3\cdot(-0.2)+2\cdot0.3\\ 1\cdot0.4+4\cdot(-0.1) & 1\cdot(-0.2)+4\cdot0.3\end{bmatrix}=\begin{bmatrix}1&0\\0&1\end{bmatrix}=I$。✓ 反例 $\begin{bmatrix}1&2\\2&4\end{bmatrix}$:$\det=1\cdot4-2\cdot2=0$,公式分母为 0,无逆。

**转置**。$\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}^{T}=\begin{bmatrix}1&4\\2&5\\3&6\end{bmatrix}$,第 $i$ 行变第 $i$ 列。逐元素看:$(A^\top)_{ij}=A_{ji}$,如原来 $A_{12}=2$(第 1 行第 2 列)挪到 $(A^\top)_{21}$(第 2 行第 1 列)。形状从 $2\times3$ 变 $3\times2$。

## 原理

**秩**。$\text{rank}(A)$ 的等价定义有好几个,记住它们等价很重要:

- **线性无关的列数** = 列空间([[06 矩阵乘法的几何意义|列向量张成]]的空间)的维数;
- **线性无关的行数**;
- 行秩恒等于列秩,所以 $\text{rank}(A)=\text{rank}(A^T)$。

对 $m\times n$ 矩阵,$\text{rank}(A)\le\min(m,n)$。取到 $\min(m,n)$ 叫**满秩**。秩亏(rank-deficient)意味着变换把空间压扁了,见下图。

![[la-秩列空间压缩.png]]

**四个基本子空间(秩把它们串起来)**。对 $m\times n$ 矩阵 $A$,秩 $r$:

- **列空间**(列张成,$\subseteq\mathbb{R}^m$)维数 $=r$ —— 所有可能的输出 $A\mathbf{x}$。
- **行空间**(行张成,$\subseteq\mathbb{R}^n$)维数 $=r$ —— 行秩=列秩在这里体现。
- **零空间**($A\mathbf{x}=\mathbf{0}$ 的解,$\subseteq\mathbb{R}^n$)维数 $=n-r$ —— 被"压没"的输入方向。
- **左零空间**($A^\top\mathbf{y}=\mathbf{0}$,$\subseteq\mathbb{R}^m$)维数 $=m-r$。

**秩-零化度定理**:$\text{rank}(A)+\dim(\text{零空间})=n$(列数)。直觉:输入有 $n$ 个自由度,被压没 $n-r$ 个,剩 $r$ 个变成输出维度。

**乘积的秩**:$\text{rank}(AB)\le\min(\text{rank}(A),\text{rank}(B))$ —— 乘法只会丢信息不会凭空增秩。对外积 $\mathbf{u}\mathbf{v}^\top$,当 $\mathbf u\ne\mathbf0$ 且 $\mathbf v\ne\mathbf0$ 时秩为 1;任一向量为零时外积就是零矩阵、秩为 0(见 [[03 点积、范数与相似度|外积]])。非零外积是 [[10 SVD 奇异值分解|SVD]] 把矩阵拆成秩 1 块求和的基础。低秩矩阵在深度学习里很关键:LoRA 微调就是用两个瘦长矩阵的积 $BA$(秩 $\ll$ 全秩)去近似权重更新。

**逆**。方阵 $A$ 可逆 $\iff$ 以下任一成立(都等价):

$$\det(A)\ne 0 \iff \text{rank}(A)=n \iff Ax=0\text{ 只有零解} \iff \text{列向量线性无关}$$

逆的几何含义:$A$ 把单位方格变成某个平行四边形,$A^{-1}$ 把它精确变回去,$A^{-1}A=I$。一旦 $\det(A)=0$(面积被压成 $0$,见 [[08 行列式与空间缩放|行列式]]),信息丢了,逆不存在。

![[la-逆变换撤销.png]]

逆的运算律(面试爱考顺序反转):

$$(AB)^{-1}=B^{-1}A^{-1},\qquad (A^{-1})^{-1}=A,\qquad (A^T)^{-1}=(A^{-1})^T$$

直觉:先穿袜子再穿鞋,脱的时候要先脱鞋再脱袜子——顺序反过来。

**转置**。定义 $(A^T)_{ij}=A_{ji}$,几何上是沿主对角线翻折。

![[la-转置几何.png]]

转置的运算律:

$$(A+B)^T=A^T+B^T,\qquad (AB)^T=B^T A^T,\qquad (A^T)^T=A$$

注意 $(AB)^T=B^TA^T$ 也是**顺序反转**。点积可以写成 $x\cdot y=x^Ty$(见 [[03 点积、范数与相似度|点积]]),所以转置在内积、协方差矩阵 $X^TX$、反向传播 $J^T$ 里无处不在。

**对称矩阵**:满足 $A=A^T$。它沿对角线翻折后不变,有极好的性质(实特征值、正交特征向量),是 [[09 特征值与特征向量|特征分解]] 和 [[11 主成分分析 PCA|PCA]] 的主角。任何矩阵 $X$ 的 $X^\top X$、$XX^\top$(协方差/Gram 矩阵)都对称且半正定,这是 PCA 与 [[10 SVD 奇异值分解|SVD]] 的入口。

**正交矩阵**:满足 $Q^\top Q=I$,即 $Q^{-1}=Q^\top$(逆=转置,免求逆)。它代表**旋转/镜像**——保长度、保角度、保内积($\|Q\mathbf{x}\|=\|\mathbf{x}\|$)。$\det Q=\pm1$。SVD 里的 $U,V$、特征分解里对称阵的 $Q$ 都是正交矩阵。

**伪逆(Moore-Penrose pseudo-inverse)$A^+$**:非方阵或奇异矩阵没有真逆,但有伪逆,用来求最小二乘解。列满秩时 $A^+=(A^\top A)^{-1}A^\top$(左逆),行满秩时 $A^+=A^\top(AA^\top)^{-1}$(右逆);一般情形由 SVD 给出 $A^+=V\Sigma^+U^\top$(把非零奇异值取倒数)。线性回归的正规方程解 $\hat{\mathbf{w}}=(X^\top X)^{-1}X^\top\mathbf{y}=X^+\mathbf{y}$ 就是它。

**伪逆手算(3×2 瘦高最小二乘)**。拟合 $y=w_0+w_1x$,数据 $(0,1),(1,2),(2,2)$,设计矩阵与目标
$$A=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix},\quad \mathbf{y}=\begin{bmatrix}1\\2\\2\end{bmatrix}.$$
列满秩,走左逆 $A^+=(A^\top A)^{-1}A^\top$。先 $A^\top A=\begin{bmatrix}3&3\\3&5\end{bmatrix}$,$\det=3\cdot5-3\cdot3=6$,故
$$(A^\top A)^{-1}=\frac{1}{6}\begin{bmatrix}5&-3\\-3&3\end{bmatrix}.$$
再 $A^\top\mathbf{y}=\begin{bmatrix}1+2+2\\0+2+4\end{bmatrix}=\begin{bmatrix}5\\6\end{bmatrix}$,于是
$$\hat{\mathbf{w}}=(A^\top A)^{-1}A^\top\mathbf{y}=\frac{1}{6}\begin{bmatrix}5&-3\\-3&3\end{bmatrix}\begin{bmatrix}5\\6\end{bmatrix}=\frac{1}{6}\begin{bmatrix}7\\3\end{bmatrix}=\begin{bmatrix}7/6\\1/2\end{bmatrix}.$$
即最优直线 $\hat y=\tfrac{7}{6}+\tfrac{1}{2}x$。注意 $A^+$ 是 $2\times3$:它把三维观测压回二维参数,这正是"瘦高矩阵无真逆、伪逆给最小二乘解"的含义。

## 代码

```python
import numpy as np

A = np.array([[1, 2, 3],
              [2, 4, 6],
              [1, 1, 1]])
print("rank:", np.linalg.matrix_rank(A))   # 2,因为第二行=2×第一行

# 可逆矩阵
B = np.array([[2, 1],
              [1, 1]])
Binv = np.linalg.inv(B)
print("B^-1:\n", Binv)            # [[ 1 -1] [-1  2]]
print("B @ B^-1:\n", B @ Binv)    # 单位阵 I
print("det:", np.linalg.det(B))   # 1.0 ≠ 0,可逆

# 转置
M = np.array([[1, 2, 3],
              [4, 5, 6]])
print("M^T:\n", M.T)              # 3×2

# 奇异(不可逆)矩阵会报错或给出巨大数:
S = np.array([[1., 2.],
              [2., 4.]])           # 第二行=2×第一行,rank=1
print("det S:", np.linalg.det(S))  # ≈ 0
try:
    np.linalg.inv(S)
except np.linalg.LinAlgError as e:
    print("不可逆:", e)            # Singular matrix
```

手算对照:`B^-1` 与上面手算的 $\begin{bmatrix}1&-1\\-1&2\end{bmatrix}$ 完全一致;`rank(A)=2` 与"两个独立行"的手算一致。

```python
# 工程实践:解 Ax=b 不要显式求逆,用 solve(更快更稳)
A2 = np.array([[2., 1.], [1., 1.]])
bb = np.array([3., 2.])
x_bad  = np.linalg.inv(A2) @ bb     # ❌ 求逆再乘,数值差、慢
x_good = np.linalg.solve(A2, bb)    # ✅ 直接解,LU 分解
print(np.allclose(x_bad, x_good))   # True 但 good 更稳更快

# 正交矩阵:逆 = 转置,保长度
theta = 0.7
Q = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
print(np.allclose(Q.T @ Q, np.eye(2)))     # True  Q^T Q = I
print(np.allclose(np.linalg.inv(Q), Q.T))  # True  逆就是转置
v = np.array([3., 4.])
print(np.linalg.norm(Q @ v), np.linalg.norm(v))  # 5.0 5.0 旋转保长度

# 伪逆:非方阵的最小二乘(线性回归正规方程 (X^T X)^-1 X^T y)
X = np.array([[1., 1.], [1., 2.], [1., 3.]])   # 3x2,瘦高,列满秩
y = np.array([1., 2., 2.])
w = np.linalg.pinv(X) @ y
print("最小二乘解:", w.round(3))
```

## 面试高频

- **"秩是什么的直觉解释?"** 标准答法:线性变换后输出空间(列空间)的维数,也就是"压扁后还剩几维"。陷阱:别只背"线性无关行/列数",要能说出几何含义和"行秩=列秩"。
- **"什么时候矩阵不可逆?"** 答:$\det=0$ / 非满秩 / 列线性相关 / 有非零解的零空间——这些等价,任答一个并说"它们等价"加分。陷阱:非方阵根本没有(双边)逆,只有伪逆。
- **"$(AB)^{-1}$ 和 $(AB)^T$ 等于什么?"** 都顺序反转:$B^{-1}A^{-1}$、$B^TA^T$。这是高频送分题,但很多人会写反。
- **"实际中真的去求逆吗?"** 标准答:几乎不。解 $Ax=b$ 用 LU 分解 / `np.linalg.solve`,数值更稳更快;深度学习里更不会显式求大矩阵的逆。说出这点显示工程素养。
- **陷阱题**:"满秩一定可逆吗?" 只有**方阵满秩**才可逆;非方阵满秩(行满秩或列满秩)不等于可逆。
- **"秩-零化度定理是什么?"** $\text{rank}(A)+\dim(\text{零空间})=n$(列数):输入自由度 = 留下的秩 + 被压没的零空间维度。
- **"对称矩阵 / 正交矩阵有什么特殊?"** 对称 $A=A^\top$ ⇒ 实特征值 + 正交特征向量(谱定理);正交 $Q^\top Q=I$ ⇒ 逆=转置、保长度、代表旋转/镜像。两者在 PCA/SVD 里是主角。
- **"$\text{rank}(AB)$ 和 $\text{rank}(A)$ 谁大?"** $\text{rank}(AB)\le\min(\text{rank }A,\text{rank }B)$,乘法不增秩;外积 $\mathbf{u}\mathbf{v}^\top$ 在两向量都非零时秩为 1,任一为零时秩为 0(LoRA、SVD 的基础)。
- **"伪逆什么时候用?"** 非方阵/奇异矩阵求最小二乘解;列满秩时 $A^+=(A^\top A)^{-1}A^\top$,一般情形由 SVD 给出。

## 关键事实

- 行秩 = 列秩(rank 的对称性)是线性代数基本定理之一,见 Strang《Introduction to Linear Algebra》(第 6 版,2023)对四个基本子空间的论述。
- 可逆矩阵定理(Invertible Matrix Theorem)把"可逆 / 满秩 / 行列式非零 / 零空间平凡"等十余个等价条件并列,见 Lay《Linear Algebra and Its Applications》(第 5 版,2016)§2.3。
- 工程上解线性方程组优先用分解(LU/QR/Cholesky)而非显式求逆,见 Golub & Van Loan《Matrix Computations》(第 4 版,2013)。
