[[02 向量运算：加法、缩放与线性组合|向量加法与缩放]]:向量只有两种基本运算——**逐分量相加**(几何上首尾相接)和**乘以一个标量缩放长度**;把两者拼起来就是**线性组合** $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \dots$,它是整个线性代数(乃至神经网络每一层)的运算骨架。

## 直觉

接着 [[01 标量、向量与几何直觉|向量]] 那个"导航"比喻:

- **加法**:你先"向东 2、向北 1"(向量 $\mathbf{a}$),再接着"向东 1、向北 3"(向量 $\mathbf{b}$)。最终落点 = 两段位移接力。几何上就是把 $\mathbf{b}$ 的尾巴接到 $\mathbf{a}$ 的箭头上——**首尾相接**。
- **缩放(标量乘法)**:把"向东 2、向北 1"整体放大 3 倍 = "向东 6、向北 3"。方向不变,长度变 3 倍。乘负数则**反向**。
- **线性组合**:任意"几份这个方向 + 几份那个方向"的配方。例如 $2\mathbf{v} - \mathbf{w}$ = "走 2 份 v,再倒退 1 份 w"。

为什么重要?神经网络一层的核心计算就是:把输入向量的各分量按权重缩放再相加,这正是线性组合。看懂这一节,你就看懂了全连接层在算什么。

## 例子

设 $\mathbf{a} = [2, 1]$,$\mathbf{b} = [1, 3]$。

**加法**(逐分量相加)——对齐同一根轴的分量,各自相加:

$$\mathbf{a} + \mathbf{b} = [\,\underbrace{2+1}_{\text{x 轴}},\; \underbrace{1+3}_{\text{y 轴}}\,] = [3, 4]$$

![[la-向量加法平行四边形.png]]

**减法**(逐分量相减,几何上是"从 b 指向 a 的箭头"):

$$\mathbf{a} - \mathbf{b} = [2-1,\; 1-3] = [1, -2]$$

记住一个万能视角:$\mathbf{a}-\mathbf{b}=\mathbf{a}+(-\mathbf{b})$,减法就是"加上反向向量"。差向量 $\mathbf{a}-\mathbf{b}$ 的几何意义是**从 b 的尖端指向 a 的尖端**(后面 [[03 点积、范数与相似度|欧氏距离]] $\|\mathbf{a}-\mathbf{b}\|$ 就是这根箭头的长度)。

**缩放**(每个分量都乘同一个标量):

$$3\mathbf{a} = [3\times 2,\; 3\times 1] = [6, 3]\quad(\text{方向不变、长 3 倍})$$
$$-\mathbf{b} = (-1)\cdot[1,3]=[-1, -3]\quad(\text{长度不变、方向掉头})$$
$$0.5\,\mathbf{a}=[1,\,0.5]\quad(\text{缩到一半}),\qquad 0\cdot\mathbf{a}=[0,0]=\mathbf{0}\quad(\text{乘 0 塌成零向量})$$

**再换一组三维数字手算一遍**(别只会二维)。设 $\mathbf{u}=[1,-2,3]$、$\mathbf{w}=[4,0,-1]$:

$$\mathbf{u}+\mathbf{w}=[1+4,\,-2+0,\,3+(-1)]=[5,-2,2]$$
$$\mathbf{u}-\mathbf{w}=[1-4,\,-2-0,\,3-(-1)]=[-3,-2,4]$$
$$2\mathbf{u}=[2,-4,6],\qquad -3\mathbf{w}=[-12,0,3]$$

**线性组合**:取 $\mathbf{v}=[1,1]$、$\mathbf{w}=[2,-1]$,算 $2\mathbf{v} - \mathbf{w}$,分三步走最稳:

$$\text{① 缩放: } 2\mathbf{v} = [2,2],\quad \text{② 缩放: } -\mathbf{w} = [-2, 1],\quad \text{③ 逐分量相加: } 2\mathbf{v}-\mathbf{w} = [2+(-2),\; 2+1] = [0, 3]$$

**再算一个三向量的线性组合**(神经元的味道):$3\mathbf{v}_1-2\mathbf{v}_2+\mathbf{v}_3$,其中 $\mathbf{v}_1=[1,0]$、$\mathbf{v}_2=[1,1]$、$\mathbf{v}_3=[0,2]$:

$$3[1,0]+(-2)[1,1]+1[0,2]=[3,0]+[-2,-2]+[0,2]=[3-2+0,\;0-2+2]=[1,0]$$

逐轴看更清楚:x 轴 $3\cdot1-2\cdot1+1\cdot0=1$,y 轴 $3\cdot0-2\cdot1+1\cdot2=0$。一个神经元算 $\sum_i w_i x_i$ 就是这种"系数 × 输入向量再相加",只不过输入是标量分量、配比是权重。

![[la-线性组合张成.png]]

把系数 $c_1, c_2$ 取遍所有实数,$c_1\mathbf{v} + c_2\mathbf{w}$ 能扫出**整个平面**——这就是"$\mathbf{v}, \mathbf{w}$ **张成**(span)了 $\mathbb{R}^2$",是 [[04 向量空间、基与维度]] 的预演。但注意:如果 $\mathbf{v}$、$\mathbf{w}$ 共线(如 $\mathbf{w}=2\mathbf{v}$),无论怎么配比都只能落在那一条直线上,张成的只是 1 维——这就是 [[04 向量空间、基与维度|线性相关]] 的几何后果。

## 原理

对 $\mathbf{u}, \mathbf{v} \in \mathbb{R}^n$ 和标量 $c \in \mathbb{R}$,逐分量定义:

$$(\mathbf{u} + \mathbf{v})_i = u_i + v_i, \qquad (c\,\mathbf{u})_i = c\,u_i$$

**线性组合**是这两者的复合:给定向量组 $\mathbf{v}_1, \dots, \mathbf{v}_k$ 和系数 $c_1, \dots, c_k$,

$$\sum_{j=1}^{k} c_j\, \mathbf{v}_j = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k$$

这些运算满足**向量空间公理**,实用记忆:

- **交换律**:$\mathbf{u}+\mathbf{v} = \mathbf{v}+\mathbf{u}$(走的顺序不影响落点)。
- **结合律**:$(\mathbf{u}+\mathbf{v})+\mathbf{w} = \mathbf{u}+(\mathbf{v}+\mathbf{w})$。
- **分配律**:$c(\mathbf{u}+\mathbf{v}) = c\mathbf{u} + c\mathbf{v}$,$(c+d)\mathbf{u} = c\mathbf{u}+d\mathbf{u}$。
- **零向量** $\mathbf{0}$ 是加法单位元;$-\mathbf{u}$ 是 $\mathbf{u}$ 的逆。

> 关键洞察:神经网络全连接层 $\mathbf{y} = W\mathbf{x} + \mathbf{b}$,其中 $W\mathbf{x}$ 的每个输出分量都是输入分量的线性组合(权重就是系数)。所谓"学习"很大程度就是在学这些系数。矩阵乘法 $W\mathbf{x}$ 的列视角(见 [[06 矩阵乘法的几何意义]])正是"把 $W$ 的列向量按 $\mathbf{x}$ 的分量做线性组合"。

注意线性组合**不允许**的操作:逐分量相乘(那是 Hadamard 积,不是线性运算)、开方、取 max——这些非线性操作要靠[[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]]单独引入。

**几何法则速记**:

- **加法 = 平行四边形法则 / 首尾相接**:把 $\mathbf{b}$ 平移到 $\mathbf{a}$ 的尖端,$\mathbf{a}+\mathbf{b}$ 是从原点到新尖端的对角线。等价地,以 $\mathbf{a},\mathbf{b}$ 为两边作平行四边形,对角线就是和。
- **减法 = 连接两个尖端**:$\mathbf{a}-\mathbf{b}$ 是从 $\mathbf{b}$ 尖端指向 $\mathbf{a}$ 尖端的箭头(再平移回原点)。
- **缩放 = 沿原方向伸缩**:$c>1$ 拉长、$0<c<1$ 缩短、$c<0$ 反向、$c=0$ 塌成原点。

**一个常被忽略的事实:范数对缩放是"齐次"的,对加法只满足"不等式"**。

$$\|c\mathbf{v}\|=|c|\,\|\mathbf{v}\|\quad(\text{绝对齐次}),\qquad \|\mathbf{a}+\mathbf{b}\|\le\|\mathbf{a}\|+\|\mathbf{b}\|\quad(\text{三角不等式})$$

例:$\|3\mathbf{a}\|=3\|\mathbf{a}\|$(缩 3 倍长度也 3 倍);但 $\|\mathbf{a}+\mathbf{b}\|$ 一般 **小于** $\|\mathbf{a}\|+\|\mathbf{b}\|$(两段路接力走的直线距离 ≤ 分头走的总路程),仅当同向时取等。详见 [[03 点积、范数与相似度|范数]]。

## 代码

```python
import numpy as np

a = np.array([2, 1])
b = np.array([1, 3])

# 加法：逐分量
print(a + b)        # [3 4]

# 减法：逐分量(= a + (-b))
print(a - b)        # [1 -2]

# 缩放：广播标量到每个分量
print(3 * a)        # [6 3]
print(-b)           # [-1 -3]
print(0.5 * a)      # [1.  0.5]

# 三维也一样,逐分量
u = np.array([1, -2, 3]); ww = np.array([4, 0, -1])
print(u + ww)       # [5 -2 2]
print(2*u - 3*ww)   # [-10 -4 9]

# 线性组合 2v - w
v = np.array([1, 1])
w = np.array([2, -1])
print(2 * v - w)    # [0 3]

# 三向量线性组合 3v1 - 2v2 + v3
v1, v2, v3 = np.array([1,0]), np.array([1,1]), np.array([0,2])
print(3*v1 - 2*v2 + v3)   # [1 0]

# 一般线性组合：系数向量 c 点乘 向量组（堆成矩阵）
V = np.stack([v, w])          # shape (2,2)，每行一个向量
c = np.array([2, -1])         # 系数
print(c @ V)                  # [0 3]  = 2*v + (-1)*w
```

```python
# ❌ 朴素：for 循环逐分量做线性组合，维度一大就慢
def lincomb_slow(coeffs, vecs):
    out = np.zeros_like(vecs[0])
    for c, v in zip(coeffs, vecs):
        for i in range(len(v)):
            out[i] += c * v[i]
    return out

# ✅ 向量化：一行矩阵乘法搞定，底层并行
def lincomb_fast(coeffs, vecs):
    return np.asarray(coeffs) @ np.asarray(vecs)   # (k,) @ (k,n) -> (n,)
```

```python
# 易错对照：逐元素乘 vs 线性组合，完全不同
a = np.array([2, 3]); b = np.array([4, 5])
print(a + b)        # [6 8]   ← 线性运算(加法)
print(a * b)        # [8 15]  ← Hadamard 逐元素乘,不是线性组合!
print(2*a)          # [4 6]   ← 标量缩放(线性)

# 易错：形状不一致的加法会广播或报错,不是你想的逐分量
try:
    np.array([1,2,3]) + np.array([1,2])   # (3,) + (2,) 既不等也无 1 → 报错
except ValueError as e:
    print("形状不匹配:", e)
```

## 面试高频

- **"全连接层在数学上做了什么?"** 标准答法:对输入向量做**仿射变换** $W\mathbf{x}+\mathbf{b}$,其中 $W\mathbf{x}$ 是把输入分量做线性组合,$\mathbf{b}$ 平移;再叠加激活函数引入非线性。
- **"线性组合和点积是什么关系?"** $W\mathbf{x}$ 的每个输出分量 = $W$ 的对应行与 $\mathbf{x}$ 的[[03 点积、范数与相似度|点积]];而整体 $W\mathbf{x}$ 又可看成 $W$ 的列的线性组合。两种视角都对,面试能切换说明你理解透了。
- **陷阱:逐元素乘 ≠ 线性运算。** `a * b`(numpy 里是 Hadamard 积 `[2,3]`)不是向量空间运算,别和点积/线性组合混淆。
- **陷阱:广播的方向。** `3 * a` 靠广播把标量铺到每个分量;但 `a * b` 要求形状可广播,否则报错。
- **"向量加法满足哪些律?"** 交换律、结合律、有零向量(加法单位元)、有逆元(每个 $\mathbf{u}$ 有 $-\mathbf{u}$);缩放满足分配律与结合律——这 8 条就是向量空间公理(见 [[04 向量空间、基与维度]])。能背出"零元和逆元"是区分度。
- **"线性组合里系数能取负 / 取 0 吗?"** 能。取负 = 反向叠加,取 0 = 该向量不参与;系数遍历全体实数时所有组合的集合就是**张成空间(span)**。
- **陷阱:`a - b` 和 `b - a` 方向相反。** $\mathbf{a}-\mathbf{b}=-(\mathbf{b}-\mathbf{a})$,但长度相同 $\|\mathbf{a}-\mathbf{b}\|=\|\mathbf{b}-\mathbf{a}\|$——求"两点距离"时谁减谁无所谓,求"方向"时必须分清。

## 关键事实

- 两种基本运算:逐分量加法、标量缩放;复合得到线性组合。
- 几何上加法 = 首尾相接(平行四边形法则),缩放 = 改长度(负号反向)。
- 满足交换/结合/分配律 + 零向量 + 逆元,即向量空间公理(见 [[04 向量空间、基与维度]])。
- 神经网络全连接层 $\mathbf{y}=W\mathbf{x}+\mathbf{b}$ 的本质是线性组合 + 平移。
- 线性组合**不含**逐元素乘、开方等非线性操作,后者靠激活函数补足。
- 减法 $\mathbf{a}-\mathbf{b}=\mathbf{a}+(-\mathbf{b})$,几何上是连接两尖端的差向量;$\|\mathbf{a}-\mathbf{b}\|$ 是两点欧氏距离(见 [[03 点积、范数与相似度]])。
- 范数对缩放绝对齐次 $\|c\mathbf{v}\|=|c|\,\|\mathbf{v}\|$,对加法满足三角不等式 $\|\mathbf{a}+\mathbf{b}\|\le\|\mathbf{a}\|+\|\mathbf{b}\|$(同向取等)。
- 向量空间 8 条公理(交换/结合/分配 + 零元 + 逆元 + 标量乘单位元)见 Strang《Introduction to Linear Algebra》(第 6 版, 2023)第 1 章。
