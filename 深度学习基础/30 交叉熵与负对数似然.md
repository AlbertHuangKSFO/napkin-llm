[[30 交叉熵与负对数似然]]:**交叉熵 $H(p,q)=-\sum p\log q$ 衡量"用预测分布 $q$ 去编码真实分布 $p$ 的平均代价"**;它同时是分类任务的标准损失、是 [[25 最大似然估计 MLE|最大似然]]的负对数,也是把 [[27 Softmax 与温度|Softmax]] 输出接成可训练目标的那座桥——本库的中枢。

## 直觉

[[29 熵与信息量|熵]] $H(p)$ 是"用**真分布自己**的最优编码,平均要花多少 bit"。但模型并不知道真分布,它只有一个**猜测** $q$。如果你拿 $q$ 的编码去编真实发生的事件,平均代价会**变大**——大出来的那部分,就是你"猜错"的惩罚。

交叉熵 $H(p,q)$ 就是这个"用错码本的平均代价":

- $q$ 猜得越准($q\approx p$)→ 代价越接近真熵 $H(p)$ → 损失小。
- $q$ 猜得越离谱 → 代价越大 → 损失大。
- 而且它**专门惩罚"自信地犯错"**:当真类的预测概率 $q\to 0$,$-\log q\to+\infty$,损失爆炸。

分类里真标签是 **one-hot**($p$ 在真类上为 1、其余为 0),于是 $H(p,q)$ 整个求和**只剩真类那一项**,塌缩成 $-\log q[\text{真类}]$——这正是**负对数似然(NLL)**。"交叉熵损失 = NLL = $-\log$ 你给正确答案的概率",三句话是同一件事。

## 例子

**例 1:三分类,真标签是"猫"** $p=[1,0,0]$。模型预测 $q=[0.7,0.2,0.1]$(用 $\ln$):

$$H(p,q)=-(1\cdot\ln 0.7+0\cdot\ln 0.2+0\cdot\ln 0.1)=-\ln 0.7=0.357$$

只有真类项存活。若预测更准 $q=[0.9,\dots]$:$-\ln 0.9=0.105$(更小);若预测错 $q=[0.1,\dots]$:$-\ln 0.1=2.303$(大得多)。

**例 2:软标签(非 one-hot)。** 知识蒸馏里 $p=[0.6,0.3,0.1]$,$q=[0.5,0.4,0.1]$:

$$H(p,q)=-(0.6\ln 0.5+0.3\ln 0.4+0.1\ln 0.1)=0.416+0.275+0.230=0.921$$

此时所有项都参与。

**例 3:softmax+交叉熵梯度手算。** logits $z=[2,1,0.1]$,真类是第 1 类。
softmax:$\hat y=[0.659,0.242,0.099]$。梯度 $\partial L/\partial z=\hat y-y=[0.659-1,\ 0.242,\ 0.099]=[-0.341,\ 0.242,\ 0.099]$。
直觉:真类的 logit 该往**上**推(负梯度 → 增大),其余往下压。

**例 4:二元交叉熵 BCE(配 sigmoid)。** 真标签 $y=1$,sigmoid 输出 $\hat y=0.8$:
$$\text{BCE}=-[y\ln\hat y+(1-y)\ln(1-\hat y)]=-\ln 0.8=0.223$$
若 $y=0,\hat y=0.8$(预测严重错):$-\ln(1-0.8)=-\ln0.2=1.609$。BCE 是交叉熵在伯努利上的特例,梯度同样是 $\hat y-y$。

**例 5:CE 惩罚"自信地错"有多狠(对照表)**。真类概率 $\hat y_c$ 与损失 $-\ln\hat y_c$:

| $\hat y_c$ | 0.99 | 0.9 | 0.5 | 0.1 | 0.01 |
|---|---|---|---|---|---|
| $-\ln\hat y_c$ | 0.010 | 0.105 | 0.693 | 2.303 | 4.605 |

从 0.1 掉到 0.01(更自信地错)损失翻倍——$-\log$ 在 $\hat y\to0$ 时趋 $+\infty$,这正是我们要的"自信犯错重罚"。MSE 对同样的错只从 0.81 涨到 0.98,惩罚平缓得多。

**例 6:标签平滑(label smoothing)对 CE 的影响**。把 one-hot 真标签 $[1,0,0]$ 软化成 $[0.9,0.05,0.05]$($\varepsilon=0.1$),交叉熵变成对软标签求和:$H(p_{\text{soft}},q)=-(0.9\ln q_1+0.05\ln q_2+0.05\ln q_3)$。效果:不再逼真类概率到 1(防过度自信、改善校准),非真类也分到一点目标概率。这是现代分类/翻译模型的常用 trick(见 [[42 正则化(L2、Dropout、早停、标签平滑)]])。

## 原理

**交叉熵定义:**

$$H(p,q)=-\sum_x p(x)\log q(x)=\underbrace{H(p)}_{\text{真熵}}+\underbrace{D_{KL}(p\|q)}_{\ge 0}$$

由 $D_{KL}\ge 0$ 得 $H(p,q)\ge H(p)$:交叉熵的下界是真熵,$q=p$ 时取等。训练时 $H(p)$ 是常数,所以**最小化交叉熵 ⇔ 最小化 KL ⇔ 让 $q$ 逼近 $p$**(详见 [[31 KL 散度与 JS 散度]])。

**与最大似然等价。** 数据集 $\{(x_i,y_i)\}$,模型给真类的概率是 $q_\theta(y_i\mid x_i)$。对数似然

$$\log\mathcal L=\sum_i\log q_\theta(y_i\mid x_i)\quad\Rightarrow\quad -\log\mathcal L=\sum_i\bigl(-\log q_\theta(y_i\mid x_i)\bigr)$$

右边逐样本就是 NLL = one-hot 交叉熵。**最大化似然 = 最小化负对数似然 = 最小化交叉熵**,三者是同一个优化问题,见 [[25 最大似然估计 MLE]]。

**Softmax + 交叉熵的梯度(要会推)。** 设 logits $z$,$\hat y_i=\dfrac{e^{z_i}}{\sum_k e^{z_k}}$,真标签 one-hot $y$,损失 $L=-\sum_i y_i\log\hat y_i$。

softmax 雅可比:

$$\frac{\partial\hat y_i}{\partial z_j}=\hat y_i(\delta_{ij}-\hat y_j)$$

链式法则:

$$\frac{\partial L}{\partial z_j}=-\sum_i \frac{y_i}{\hat y_i}\frac{\partial\hat y_i}{\partial z_j}=-\sum_i \frac{y_i}{\hat y_i}\hat y_i(\delta_{ij}-\hat y_j)=-\sum_i y_i(\delta_{ij}-\hat y_j)$$

$$=-y_j+\hat y_j\sum_i y_i=\hat y_j-y_j\qquad(\textstyle\sum_i y_i=1)$$

$$\boxed{\ \frac{\partial L}{\partial z}=\hat y-y\ }$$

**预测减真值**,干净到反直觉——这正是把 softmax 和交叉熵**配对**使用的根本原因:中间所有 $\hat y_i/\hat y_i$ 和雅可比的交叉项全约掉,反传又快又稳。若把 softmax 换成别的、或损失换成 MSE,就拿不到这个简洁梯度。

**为什么 MSE + softmax 学得慢(梯度对比)**。若分类用 MSE,$\partial L/\partial z$ 会带上 softmax 雅可比因子 $\hat y_i(1-\hat y_i)$;当模型**自信地错**($\hat y$ 接近 0 或 1)时这个因子趋 0,**梯度饱和、几乎不更新**——明明错得离谱却学不动。交叉熵的 $\hat y-y$ 没有这个饱和因子,错得越狠梯度越大,所以收敛快。这是"分类必用交叉熵"最硬的工程理由。

**加权交叉熵(类别不平衡)**。给每类一个权重 $w_c$:$L=-\sum_c w_c\,y_c\ln\hat y_c$。少数类给大权重,缓解多数类主导梯度的问题;更强的版本是 [[36 损失函数(MSE、交叉熵、对比、Focal)|Focal Loss]],按预测置信度自适应降权简单样本。

## 代码

```python
import numpy as np

# ❌ 错 1:先 softmax 再 log,大 logit 时 exp 溢出 → inf/nan
def ce_naive(logits, y_idx):
    p = np.exp(logits) / np.exp(logits).sum()   # logits=1000 → exp 溢出
    return -np.log(p[y_idx])

# ❌ 错 2:把 softmax 概率再喂进框架的 CrossEntropyLoss(它内部已含 softmax)→ 等于做了两次

# ✅ 对:log-sum-exp 稳定版;CE 直接 = logsumexp(z) - z[真类]
def cross_entropy(logits, y_idx):
    z = np.asarray(logits, float)
    m = z.max()                                  # 减最大值防溢出
    logZ = m + np.log(np.exp(z - m).sum())       # log Σ exp(z)
    return logZ - z[y_idx]                        # = -log softmax[真类]

z = np.array([2.0, 1.0, 0.1])
print(cross_entropy(z, 0))                        # 0.417

# 梯度 = softmax(z) - onehot(y),一行搞定
def softmax(z):
    e = np.exp(z - z.max()); return e / e.sum()
grad = softmax(z).copy(); grad[0] -= 1
print(grad)                                       # [-0.341, 0.242, 0.099] = ŷ - y
```

```python
import torch, torch.nn.functional as F
logits = torch.tensor([[2.0, 1.0, 0.1]], requires_grad=True)
target = torch.tensor([0])
loss = F.cross_entropy(logits, target)            # 内部 = log_softmax + nll_loss,已防溢出
loss.backward()
print(logits.grad)                                # tensor([[-0.341, 0.242, 0.099]]) = ŷ - y
```

> 关键工程坑:PyTorch `nn.CrossEntropyLoss` **接收 logits,不要先 softmax**;`NLLLoss` 才需要先 `log_softmax`。

## 面试高频

- **"分类为什么用交叉熵不用 MSE?"** ① 交叉熵 = 最大似然,概率意义正;② 配 softmax 梯度为 $\hat y-y$,不会像 MSE 那样在饱和区梯度趋零导致学得慢;③ 对"自信地错"惩罚是 $-\log$ 级,远强于 MSE 的平方。
- **"交叉熵、NLL、KL、最大似然啥关系?"** one-hot 时交叉熵 = NLL;交叉熵 = 熵 + KL;最小化交叉熵 = 最大似然(因为 $H(p)$ 常数,等于最小化 KL)。
- **"推一下 softmax+交叉熵的梯度。"** 见上,答案 $\hat y-y$,要能写出 softmax 雅可比 $\hat y_i(\delta_{ij}-\hat y_j)$ 并约项。
- **"二分类的 BCE 是什么?"** $-[y\log\hat y+(1-y)\log(1-\hat y)]$,是交叉熵在伯努利上的特例,配 sigmoid。
- **"标签平滑做什么?"** 把 one-hot 软化(真类 $1-\varepsilon$、其余均分 $\varepsilon$),防过度自信、改善校准、略提泛化;代价是 logit 间隔变小。
- **"加权 CER / 类别不平衡怎么办?"** 给少数类更大权重的加权交叉熵,或用 Focal Loss 按置信度自适应降权简单样本。
- **"交叉熵对称吗?"** 不对称:$H(p,q)\ne H(q,p)$(KL 不对称的直接后果)。训练里固定 $p$ 是真分布、$q$ 是模型。
- **数值稳定:** 永远用 `log_softmax`/`cross_entropy` 一体化算子,别手动 `log(softmax(x))`。

## 关键事实

- 交叉熵分解 $H(p,q)=H(p)+D_{KL}(p\|q)$,且 $D_{KL}\ge 0$(吉布斯不等式),Cover & Thomas《Elements of Information Theory》第 2 版,2006。
- one-hot 标签下交叉熵损失 = 负对数似然 = $-\log q[\text{真类}]$,等价于最大似然估计(Goodfellow《Deep Learning》2016,第 5.5 / 6.2 节)。
- Softmax + 交叉熵的 logit 梯度为 $\hat y - y$(同上,5.5 与 6.2);这是二者配对的核心原因。
- PyTorch `F.cross_entropy = log_softmax + nll_loss`,输入必须是 logits(官方文档,2024)。
