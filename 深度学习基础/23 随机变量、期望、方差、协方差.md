[[23 随机变量、期望、方差、协方差|随机变量]]是把随机结果映射成数的函数,**期望**是它的"加权平均/重心",**方差**衡量它围绕重心抖得多散,**协方差**衡量两个随机变量是否同涨同跌——这四个量是损失、梯度噪声、初始化方差等一切统计推理的语言。

## 直觉

**随机变量**:掷骰子的结果是"点数",抛硬币正面记 1、反面记 0——把"随机的事"翻译成"随机的数",才能做平均、求和、算方差。随机变量分**离散**(取值可数,如骰子点数)和**连续**(取值充满区间,如身高);离散用**概率质量函数 PMF** $p(x)$ 描述,连续用**概率密度函数 PDF** $f(x)$ 描述,两者都可用**累积分布函数 CDF** $F(x)=P(X\le x)$ 统一刻画。

**期望** $E[X]$ 是这些数的**重心**:每个取值乘以它的概率再相加。它是你"长期平均会拿到多少"的最佳单值预测;也是平方误差意义下的最优常数预测(用任何常数 $c$ 去猜 $X$,$E[(X-c)^2]$ 在 $c=E[X]$ 时最小)。

**方差** $\text{Var}(X)$ 量"抖动幅度":数离重心平均有多远(平方意义下)。方差大=不稳定、风险高。标准差 $\sigma=\sqrt{\text{Var}}$ 把单位拉回和 $X$ 一致。

**协方差** $\text{Cov}(X,Y)$ 量"两个量是否同步":一个高于自己均值时另一个也偏高,协方差为正;反向偏离则为负;无关联则约 0。除以两者标准差就得到 $[-1,1]$ 的**相关系数**。

## 例子

**期望与方差(掷一颗六面骰)**。取值 $1..6$ 各概率 $1/6$。

$$E[X]=\frac{1+2+3+4+5+6}{6}=3.5$$

$$E[X^2]=\frac{1+4+9+16+25+36}{6}=\frac{91}{6}\approx15.167$$

用便捷公式 $\text{Var}(X)=E[X^2]-(E[X])^2$:

$$\text{Var}(X)=15.167-3.5^2=15.167-12.25=2.917,\qquad \sigma\approx1.708$$

**协方差(两个变量)**。数据点 $(X,Y)$:$(1,2),(2,4),(3,6)$,各 $1/3$。$E[X]=2,E[Y]=4$。

$$\text{Cov}(X,Y)=E[(X-2)(Y-4)]=\tfrac13[(-1)(-2)+0\cdot0+(1)(2)]=\tfrac13(2+0+2)=\tfrac43\approx1.33$$

正值且完全线性($Y=2X$),相关系数 $\rho=\frac{\text{Cov}}{\sigma_X\sigma_Y}$ 应为 $+1$:$\sigma_X^2=\tfrac23,\sigma_Y^2=\tfrac83$,$\rho=\frac{4/3}{\sqrt{2/3}\sqrt{8/3}}=\frac{4/3}{4/3}=1$。✓

**伯努利的期望与方差(分类必背)**。$X\in\{0,1\}$,$P(X=1)=p$:$E[X]=p$,$E[X^2]=p$(因为 $0^2=0,1^2=1$),故 $\text{Var}=p-p^2=p(1-p)$。取 $p=0.3$:$E[X]=0.3$,$\text{Var}=0.3\times0.7=0.21$。$p=0.5$ 时方差最大 $0.25$(最不确定)。

**两个骰子之和的期望与方差(线性 + 独立可加)**。$S=X_1+X_2$,各骰 $E=3.5,\text{Var}=2.917$。因独立:$E[S]=3.5+3.5=7$,$\text{Var}(S)=2.917+2.917=5.833$。注意**期望永远可加**(不需独立),**方差可加需独立**——这条区别是面试高频。

**LOTUS(无意识统计学家定律)手算**。求函数的期望不必先求该函数的分布,直接对原分布加权:$E[g(X)]=\sum_x g(x)p(x)$。例:骰子的 $E[X^2]=\sum_{x=1}^6 x^2\cdot\tfrac16=\tfrac{91}{6}\approx15.17$(上面方差就用到它)。这是从 $E[X^2]-(E[X])^2$ 算方差的依据。

**协方差矩阵手算(2 维)**。三点 $(1,2),(2,4),(3,6)$,$\mu=(2,4)$。中心化后 $(-1,-2),(0,0),(1,2)$,
$$\Sigma=\frac13\sum (x-\mu)(x-\mu)^\top=\frac13\left(\begin{bmatrix}1&2\\2&4\end{bmatrix}+\begin{bmatrix}0&0\\0&0\end{bmatrix}+\begin{bmatrix}1&2\\2&4\end{bmatrix}\right)=\begin{bmatrix}2/3&4/3\\4/3&8/3\end{bmatrix}$$
对称、对角是各维方差($\tfrac23,\tfrac83$)、非对角是协方差($\tfrac43$),且行列式 $=\tfrac23\cdot\tfrac83-(\tfrac43)^2=0$——因为 $Y=2X$ 完全共线,矩阵退化(半正定但奇异)。

## 原理

**随机变量**:从样本空间到实数的可测函数 $X:\Omega\to\mathbb R$。离散用概率质量 $p(x)$,连续用概率密度 $f(x)$。

**期望(线性算子)**:

$$E[X]=\sum_x x\,p(x)\quad\text{或}\quad\int x f(x)\,dx$$

关键性质——**线性**(无论是否独立都成立):

$$E[aX+bY+c]=a\,E[X]+b\,E[Y]+c$$

**方差**:

$$\text{Var}(X)=E\big[(X-E[X])^2\big]=E[X^2]-(E[X])^2\ge0$$

缩放与平移:$\text{Var}(aX+b)=a^2\text{Var}(X)$(常数 $b$ 不影响散度,系数 $a$ 进去要平方)。

**协方差与相关**:

$$\text{Cov}(X,Y)=E\big[(X-E[X])(Y-E[Y])\big]=E[XY]-E[X]E[Y]$$

$$\rho_{XY}=\frac{\text{Cov}(X,Y)}{\sigma_X\sigma_Y}\in[-1,1]$$

注意 $\text{Cov}(X,X)=\text{Var}(X)$。多维下排成**协方差矩阵** $\Sigma$,$\Sigma_{ij}=\text{Cov}(X_i,X_j)$,对称半正定——它是高维 [[24 常见分布(高斯、伯努利、类别)|高斯分布]] 的形状参数,也是 [[11 主成分分析 PCA|PCA]] 分解的对象。

**和的方差**:

$$\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)+2\,\text{Cov}(X,Y)$$

若 $X,Y$ **独立**则 $\text{Cov}=0$,方差可加——这条是权重初始化推方差、推 mini-batch 梯度噪声的基础。注意:**独立 ⟹ 协方差 0,但协方差 0 不一定独立**(只说明无线性关联)。经典反例:$X\sim U(-1,1)$,$Y=X^2$,则 $\text{Cov}(X,Y)=E[X^3]-E[X]E[X^2]=0-0=0$,但 $Y$ 完全由 $X$ 决定,绝非独立——协方差只测线性关系。

**$n$ 项之和的方差(向量化)**。$\text{Var}\big(\sum_i X_i\big)=\sum_i\text{Var}(X_i)+\sum_{i\ne j}\text{Cov}(X_i,X_j)$。若两两独立,交叉项全消,$\text{Var}\big(\sum_i X_i\big)=\sum_i\text{Var}(X_i)$;再若同分布($\text{Var}=\sigma^2$),则 $\text{Var}(\bar X)=\text{Var}(\tfrac1n\sum X_i)=\tfrac{\sigma^2}{n}$——**样本均值的方差随 $n$ 反比下降**,这就是"多取样更稳"和 mini-batch 梯度方差 $\propto 1/B$ 的来源(见 [[37 梯度下降：BGD、SGD、Mini-batch|mini-batch]])。

**全期望 / 全方差定律(进阶但好用)**:
$$E[X]=E\big[E[X\mid Y]\big],\qquad \text{Var}(X)=\underbrace{E[\text{Var}(X\mid Y)]}_{\text{组内}}+\underbrace{\text{Var}(E[X\mid Y])}_{\text{组间}}$$
方差被拆成"组内平均方差 + 组间均值方差"——这是分层抽样、偏差-方差分解、混合分布分析的工具。

**贝塞尔校正(为什么样本方差除以 $N-1$)**。用样本均值 $\bar X$ 代替真均值 $\mu$ 时,样本点离 $\bar X$ 比离 $\mu$ 系统地更近(因为 $\bar X$ 是这批样本"量身定做"的重心),所以 $\frac1N\sum(x_i-\bar X)^2$ 会**低估**真方差;可证其期望是 $\frac{N-1}{N}\sigma^2$,除以 $N-1$ 而非 $N$ 才把它"补"成无偏估计 $E[s^2]=\sigma^2$。

## 代码

```python
import numpy as np
rng = np.random.default_rng(0)

# 骰子:解析 vs 模拟
faces = np.arange(1, 7)
print("E[X] 解析:", faces.mean())                  # 3.5
print("Var 解析:", ((faces - 3.5)**2).mean())      # 2.9167
sample = rng.integers(1, 7, size=1_000_000)
print("Var 模拟:", round(sample.var(), 3))          # ≈ 2.917

# ❌ 求方差时除以 N-1 还是 N?默认 ddof 易踩坑
x = np.array([1., 2., 3.])
print("❌ ddof=1(样本无偏,默认 np.var 不是它):", x.var(ddof=1))  # 1.0
# ✅ 总体方差(定义式,除以 N)
print("✅ ddof=0(总体方差):", x.var(ddof=0))                      # 0.6667

# 协方差矩阵:Y = 2X 完全线性,相关系数应为 1
X = np.array([1., 2., 3.]); Y = 2 * X
print("Cov 矩阵:\n", np.cov(X, Y, ddof=0))
print("相关系数:\n", np.corrcoef(X, Y))   # 对角外为 1.0
```

`❌vs✅`:`np.var` 默认 `ddof=0`(总体方差,除以 $N$),做**样本无偏估计**要显式 `ddof=1`(除以 $N-1$);面试和工程都常因此差一点。协方差矩阵对角外元素为正、相关系数为 $1$,印证 $Y=2X$ 完全正相关。

```python
# 验证“协方差为0不一定独立”:Y=X^2,Cov≈0 但显然相关
import numpy as np
rng = np.random.default_rng(0)
X = rng.uniform(-1, 1, 1_000_000); Y = X**2
print("Cov(X,Y):", round(np.cov(X, Y, ddof=0)[0, 1], 4))   # ≈ 0
print("corr:", round(np.corrcoef(X, Y)[0, 1], 4))          # ≈ 0,但 Y 完全由 X 决定

# 验证样本均值方差 ∝ 1/n
for n in (10, 100, 1000):
    means = [rng.normal(0, 1, n).mean() for _ in range(5000)]
    print(f"n={n:5d}  Var(mean)≈{np.var(means):.4f}  理论 1/n={1/n:.4f}")
```

样本均值的方差随 $n$ 反比下降,印证 $\text{Var}(\bar X)=\sigma^2/n$;$Y=X^2$ 的协方差近 0 却高度依赖,印证"零协方差 ≠ 独立"。

## 面试高频

- **"$\text{Var}(X)=?$ 的两种写法?"** $E[(X-\mu)^2]=E[X^2]-(E[X])^2$。后者算起来快,务必会推。
- **"$\text{Var}(aX+b)=?$"** $a^2\text{Var}(X)$,$b$ 无关。权重初始化(He/Xavier)就靠它推每层方差。
- **"协方差为 0 是否等于独立?"** 否。独立 ⟹ 协方差 0,反之不成立(协方差只测线性关系)。经典陷阱。
- **"期望的线性需要独立吗?"** 不需要。$E[X+Y]=E[X]+E[Y]$ 永远成立;但 $\text{Var}(X+Y)$ 可加才需要独立(或协方差为 0)。
- **"样本方差为什么除以 $N-1$?"** 贝塞尔校正:用样本均值代替真均值会低估散度(样本点离自己的重心系统偏近),期望只有 $\frac{N-1}{N}\sigma^2$,除以 $N-1$ 才无偏。
- **"协方差矩阵什么性质?"** 对称、半正定;对角是各维方差、非对角是协方差;PCA 对它做特征分解,主成分是其特征向量、特征值是该方向方差。完全共线时奇异(行列式 0)。
- **"相关系数和协方差区别?为什么要相关系数?"** 协方差有量纲、量级随单位变化,不可横向比较;相关系数 $\rho=\text{Cov}/(\sigma_X\sigma_Y)\in[-1,1]$ 无量纲、标准化,才能比"哪对更相关"。
- **"相关 ≠ 因果。"** $\rho$ 大只说明同涨同跌,可能是巧合、反向因果或共同原因(混淆变量)。面试给数据下因果结论是大忌。
- **"样本均值方差是多少?"** $\sigma^2/n$(独立同分布)。这条解释了为什么大 batch 梯度更稳、为什么多次测量取平均更准。
- **"期望/方差对线性变换怎么变?"** $E[aX+b]=aE[X]+b$;$\text{Var}(aX+b)=a^2\text{Var}(X)$。标准化 $Z=(X-\mu)/\sigma$ 后 $E[Z]=0,\text{Var}(Z)=1$——这正是 BatchNorm / 特征标准化在做的事。

## 关键事实

- 期望、方差、协方差的标准定义与性质见 Casella & Berger《Statistical Inference》(2nd ed., 2002)第 2–4 章。
- 协方差矩阵的半正定性与谱分解是 PCA 的数学基础,见 Bishop《Pattern Recognition and Machine Learning》(2006)第 12 章。
- 贝塞尔校正(样本方差除以 $N-1$ 得无偏估计)是数理统计标准结论,见同类教材。
