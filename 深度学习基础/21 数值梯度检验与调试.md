[[21 数值梯度检验与调试|数值梯度检验]]是用**中心差分** $\dfrac{f(x+\epsilon)-f(x-\epsilon)}{2\epsilon}$ 近似梯度,拿它当"裁判"去核对你手写或框架算出的**解析梯度**([[20 反向传播的数学推导|反向传播]] 的结果)对不对。它是 debug 反向传播的终极兜底:解析梯度和数值梯度的相对误差小到 $\sim10^{-7}$,才敢相信梯度没写错。

## 直觉

反向传播公式一长串转置、外积、逐元素乘,极易写反(把 $W$ 写成 $W^T$、$\delta a^T$ 写成 $a\delta^T$)。可怕的是:**梯度写错了,网络往往还在训练、loss 也在降**,只是降得慢或最终更差——根本不报错。怎么抓这种"沉默的 bug"?

办法是回到导数最朴素的定义:**导数 = 把变量推一点点,函数变化的比率**(见 [[14 导数与偏导数|导数]])。我不信你的公式,我就**真的去推一下**:把参数 $x$ 加一个微小 $\epsilon$、减一个 $\epsilon$,看 $f$ 差多少,除以 $2\epsilon$。这个"实测"出来的梯度不依赖任何推导,纯靠函数值,所以能当客观裁判。

为什么用**中心**差分(两边都推)而不是单边 $(f(x+\epsilon)-f(x))/\epsilon$?因为中心差分的截断误差是 $O(\epsilon^2)$,单边是 $O(\epsilon)$——同样的 $\epsilon$,中心差分准得多(下面原理里推)。代价是每个参数要算两次 $f$,慢,所以它**只配做检验、不能做训练主力**(训练用 [[19 自动微分：前向 vs 反向模式|反向模式 AD]],一遍拿全部梯度)。

类比:你声称记得回家的路(解析梯度),我不验算路线对错,而是让你往左挪一步、往右挪一步,看你离家是近了还是远了(数值梯度),用脚投票。

## 例子

**检验 $f(x)=x^3$ 在 $x=2$ 的梯度**。解析:$f'(x)=3x^2$,$f'(2)=12$。中心差分,取 $\epsilon=10^{-5}$:

$$\frac{f(2.00001)-f(1.99999)}{2\times10^{-5}}=\frac{8.00012\ldots-7.99988\ldots}{0.00002}\approx12.0000000012$$

数值 $\approx12$ 与解析 $12$ 几乎完全吻合,**相对误差** $\sim10^{-10}$ → 梯度对。

**抓一个真 bug**。假设反传里你把 $f(x)=x^3$ 的导数误写成 $2x^2$(指数抄错):解析给 $2\cdot4=8$,数值给 $12$。相对误差

$$\frac{|12-8|}{\max(|12|,|8|)}=\frac{4}{12}\approx0.33$$

误差 $0.33\gg10^{-7}$ → **立刻报警**,bug 被逮住。

**单边 vs 中心(看精度差)**,$\epsilon=10^{-4}$,真值 12:

| 方法 | 公式 | 结果 | 误差量级 |
|---|---|---|---|
| 单边 | $(f(x+\epsilon)-f(x))/\epsilon$ | $12.0006$ | $\sim10^{-4}$($O(\epsilon)$) |
| 中心 | $(f(x+\epsilon)-f(x-\epsilon))/2\epsilon$ | $12.00000001$ | $\sim10^{-8}$($O(\epsilon^2)$) |

中心差分用同样 $\epsilon$ 精度高 4 个数量级——所以检验一律用中心差分。

**检验 softmax+交叉熵的梯度(贴近真实场景)**。logits $z=[2,1,0]$、真类 0,解析梯度是 $\hat y-y$(见 [[30 交叉熵与负对数似然|交叉熵]])。算 softmax $\hat y=[0.665,0.245,0.090]$,解析梯度 $=[0.665-1,0.245,0.090]=[-0.335,0.245,0.090]$。逐分量中心差分扰动 $z_i$、看损失变化,数值梯度应与之相对误差 $<10^{-7}$——这是把"$\hat y-y$ 这条公式没写错"用实测验证一遍。

**$\epsilon$ 取值的"两头都不行"(数字感受)**,真值 $f'(2)=12$:
| $\epsilon$ | 主导误差 | 典型相对误差 |
|---|---|---|
| $10^{-1}$ | 截断 $O(\epsilon^2)$ | $\sim10^{-2}$(太大) |
| $10^{-5}$ | 平衡点 | $\sim10^{-10}$(最优) |
| $10^{-12}$ | 浮点舍入(相近数相减) | 急剧变差甚至全错 |
太大截断误差主导、太小舍入误差主导,甜点在 $10^{-6}\!\sim\!10^{-4}$。

## 原理

**为什么中心差分误差是 $O(\epsilon^2)$**。泰勒展开:

$$f(x+\epsilon)=f(x)+f'(x)\epsilon+\tfrac12 f''(x)\epsilon^2+\tfrac16 f'''(x)\epsilon^3+\dots$$
$$f(x-\epsilon)=f(x)-f'(x)\epsilon+\tfrac12 f''(x)\epsilon^2-\tfrac16 f'''(x)\epsilon^3+\dots$$

两式相减,偶数次项($f,f''$)抵消:

$$f(x+\epsilon)-f(x-\epsilon)=2f'(x)\epsilon+\tfrac13 f'''(x)\epsilon^3+\dots$$
$$\Rightarrow\quad\frac{f(x+\epsilon)-f(x-\epsilon)}{2\epsilon}=f'(x)+\underbrace{\tfrac16 f'''(x)\epsilon^2+\dots}_{O(\epsilon^2)\text{ 截断误差}}$$

而单边差分只让一阶项留下、二阶项 $\tfrac12 f''\epsilon$ 不抵消 → 误差 $O(\epsilon)$。这就是中心差分胜出的数学原因。

**多维:逐分量扰动**。参数 $\theta\in\mathbb R^n$,梯度第 $i$ 个分量:

$$\big[\nabla_\theta L\big]_i\approx\frac{L(\theta+\epsilon e_i)-L(\theta-\epsilon e_i)}{2\epsilon}$$

$e_i$ 是只有第 $i$ 位为 1 的单位向量。要全梯度得对每个 $i$ 各扰动一次 → $2n$ 次前向,$n$ 大就极慢,**故只在小网络/抽查少数参数上做检验**。

**用相对误差判定**(不能用绝对误差,函数尺度不同):

$$\text{rel\_err}=\frac{\big|g_{\text{解析}}-g_{\text{数值}}\big|}{\max\big(|g_{\text{解析}}|,\,|g_{\text{数值}}|\big)+10^{-8}}$$

经验阈值:

- $<10^{-7}$:几乎肯定正确。
- $10^{-7}\sim10^{-4}$:可疑,若网络含 ReLU/kink 等不可导点可能正常,否则要查。
- $>10^{-4}$:基本是 bug。

**$\epsilon$ 怎么选**:太大 → 截断误差($O(\epsilon^2)$)主导;太小 → 浮点**舍入误差**主导(两个相近的数相减损失有效位)。甜点约 $\epsilon\in[10^{-6},10^{-4}]$,常用 $10^{-5}$。

**实战注意**:
- **关掉随机性**(Dropout、数据增强)再检验,否则两次前向 $f$ 不是同一函数。
- **kink 问题**:ReLU、$\max$、$|\cdot|$ 在 0 点不可导,若扰动恰好跨过 kink,数值梯度会偏——用稍大 $\epsilon$ 或避开这些点判断。
- 检验通过后**记得删掉/关掉**数值检验(它太慢),训练只用 [[20 反向传播的数学推导|反向传播]]。

## 代码

```python
import numpy as np

# ✅ 通用数值梯度检验器:对任意标量函数 f(θ) 和它的解析梯度对照
def numeric_grad(f, theta, eps=1e-5):
    """中心差分,逐分量扰动,返回与 theta 同形的数值梯度"""
    g = np.zeros_like(theta)
    it = np.nditer(theta, flags=['multi_index'])
    while not it.finished:
        idx = it.multi_index
        old = theta[idx]
        theta[idx] = old + eps; fp = f(theta)
        theta[idx] = old - eps; fm = f(theta)
        theta[idx] = old                       # 复原,别污染参数
        g[idx] = (fp - fm) / (2 * eps)         # (f(x+ε)-f(x-ε))/2ε
        it.iternext()
    return g

def rel_error(a, b):
    return np.abs(a - b) / (np.maximum(np.abs(a), np.abs(b)) + 1e-8)

# 例:线性回归损失 L=½‖Wx-y‖²,解析梯度 (Wx-y)x^T
np.random.seed(0)
x = np.random.randn(3); y = np.random.randn(2)
W = np.random.randn(2, 3)

f = lambda W_: 0.5 * np.sum((W_ @ x - y)**2)          # 标量损失
grad_analytic = np.outer(W @ x - y, x)                # ✅ 解析梯度
grad_numeric  = numeric_grad(f, W.copy())             # 裁判

print("最大相对误差:", rel_error(grad_analytic, grad_numeric).max())  # ~1e-9 → 通过

# ❌ 朴素错误1:用单边差分(精度差一个数量级),阈值卡不过还以为梯度错
def numeric_grad_onesided(f, theta, eps=1e-5):        # 反例,别这么写
    g = np.zeros_like(theta); f0 = f(theta)
    it = np.nditer(theta, flags=['multi_index'])
    while not it.finished:
        idx = it.multi_index; old = theta[idx]
        theta[idx] = old + eps; g[idx] = (f(theta)-f0)/eps  # 只推一边,O(ε) 误差
        theta[idx] = old; it.iternext()
    return g
print("单边法相对误差:", rel_error(grad_analytic,
      numeric_grad_onesided(f, W.copy())).max())      # 比中心差分大几个量级

# ❌ 朴素错误2:故意写错解析梯度(漏转置),检验立刻抓出
grad_buggy = np.outer(x, W @ x - y).T[:2]             # 形状凑巧但值错
# 真实场景里维度对但语义错;此处示意:相对误差爆炸 → 报警
```

手算对照:线性回归解析梯度 $(Wx-y)x^T$ 与中心差分的相对误差 $\sim10^{-9}$,远低于 $10^{-7}$ → 判定正确;单边差分相对误差大几个数量级,印证中心差分更适合做检验;一旦把解析梯度写错(漏转置等),相对误差会暴涨到肉眼可见,bug 被当场逮住。

## 面试高频

- **"怎么验证反向传播写对没?"** 用中心差分数值梯度对照解析梯度,看相对误差 $<10^{-7}$。能说出"中心差分、相对误差、阈值"三件套就专业。
- **"为什么用中心差分不用单边?"** 中心差分泰勒展开偶次项抵消,误差 $O(\epsilon^2)$;单边 $O(\epsilon)$。同 $\epsilon$ 下精度高几个量级。
- **"$\epsilon$ 取多大?"** $\sim10^{-5}$。太大截断误差主导,太小浮点相减舍入误差主导——这个"两头都不行"是高频追问。
- **"为什么用相对误差不用绝对误差?"** 不同函数/参数尺度差异巨大,绝对误差无意义;相对误差无量纲、可设统一阈值。
- **"检验时要注意什么?"(陷阱)** 关掉 Dropout/数据增强等随机性(否则两次 $f$ 不同函数);ReLU 等 kink 点附近数值梯度会偏;检验后要关掉(太慢)。
- **"数值梯度能不能直接拿来训练?"** 不能,要对每个参数各扰动两次($2n$ 次前向),百万参数完全不可行;训练必须用反向模式 AD(见 [[19 自动微分：前向 vs 反向模式|自动微分]])。
- **"梯度检验通过了还会有 bug 吗?"** 可能:数据流水线、损失定义、随机种子等非梯度环节的 bug 它查不出;它只保证"给定前向,反向梯度算对了"。
- **"怎么高效检验大网络?"** 不必查所有参数:随机抽样少数参数、或只查每层的几个维度;并用一两个小 batch、关掉随机性,够抓住实现 bug。
- **"为什么不能用绝对误差阈值统一判定?"** 不同层/参数梯度量级差几个数量级,绝对误差对大梯度太松、对小梯度太严;相对误差无量纲、可设统一阈值 $10^{-7}$。
- **"ReLU 的 kink 让检验失败正常吗?"** 若扰动跨过 $z=0$ 的不可导点,数值梯度会偏,出现 $10^{-4}\sim10^{-2}$ 的"假报警";避开这些点或换稍大 $\epsilon$ 即可,这不是真 bug。

## 关键事实

- 中心差分 $(f(x+\epsilon)-f(x-\epsilon))/2\epsilon$ 误差 $O(\epsilon^2)$、单边差分 $O(\epsilon)$,由泰勒展开偶次项抵消得到,见 Nocedal & Wright《Numerical Optimization》(2nd ed., 2006)第 8 章。
- 用相对误差 $\sim10^{-7}$ 阈值、$\epsilon\approx10^{-5}$、关闭随机性、注意 ReLU kink 的梯度检验实践,见 Stanford CS231n 课程讲义 "Gradient checks"(Karpathy et al.)。
- 梯度检验作为反向传播实现的标准调试手段,见 Goodfellow, Bengio & Courville《Deep Learning》(2016)第 6.5.10 节及 Andrew Ng 深度学习课程(gradient checking)。
