[[05 矩阵与线性变换(可视化)|矩阵]]:一个 $m\times n$ 矩阵不只是数表,它是一个**线性变换**——把 $n$ 维空间里的每个向量映射到 $m$ 维空间,几何上就是"把整张网格均匀拉伸、旋转、剪切,但保持原点不动、直线仍是直线";读懂"矩阵的每一列 = 一个基向量变换后落在哪",就读懂了矩阵在干什么。

## 直觉

把矩阵想成一台**"空间变形机器"**。

- 你给它一个向量(空间里一个点),它吐出另一个向量(那个点被搬到的新位置)。
- 它对**所有点同时操作**:整张方格纸被均匀地拉伸/旋转/压扁/推斜,但有三条铁律——**原点不动**、**网格线保持平行且等距**、**直线变换后还是直线**。满足这三条的变形才叫"线性"。

最关键的直觉:**你只需要知道两个基向量 $\mathbf{e}_1,\mathbf{e}_2$ 被搬到哪,就知道所有点被搬到哪**。因为任意点都是基向量的[[02 向量运算：加法、缩放与线性组合|线性组合]],而线性变换"保持组合关系"。而这"两个基向量的新落点",恰好就是矩阵的**两列**。

所以读矩阵的正确姿势:**别盯着数,盯着它的列——每一列告诉你一根坐标尺被掰到了哪个方向、拉到了多长。**

## 例子

取矩阵 $A = \begin{bmatrix} 2 & 1 \\ 0 & 1 \end{bmatrix}$,它对二维空间做什么?

看它的列:

- **第 1 列** $[2, 0]$ = 基向量 $\mathbf{e}_1=[1,0]$ 的新落点 → $\mathbf{e}_1$ 沿 x 轴被拉长到 2 倍。
- **第 2 列** $[1, 1]$ = 基向量 $\mathbf{e}_2=[0,1]$ 的新落点 → $\mathbf{e}_2$ 被"推斜"(剪切 shear)。

![[la-矩阵列即基去向.svg]]

于是任意向量 $[x,y]$ 的去向 = 两列按 $x,y$ 配比的线性组合:

$$A\begin{bmatrix}x\\y\end{bmatrix} = x\begin{bmatrix}2\\0\end{bmatrix} + y\begin{bmatrix}1\\1\end{bmatrix} = \begin{bmatrix}2x+y\\ y\end{bmatrix}$$

代入 $[3,2]$ 手算一遍:

$$A\begin{bmatrix}3\\2\end{bmatrix} = \begin{bmatrix}2\cdot 3 + 1\cdot 2\\ 0\cdot 3 + 1\cdot 2\end{bmatrix} = \begin{bmatrix}8\\2\end{bmatrix}$$

逐行点积验证:第 1 行 $[2,1]\cdot[3,2]=8$,第 2 行 $[0,1]\cdot[3,2]=2$。✓

**再手算一个 $3\times3$ 作用在向量上的例子**(把"行点积"练到不假思索)。取

$$A=\begin{bmatrix}1&2&0\\0&1&1\\3&0&1\end{bmatrix},\quad \mathbf{x}=\begin{bmatrix}1\\2\\1\end{bmatrix}$$

逐行与 $\mathbf{x}$ 点积:

$$A\mathbf{x}=\begin{bmatrix}1\cdot1+2\cdot2+0\cdot1\\ 0\cdot1+1\cdot2+1\cdot1\\ 3\cdot1+0\cdot2+1\cdot1\end{bmatrix}=\begin{bmatrix}1+4+0\\0+2+1\\3+0+1\end{bmatrix}=\begin{bmatrix}5\\3\\4\end{bmatrix}$$

列视角验证(同一结果,换个算法):$A\mathbf{x}=1\!\cdot\![1,0,3]+2\!\cdot\![2,1,0]+1\!\cdot\![0,1,1]=[1,0,3]+[4,2,0]+[0,1,1]=[5,3,4]$。✓ 两种算法必然一致,平时算用行点积(直接),理解几何用列组合。

**升维 / 降维的例子**(矩阵不一定是方阵)。$A$ 是 $3\times2$ 把二维"嵌入"三维:

$$A=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad A\begin{bmatrix}2\\3\end{bmatrix}=\begin{bmatrix}1\cdot2+0\cdot3\\0\cdot2+1\cdot3\\1\cdot2+1\cdot3\end{bmatrix}=\begin{bmatrix}2\\3\\5\end{bmatrix}$$

输入二维($n=2$=列数)、输出三维($m=3$=行数)。神经网络从 768 维投到 3072 维的升维层就是这种 $m>n$ 的矩阵。

## 原理

矩阵-向量乘法的定义,第 $i$ 个输出分量 = $A$ 第 $i$ 行与 $\mathbf{x}$ 的[[03 点积、范数与相似度|点积]]:

$$(A\mathbf{x})_i = \sum_{j=1}^{n} A_{ij}\,x_j$$

但更深刻的是**列视角**——$A\mathbf{x}$ 是 $A$ 各列的线性组合,系数是 $\mathbf{x}$ 的分量:

$$A\mathbf{x} = x_1\,\mathbf{a}_1 + x_2\,\mathbf{a}_2 + \cdots + x_n\,\mathbf{a}_n,\quad \mathbf{a}_j = A \text{ 的第 } j \text{ 列}$$

**线性变换**的定义性质(可加性 + 齐次性):

$$T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u})+T(\mathbf{v}),\qquad T(c\,\mathbf{u}) = c\,T(\mathbf{u})$$

**核心定理**:每个有限维线性变换 $T:\mathbb{R}^n\to\mathbb{R}^m$ 都唯一对应一个 $m\times n$ 矩阵 $A$,且

$$A = \big[\,T(\mathbf{e}_1)\;\big|\;T(\mathbf{e}_2)\;\big|\;\cdots\;\big|\;T(\mathbf{e}_n)\,\big]$$

即**矩阵的第 $j$ 列就是第 $j$ 个标准基向量的像**。这把"抽象的变换"和"具体的数表"画上等号。

形状含义:$A$ 是 $m\times n$,则输入 $\in\mathbb{R}^n$、输出 $\in\mathbb{R}^m$。$m<n$ 是降维(投影),$m>n$ 是升维(嵌入)。神经网络一层的权重 $W\in\mathbb{R}^{d_{out}\times d_{in}}$ 正是这样一个变换。

常见 2×2 变换速记:

| 矩阵 | 几何效果 | 行列式(面积倍数) |
|---|---|---|
| $\begin{bmatrix}1&0\\0&1\end{bmatrix}$ | 单位阵 $I$,什么都不做 | $1$ |
| $\begin{bmatrix}k&0\\0&k\end{bmatrix}$ | 整体缩放 $k$ 倍 | $k^2$ |
| $\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$ | 旋转 $\theta$ | $1$(旋转不改面积) |
| $\begin{bmatrix}1&s\\0&1\end{bmatrix}$ | 水平剪切 | $1$(剪切不改面积) |
| $\begin{bmatrix}-1&0\\0&1\end{bmatrix}$ | 关于 y 轴镜像(翻转) | $-1$(负号=翻面) |
| $\begin{bmatrix}1&0\\0&0\end{bmatrix}$ | 投影到 x 轴(降维,不可逆) | $0$(压成线,面积归零) |

**手算"旋转 90°"把直觉坐实**。$\theta=90°$ 时 $\cos90°=0,\sin90°=1$,$R=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$。看它把基向量搬到哪:第 1 列 $[0,1]$ = $\mathbf{e}_1=[1,0]$ 转到了 y 轴正向;第 2 列 $[-1,0]$ = $\mathbf{e}_2=[0,1]$ 转到了 x 轴负向。整张纸逆时针转了 90°,完全符合预期。

> 联系:变换"放大/压缩面积"的倍数 = [[08 行列式与空间缩放|行列式]];变换里"方向不变、只被拉伸"的特殊向量 = [[09 特征值与特征向量|特征向量]];把一般变换拆成"旋转-拉伸-旋转"三步 = [[10 SVD 奇异值分解]]。本节是它们的总入口。

## 代码

```python
import numpy as np

A = np.array([[2, 1],
              [0, 1]])

x = np.array([3, 2])
print(A @ x)                # [8 2]  —— 矩阵 × 向量

# 列视角：A@x = 列的线性组合
cols = A.T                  # 行=原矩阵的列
print(x[0]*A[:,0] + x[1]*A[:,1])   # [8 2]  同结果

# “矩阵的列 = 基向量的像”验证
e1, e2 = np.array([1,0]), np.array([0,1])
print(A @ e1)               # [2 0]  = A 第 1 列
print(A @ e2)               # [1 1]  = A 第 2 列

# 旋转 90°：看基向量去哪
theta = np.pi/2
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
print(np.round(R @ e1, 3))  # [0 1]  e1 转到了 y 轴
```

```python
# ❌ 朴素：双重 for 手算矩阵-向量乘，慢
def matvec_slow(A, x):
    m, n = A.shape
    out = np.zeros(m)
    for i in range(m):
        for j in range(n):
            out[i] += A[i, j] * x[j]
    return out

# ✅ 向量化：A @ x，底层 BLAS，快几个数量级；神经网络前向就是它
def matvec_fast(A, x):
    return A @ x
```

## 面试高频

- **"为什么说矩阵就是线性变换?"** 标准答法:因为每个线性变换由它在基向量上的作用唯一确定,而把这些像按列排好就是矩阵;反之矩阵-向量乘法满足可加性和齐次性。两者一一对应。
- **"矩阵的列空间是什么?"** 列向量张成的子空间 = 所有可能的输出 $A\mathbf{x}$,其维度 = [[07 矩阵的秩、逆与转置|秩]]。输出"塌缩"到低维(如投影矩阵)就说明秩亏、不可逆。
- **"神经网络一层在几何上做什么?"** $W\mathbf{x}+\mathbf{b}$ = 线性变换(旋转+拉伸+剪切)再平移,激活函数再"折叠"空间引入非线性;深度网络就是一连串这样的空间变形。
- **陷阱:列视角 vs 行视角别混。** 行视角:$(A\mathbf{x})_i$ = 第 $i$ 行点积 $\mathbf{x}$(算单个分量好用);列视角:$A\mathbf{x}$ = 列的线性组合(理解几何好用)。面试能自由切换是加分项。
- **陷阱:左乘 vs 右乘不可交换。** $AB\neq BA$,因为"先做变换 B 再做 A"和反过来几何上不同(见 [[06 矩阵乘法的几何意义]])。
- **"仿射变换 vs 线性变换的区别?"** 线性变换 $\mathbf{x}\mapsto A\mathbf{x}$ 必保持原点不动;加了偏置 $\mathbf{x}\mapsto A\mathbf{x}+\mathbf{b}$ 是**仿射**变换(原点会被平移到 $\mathbf{b}$)。神经网络层是仿射,不是纯线性——这是面试爱抠的措辞。
- **"哪些 2×2 矩阵保持面积不变?"** 行列式绝对值为 1 的(旋转、剪切、镜像);缩放 $kI$ 把面积变 $k^2$ 倍;投影把面积压到 0(见 [[08 行列式与空间缩放|行列式]])。
- **陷阱:`A @ x` 与 `x @ A` 含义不同。** 前者是 $A$ 作用于列向量 $\mathbf{x}$;后者按行向量左乘,等价于 $A^\top$ 作用。形状对得上不代表语义对。

## 关键事实

- $m\times n$ 矩阵 = 从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性变换;输入维 = 列数,输出维 = 行数。
- 线性变换三铁律:原点不动、网格线平行且等距、直线仍直。
- 矩阵第 $j$ 列 = 第 $j$ 个基向量 $\mathbf{e}_j$ 变换后的像;知道基去哪 ⇒ 知道一切。
- $A\mathbf{x}$ 两种读法:行点积(逐分量)/ 列的线性组合(几何)。
- 缩放/旋转/剪切/投影都是特定矩阵;神经网络层 $W\mathbf{x}+\mathbf{b}$ 是仿射变换(线性 + 平移,原点会动)。
- 旋转/剪切/镜像 $|\det|=1$ 保面积,缩放 $kI$ 把面积变 $k^2$ 倍,投影 $\det=0$ 把面积压成 0。
- 线性变换 = 矩阵的一一对应、矩阵列 = 基向量的像,标准论述见 Strang《Introduction to Linear Algebra》(第 6 版, 2023)第 8 章及 3Blue1Brown《Essence of Linear Algebra》系列。
