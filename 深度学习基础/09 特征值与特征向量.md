[[09 特征值与特征向量|特征向量]]是被矩阵 $A$ 这个 [[05 矩阵与线性变换(可视化)|线性变换]] 作用后**方向保持不变、只被拉伸或压缩**的特殊向量,对应的拉伸倍数就是 [[09 特征值与特征向量|特征值]] $\lambda$,满足 $Av=\lambda v$。找到它们等于找到了变换的"天然坐标轴",是 [[10 SVD 奇异值分解|SVD]]、[[11 主成分分析 PCA|PCA]] 的根基。

## 直觉

一台变换机器作用在每个向量上,大多数向量会被又转又拉、面目全非。但总有几个**特殊方向**:向量沿这个方向放进去,出来时还在同一条直线上,只是长度变了。

类比一台**离心机**或**旋转的地球**:绝大多数点都在转圈(方向变),唯独**转轴**上的点不动方向——转轴就是特征向量,而沿转轴的伸缩比例就是特征值。再比如拉橡皮膜:沿某些"主方向"拉,膜上的网格线方向不变、只变疏密,这些主方向就是特征向量。

$Av=\lambda v$ 读作:"$A$ 作用在 $v$ 上,效果等同于把 $v$ 简单地数乘 $\lambda$。"

## 例子

**$2\times2$ 求特征值(必背流程)**。取

$$A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$$

第一步,解**特征方程** $\det(A-\lambda I)=0$:

$$\det\begin{bmatrix}2-\lambda&1\\1&2-\lambda\end{bmatrix}=(2-\lambda)^2-1=\lambda^2-4\lambda+3=0$$

因式分解 $(\lambda-1)(\lambda-3)=0$,得 $\lambda_1=3,\ \lambda_2=1$。

第二步,对每个 $\lambda$ 解 $(A-\lambda I)v=0$ 求特征向量。

- $\lambda_1=3$:$\begin{bmatrix}-1&1\\1&-1\end{bmatrix}v=0\Rightarrow v_1=\begin{bmatrix}1\\1\end{bmatrix}$。验证 $Av_1=\begin{bmatrix}3\\3\end{bmatrix}=3v_1$。✓
- $\lambda_2=1$:$\begin{bmatrix}1&1\\1&1\end{bmatrix}v=0\Rightarrow v_2=\begin{bmatrix}1\\-1\end{bmatrix}$。验证 $Av_2=\begin{bmatrix}1\\-1\end{bmatrix}=1\cdot v_2$。✓

注意这两个特征向量 $(1,1)$ 与 $(1,-1)$ **正交**——因为 $A$ 是对称矩阵,这不是巧合(谱定理)。

![[la-特征向量不变方向.png]]

**交叉验证**:$\lambda_1\lambda_2=3\cdot1=3=\det A$;$\lambda_1+\lambda_2=4=\text{tr}(A)=2+2$。对上了。

**再练一个非对称、特征向量不正交的例子**。$A=\begin{bmatrix}2&1\\0&3\end{bmatrix}$(上三角)。上三角/下三角矩阵的特征值**直接读对角线**:$\lambda_1=2,\lambda_2=3$。验证特征方程 $\det\begin{bmatrix}2-\lambda&1\\0&3-\lambda\end{bmatrix}=(2-\lambda)(3-\lambda)=0$。求特征向量:

- $\lambda=2$:$(A-2I)v=\begin{bmatrix}0&1\\0&1\end{bmatrix}v=0\Rightarrow v_2=0$,取 $v=[1,0]$。
- $\lambda=3$:$(A-3I)v=\begin{bmatrix}-1&1\\0&0\end{bmatrix}v=0\Rightarrow v_1=v_2$,取 $v=[1,1]$。

注意 $[1,0]$ 与 $[1,1]$ **不正交**($[1,0]\cdot[1,1]=1\ne0$)——因为 $A$ 非对称,谱定理不保证正交。

**特征值可能是复数 / 不存在实根的例子**。旋转矩阵 $R=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$(转 90°),特征方程 $\lambda^2+1=0\Rightarrow\lambda=\pm i$,**没有实特征值**——直觉上旋转把每个实向量都转走了方向,没有"方向不变"的实向量,所以实数范围内无特征向量。这说明特征分解不是万能的(但 [[10 SVD 奇异值分解|SVD]] 对任何矩阵都成立)。

## 原理

**定义**:非零向量 $v$ 满足 $Av=\lambda v$,则 $v$ 是特征向量,$\lambda$ 是特征值。改写为 $(A-\lambda I)v=0$,要有非零解就要求 $A-\lambda I$ 不可逆,即

$$\det(A-\lambda I)=0\quad(\text{特征方程})$$

这是关于 $\lambda$ 的 $n$ 次多项式(特征多项式),它的根就是特征值。

**两个永远成立的恒等式**(连特征值都不用求就能用):

$$\sum_i\lambda_i=\text{tr}(A)\ (\text{对角线之和}),\qquad \prod_i\lambda_i=\det(A)$$

**特征分解(对角化)**。若 $A$ 有 $n$ 个线性无关的特征向量,把它们排成矩阵 $P$ 的列,特征值放进对角阵 $\Lambda$,则

$$A=P\Lambda P^{-1}$$

几何上读作三步:$P^{-1}$ 换到"特征坐标系" → $\Lambda$ 在每根特征轴上独立缩放 → $P$ 换回原坐标系。复杂变换被拆成"换基—纯缩放—换回"。

![[la-特征分解对角化.png]]

**对称矩阵的特例(谱定理,极重要)**。若 $A=A^T$:

- 特征值全为**实数**;
- 特征向量可取为**两两正交**;
- 于是 $P$ 可取正交矩阵 $Q$($Q^{-1}=Q^T$),$A=Q\Lambda Q^T$。

这就是 [[11 主成分分析 PCA|PCA]] 对协方差矩阵做的事,也是 [[10 SVD 奇异值分解|SVD]] 的近亲。

**为什么对角化有用**:算 $A^k$ 时,$A^k=P\Lambda^k P^{-1}$,而 $\Lambda^k$ 只是把对角线各自 $k$ 次方——瞬间算完。马尔可夫链稳态、微分方程、PageRank 全靠它。

**特征值的"代数重数 vs 几何重数"(亏损判据)**。代数重数 = 该 $\lambda$ 在特征多项式里的重根次数;几何重数 = 它对应的线性无关特征向量个数($\dim$ 零空间 $(A-\lambda I)$)。几何 ≤ 代数;**当某个特征值几何重数 < 代数重数时,矩阵凑不齐 $n$ 个线性无关特征向量 ⇒ 不可对角化(亏损矩阵)**。典型反例 $\begin{bmatrix}1&1\\0&1\end{bmatrix}$:$\lambda=1$ 代数重数 2,但只解出 1 个特征向量 $[1,0]$,几何重数 1,亏损。

**幂迭代(power iteration):怎么不解特征方程就找到最大特征值**。随机起一个向量 $v$,反复做 $v\leftarrow Av/\|Av\|$,它会收敛到**最大特征值对应的特征向量**(主特征向量),收敛速度由 $|\lambda_2/\lambda_1|$ 决定。PageRank、谱聚类、PCA 的迭代实现都用它——大矩阵上比直接特征分解省得多。

![[la-幂迭代收敛.png]]

**正定 / 半正定(深度学习的高频术语)**。对称矩阵按特征值符号分类:全 $>0$ 叫**正定**(对所有 $\mathbf{x}\ne0$ 有 $\mathbf{x}^\top A\mathbf{x}>0$),全 $\ge0$ 叫**半正定**。协方差矩阵、$X^\top X$、Hessian 在凸点处都半正定;正定 ⟺ 二次型是"碗朝上"(见 [[17 雅可比与 Hessian|Hessian 二阶判据]])、可做 Cholesky 分解。

## 代码

```python
import numpy as np

A = np.array([[2., 1.],
              [1., 2.]])
vals, vecs = np.linalg.eig(A)        # 对称阵也可用 eigh(更快更稳)
print("特征值:", vals)               # [3. 1.]
print("特征向量(按列):\n", vecs)     # 列已单位化

# 验证 A v = λ v(取第一个)
v0 = vecs[:, 0]
print("A v0:", A @ v0)
print("λ0 v0:", vals[0] * v0)        # 两者相等

# 验证两个恒等式
print("和=迹:", vals.sum(), np.trace(A))      # 4 4
print("积=det:", np.prod(vals), np.linalg.det(A))  # 3 3

# 对角化重建 A = P Λ P^-1
P = vecs
Lam = np.diag(vals)
print("重建:\n", P @ Lam @ np.linalg.inv(P))  # ≈ 原 A
```

手算对照:`vals=[3,1]` 与手算 $\lambda=3,1$ 一致;numpy 把特征向量单位化为 $\pm\frac{1}{\sqrt2}(1,1)$、$\pm\frac{1}{\sqrt2}(1,-1)$,方向与手算 $(1,1),(1,-1)$ 相同(差一个长度/符号)。

```python
# 旋转矩阵:复特征值(没有实方向不变向量)
R = np.array([[0., -1.], [1., 0.]])
print(np.linalg.eigvals(R))     # [0.+1.j 0.-1.j]  纯虚数 ±i

# 亏损矩阵:不可对角化(几何重数 < 代数重数)
J = np.array([[1., 1.], [0., 1.]])
w, V = np.linalg.eig(J)
print("特征值:", w)             # [1. 1.] 重根
print("特征向量秩:", np.linalg.matrix_rank(V))  # 1 < 2 → 凑不齐,亏损

# 幂迭代:不解方程也能找最大特征值/主特征向量
A = np.array([[2., 1.], [1., 2.]])
v = np.array([1., 0.])
for _ in range(50):
    v = A @ v
    v = v / np.linalg.norm(v)
lam = (v @ A @ v)              # 瑞利商 ≈ 最大特征值
print("主特征值≈", round(lam, 4), " 主向量≈", v.round(4))  # 3.0  ≈[0.707,0.707]
```

## 面试高频

- **"特征向量的直觉?"** 标准答:被变换后方向不变、只缩放的向量;$\lambda$ 是缩放倍数。陷阱:别答成"特殊的向量"这种空话,要点出"方向不变"。
- **"怎么求?"** 解 $\det(A-\lambda I)=0$ 得 $\lambda$,再代回 $(A-\lambda I)v=0$ 得 $v$。$2\times2$ 必须能手算。
- **"特征值之和、之积等于什么?"** 迹、行列式。秒答送分。
- **"对称矩阵特征值/特征向量有什么特殊?"** 实特征值 + 正交特征向量(谱定理),可写成 $Q\Lambda Q^T$。这是连接 PCA 的关键,几乎必考。
- **陷阱:特征值 vs 奇异值。** 特征值可为负/复数、只对方阵定义、可能不存在实数解;奇异值恒非负、对任意矩阵都有(见 [[10 SVD 奇异值分解|SVD]])。对称半正定矩阵两者才一致。
- **"不是所有矩阵都能对角化?"** 对。缺少 $n$ 个线性无关特征向量时(亏损矩阵,如 $\begin{bmatrix}1&1\\0&1\end{bmatrix}$)不能对角化——但任何矩阵都有 SVD。
- **"上三角矩阵的特征值?"** 直接读对角线(秒答),不必解方程。
- **"什么是正定/半正定矩阵?"** 对称且特征值全正/全非正;等价于 $\mathbf{x}^\top A\mathbf{x}>0$($\ge0$)。协方差、$X^\top X$、凸点 Hessian 都半正定,可做 Cholesky。
- **"怎么不解方程就求最大特征值?"** 幂迭代 $v\leftarrow Av/\|Av\|$,收敛到主特征向量,速率 $|\lambda_2/\lambda_1|$;PageRank、谱聚类用它。
- **"代数重数和几何重数?"** 重根次数 vs 独立特征向量数;后者 < 前者就不可对角化(亏损)。

## 关键事实

- 特征值/特征向量的定义与特征方程见 Strang《Introduction to Linear Algebra》(第 6 版,2023)第 6 章。
- 谱定理(实对称矩阵有实特征值与正交特征向量,$A=Q\Lambda Q^T$)是经典结果,见 Lay《Linear Algebra and Its Applications》(第 5 版,2016)§7.1;现代综述亦见各大线性代数公开课(如 MIT 18.06,Gilbert Strang)。
- $\text{tr}(A)=\sum\lambda_i$、$\det(A)=\prod\lambda_i$ 为标准恒等式,见 Horn & Johnson《Matrix Analysis》(第 2 版,2013)。
