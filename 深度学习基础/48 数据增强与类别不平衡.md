[[48 数据增强与类别不平衡|数据增强与类别不平衡]] 是两类常见的"数据侧"问题处理:数据增强通过对训练样本做保标签的随机变换来扩充数据、抑制过拟合;类别不平衡则用重采样、类权重或 Focal Loss,防止多数类淹没少数类。

## 直觉

**数据增强**:你只有 100 张猫的照片,怕模型背下来(过拟合)。于是把每张照片翻转、旋转、裁剪、调亮度 —— **它还是同一只猫,但像素全变了**。模型被迫学"不管怎么转、怎么照,这都是猫"的本质特征,而不是死记某张图。等于免费把数据集放大好几倍。

**类别不平衡**:做信用卡欺诈检测,99% 是正常交易、1% 是欺诈。模型只要**永远猜"正常"**,准确率就有 99% —— 看起来很棒,实则一个欺诈都没抓到,完全没用。少数类被多数类"淹没"了。

两件事都在告诉你:**数据的"量"和"分布"本身就是要调的对象,不只是调模型。**

## 例子

**数据增强扩容**。原始 1000 张训练图。每张图在线随机做:50% 概率水平翻转、±15° 旋转、随机裁剪到 90%、亮度抖动 ±20%。每个 epoch 看到的都是不同变体,相当于训练集"无限大",模型几乎不可能记住单张图 → 过拟合大幅下降。但注意:**数字 6 旋转 180° 会变成 9**,这种增强会破坏标签,不能用 —— 增强必须**保标签**。

**不平衡下"准确率骗人"**。1000 条数据,950 负、50 正。一个永远预测"负"的傻模型:

- 准确率 = 950/1000 = **95%**(看着很高)
- 召回率(抓到的正例/全部正例) = 0/50 = **0%**(一个没抓到)

所以不平衡问题**绝不能只看准确率**,要看召回、精确率、F1、或 **AUPRC**(精确率-召回率曲线下面积)。

**类权重手算**。负例 950、正例 50。按 $1/\text{频率}$ 设权重:负例权重 $\propto 1000/950\approx1.05$,正例权重 $\propto1000/50=20$。即**正例每错一个,损失乘约 19 倍**,逼模型重视少数类。

**SMOTE 合成手算**。少数类有两个样本 $x_i=[2,4]$、其近邻 $x_{zi}=[6,8]$。取随机 $\lambda=0.25$,合成新点:
$$x_{\text{new}}=x_i+\lambda(x_{zi}-x_i)=[2,4]+0.25\cdot[4,4]=[3,5]$$
新点落在两个真实少数类点的连线上(更靠近 $x_i$),既不是简单复制、也不会跳到类别外的"无人区"——这就是 SMOTE 比纯复制泛化好的几何原因。$\lambda$ 越大越靠近邻居。

**Focal Loss 调制手算**。$\gamma=2$。
- 易样本(已分对,$p_t=0.9$):调制因子 $(1-0.9)^2=0.01$,损失被压到原来的 1%。
- 难样本(快分错,$p_t=0.1$):调制因子 $(1-0.1)^2=0.81$,损失基本保留。
- 对比:$\gamma=0$(退回普通 CE)时两者因子都是 1,易样本和难样本一视同仁。可见 $\gamma$ 越大,**易样本被压得越狠、训练越聚焦难样本**,这正是 Focal Loss 在"背景占 99%"的检测里能 work 的关键。

## 原理

### 数据增强

核心思想:利用**已知的不变性(invariance)**生成新样本。猫翻转还是猫(平移/翻转不变),所以对图像做这些变换不改标签,却给模型更多视角。本质是一种**正则化**(见 [[42 正则化(L2、Dropout、早停、标签平滑)|正则化]]):它在数据空间注入先验,扩大有效样本量,降低 [[45 过拟合、欠拟合与偏差方差|方差]]。

常见手段:

- **图像**:翻转、旋转、裁剪/缩放、平移、颜色抖动、加噪、遮挡(Cutout)。
- **混合类**:**Mixup**(两张图按 $\lambda$ 线性插值,标签也插值)、**CutMix**(把一块区域贴到另一张图)。
- **文本**:同义词替换、随机删除/交换、**回译**(译成另一语言再译回)。
- **语音**:时间/频率掩蔽(SpecAugment)、变速、加背景噪声。

铁律:**增强只对训练集做,验证/测试集保持原样**(否则评估不准);且变换不能破坏标签语义。

**保标签 vs 破标签(易错点)**:水平翻转一只猫还是猫(✓);但翻转一个"b"会变成"d"、翻转手写"6"变"9"、水平翻转交通标志可能改变含义(左转→右转)、镜像医学影像可能改变左右病灶——这些都**破坏标签**,不能盲目套用。增强的不变性必须**匹配任务的真实不变性**。

**Mixup 手算**。两张图 $x_1$(猫,标签 $[1,0]$)、$x_2$(狗,标签 $[0,1]$),取 $\lambda=0.7$:
$$\tilde x=0.7\,x_1+0.3\,x_2,\qquad \tilde y=0.7\,[1,0]+0.3\,[0,1]=[0.7,0.3]$$
**输入和标签同步线性插值**,逼模型在样本之间"线性过渡",平滑决策边界、提升鲁棒性与校准。$\lambda$ 从 Beta 分布采。CutMix 则是把 $x_2$ 的一块矩形贴到 $x_1$ 上,标签按面积比例混合。

**测试时增强(TTA)**:推理时对同一张图做多种增强(翻转、多裁剪),分别预测再平均,常能小幅涨点;这是**评估/推理阶段**用增强的合法场景(与"验证集不增强"不矛盾,因为是对预测做集成而非改变标签)。

### 类别不平衡

问题根源:损失函数默认每个样本等权,多数类样本数量碾压,主导了梯度方向,少数类的信号被平均掉。三类对策:

**① 重采样(改数据分布)**:

- **过采样(oversampling)**:复制少数类样本,直到比例平衡。简单,但单纯复制易过拟合少数类。
- **欠采样(undersampling)**:随机丢弃多数类样本。会丢信息,适合多数类极多时。
- **SMOTE(合成少数类过采样)**:不是复制,而是在**少数类样本与其 $k$ 近邻的连线上插值**生成新样本。设少数类点 $x_i$ 和近邻 $x_{zi}$,合成点为:
$$x_{\text{new}}=x_i+\lambda\,(x_{zi}-x_i),\qquad \lambda\sim U(0,1)$$
比纯复制泛化更好(Chawla 等 2002)。**关键坑:SMOTE/过采样必须在切分训练/验证之后、只对训练集做**,否则合成样本会"渗"进验证集造成数据泄漏(见 [[46 训练、验证、测试与交叉验证|数据泄漏]])。

**② 类权重(改损失)**:不动数据,给少数类的损失项乘更大权重 $w_c\propto 1/n_c$($n_c$ 为类 $c$ 的样本数),让两类对总损失的贡献平衡。实现一行代码,常作首选。

$$\mathcal L=-\sum_c w_c\, y_c \log \hat y_c$$

**③ Focal Loss(聚焦难样本)**:Lin 等(2017,RetinaNet)针对极端不平衡(目标检测里背景占绝大多数)提出。在交叉熵前乘一个**调制因子** $(1-p_t)^\gamma$,把"已经分对的易样本"($p_t\to1$)损失压到接近 0,让训练聚焦于难样本:

$$\text{FL}(p_t)=-\alpha_t\,(1-p_t)^{\gamma}\log(p_t)$$

其中 $p_t$ 是模型对正确类的预测概率,$\gamma$(常取 2)控制压低力度,$\alpha_t$ 是类平衡权重。$\gamma=0$ 时退化为加权交叉熵。这与 [[36 损失函数(MSE、交叉熵、对比、Focal)|损失函数]] 里的 Focal 一致。

**④ 阈值调整(改决策)**:模型输出概率后,默认 0.5 切分在不平衡下常不是最优。可在验证集上扫阈值,按业务目标(高召回 or 高精确)选切点;这与改数据/改损失正交,常作最后一道调节。

**评估指标全家(不平衡核心)**:
- **准确率(accuracy)**:不平衡下骗人,慎用。
- **精确率(precision)** = TP/(TP+FP):预测为正里有多少真的正(关心"误报代价")。
- **召回率(recall)** = TP/(TP+FN):真正例里抓到多少(关心"漏报代价",如疾病/欺诈)。
- **F1** = 精确率与召回率的调和平均,平衡二者。
- **ROC-AUC**:对阈值无关,但**极端不平衡下会乐观**(FPR 分母含大量负例,不敏感)。
- **AUPRC(PR 曲线下面积)**:不平衡下比 ROC-AUC 更敏感、更该看(Davis & Goadrich 2006)。
- **混淆矩阵**:直接看四个格子,最透明。
精确率-召回率本身是一对权衡(调阈值此消彼长),选哪个看业务:**漏报致命选高召回(医疗/安全),误报扰民选高精确(垃圾邮件)。**

**评估指标**:不平衡下用**精确率/召回率/F1/AUPRC**,而非准确率;或用混淆矩阵看少数类的真正例率。阈值也可单独调(默认 0.5 在不平衡下常不是最优)。

**三类对策怎么选(实战优先级)**:数据量够 → 先试**类权重**(一行代码、不改数据、最省事);类权重不够 → 试**重采样**(SMOTE 优于纯复制,务必切分后只对训练集做);极端不平衡(如检测背景占 99%+)→ 上 **Focal Loss**;最后用**阈值调整 + 选对指标**收尾。**验证/测试集永远保持真实(不平衡)分布**,否则评估失真。

## 代码

```python
import numpy as np
import torch, torch.nn as nn

# ① 类权重:一行让损失重视少数类
counts = torch.tensor([950., 50.])               # 负、正
weights = counts.sum() / (len(counts) * counts)  # 反比于频率
loss_fn = nn.CrossEntropyLoss(weight=weights)    # 少数类损失自动加权

# ③ Focal Loss:压低易样本,聚焦难样本
def focal_loss(logits, target, gamma=2.0, alpha=0.25):
    p = torch.sigmoid(logits)
    ce = nn.functional.binary_cross_entropy_with_logits(logits, target, reduction="none")
    p_t = p * target + (1 - p) * (1 - target)     # 对正确类的概率
    return (alpha * (1 - p_t) ** gamma * ce).mean()
```

# Mixup:输入和标签同步插值(逼模型平滑过渡)
import numpy as np
def mixup(x1, x2, y1, y2, alpha=0.4):
    lam = np.random.beta(alpha, alpha)        # λ 从 Beta 采
    x = lam * x1 + (1 - lam) * x2
    y = lam * y1 + (1 - lam) * y2             # 标签也插值
    return x, y, lam
x, y, lam = mixup(np.ones(4), np.zeros(4), np.array([1.,0]), np.array([0.,1]), 0.4)
print(f"λ={lam:.2f}  混合标签={y.round(2)}")   # 标签按 λ 混合

# WeightedRandomSampler:训练时按类权重采样,让 batch 里少数类不被淹没

## 面试高频

- **Q:数据增强为什么能减过拟合?**
  A:利用已知不变性(翻转/旋转不改标签)生成新样本,扩大有效数据量、注入先验,降低模型方差。本质是数据空间的正则化。只对训练集做、不能破坏标签。
- **Q:类别不平衡为什么不能只看准确率?该看什么?**
  A:多数类占比极高时,模型全猜多数类就有高准确率却毫无用处。应看召回、精确率、F1、AUPRC,或混淆矩阵里少数类的真正例率。
- **Q:处理类别不平衡有哪些方法?**
  A:①重采样(过采样/欠采样/SMOTE合成);②类权重(损失里给少数类加权);③Focal Loss(压低易样本、聚焦难样本);④调分类阈值。
- **Q:SMOTE 和单纯复制少数类的区别?用 SMOTE 要注意什么?**
  A:SMOTE 在少数类样本与近邻连线上插值合成**新样本**,泛化优于纯复制(复制易过拟合)。必须在切分后只对训练集做,否则数据泄漏。
- **Q:Focal Loss 怎么工作的?γ 的作用?**
  A:在交叉熵前乘 $(1-p_t)^\gamma$,把已分对的易样本损失压向 0,让训练聚焦难样本。γ(常 2)越大压得越狠,γ=0 退化为加权 CE。
- **Q:Mixup 是怎么做的?为什么有用?**
  A:两张图按 $\lambda$(Beta 采样)线性插值,**标签也按 $\lambda$ 插值**。逼模型在样本间线性过渡,平滑决策边界、提升鲁棒与校准、抗对抗样本。CutMix 是贴矩形块、标签按面积比混合。
- **Q:不平衡下 ROC-AUC 和 AUPRC 选哪个?**
  A:AUPRC。极端不平衡时 ROC-AUC 因 FPR 分母含大量负例而不敏感、显得乐观;PR 曲线直接盯精确率-召回率,对少数类更敏感(Davis & Goadrich 2006)。
- **Q:精确率和召回率怎么权衡?何时偏哪个?**
  A:调阈值时二者此消彼长。漏报代价高(疾病、欺诈、安全)→ 重召回;误报代价高(垃圾邮件、推荐打扰)→ 重精确;不确定就看 F1 或按业务定。
- **Q:WeightedRandomSampler 和类权重损失有何不同?**
  A:前者改**采样**(让 batch 里类更平衡),后者改**损失**(让少数类错误更贵)。效果相近,可二选一;同时叠加重采样 + SMOTE 容易过采样过头、过拟合少数类。
- **陷阱**:① 增强用到验证/测试集。② 用会破坏标签的增强(6 转成 9、镜像医学影像)。③ SMOTE/过采样在切分前做 → 泄漏。④ 不平衡下只报准确率。⑤ 验证集也被重采样成平衡分布 → 评估失真(验证应保持真实分布)。⑥ 重采样和类权重同时猛上 → 过度补偿。

## 关键事实

- SMOTE 由 Chawla、Bowyer、Hall、Kegelmeyer 提出(2002,JAIR,"SMOTE: Synthetic Minority Over-sampling Technique"):连线插值合成少数类,而非复制。
- Focal Loss 由 Lin、Goyal、Girshick、He、Dollár 提出(2017,ICCV,RetinaNet,arXiv:1708.02002):用 $(1-p_t)^\gamma$ 调制因子解决一阶段检测器的前景-背景极端不平衡,$\gamma=2,\ \alpha=0.25$ 为常用默认。
- Mixup:Zhang 等(2018,ICLR);CutMix:Yun 等(2019,ICCV);Cutout:DeVries & Taylor(2017);均是强力图像增强。
- AutoAugment(Cubuk 等 2019)用搜索自动学增强策略;RandAugment(2020)简化之。
- 不平衡评估推荐 AUPRC(Davis & Goadrich 2006 指出在不平衡下比 ROC-AUC 更敏感)。
- 关联:增强对接 [[45 过拟合、欠拟合与偏差方差|过拟合]] 与 [[42 正则化(L2、Dropout、早停、标签平滑)|正则化]];Focal/类权重对接 [[36 损失函数(MSE、交叉熵、对比、Focal)|损失函数]];重采样别踩 [[46 训练、验证、测试与交叉验证|数据泄漏]] 坑。
