[[29 熵与信息量]]:**熵是一个概率分布的平均不确定性**,等于每个事件"信息量" $-\log p$ 的期望;它是后面所有损失函数([[30 交叉熵与负对数似然]]、[[31 KL 散度与 JS 散度]]、[[32 困惑度 Perplexity]])的地基。

## 直觉

想象你在猜"明天会发生什么"。

- 如果一件事**几乎必然发生**(太阳升起,$p=1$),它发生时你毫不惊讶,**信息量为 0**。
- 如果一件事**非常罕见**($p=0.001$),它真发生了,你会大吃一惊,**信息量很大**。

所以"信息量"度量的是**惊讶程度**:越罕见越惊讶。数学上要求一个函数满足:概率越小值越大、$p=1$ 时为 0、两个独立事件信息可相加。唯一满足这些条件的就是 $I(x)=-\log p(x)$。

**熵**则是把这个惊讶程度按概率**加权平均**:平均而言,从这个分布里抽一个样本,你会有多惊讶?

- 分布越**均匀**(比如均匀骰子),每次都难猜 → 熵大。
- 分布越**集中**(几乎总是某个值)→ 熵小。

熵 = "你需要多少 bit 才能平均编码一个样本",也是"这个系统有多少不确定性"。

## 例子

**例 1:抛硬币(手算)。** 公平硬币 $p=[0.5,0.5]$,用 $\log_2$:

$$H=-(0.5\log_2 0.5+0.5\log_2 0.5)=-(0.5\times(-1)+0.5\times(-1))=1\ \text{bit}$$

正好 1 bit——这就是"信息"的单位定义:一次公平二选一 = 1 bit。

**例 2:作弊硬币** $p=[0.9,0.1]$:

$$H=-(0.9\log_2 0.9+0.1\log_2 0.1)=-(0.9\times(-0.152)+0.1\times(-3.322))=0.137+0.332=0.469\ \text{bit}$$

更确定了 → 熵从 1 降到 0.47。

**例 3:三类均匀** $p=[\tfrac13,\tfrac13,\tfrac13]$:$H=\log_2 3=1.585$ bit。**$n$ 个等概率事件,熵恰为 $\log_2 n$**(均匀分布是给定支撑集上熵最大的分布)。

**例 4:四类非均匀**(展示二元熵以外的算法) $p=[0.5,0.25,0.125,0.125]$:
$$H=-(0.5\log_2 0.5+0.25\log_2 0.25+2\times0.125\log_2 0.125)=0.5\cdot1+0.25\cdot2+0.25\cdot3=1.75\ \text{bit}$$
有趣的是这恰好等于"最优前缀码"的平均码长(0、10、110、111),印证"熵 = 平均最短编码长度"(香农信源编码定理)。

**例 5:用 nat 重算公平硬币**(深度学习默认底)。$H=-2\times0.5\ln0.5=\ln2\approx0.693$ nat。换算 $0.693\,\text{nat}\times1.443=1$ bit,与例 1 一致——**同一分布,bit 和 nat 只差常数倍 $\log_2 e\approx1.443$**。

**例 6:二元熵函数 $H(p)$ 的形状**。$H(p)=-p\log_2 p-(1-p)\log_2(1-p)$,在 $p=0.5$ 取最大 1 bit,在 $p=0$ 或 $1$ 取 0,关于 $0.5$ 对称、凹。这条曲线是理解"越接近确定越少信息"的标准图像。

## 原理

**自信息(信息量)** 定义为

$$I(x)=-\log p(x)$$

底数决定单位:$\log_2 \Rightarrow$ **bit**,$\ln \Rightarrow$ **nat**(深度学习里默认 $\ln$,因为求导干净)。两者只差常数倍:$1\ \text{nat}=\log_2 e\approx 1.443$ bit。

**香农熵**是自信息的期望:

$$H(p)=\mathbb{E}_{x\sim p}[-\log p(x)]=-\sum_{x} p(x)\log p(x)$$

约定 $0\log 0 = 0$(取极限 $\lim_{p\to 0^+}p\log p=0$)。

**关键性质:**

1. $H(p)\ge 0$,当且仅当某个 $p(x)=1$(完全确定)时取 0。
2. 对 $|\mathcal{X}|=n$ 的离散分布,$H(p)\le\log n$,均匀分布时取最大。
3. 连续型用微分熵 $h(p)=-\int p(x)\log p(x)\,dx$,可为负(因为概率密度可 $>1$)。

**为什么是这个公式而不是别的?** 香农证明:满足"连续性 + 等概率时随 $n$ 单调增 + 可分解(分组求和不变)"三条公理的不确定性度量,**唯一**(差一个正比例常数)就是 $-\sum p\log p$。

**为什么信息量是 $-\log p$(可加性导出)**。要求"两个独立事件一起发生的信息 = 各自信息之和":$I(x,y)=I(x)+I(y)$。而独立事件 $p(x,y)=p(x)p(y)$,概率是相乘的。唯一能把"相乘"变成"相加"的函数就是对数,$\log(ab)=\log a+\log b$。再要求概率越小信息越大、$p=1$ 时为 0,就锁定 $I(x)=-\log p(x)$。

## 信息论各量(一张地图)

熵不是孤立的,它是一族量的核心。**这族量串起了交叉熵、KL、互信息、困惑度**:

| 量 | 定义 | 含义 |
|---|---|---|
| 自信息 | $I(x)=-\log p(x)$ | 单个事件的惊讶度 |
| 熵 | $H(p)=-\sum p\log p$ | 分布的平均不确定性 |
| 联合熵 | $H(X,Y)=-\sum p(x,y)\log p(x,y)$ | 两变量整体不确定性 |
| 条件熵 | $H(Y\mid X)=H(X,Y)-H(X)$ | 已知 $X$ 后 $Y$ 剩多少不确定 |
| 交叉熵 | $H(p,q)=-\sum p\log q$ | 用 $q$ 编 $p$ 的平均代价(见 [[30 交叉熵与负对数似然|交叉熵]]) |
| KL 散度 | $D_{KL}(p\|q)=\sum p\log\frac pq$ | 用错码本多花的 bit(见 [[31 KL 散度与 JS 散度|KL]]) |
| 互信息 | $I(X;Y)=H(X)-H(X\mid Y)$ | 知道一个变量减少另一个多少不确定 |

**关键恒等式**:$H(p,q)=H(p)+D_{KL}(p\|q)$(交叉熵 = 熵 + KL,故交叉熵 $\ge$ 熵);$I(X;Y)=D_{KL}\big(p(x,y)\,\|\,p(x)p(y)\big)\ge0$(互信息 = 联合分布与"独立假设"的 KL,故非负,$=0$ 当且仅当独立)。

**手算条件熵 / 互信息**。设 $X,Y\in\{0,1\}$,联合 $p(0,0)=p(1,1)=0.4,\ p(0,1)=p(1,0)=0.1$。边际 $p(X)=p(Y)=[0.5,0.5]$,$H(X)=1$ bit。联合熵 $H(X,Y)=-(2\times0.4\log_2 0.4+2\times0.1\log_2 0.1)=2\times0.4\times1.322+2\times0.1\times3.322=1.058+0.664=1.722$ bit。互信息 $I(X;Y)=H(X)+H(Y)-H(X,Y)=1+1-1.722=0.278$ bit——$X,Y$ 正相关,知道一个能减少另一个约 0.28 bit 的不确定性。

**最大熵原理**。在只知道某些约束(如均值)时,应选**满足约束中熵最大**的分布(假设最少、最"不偏")。结论:无约束(仅支撑集有限)→ 均匀分布;固定均值方差 → 高斯;固定均值(正实数)→ 指数分布。这给了"为什么默认高斯"一个信息论解释,也是逻辑回归/softmax 的另一条推导路径(最大熵模型)。

**拉格朗日推导(为什么无约束最大熵是均匀)**。在唯一约束 $\sum_i p_i=1$ 下最大化 $H=-\sum_i p_i\ln p_i$,构造
$$\mathcal{L}=-\sum_i p_i\ln p_i+\lambda\Big(\sum_i p_i-1\Big).$$
对每个 $p_i$ 求偏导并置零:$\frac{\partial\mathcal{L}}{\partial p_i}=-\ln p_i-1+\lambda=0\Rightarrow p_i=e^{\lambda-1}$。右边**与 $i$ 无关**,所以所有 $p_i$ 相等;代入归一化 $\sum_i p_i=n\,e^{\lambda-1}=1$ 得 $p_i=\tfrac1n$,此时 $H=\ln n$,正是上界。直觉:导数让每一项的"边际信息贡献"被拉平,谁都不偏,自然均匀。多加一条约束(如固定 $\sum_i p_i x_i=\mu$)就多一个乘子,解形如 $p_i\propto e^{-\beta x_i}$,这就长出指数族/高斯。

## 代码

```python
import numpy as np

# ❌ 错:直接 sum(p * log p),p=0 处 log(0) = -inf,结果变 nan
def entropy_bad(p):
    return -np.sum(p * np.log2(p))          # p 含 0 → nan

# ✅ 对:mask 掉 0,或加极小 eps;并断言 p 是合法分布
def entropy(p, base=2):
    p = np.asarray(p, dtype=float)
    assert np.all(p >= 0) and np.isclose(p.sum(), 1.0), "p 必须是概率分布"
    p = p[p > 0]                            # 0*log0 = 0,直接丢掉
    log = np.log2 if base == 2 else np.log
    return -np.sum(p * log(p))

print(entropy([0.5, 0.5]))                 # 1.0  bit
print(entropy([0.9, 0.1]))                 # 0.469 bit
print(entropy([1/3, 1/3, 1/3]))            # 1.585 = log2(3)
print(entropy([0.5,0.25,0.125,0.125]))     # 1.75 = 最优前缀码平均码长
print(entropy([1.0, 0.0]))                 # 0.0  完全确定

# 联合熵 / 互信息(验证手算 I(X;Y)=0.278 bit)
joint = np.array([[0.4, 0.1],
                  [0.1, 0.4]])             # p(x,y)
px = joint.sum(axis=1); py = joint.sum(axis=0)
H = lambda p: -np.sum(p[p>0]*np.log2(p[p>0]))
H_xy = -np.sum(joint[joint>0]*np.log2(joint[joint>0]))
MI = H(px) + H(py) - H_xy
print("H(X,Y)=", round(H_xy,3), " I(X;Y)=", round(MI,3))   # 1.722  0.278
```

四类 $[0.5,0.25,0.125,0.125]$ 的熵恰为 1.75 bit = 最优前缀码平均码长;联合分布算出 $I(X;Y)=0.278$ bit,与手算一致。

## 面试高频

- **"熵衡量什么?"** 一个分布的平均不确定性 / 编码一个样本平均所需 bit 数 / 平均惊讶度。
- **"熵什么时候最大、最小?"** 均匀分布最大($\log n$);某事件概率为 1 时最小(0)。
- **"bit 和 nat 区别?"** 只是 $\log$ 底数不同($2$ vs $e$),差常数倍 $1.443$;深度学习用 nat 因为 $\ln$ 求导是 $1/x$ 最干净。
- **"熵和交叉熵、KL 什么关系?"** 交叉熵 $H(p,q)=H(p)+D_{KL}(p\|q)$,熵是其中"不可压缩"的下界部分,见 [[30 交叉熵与负对数似然]]。
- **"为什么信息量是 $-\log p$?"** 要求独立事件信息可加,而独立概率相乘;唯一把乘变加的是对数,加上"$p=1$ 信息为 0""越罕见越大"就锁定 $-\log p$。
- **"互信息是什么?有什么用?"** $I(X;Y)=H(X)-H(X\mid Y)\ge0$,知道一个变量能减少另一个多少不确定性;$=0$ 当且仅当独立。特征选择、表示学习(InfoNCE 是互信息下界)都用它。
- **"条件熵 vs 联合熵?"** $H(X,Y)=H(X)+H(Y\mid X)$(链式法则);$H(Y\mid X)\le H(Y)$(条件化不增熵,知道更多信息只会减少不确定性)。
- **"最大熵原理?"** 约束下选熵最大的分布(假设最少);固定均值方差时是高斯,这是"默认高斯"的信息论理由。
- **陷阱:** 微分熵(连续型)可以为负,离散熵永远非负。

## 关键事实

- 香农 1948《A Mathematical Theory of Communication》提出熵与信息量,奠定信息论。
- 离散熵 $H(p)=-\sum p\log p\ge 0$;$n$ 类均匀时取最大值 $\log n$(Cover & Thomas《Elements of Information Theory》第 2 版,2006,第 2 章)。
- 自信息 $I(x)=-\log p(x)$ 的可加性源于独立事件概率相乘 → $\log$ 相加。
- 深度学习默认以 $e$ 为底(nat),PyTorch 的 `torch.distributions` / 交叉熵实现内部均用自然对数。
