[[11 主成分分析 PCA|PCA]](主成分分析)是一种**无监督降维**方法:它在高维数据里找到**方差最大的几个正交方向(主成分)**,把数据投影上去,用更少的维度保留尽可能多的信息。数学上它就是对数据协方差矩阵做 [[09 特征值与特征向量|特征分解]],或等价地对中心化数据做 [[10 SVD 奇异值分解|SVD]]。

## 直觉

想象你拍一个**雪茄形状(细长)的三维点云**。要拍成一张二维照片,从哪个角度拍信息最多?

- 沿着雪茄**最长方向**看,点散得最开、彼此最容易区分——这个方向方差最大,就是**第一主成分 PC1**。
- 与它垂直、第二散开的方向是 **PC2**。
- 沿着雪茄"最细"的方向几乎没信息,可以扔掉。

PCA 就是自动找出这些"看点云最清楚的角度",并按信息量(方差)从大到小排序,让你只留前几个就能近似还原数据。**方差 = 信息**,这是 PCA 的核心假设。

## 例子

**手算二维 PCA**。四个点(已去均值):$(2,0),(-2,0),(0,1),(0,-1)$,均值已在原点。协方差矩阵 $C=\frac{1}{n-1}X^TX$(这里 $n=4$):

$$X^TX=\begin{bmatrix}2&-2&0&0\\0&0&1&-1\end{bmatrix}\begin{bmatrix}2&0\\-2&0\\0&1\\0&-1\end{bmatrix}=\begin{bmatrix}8&0\\0&2\end{bmatrix}$$

$$C=\frac{1}{3}\begin{bmatrix}8&0\\0&2\end{bmatrix}=\begin{bmatrix}2.67&0\\0&0.67\end{bmatrix}$$

$C$ 已是对角阵,特征值 $\lambda_1=2.67$(沿 $x$ 轴方向,$v_1=(1,0)$)、$\lambda_2=0.67$(沿 $y$ 轴,$v_2=(0,1)$)。

- **PC1** = $(1,0)$,因为数据沿 $x$ 散得更开(方差 2.67 > 0.67)。
- **解释方差比**:PC1 占 $\frac{2.67}{2.67+0.67}=\frac{2.67}{3.34}=80\%$。只留 PC1 就保住 80% 的信息,把二维降到一维。

**投影到 PC1 的坐标(手算降维结果)**。把每个点点积 PC1 方向 $(1,0)$:$(2,0)\to2$、$(-2,0)\to-2$、$(0,1)\to0$、$(0,-1)\to0$。一维坐标 $[2,-2,0,0]$——前两个点被区分开,后两个挤在 0(它们在 PC1 上没差异,信息都在被丢的 PC2 上)。

**重建(从 1 维还原回 2 维,看丢了什么)**。把一维坐标乘回 PC1 方向:$2\cdot(1,0)=(2,0)$、$0\cdot(1,0)=(0,0)$。原来的 $(0,1)$ 被重建成 $(0,0)$——y 方向的信息(PC2 上的 20%)永久丢失。**重建误差 = 被丢弃特征值之和 = 0.67**,正好是 [[10 SVD 奇异值分解|Eckart-Young]] 说的截断误差。

## 原理

**目标**:找单位向量 $w$,使数据投影 $Xw$ 的方差最大。中心化后方差 $=\frac{1}{n-1}w^TX^TXw=w^TCw$,约束 $\|w\|=1$。用拉格朗日乘子:

$$\max_w\ w^TCw\ \text{ s.t. }w^Tw=1\quad\Longrightarrow\quad Cw=\lambda w$$

结论惊人地干净:**最大化方差的方向 $w$ 正好是协方差矩阵 $C$ 的特征向量**,且方差值 $=$ 对应特征值 $\lambda$。所以:

- 主成分方向 = $C$ 的特征向量(按特征值从大到小排);
- 每个主成分上的方差 = 对应特征值 $\lambda_i$;
- 因为 $C$ 对称,特征向量两两**正交**(谱定理,见 [[09 特征值与特征向量|特征值]]),主成分互不相关。

**完整流水线**:

1. **中心化**:每列减去均值($X\leftarrow X-\mu$);常还要标准化(除标准差),否则量纲大的特征会主导。
2. **协方差矩阵** $C=\frac{1}{n-1}X^TX$($d\times d$,对称半正定)。
3. **特征分解** $C=Q\Lambda Q^T$,特征向量=主轴,特征值=各轴方差。
4. **投影降维**:取 $\lambda$ 最大的 $k$ 个特征向量组成 $Q_k$,$Z=XQ_k$,$d$ 维降到 $k$ 维。

![[la-PCA协方差特征.png]]

**用 SVD 实现(实践首选)**。对中心化的 $X$ 直接 SVD:$X=U\Sigma V^T$。则

$$C=\frac{1}{n-1}X^TX=\frac{1}{n-1}V\Sigma^2V^T$$

对比 $C=Q\Lambda Q^T$ 立刻得到:右奇异向量 $V=$ 主成分 $Q$,$\lambda_i=\frac{\sigma_i^2}{n-1}$。所以**不用显式构造协方差矩阵**(省内存、数值更稳),直接对数据做 [[10 SVD 奇异值分解|SVD]] 即可——这也是 `sklearn` 的做法。

**白化(whitening / sphering)**。降维后若再把每个主成分**除以其标准差** $\sqrt{\lambda_i}$,得到的新坐标各维方差都为 1、互不相关——数据被"球化"。$Z_{\text{white}}=XQ_k\Lambda_k^{-1/2}$。白化用于去相关预处理、某些生成模型、以及解释 BatchNorm 的部分作用。

**PCA 的局限与替代(高频追问)**:

- **线性**:只能找线性子空间。数据若躺在弯曲流形(瑞士卷),PCA 会"切穿"流形,要用核 PCA、t-SNE、UMAP、自编码器。
- **无监督**:只看方差不看标签。**方差大 ≠ 判别性强**——最能分类的方向可能方差很小被 PCA 当噪声扔掉;要判别降维用 LDA。
- **对量纲敏感**:不标准化时大尺度特征(如"年收入"vs"年龄")会霸占主成分,所以常先标准化(z-score)。
- **对异常值敏感**:方差被极端点拉偏,必要时用鲁棒 PCA。

**与表示学习的联系**:PCA 给出的低维坐标 $Z$ 就是一种线性 [[04 Embedding 与向量数据库|Embedding]];现代神经网络嵌入是它的非线性强化版。线性自编码器(无激活、MSE 损失)学到的子空间恰好就是 PCA 子空间——这是连接经典降维与深度表示的经典结论。

## 代码

```python
import numpy as np

# 4 个二维点(行=样本)
X = np.array([[2., 0.],
              [-2., 0.],
              [0., 1.],
              [0., -1.]])

# 1) 中心化
Xc = X - X.mean(axis=0)

# 2) 协方差 + 特征分解(eigh 用于对称阵)
C = (Xc.T @ Xc) / (len(X) - 1)
vals, vecs = np.linalg.eigh(C)          # 升序
order = vals[::-1]                       # 降序方差
print("各主成分方差(特征值):", order)    # [2.667, 0.667]
print("解释方差比:", order / order.sum())# [0.8, 0.2]

# 3) 用 SVD 做同一件事(实践推荐)
U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
print("SVD 推出的方差:", (S**2) / (len(X) - 1))  # 同样 [2.667, 0.667]
print("PC1 方向:", Vt[0])                # ≈ [±1, 0]

# 4) 降到 1 维
Z = Xc @ Vt[0]
print("一维坐标:", Z)                    # [2, -2, 0, 0]

# 5) 重建回 2 维,看重建误差 = 被丢的特征值
Xrec = np.outer(Z, Vt[0])               # 一维坐标 × PC1 方向
err = ((Xc - Xrec)**2).sum()            # 重建平方误差
print("重建误差:", round(err, 3))        # 2.0 = (n-1)*λ2 = 3*0.667

# 6) 白化:降维后各维除以 sqrt(方差),得到去相关、单位方差
Zw = Z / np.sqrt(order[0])              # 这里只 1 维
print("白化后方差≈1:", round(Zw.var(ddof=1), 3))

# 对照 sklearn
# from sklearn.decomposition import PCA
# print(PCA(n_components=1).fit(X).explained_variance_ratio_)  # [0.8]
```

```python
# ❌ 常见 bug:忘了中心化,第一主成分会指向均值方向(完全错)
X2 = X + 100                              # 整体平移,数据形状没变
U, S, Vt = np.linalg.svd(X2, full_matrices=False)  # 没减均值!
print("未中心化 PC1(错):", Vt[0].round(3))   # 指向 (≈0.7,0.7),被均值带偏

# ✅ 正确:先中心化再 SVD
Xc2 = X2 - X2.mean(axis=0)
U, S, Vt = np.linalg.svd(Xc2, full_matrices=False)
print("中心化 PC1(对):", Vt[0].round(3))     # ≈[1,0],与原结果一致
```

手算对照:特征值 `[2.667, 0.667]` 与手算 $\lambda_1=2.67,\lambda_2=0.67$ 一致;解释方差比 `[0.8, 0.2]` 与手算 80% 一致;SVD 路径给出同样的方差,印证 $\lambda_i=\sigma_i^2/(n-1)$。

## 面试高频

- **"PCA 在做什么?一句话。"** 找方差最大的正交方向,把数据投上去降维。陷阱:别说成"压缩",要点出"保留方差最大方向"。
- **"为什么主成分是协方差矩阵的特征向量?"** 拉格朗日法:最大化 $w^TCw$ s.t. $\|w\|=1$ 推出 $Cw=\lambda w$。能写出这步是区分度。
- **"做 PCA 前为什么要标准化/中心化?"** 中心化是必须的(否则第一主成分会指向均值方向);标准化是因为方差对量纲敏感,大尺度特征会霸占主成分。这是高频陷阱。
- **"PCA 用特征分解还是 SVD?"** 实践用对中心化数据做 SVD,数值更稳、不必显式算 $d\times d$ 协方差(高维时省巨大内存)。
- **"怎么选保留几维?"** 看累计解释方差比(如保到 95%),或看 scree plot 的"肘部"。
- **陷阱:PCA 是线性、无监督的。** 它不看标签,只看方差;对非线性流形(如瑞士卷)效果差,要用 t-SNE/UMAP/核 PCA。方差大 ≠ 对分类有用(可能扔掉判别方向)。
- **"PCA vs LDA 区别?"** PCA 无监督、最大化方差;LDA 有监督、最大化类间/类内方差比(判别)。要降维后还好分类,LDA 往往更优。
- **"什么是白化?"** 降维后各主成分除以 $\sqrt{\lambda_i}$,得到去相关、单位方差的坐标;用于去相关预处理。
- **"重建误差等于什么?"** 被丢弃特征值之和($\sum_{i>k}\lambda_i$),即 [[10 SVD 奇异值分解|Eckart-Young]] 的最优截断误差。
- **"线性自编码器和 PCA 什么关系?"** 无激活、MSE 的线性 AE 学到的子空间就是 PCA 子空间。

## 关键事实

- PCA 由 Karl Pearson 于 1901 年首次提出("On Lines and Planes of Closest Fit to Systems of Points in Space", *Philosophical Magazine*, 1901),作为几何上"最近拟合直线/平面"问题;Harold Hotelling 于 1933 年独立给出代数推导并命名"主成分"("Analysis of a Complex of Statistical Variables Into Principal Components", *Journal of Educational Psychology*, 1933)。
- 主成分 = 协方差矩阵特征向量、方差 = 特征值,标准推导见 Jolliffe《Principal Component Analysis》(第 2 版,2002)。
- 用 SVD 实现 PCA(对中心化数据)是数值首选,$\lambda_i=\sigma_i^2/(n-1)$,见 scikit-learn 文档及 Trefethen & Bau《Numerical Linear Algebra》(1997)。
