[[45 过拟合、欠拟合与偏差方差|过拟合与偏差方差]] 描述模型容量与泛化的权衡:容量太小则欠拟合(高偏差,连训练集都学不好),太大则过拟合(高方差,把训练集的噪声也背下来,验证集崩),目标是找到使总误差最小的中间点。

## 直觉

把"学习"想成学生备考。

- **欠拟合(高偏差)**:学生只背了"考试都考加减法"这种过度简化的规律,连平时的练习题都做不对 —— **模型太笨,训练集都学不好**。
- **过拟合(高方差)**:学生把每道练习题的答案死记硬背(连印刷错误都背了),练习全对,**一换新题就傻眼** —— 模型太"死记",学到了训练集的噪声而非规律。
- **恰好**:学生真正理解了解题方法,练习好、考试也好 —— **学到的是泛化规律**。

"偏差"=你系统性地偏离真相多少(笨);"方差"=换一批训练数据,你的预测抖动多大(不稳)。

## 例子

**用多项式拟合 8 个点感受三种状态**(对应上图):真实规律是一条平滑上升的曲线,数据带点噪声。

- 用**一次直线**拟合:无论怎么调,直线穿不过这些有弯曲的点,训练误差就很大 → **欠拟合 / 高偏差**。
- 用**三次曲线**拟合:平滑地跟着趋势走,训练误差小,换新点也准 → **恰好**。
- 用**七次多项式**(8 个点能被 7 次多项式完美穿过):训练误差=0,但曲线剧烈扭动去迁就每个噪声点,两点之间狂甩,新点预测离谱 → **过拟合 / 高方差**。

**偏差方差数值直觉**。同一个问题,我们重复采 5 批训练数据,各训一个模型,在某测试点 $x_0$(真值 $f(x_0)=10$)上得到 5 个预测:

- 高偏差模型预测 $\{6,6.2,5.9,6.1,6\}$:平均 6.04,**系统性偏低**(偏差 ≈ 4),但很集中(方差 ≈ 0.01)。
- 高方差模型预测 $\{10,3,17,8,12\}$:平均 10,**偏差几乎为 0**,但乱跳(方差很大)。

两者都不好;好模型要预测**既准(偏差小)又稳(方差小)**。打个比方:**偏差 = 射箭总体偏离靶心(准星歪了),方差 = 每箭落点四处乱散(手抖)**。高偏差像准星固定歪向左下、箭都聚在左下(稳但不准);高方差像准星没问题但手抖、箭散落在靶心周围(平均准但单箭不可信)。

**把分解每一项算出来(数值代入)**。真值 $f(x_0)=10$,噪声 $\sigma^2=1$。
- 高偏差模型 5 次预测 $\{6,6.2,5.9,6.1,6\}$:均值 $\bar f=6.04$。**偏差² = $(\bar f-f)^2=(6.04-10)^2=15.68$**;**方差 = $\frac15\sum(\hat f-\bar f)^2\approx0.012$**;总期望误差 $\approx15.68+0.012+1=16.69$,几乎全是偏差。
- 高方差模型 $\{10,3,17,8,12\}$:均值 $\bar f=10$。**偏差² = $(10-10)^2=0$**;**方差 = $\frac15[(0)^2+(-7)^2+(7)^2+(-2)^2+(2)^2]=\frac{106}{5}=21.2$**;总误差 $\approx0+21.2+1=22.2$,几乎全是方差。
两者总误差都远大于最优,但**病因相反**:一个该加容量/减正则,一个该加数据/加正则——用错药只会更糟。

**误差随训练量的变化(学习曲线)**。再给一个诊断利器:把训练集大小 $m$ 当横轴,画训练误差和验证误差两条曲线。
- **高偏差**:两条线很快**贴在一起且都高**——加数据没用(模型本身太弱),该加容量。
- **高方差**:两条线之间有**明显且持久的大间隙**(训练低、验证高)——加数据有用(间隙会随 $m$ 增大慢慢缩小)。
学习曲线能直接告诉你"该加数据还是加容量",比单看一个点更可靠。

## 原理

**偏差-方差分解**(MSE 损失下,核心公式)。设真值 $y=f(x)+\varepsilon$,噪声 $\varepsilon$ 满足 $\mathbb E[\varepsilon]=0,\ \text{Var}(\varepsilon)=\sigma^2$。模型 $\hat f$ 在不同训练集上随机,记其在点 $x$ 的预测为 $\hat f(x)$。期望平方误差可分解为:

$$\mathbb E\big[(y-\hat f(x))^2\big]=\underbrace{\big(\,\mathbb E[\hat f(x)]-f(x)\,\big)^2}_{\text{偏差}^2}+\underbrace{\mathbb E\big[(\hat f(x)-\mathbb E[\hat f(x)])^2\big]}_{\text{方差}}+\underbrace{\sigma^2}_{\text{噪声}}$$

**推导(不跳步)**。记 $\bar f=\mathbb E[\hat f(x)]$(对训练集随机性求期望)。把误差拆成两段并平方:

$$\mathbb E[(y-\hat f)^2]=\mathbb E\big[(y-\bar f+\bar f-\hat f)^2\big]=\mathbb E[(y-\bar f)^2]+\mathbb E[(\bar f-\hat f)^2]+2\,\mathbb E[(y-\bar f)(\bar f-\hat f)]$$

交叉项为 0:$\bar f$ 是常数,$\mathbb E[\bar f-\hat f]=\bar f-\bar f=0$,而 $y$ 与训练集独立,故 $\mathbb E[(y-\bar f)(\bar f-\hat f)]=(\,\mathbb E[y]-\bar f)\cdot\mathbb E[\bar f-\hat f]=0$。剩下两项:

- 第二项 $\mathbb E[(\bar f-\hat f)^2]=\text{Var}(\hat f)$ = **方差**。
- 第一项再拆 $y=f+\varepsilon$:$\mathbb E[(f+\varepsilon-\bar f)^2]=(f-\bar f)^2+\mathbb E[\varepsilon^2]+2(f-\bar f)\mathbb E[\varepsilon]=\underbrace{(f-\bar f)^2}_{\text{偏差}^2}+\sigma^2$。

合起来即得分解式。**噪声 $\sigma^2$ 是不可约的下界**,任何模型都消不掉。

**权衡**。模型复杂度上升:拟合能力变强 → 偏差下降;但对训练数据更敏感 → 方差上升。总误差 = 偏差² + 方差 + 噪声,通常呈 **U 形**,最低点就是最优复杂度。

![[nn-偏差方差权衡.svg]]

**诊断与对策**(面试常考):

| 现象 | 训练误差 | 验证误差 | 诊断 | 对策 |
|---|---|---|---|---|
| 都高 | 高 | 高 | 欠拟合/高偏差 | 加容量、训久、减正则、加特征 |
| 训低验高 | 低 | 高 | 过拟合/高方差 | [[42 正则化(L2、Dropout、早停、标签平滑)|正则化]]、加数据/增强、减容量、早停 |
| 都低且接近 | 低 | 低 | 恰好 | 收工 |

注:关键看**训练误差**先 —— 训练误差就大,说明连拟合都没做到,是偏差问题,加正则只会更糟;训练误差小而验证误差大,才是方差问题。

**与正则化的关系**:[[26 最大后验 MAP 与正则化的概率解释|正则化]] 本质是用"加偏差换减方差" —— L2/Dropout 限制模型乱拟合的自由度,略升偏差、大降方差,把 U 形曲线往左推到更优点。

**各手段在偏差-方差天平上的位置(背一张表)**:

| 操作 | 偏差 | 方差 | 适用 |
|---|---|---|---|
| 加容量(更深/更宽) | ↓ | ↑ | 欠拟合 |
| 加正则(L2/Dropout/早停) | ↑(略) | ↓ | 过拟合 |
| 加数据 / 数据增强 | ≈不变 | ↓↓ | 过拟合(最优先) |
| 加特征 / 更好结构 | ↓ | — | 欠拟合 |
| 集成(bagging) | ≈不变 | ↓ | 高方差模型 |
| Boosting | ↓ | ↑ | 高偏差弱学习器 |

注意 **bagging(随机森林)主要降方差、boosting(GBDT)主要降偏差**——这是经典机器学习高频对比题,根子就在偏差-方差。

> 补充:现代超大模型出现"双下降(double descent)"现象,误差随容量先 U 形再二次下降,经典 U 形是其低容量段的近似;面试提一句即可。深度学习中"过参数化反而泛化好"挑战了经典直觉,但**给定数据和正则下仍存在一个最优容量**,偏差-方差框架在工程诊断上依然实用。

## 代码

```python
import numpy as np
from numpy.polynomial import polynomial as P

# 真实规律 + 噪声
rng = np.random.default_rng(0)
x = np.linspace(0, 1, 12)
y = np.sin(2*np.pi*x) + rng.normal(0, 0.15, x.shape)
xv = np.linspace(0, 1, 100)
yv_true = np.sin(2*np.pi*xv)

for deg, tag in [(1, "欠拟合"), (3, "恰好"), (11, "过拟合")]:
    c = np.polyfit(x, y, deg)
    train_err = np.mean((np.polyval(c, x) - y) ** 2)
    val_err   = np.mean((np.polyval(c, xv) - yv_true) ** 2)
    print(f"{tag} deg={deg:2d}: 训练MSE={train_err:.3f}  验证MSE={val_err:.3f}")
# 欠拟合: 训练高、验证高
# 恰好:   训练低、验证低
# 过拟合: 训练≈0、验证爆炸  ← 高方差
```

```python
# 经验性偏差/方差:重复采样训练,看预测的偏差与抖动
def bias_var(deg, x0=0.5, runs=200):
    preds = []
    for _ in range(runs):
        xs = rng.uniform(0, 1, 12)
        ys = np.sin(2*np.pi*xs) + rng.normal(0, 0.15, xs.shape)
        c = np.polyfit(xs, ys, deg)
        preds.append(np.polyval(c, x0))
    preds = np.array(preds)
    f_true = np.sin(2*np.pi*x0)
    print(f"deg={deg}: bias²={(preds.mean()-f_true)**2:.3f}  var={preds.var():.3f}")

bias_var(1)    # 高 bias、低 var
bias_var(11)   # 低 bias、高 var ← 复杂模型方差大
```

```python
# 学习曲线:误差随训练集大小的变化,直接区分"该加数据"还是"该加容量"
from sklearn.linear_model import Ridge
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline

def learning_curve(deg, sizes=(10, 30, 80, 200)):
    for m in sizes:
        xs = rng.uniform(0, 1, m)
        ys = np.sin(2*np.pi*xs) + rng.normal(0, 0.15, m)
        model = make_pipeline(PolynomialFeatures(deg), Ridge(alpha=1e-6))
        model.fit(xs.reshape(-1,1), ys)
        tr = np.mean((model.predict(xs.reshape(-1,1)) - ys)**2)
        va = np.mean((model.predict(xv.reshape(-1,1)) - yv_true)**2)
        print(f"deg={deg} m={m:3d}: 训练={tr:.3f} 验证={va:.3f} 间隙={va-tr:+.3f}")

learning_curve(1)    # 高偏差:两线很快贴一起且都高 → 加数据没用,该加容量
learning_curve(15)   # 高方差:间隙大且随 m 增大才缩小 → 加数据有用
```

## 面试高频

- **Q:写出偏差-方差分解并解释每一项。**
  A:$\mathbb E[(y-\hat f)^2]=\text{bias}^2+\text{var}+\text{noise}$。偏差²=模型期望预测偏离真值多少(欠拟合大);方差=换训练集预测抖动多大(过拟合大);噪声=数据本身不可约的随机性,任何模型消不掉。
- **Q:如何判断模型欠拟合还是过拟合?**
  A:先看训练误差。训练误差就大 → 欠拟合(高偏差);训练误差小但验证误差明显大 → 过拟合(高方差)。
- **Q:过拟合怎么治?欠拟合怎么治?**
  A:过拟合:加数据/数据增强、正则化(L2/Dropout)、早停、降容量。欠拟合:加容量、训更久、减正则、加特征/更好的结构。
- **Q:正则化为什么能减过拟合?用偏差方差解释。**
  A:正则化限制模型自由度,用"略升偏差"换"大降方差",把总误差 U 形曲线推向更优点。
- **Q:学习曲线怎么读?能告诉你什么?**
  A:横轴训练集大小,画训练/验证两条误差曲线。两线快速贴合且都高 = 高偏差(加数据无用,加容量);两线间隙大且持久、随数据增大才缩 = 高方差(加数据有用)。
- **Q:bagging 和 boosting 谁降偏差谁降方差?**
  A:bagging(随机森林)主要**降方差**(对多个高方差模型平均);boosting(GBDT)主要**降偏差**(串行纠正弱学习器的系统误差)。这正是偏差-方差框架的经典应用。
- **Q:深度学习里大模型不是越大越好吗,还讲偏差方差?**
  A:存在双下降——超过插值点后误差可二次下降。但实务上,给定数据/正则仍有最优容量,且诊断"加数据还是加容量"靠的就是偏差-方差直觉,框架不过时。
- **陷阱**:① 训练误差大时加正则 —— 错,那是偏差问题,会更糟。② 用测试集调超参 —— 数据泄漏,验证应在独立验证集做(见 [[46 训练、验证、测试与交叉验证|验证集]])。③ 以为"训练准=模型好" —— 训练准可能正是过拟合。④ 噪声项也想优化掉 —— 不可约。⑤ 把高方差错当高偏差(反之亦然)→ 用错药;务必先看训练误差再看间隙。

## 关键事实

- 偏差-方差分解是统计学习经典结果,系统化见 Geman、Bienenstock、Doursat(1992,"Neural Networks and the Bias/Variance Dilemma")。
- 分解 $E=\text{bias}^2+\text{var}+\text{noise}$ 严格成立于 **MSE/平方损失**;0-1 分类损失下有类似但不同的分解(Domingos 2000)。
- 双下降(double descent)现象由 Belkin 等(2019,PNAS)与 Nakkiran 等(2020)在深度学习中刻画:过参数化区误差可二次下降,挑战经典 U 形直觉。
- 标准教材:Hastie、Tibshirani、Friedman《The Elements of Statistical Learning》第 2、7 章。
