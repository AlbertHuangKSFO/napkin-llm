[[52 残差连接与深度可训练性|残差连接]](residual / skip connection)让一层不直接学目标映射 $H(x)$,而是学**增量** $F(x)=H(x)-x$,再把输入抄一条捷径加回来:$y=F(x)+x$。这一改解决了「网络越深训练误差反而越大」的**退化问题**,并给反向传播开了一条**梯度高速路**,让 ResNet 把可训练深度从几十层推到上百层。

## 直觉

[[51 池化与经典 CNN(LeNet→AlexNet→VGG→ResNet)|VGG]] 证明了「深」有用,但继续堆层却撞墙:**56 层的普通网络训练误差比 20 层还高**。这不是过拟合(训练误差就高),也不全是 [[44 梯度消失、爆炸与梯度裁剪|梯度消失]](已有归一化缓解),而是**退化**(degradation)——更深的网络**连「恒等映射」都难学好**。

直觉很反常:深网络至少应该不输浅网络——把多出来的层全设成「原样传过去」(恒等)即可。但实践中,让一堆非线性层精确拟合出恒等映射 $H(x)=x$ 出奇地难,优化器找不到。

残差连接把这件事变简单:与其让层学 $H(x)$,不如让它学**残差** $F(x)=H(x)-x$,输出 $y=F(x)+x$。这样:
- 想要恒等?只需把 $F$ 学成 **0**(让权重趋零),比拟合 $H(x)=x$ 容易得多。
- 一般情况下,层只需学「在输入基础上**改一点点**」的小增量,优化空间更平滑、更好走。

## 例子

**为什么学恒等时,残差更容易。** 设想一层最优解就是恒等 $H(x)=x$。

- **普通层**:要让带非线性的 $H(x;W)$ 在所有 $x$ 上等于 $x$,得把权重精调到一个很特殊的组合,梯度信号还得穿过非线性,难。
- **残差层**:$y=F(x;W)+x$,只要 $F(x;W)\to0$ 即可——把权重往 0 推就行,而**权重衰减/初始化本来就把权重往 0 拉**,所以「默认就接近恒等」,层可以「先不破坏信息,再慢慢学增量」。

**小数字看梯度高速路。** 一个残差块 $y=F(x)+x$,对输入求导:
$$\frac{\partial y}{\partial x}=\frac{\partial F}{\partial x}+1$$
假设某层 $\frac{\partial F}{\partial x}=-0.9$(很负、单独会让梯度衰减)。普通网若 10 层每层因子 $0.1$,连乘后 $0.1^{10}=10^{-10}$ → **梯度消失**。残差网每层因子变成 $1+(-0.9)=0.1$?不——关键在那个 **$+1$ 提供了一条不经过 $F$ 的直通路**:沿捷径方向梯度因子恒为 $1$,连乘仍是 $1$,**梯度无衰减地直达浅层**。即使 $F$ 那支很小,捷径这支也保证浅层「收得到信号」。

**展开式看「梯度抄近路」(更精确)**。把 $L$ 个残差块的梯度严格展开,$\frac{\partial x_L}{\partial x_\ell}=\prod_{i=\ell}^{L-1}\big(1+\frac{\partial F_i}{\partial x_i}\big)$。把每个 $(1+\frac{\partial F_i}{\partial x_i})$ 乘开,会得到一堆项之和,其中**有一项恒等于 1**(所有括号都取那个 1),它就是「完全走捷径、不碰任何 $F$」的通路,贡献一个不衰减的梯度;其余项才涉及 $\frac{\partial F}{\partial x}$ 的连乘。所以即使所有 $\frac{\partial F}{\partial x}$ 都很小、那些项趋零,**那条恒为 1 的项也兜底**,梯度永不整体归零。这就是「残差网梯度有一条恒等高速路」的数学本质。

## 原理

**前向。** 一个残差块:
$$y=F(x,\{W_i\})+x$$
$F$ 通常是「conv→BN→ReLU→conv→BN」两到三层。要求 $F(x)$ 与 $x$ **形状相同**才能相加;若中间下采样或改了通道数,捷径上加一个 $1\times1$ 卷积做投影 $y=F(x)+W_s x$ 对齐维度。

**为什么解决退化。** 把网络重参数化为「恒等 + 残差」,**假设空间没变**(残差网能表达的函数普通网也能),但**优化地形变好走**:最优解附近,残差网只需把若干 $F$ 推向 0,对应一个接近原点的、平坦的解,优化器容易找到;普通网要在高维非线性里精确凑出恒等,地形崎岖。这是经验上的退化消失的核心解释。

**梯度高速路(反向)。** 设第 $L$ 块输出 $x_L$,堆叠后有
$$x_L=x_\ell+\sum_{i=\ell}^{L-1}F_i(x_i)$$
对浅层 $x_\ell$ 求梯度(链式法则):
$$\frac{\partial \mathcal L}{\partial x_\ell}=\frac{\partial \mathcal L}{\partial x_L}\Big(1+\frac{\partial}{\partial x_\ell}\sum_{i=\ell}^{L-1}F_i\Big)$$
括号里的 **$1$** 表示:上层梯度 $\frac{\partial \mathcal L}{\partial x_L}$ **原封不动地直达** $x_\ell$,不经过任何权重连乘。所以即便 $\sum\frac{\partial F}{\partial x}$ 很小,梯度也**不会整体趋零**——这就根治了深网的 [[44 梯度消失、爆炸与梯度裁剪|梯度消失]]。配合 [[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|BatchNorm]],ResNet 能稳定训练上百层。

**Bottleneck 设计。** 深层 ResNet(50/101/152)用 $1\times1\to3\times3\to1\times1$ 的瓶颈块:先用 $1\times1$ 降维、再 $3\times3$ 卷积、再 $1\times1$ 升维,大幅省算力,使 152 层 FLOPs 仍低于 [[51 池化与经典 CNN(LeNet→AlexNet→VGG→ResNet)|VGG]]。举例:输入 256 通道,先 $1\times1$ 降到 64,$3\times3$ 在 64 通道上卷(算力只有直接在 256 上卷的 $1/16$),再 $1\times1$ 升回 256。「降维-卷积-升维」让昂贵的 $3\times3$ 只在窄通道上做。

**1/16 的 FLOPs 算式**。卷积每像素 FLOPs $\propto C_{\text{in}}\cdot C_{\text{out}}\cdot k^2$。直接在 256 通道上做 $3\times3$:$256\times256\times9=589{,}824$。瓶颈里的 $3\times3$ 只在 64 通道上做:$64\times64\times9=36{,}864$,比值 $\frac{64^2}{256^2}=\frac{1}{16}=0.0625$——这就是"$1/16$"的来源(通道降 $4$ 倍,而 FLOPs 随 $C_{\text{in}}\!\cdot\!C_{\text{out}}$ 走,降 $4^2=16$ 倍)。即便把两个 $1\times1$ 算上($256\times64=16{,}384$ 各一个),整块 $16{,}384+36{,}864+16{,}384=69{,}632$,仍只有那个直接 $3\times3$ 的约 $0.118$(≈ $1/8.5$)。可见省的算力主要来自把 $3\times3$ 关进窄瓶颈。

**Pre-activation 残差块(改进版)。** He 等(2016b)发现把激活/BN 的顺序改成 **BN→ReLU→conv**(而非 conv→BN→ReLU),让捷径成为**纯恒等**($y=x+F(x)$ 中 $x$ 一路不被任何非线性/BN 碰),梯度传播更顺,1000 层也能训。这就是 "Identity Mappings" 论文的核心:**捷径越「干净」(纯恒等、不加门控/不加缩放),梯度越无阻**。

**集成视角(为什么残差网像浅网集成)。** Veit 等(2016)指出:一个 $L$ 块残差网展开后等价于 $2^L$ 条不同长度路径的集合(每块可走 $F$ 或走捷径);实际有效的多是**较短路径**。所以残差网更像「指数多个浅网络的隐式集成」,这既解释了它的鲁棒(删掉某块影响小)、也呼应了「它没真的让单条路径变那么深」。

**与门控版的对比:Highway Network。** Srivastava 等(2015)的 Highway Net 比 ResNet 早一点,用**可学习的门** $T(x)$ 做 $y=T\odot F(x)+(1-T)\odot x$(类似 LSTM 门)。ResNet 把门简化成「恒为 1 的纯加法捷径」,反而更稳更好训——印证了「捷径越简单越好」。

**深远影响:残差成了深网标配。** 这条「加一条恒等捷径」的思想之后无处不在——Transformer 的每个子层(多头注意力、前馈)都用 [[LLM/009 残差连接与梯度流|残差连接]] **+ 层归一化**($x+\text{Sublayer}(x)$),正是靠它才能把几十上百层堆起来还训得动。可以说残差连接是「让网络变深」这条路线的通用地基。

## 代码

```python
import torch, torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.conv1 = nn.Conv2d(c, c, 3, padding=1, bias=False)
        self.bn1   = nn.BatchNorm2d(c)
        self.conv2 = nn.Conv2d(c, c, 3, padding=1, bias=False)
        self.bn2   = nn.BatchNorm2d(c)
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return torch.relu(out + x)          # ✅ y = F(x) + x,跳连接相加

# ❌ 普通堆叠:没有 +x,深了易退化/梯度消失
class PlainBlock(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.conv1, self.conv2 = nn.Conv2d(c,c,3,padding=1), nn.Conv2d(c,c,3,padding=1)
    def forward(self, x):
        return torch.relu(self.conv2(torch.relu(self.conv1(x))))   # 直接学 H(x),无捷径

x = torch.randn(1, 16, 8, 8)
print(ResidualBlock(16)(x).shape)   # [1,16,8,8] 形状不变,可继续堆

# 直观验证「梯度高速路」:残差块对输入的梯度含 +1 项,不易消失
x = torch.randn(1, 16, 8, 8, requires_grad=True)
ResidualBlock(16)(x).sum().backward()
print("残差块输入梯度范数:", x.grad.norm().item())   # 量级稳定,不趋于 0 ✅

# ❌ 维度不匹配时直接相加会报错;✅ 用 1x1 卷积投影对齐
# shortcut = nn.Conv2d(c_in, c_out, 1, stride=2)   # y = F(x) + shortcut(x)

# 带下采样/改通道的残差块(真实 ResNet 的 stride2 块)
class DownBlock(nn.Module):
    def __init__(self, c_in, c_out, stride=2):
        super().__init__()
        self.conv1 = nn.Conv2d(c_in, c_out, 3, stride=stride, padding=1, bias=False)
        self.bn1   = nn.BatchNorm2d(c_out)
        self.conv2 = nn.Conv2d(c_out, c_out, 3, padding=1, bias=False)
        self.bn2   = nn.BatchNorm2d(c_out)
        self.short = nn.Conv2d(c_in, c_out, 1, stride=stride, bias=False)  # ✅ 1x1 投影对齐
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return torch.relu(out + self.short(x))   # 形状对齐后才能相加

# Bottleneck:1x1降维 → 3x3 → 1x1升维,省算力(ResNet-50+ 用)
class Bottleneck(nn.Module):
    def __init__(self, c, mid):     # 如 c=256, mid=64
        super().__init__()
        self.c1 = nn.Conv2d(c, mid, 1, bias=False)        # 降维
        self.c2 = nn.Conv2d(mid, mid, 3, padding=1, bias=False)  # 窄通道卷积
        self.c3 = nn.Conv2d(mid, c, 1, bias=False)        # 升维
    def forward(self, x):
        out = torch.relu(self.c1(x)); out = torch.relu(self.c2(out)); out = self.c3(out)
        return torch.relu(out + x)
```

## 面试高频

- **「残差连接解决什么问题?」** **退化问题**:普通网络堆到很深,训练误差反而上升(连恒等都难学)。残差让层学增量 $F(x)=H(x)-x$,要恒等只需 $F\to0$,优化好走;同时提供梯度直通路,缓解 [[44 梯度消失、爆炸与梯度裁剪|梯度消失]]。
- **「公式 $y=F(x)+x$ 为什么有效?」** ①优化角度:重参数化后假设空间不变但地形更平滑,恒等附近易达;②梯度角度:$\partial y/\partial x=\partial F/\partial x+1$,那个 **+1** 让梯度沿捷径无衰减直达浅层。
- **「退化是梯度消失吗?」** 不完全是。即使加了归一化缓解了梯度消失,普通深网仍退化;退化主要是**优化难度**问题(难拟合恒等),残差从优化地形上解决它。
- **「捷径维度不匹配怎么办?」** 用 $1\times1$ 卷积(带 stride)做投影 $W_s x$ 对齐通道/空间,再相加。
- **「Bottleneck 块是什么?」** $1\times1$ 降维 → $3\times3$ → $1\times1$ 升维,省算力,让 ResNet-50/101/152 仍比 VGG 轻。
- **「残差思想在别处见过吗?」** Transformer 每个子层都用残差连接 + 层归一化($x+\text{Sublayer}(x)$),是堆深 Transformer 的关键;残差已是现代深网标配。
- **「Pre-activation 残差块是什么?为什么更好?」** 把顺序改成 BN→ReLU→conv,让捷径成为纯恒等($x$ 一路不被 BN/非线性碰),梯度传播无阻,He 2016b 用它训到 1000 层。结论:捷径越「干净」越好。
- **「残差网为什么像浅网集成?」** $L$ 块展开成 $2^L$ 条长短不一的路径,实际有效的多是短路径(Veit 2016);所以它更像指数多个浅网的隐式集成,删一块影响也小。
- **「Highway Network 和 ResNet 区别?」** Highway 用可学习门 $T$ 做 $y=T\odot F+(1-T)\odot x$(类 LSTM);ResNet 把门简化为恒等纯加法,更稳更好训——印证捷径越简单越好。
- **「残差和 LSTM/GRU 的门控是一回事吗?」** 同一类「加性旁路绕开连乘」思想:残差是恒等加法,LSTM cell 是 $c_t=f\odot c_{t-1}+\dots$ 的加性更新,都让梯度有不衰减通路(见 [[55 长依赖与梯度消失、爆炸|长依赖]])。

## 关键事实

- **残差连接 / ResNet**:He, Zhang, Ren & Sun, *Deep Residual Learning for Image Recognition*(CVPR 2016,arXiv:1512.03385, 2015)。提出 $y=F(x)+x$,观察到 plain 网络的退化现象(56 层训练误差高于 20 层),残差网训练到 152 层并夺 ILSVRC-2015 冠军(集成 top-5 错误 3.57%)。
- **恒等映射作为预条件**:He et al., *Identity Mappings in Deep Residual Networks*(ECCV 2016,arXiv:1603.05027),进一步论证「纯恒等捷径」对梯度无障碍传播最优(pre-activation 残差块)。
- **残差进入 Transformer**:Vaswani et al., *Attention Is All You Need*(NeurIPS 2017),每个子层用 $\text{LayerNorm}(x+\text{Sublayer}(x))$ 的残差结构。
- **残差网=路径集成**:Veit, Wilber & Belongie, *Residual Networks Behave Like Ensembles of Relatively Shallow Networks*(NeurIPS 2016)。
- **Highway Network**(门控版,早于 ResNet):Srivastava, Greff & Schmidhuber(NeurIPS 2015)。
- **无归一化的深残差训练**:Fixup(Zhang et al., ICLR 2019)、DeepNorm(Wang et al., 2022,Transformer 至 1000 层)。
- 退化非过拟合、残差改善优化地形,见 He et al.(2015)实验图与《Deep Learning》(2016)关于深度可训练性的讨论。
