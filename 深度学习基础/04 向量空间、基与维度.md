[[04 向量空间、基与维度|向量空间]]:对加法和缩放**封闭**的向量集合就是向量空间;**基**是一组"既线性无关又能张成整个空间"的向量(一套坐标尺),**维度**就是基里向量的个数——它定义了"这个空间有几个独立方向",也就是 Embedding 维度、隐藏层宽度的本质含义。

## 直觉

接着 [[02 向量运算：加法、缩放与线性组合|线性组合]]:如果你手里有几个方向的向量,把它们"任意配比相加"能到达的所有点,组成的集合就是一个**向量空间**(更准确说是这些向量张成的子空间)。

- **向量空间**:一个"封闭的活动场"。你在里面做加法、缩放,永远跑不出去——结果还在场内。$\mathbb{R}^n$ 就是最常见的向量空间。
- **基(basis)**:这个场的"坐标尺"。最熟悉的是 $\mathbf{e}_1=[1,0]$、$\mathbf{e}_2=[0,1]$——所有点都能写成"沿 e₁ 走几步、沿 e₂ 走几步"。基有两个硬条件:**互相独立**(谁也替代不了谁)+ **能拼出全空间**。
- **维度(dimension)**:基里有几根尺子。平面是 2 维,空间是 3 维,GPT 的隐藏空间可能是几千维。

为什么重要?当你听到"768 维 Embedding""隐藏层 4096 维",这个"维"就是这里的维度——模型在一个几千维的向量空间里安放每个词/每张图,维度越高,可表达的独立特征越多(但也更难训、更耗算力)。

## 例子

在 $\mathbb{R}^2$ 里,用标准基 $\mathbf{e}_1=[1,0]$、$\mathbf{e}_2=[0,1]$ 表示点 $\mathbf{p}=[3,2]$:

$$\mathbf{p} = 3\,\mathbf{e}_1 + 2\,\mathbf{e}_2 = 3[1,0] + 2[0,1] = [3,2]$$

坐标 $[3,2]$ 就是这个线性组合的**系数**。换一套基,同一个点坐标会变,但点本身不动。

**线性无关 vs 相关**——这是判断"能否当基"的关键:

- $\mathbf{v}=[2,1]$、$\mathbf{w}=[1,2]$:谁也不是对方的倍数 ⇒ **线性无关**,张成整个平面,可作 $\mathbb{R}^2$ 的基,维度 2。
- $\mathbf{v}=[2,1]$、$\mathbf{w}=[4,2]$:$\mathbf{w}=2\mathbf{v}$ ⇒ **线性相关**,两个向量挤在同一条直线上,无论怎么配比都跳不出这条线,只张成 1 维。

![[la-线性相关与张成.svg]]

判定线性无关:看方程 $c_1\mathbf{v}+c_2\mathbf{w}=\mathbf{0}$ 是否**只有** $c_1=c_2=0$ 这一个解。$[2,1],[4,2]$ 有非零解($c_1=2,c_2=-1$ 给 $\mathbf{0}$),所以相关。

**手把手判一组三维向量是否线性无关**。给 $\mathbf{v}_1=[1,0,0]$、$\mathbf{v}_2=[1,1,0]$、$\mathbf{v}_3=[1,1,1]$,解 $c_1\mathbf{v}_1+c_2\mathbf{v}_2+c_3\mathbf{v}_3=\mathbf{0}$,逐分量列方程:

$$\begin{cases}c_1+c_2+c_3=0 &(\text{第 1 维})\\ c_2+c_3=0 &(\text{第 2 维})\\ c_3=0 &(\text{第 3 维})\end{cases}$$

从下往上回代:第 3 式 $c_3=0$;代入第 2 式 $c_2=0$;代入第 1 式 $c_1=0$。**只有全零解 ⇒ 线性无关**,这三个向量是 $\mathbb{R}^3$ 的一组基,维度 3。

**再看一组相关的**:$\mathbf{u}_1=[1,2]$、$\mathbf{u}_2=[2,4]$、$\mathbf{u}_3=[0,1]$。三个二维向量,但 $\mathbb{R}^2$ 最多只能有 2 个线性无关向量(**鸽笼原理:$\mathbb{R}^n$ 里超过 $n$ 个向量必线性相关**),所以一定相关——果然 $\mathbf{u}_2=2\mathbf{u}_1$。

**一个快捷判据(只对两个向量)**:二维里两向量相关 ⟺ 成比例 ⟺ $\det\begin{bmatrix}v_1&w_1\\v_2&w_2\end{bmatrix}=v_1w_2-v_2w_1=0$。例 $[2,1],[4,2]$:$2\cdot2-1\cdot4=0$ ⇒ 相关;$[2,1],[1,2]$:$2\cdot2-1\cdot1=3\ne0$ ⇒ 无关(见 [[08 行列式与空间缩放|行列式]])。

## 原理

**向量空间**是一个集合 $V$ 配上加法和标量乘法,满足 8 条公理(见 [[02 向量运算：加法、缩放与线性组合]] 列的交换/结合/分配律 + 零元 + 逆元 + 标量乘单位元),核心是对两种运算**封闭**:

$$\mathbf{u},\mathbf{v}\in V,\; c\in\mathbb{R}\;\Rightarrow\; \mathbf{u}+\mathbf{v}\in V \text{ 且 } c\mathbf{u}\in V$$

**线性无关**:向量组 $\{\mathbf{v}_1,\dots,\mathbf{v}_k\}$ 线性无关,当且仅当

$$c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k = \mathbf{0} \;\Longrightarrow\; c_1=\cdots=c_k=0$$

(只有"全取零"这个平凡解)。否则线性相关——意味着至少一个向量是其余向量的线性组合,是"冗余"的。

**张成(span)**:$\{\mathbf{v}_1,\dots,\mathbf{v}_k\}$ 的张成是它们所有线性组合构成的集合:

$$\mathrm{span}\{\mathbf{v}_1,\dots,\mathbf{v}_k\} = \Big\{\,\textstyle\sum_j c_j\mathbf{v}_j \;\big|\; c_j\in\mathbb{R}\,\Big\}$$

**基**:既线性无关又张成 $V$ 的向量组。基是"不多不少"的——多一个就线性相关(冗余),少一个就张不满(缺方向)。

**维度**:任何基的向量个数(可证所有基大小相同,这是良定义的关键定理)。记作 $\dim V$。$\dim \mathbb{R}^n = n$。

**子空间(subspace)**:向量空间里"自带封闭性"的子集——它必须**过原点**(含 $\mathbf{0}$),且对加法、缩放封闭。例:过原点的直线、过原点的平面是子空间;不过原点的直线**不是**(因为 $0\cdot\mathbf{v}=\mathbf{0}$ 必须在内,而它没有原点)。$\mathrm{span}\{\mathbf{v}_1,\dots,\mathbf{v}_k\}$ 永远是子空间。

**标准正交基(orthonormal basis)**:基向量两两正交且都为单位长度(如 $\mathbf{e}_1,\mathbf{e}_2$)。它的好处:求某向量在这套基下的坐标**只需做点积投影**($c_i=\mathbf{v}\cdot\mathbf{e}_i$),不必解线性方程组或求逆——这是 [[11 主成分分析 PCA|PCA]]、傅里叶变换、注意力等"换到好基再处理"思路的根。

**换基(change of basis)**:同一个几何向量在不同基下坐标不同。设新基向量按列排成矩阵 $B$,则"新坐标 $\to$ 旧坐标"是 $\mathbf{x}_{\text{旧}}=B\,\mathbf{x}_{\text{新}}$,反过来"旧 $\to$ 新"是 $\mathbf{x}_{\text{新}}=B^{-1}\mathbf{x}_{\text{旧}}$(标准正交基时 $B^{-1}=B^\top$,省去求逆)。这正是 [[06 矩阵乘法的几何意义|坐标变换]] 与 [[09 特征值与特征向量|对角化]] $A=P\Lambda P^{-1}$ 中 $P,P^{-1}$ 的来历。

> 深度学习联系:一层的**隐藏维度** = 该层激活向量所在空间的维度;**Embedding 维度**就是词向量空间的维度。[[10 SVD 奇异值分解]] / [[11 主成分分析 PCA]] 做的"降维",本质是找一组新基,只保留方差最大的几个方向,把高维数据压到低维子空间——前提是真实数据往往躺在一个**低维流形**附近(秩近似亏损,见 [[07 矩阵的秩、逆与转置]])。

## 代码

```python
import numpy as np

# 标准基
e1, e2 = np.array([1, 0]), np.array([0, 1])
p = 3 * e1 + 2 * e2
print(p)                 # [3 2]  —— 坐标就是组合系数

# 判定线性无关：用秩。秩 == 向量个数 ⇒ 无关
A = np.array([[2, 1],
              [1, 2]])              # 两行是两个向量
print(np.linalg.matrix_rank(A))    # 2 ⇒ 无关，构成 R^2 的基

B = np.array([[2, 1],
              [4, 2]])
print(np.linalg.matrix_rank(B))    # 1 ⇒ 相关，只张成 1 维

# 换基：把 p 用新基 {[2,1],[1,2]} 表示，解 Bx=p 求新坐标
Basis = np.array([[2, 1],
                  [1, 2]]).T        # 列是基向量
coords = np.linalg.solve(Basis, p) # 新坐标
print(coords)                      # [1.333... 0.333...]
print(Basis @ coords)              # [3. 2.]  验证：拼回原点
```

```python
# 估计数据的“有效维度”：奇异值看有几个方向真有信息
# ❌ 朴素：以为 1000 维数据就是 1000 维空间
X = np.random.randn(500, 3) @ np.random.randn(3, 1000)  # 实则秩≤3
print(X.shape)                          # (500, 1000)

# ✅ 正确：用秩 / 奇异值看真实维度
print(np.linalg.matrix_rank(X))         # 3  —— 数据躺在 3 维子空间里
```

```python
# 手算式判定线性无关：解 c1 v1 + c2 v2 + c3 v3 = 0 是否只有零解
V = np.array([[1, 1, 1],    # 列 = v1, v2, v3
              [0, 1, 1],
              [0, 0, 1]])
print(np.linalg.matrix_rank(V))   # 3 == 列数 → 线性无关,构成 R^3 的基

# 相关的例子:R^2 里塞 3 个向量必相关
U = np.array([[1, 2, 0],
              [2, 4, 1]])         # 列 = u1,u2,u3,u2=2u1
print(np.linalg.matrix_rank(U))   # 2 < 3 → 线性相关

# 标准正交基:坐标 = 点积投影,无需解方程
q1 = np.array([1., 0.]); q2 = np.array([0., 1.])   # 标准正交
x = np.array([3., 4.])
print(x @ q1, x @ q2)             # 3.0 4.0  ——直接点积就是坐标

# 2 向量相关的行列式判据
def collinear(v, w):
    return abs(v[0]*w[1] - v[1]*w[0]) < 1e-12
print(collinear(np.array([2,1]), np.array([4,2])))  # True  相关
print(collinear(np.array([2,1]), np.array([1,2])))  # False 无关
```

## 面试高频

- **"基和坐标系是一回事吗?"** 标准答法:基定义了坐标系。同一个向量在不同基下坐标不同,但向量本身(几何对象)不变;换基就是 [[06 矩阵乘法的几何意义|坐标变换]]。
- **"维度、秩、Embedding 维度有什么关系?"** 维度是空间属性;[[07 矩阵的秩、逆与转置|秩]]是某个矩阵的列(行)空间维度;Embedding 维度是你给模型设的向量长度(名义维度),但数据的**有效维度**(本征维度)常远小于它——这正是 PCA 能降维的前提。
- **陷阱:维度高 ≠ 信息多。** 线性相关的向量再多也撑不起更高维度;"维数灾难"下高维空间里点彼此都很远、很稀疏,反而难学。
- **陷阱:子空间必须过原点。** 不过原点的平面/直线是仿射集,不是子空间(对缩放不封闭,因 $0\cdot\mathbf{v}=\mathbf{0}$ 必须在内)。
- **"$\mathbb{R}^n$ 里能有几个线性无关向量?"** 最多 $n$ 个;超过 $n$ 个必相关(鸽笼原理)。这是"为什么基恰好 $n$ 个"的直接推论。
- **"怎么快速判两个向量是否相关?"** 看是否成比例,或二维看 $v_1w_2-v_2w_1$(行列式)是否为 0。多个向量则看矩阵的秩是否等于向量个数。
- **"标准正交基好在哪?"** 求坐标只需点积投影(不必求逆),变换矩阵正交($B^{-1}=B^\top$),数值稳定;PCA/傅里叶/注意力都在"找一组好基"。
- **陷阱:同一向量换基后坐标变、向量本身不变。** 面试别把"坐标"和"向量"混为一谈。

## 关键事实

- 向量空间 = 对加法和标量乘法封闭、满足 8 条公理的集合;$\mathbb{R}^n$ 是典型。
- 线性无关 ⟺ 零向量只有平凡组合;相关 ⟺ 有向量是别人的组合(冗余)。
- 基 = 线性无关 + 张成全空间;基的大小处处相等,即维度。
- $\dim\mathbb{R}^n=n$;子空间必含原点;$\mathbb{R}^n$ 里最多 $n$ 个线性无关向量。
- 标准正交基下坐标 = 点积投影 $c_i=\mathbf{v}\cdot\mathbf{e}_i$;换基 $\mathbf{x}_{\text{旧}}=B\mathbf{x}_{\text{新}}$,正交基时 $B^{-1}=B^\top$。
- ML 中"768/4096 维"指向量空间维度;真实数据常躺在低维子空间/流形上,故可用 [[11 主成分分析 PCA]] 降维。
- 基大小处处相等(维数良定义)、四个基本子空间与秩-零化度定理见 Strang《Introduction to Linear Algebra》(第 6 版, 2023)第 3–4 章。
