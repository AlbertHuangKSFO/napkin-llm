[[44 梯度消失、爆炸与梯度裁剪|梯度消失与爆炸]] 是指反向传播时,深层梯度沿网络连乘后指数级地趋近 0(消失,浅层学不动)或冲向无穷(爆炸,训练崩溃);梯度裁剪则是给梯度模长设上限来压住爆炸。

## 直觉

把反向传播想成"消息从最后一层往前传话",每经过一层都要乘一个系数 $r$。

- 如果每层 $r<1$(比如 0.5),传 10 层就是 $0.5^{10}\approx0.001$ —— **消息越传越轻,传到最前面几乎没了**,浅层参数收不到有效梯度,学不动。这就是梯度消失。
- 如果每层 $r>1$(比如 1.5),传 10 层就是 $1.5^{10}\approx57$ —— **消息越传越响,传到前面震耳欲聋**,梯度炸成天文数字,loss 变 NaN,训练直接崩。这就是梯度爆炸。

复利效应:微小的偏差,在深度上被指数放大。

![[nn-梯度消失爆炸链.svg]]

梯度裁剪治的是"爆炸":就像给汽车装限速器 —— **不改变你想去的方向,只在车速超标时把速度压回上限**。

## 例子

**梯度消失手算**。一个 5 层网络,每层用 Sigmoid 激活。Sigmoid 导数最大只有 0.25(在 0 点),且权重初始化使每层雅可比的"等效系数"约 0.2。反向传到第 1 层时,梯度被乘了 5 次:

$$g_1 \propto 0.2^5 = 0.00032$$

而第 5 层(最后)的梯度系数是 $0.2^1=0.2$。两者相差 $0.2/0.00032\approx 625$ 倍 —— **最后一层学得飞快,第一层几乎不动**。

**梯度爆炸 + 裁剪手算**。设某步算出梯度向量 $g=[6,\,8]$,模长 $\|g\|=\sqrt{6^2+8^2}=10$。设裁剪阈值 $c=5$。因为 $\|g\|=10>5$,按范数裁剪:

$$g\leftarrow g\cdot\frac{c}{\|g\|}=[6,8]\cdot\frac{5}{10}=[3,\,4]$$

新模长 $\sqrt{3^2+4^2}=5=c$,**方向完全不变**(还是 3:4),只是长度被压到上限。若某步 $\|g\|=3<5$,则不动。

**by-norm 与 by-value 的差别看得更清(同一个 $g$)**。还是 $g=[6,8]$。
- **clip by norm**($c=5$):整体缩 $0.5$ 倍 → $[3,4]$,方向仍 3:4。
- **clip by value**($v=5$,逐元素夹到 $[-5,5]$):$6\to5$,$8\to5$ → $[5,5]$,方向从 3:4 **变成了 1:1**!方向被改了。这就是为什么 RNN/Transformer 几乎都用 by-norm:保住下降方向只压步长。

**全局范数裁剪手算(多参数)**。两组参数梯度 $g_1=[3,4]$、$g_2=[12,0]$。全局范数 = 把所有分量拼起来算:$\sqrt{3^2+4^2+12^2+0^2}=\sqrt{9+16+144}=\sqrt{169}=13$。阈值 $c=6.5$,缩放因子 $\frac{6.5}{13}=0.5$,于是 $g_1\to[1.5,2]$、$g_2\to[6,0]$——**所有参数同乘一个因子**,保住它们之间的相对比例(整体方向)。这正是 `clip_grad_norm_` 的做法,与"逐张量各裁各的"不同。

## 原理

**为什么连乘**。深度网络的损失对浅层参数的梯度,由链式法则展开成一串雅可比矩阵的乘积(见 [[16 链式法则|链式法则]]、[[20 反向传播的数学推导|反向传播]])。对一个 $L$ 层网络,损失 $\mathcal L$ 对第 1 层激活 $h_1$ 的梯度大致是:

$$\frac{\partial \mathcal L}{\partial h_1}=\frac{\partial \mathcal L}{\partial h_L}\prod_{l=2}^{L}\frac{\partial h_l}{\partial h_{l-1}}=\frac{\partial \mathcal L}{\partial h_L}\prod_{l=2}^{L} W_l^\top \,\text{diag}\big(\phi'(z_{l-1})\big)$$

这是 $L-1$ 个矩阵连乘。用最简单的标量直觉:如果每个因子的"放大率"约为 $r$,则总放大约 $r^{L}$。

- $r<1\Rightarrow r^L\to 0$:梯度消失;
- $r>1\Rightarrow r^L\to \infty$:梯度爆炸。

只有 $r\approx1$ 时梯度才稳定传播 —— 这正是各种缓解手段追求的目标。

**两个推手**:

1. **激活函数的导数**。Sigmoid/Tanh 在饱和区导数趋 0(见 [[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]]),贡献 $r<1$,主导消失。具体数字:Sigmoid 导数 $\sigma'(x)=\sigma(1-\sigma)$ 最大值在 $x=0$ 处仅 $0.25$,意味着每过一层 Sigmoid 梯度**至少打到原来的 1/4**,10 层就 $0.25^{10}\approx10^{-6}$——这就是为何深 Sigmoid 网几乎不可训。Tanh 导数 $1-\tanh^2$ 最大为 1(比 Sigmoid 好),但饱和区仍趋 0。ReLU 在正区导数恒为 1,大幅缓解消失,但负区导数为 0 会"死神经元"。
2. **权重的尺度**。权重初始化过大 → $\|W\|>1$ → 爆炸;过小 → 消失。这就是为什么要用 [[41 权重初始化(Xavier、He、正交)|Xavier / He 初始化]] 把每层方差控制在 1 附近。

**为什么"乘法"会出事,而"加法"不会**(贯穿全篇的核心)。普通深网梯度是一长串雅可比**连乘**,任何系统性偏离 1 都被指数放大;而残差连接 $y=x+F(x)$ 给梯度一条**加性**通路($\partial y/\partial x=1+\partial F/\partial x$),那个 $+1$ 不参与连乘,梯度可"抄近路"直达浅层。同样的"用加法绕开连乘"思想,也是 LSTM cell 状态、GRU 更新门、注意力的共同破局点——可以说整部深度学习史就是"想方设法把致命的连乘换成温和的加法"。

**缓解消失的手段**(裁剪治不了消失):ReLU/GELU 激活、合理初始化、[[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|归一化]]、以及最关键的**残差连接**(见 52,提供 $r\approx1$ 的恒等通路,梯度可"抄近路"绕过连乘)。一句话对照:**消失靠"激活 + 初始化 + 归一化 + 残差"治本,爆炸靠"裁剪"治标。**

**梯度裁剪治爆炸**。在优化器更新参数**之前**,对梯度做一次缩放:

- **按范数裁剪(clip by norm,主流)**:计算所有参数梯度拼成的全局范数 $\|g\|$,若超阈值 $c$ 就整体缩放,**保持方向不变**:
$$g\leftarrow \begin{cases} g, & \|g\|\le c\\[4pt] \dfrac{c}{\|g\|}\,g, & \|g\|>c \end{cases}$$
- **按值裁剪(clip by value)**:把每个梯度分量逐元素夹到 $[-v,\,v]$。简单但**会改变梯度方向**(不同分量缩放比例不同),实践中较少用。

几何上,按范数裁剪相当于把梯度向量投影回半径 $c$ 的球面内;遇到损失曲面上的"陡崖"(RNN 里常见,见下),它把会把网络"甩飞"的一大步压成安全的一小步。

![[nn-梯度裁剪几何.svg]]

**与 RNN 长依赖的呼应**。循环网络把同一权重矩阵 $W$ 在每个时间步重复相乘,$T$ 步就是 $W^T$ —— 这是连乘的极端情形,极易消失或爆炸,使 RNN 难学长距离依赖。梯度裁剪是 RNN 训练的标配来压爆炸;而消失问题则要靠 LSTM/GRU 的门控来缓解。这一主题在「55 长依赖与梯度消失、爆炸」会展开(此处仅作呼应)。

**手段一览表(背这张)**:

| 手段 | 治消失 | 治爆炸 | 原理一句话 |
|---|---|---|---|
| ReLU/GELU 激活 | ✓ | — | 正区导数为 1,不像 sigmoid 把梯度打到 1/4 |
| Xavier/He 初始化 | ✓ | ✓ | 把每层方差控制在 1 附近,$r\approx1$ |
| BatchNorm/LayerNorm | ✓ | ✓ | 每层重新标准化,稳住激活/梯度尺度 |
| 残差连接 | ✓✓ | — | $+1$ 恒等高速路,梯度不经连乘直达浅层 |
| LSTM/GRU 门控 | ✓✓ | — | 加性 cell/更新门,梯度近恒等流过时间 |
| 正交初始化 | ✓ | ✓ | 奇异值 $\approx1$,保范数(RNN 尤其) |
| 梯度裁剪 | ✗ | ✓✓ | 限模长不改方向,专压爆炸 |

记忆口诀:**消失靠"结构"(激活/初始化/归一化/残差/门控),爆炸靠"裁剪"。** 裁剪是唯一只治爆炸、对消失完全无效的手段。

## 代码

```python
import numpy as np

# 模拟深层连乘:同一系数 r,经 L 层
for r in [0.5, 1.0, 1.5]:
    grads = [r**l for l in range(1, 11)]
    print(f"r={r}: 第1层梯度系数={grads[-1]:.4g}")
# r=0.5 -> 0.0009766 (消失)
# r=1.0 -> 1        (稳定)
# r=1.5 -> 57.67    (爆炸)

# 按范数裁剪:只缩模长,不改方向
def clip_by_norm(g, c):
    norm = np.linalg.norm(g)
    return g * (c / norm) if norm > c else g

g = np.array([6.0, 8.0])
print(clip_by_norm(g, 5.0))   # [3. 4.],方向仍是 3:4

# 对比按值裁剪:会改方向
def clip_by_value(g, v):
    return np.clip(g, -v, v)
print(clip_by_value(g, 5.0))  # [5. 5.],方向从 3:4 变成 1:1 ❌

# 全局范数裁剪:多个参数张量拼起来算一个范数,同乘一个因子
def clip_global_norm(grads, c):
    total = np.sqrt(sum((g**2).sum() for g in grads))   # 全局范数
    scale = min(1.0, c / (total + 1e-6))
    return [g * scale for g in grads], total
gs, tot = clip_global_norm([np.array([3.,4.]), np.array([12.,0.])], 6.5)
print("全局范数=", tot, " 裁剪后=", gs)   # 13 → 同乘0.5 → [1.5,2],[6,0]
```

```python
import torch, torch.nn as nn

model = nn.LSTM(64, 64)            # RNN 类极易梯度爆炸
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

# ❌ 错:RNN/Transformer 不做裁剪,某步陡崖直接 loss=NaN
# loss.backward(); opt.step()

# ✅ 对:backward 之后、step 之前裁剪全局范数

opt.zero_grad()
loss.backward()

opt.step()

# 配合 AMP(混合精度)时:必须先 unscale 再裁剪,否则裁的是被放大过的梯度
# scaler.unscale_(opt)
# torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
# scaler.step(opt); scaler.update()

# 监控梯度范数(诊断爆炸/消失的实用手段):返回值就是裁剪前的总范数
gn = torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
# print(gn) 持续飙升 → 爆炸隐患;长期≈0 → 消失/学不动
```

## 面试高频

- **Q:梯度消失和爆炸的根本原因?**
  A:反向传播是雅可比/权重的连乘,等效放大率 $r$ 被深度 $L$ 指数化成 $r^L$。$r<1$ 消失、$r>1$ 爆炸。推手是饱和激活的小导数和权重尺度。
- **Q:怎么缓解梯度消失?**
  A:ReLU/GELU 激活、Xavier/He 初始化、BatchNorm/LayerNorm、**残差连接**(最关键,给梯度恒等近路)。注意:梯度裁剪治不了消失。
- **Q:梯度裁剪 clip-by-norm 和 clip-by-value 区别?**
  A:by-norm 缩放整个梯度向量、保方向(主流);by-value 逐分量夹紧、会改方向。RNN/Transformer 训练几乎都用 by-norm,典型 max_norm=1.0。
- **Q:裁剪能解决梯度消失吗?**
  A:不能。裁剪只设上限压爆炸,对趋 0 的梯度无能为力。消失要靠激活、初始化、归一化、残差。
- **Q:Sigmoid 为什么比 Tanh 更容易梯度消失?**
  A:Sigmoid 导数最大仅 0.25(在 0 点),每层至少打 1/4 折;Tanh 导数最大为 1(零中心、梯度更强),虽仍会饱和但比 Sigmoid 缓和。所以隐层宁用 Tanh 也别用 Sigmoid,更别用深 Sigmoid。
- **Q:为什么残差/LSTM 用"加法"就不消失?**
  A:连乘里任何 $r\ne1$ 都被指数放大;加法通路 $\partial(x+F)/\partial x=1+\partial F/\partial x$ 里的 $+1$ 不进连乘,梯度有一条恒为 1 的直达路,绕开了指数衰减。
- **Q:用 AMP 混合精度时裁剪要注意什么?**
  A:AMP 会先把损失放大(scale)再 backward,梯度也被放大;必须先 `scaler.unscale_(opt)` 还原再裁剪,否则裁的是放大后的假范数。
- **Q:怎么在训练中诊断梯度消失/爆炸?**
  A:打印每步全局梯度范数(`clip_grad_norm_` 的返回值就是裁前范数):持续飙升=爆炸,长期≈0=消失;也可分层看各层梯度量级是否逐层指数衰减。
- **陷阱**:① 把裁剪放在 `optimizer.step()` 之后(无效,得在 backward 后、step 前)。② 阈值 $c$ 设太小,把正常梯度也削了,变相降学习率。③ 以为 ReLU 完全免疫消失 —— 它缓解消失但带来"死神经元"。④ 多 GPU 分布式时要对**汇总后的全局梯度**裁剪。⑤ AMP 下忘了先 unscale 再裁剪。⑥ 把 by-value 当 by-norm 用导致方向被改。

## 关键事实

- 梯度消失/爆炸最早在 RNN 语境被系统分析:Bengio、Simard、Frasconi(1994)证明长依赖下梯度按时间步指数衰减/增长。
- 梯度裁剪(clip-by-norm)由 Pascanu、Mikolov、Bengio 提出(2013,"On the difficulty of training recurrent neural networks",ICML),专治 RNN 梯度爆炸,描述了损失曲面的"陡崖"现象。
- ReLU 缓解消失:Glorot、Bordes、Bengio(2011)。残差连接缓解深网梯度:He 等 ResNet(2016),见 [[52 残差连接与深度可训练性|残差连接]](未来笔记)。
- 实践默认:Transformer 预训练常用 `clip_grad_norm_(max_norm=1.0)`(GPT、LLaMA 等)。
- 关联:本主题串起 [[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]]、[[41 权重初始化(Xavier、He、正交)|初始化]]、[[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|归一化]] 三大稳训练手段,并直通后续 RNN/LSTM/GRU。
