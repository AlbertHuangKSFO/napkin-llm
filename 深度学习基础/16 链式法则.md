[[16 链式法则|链式法则]]是给"函数套函数"求导的法则:嵌套复合函数的导数 = **各层局部导数连乘**。它是 [[18 计算图(前向)|计算图]] 与 [[20 反向传播的数学推导|反向传播]] 的发动机——神经网络就是一长串函数复合,backprop 本质上就是把链式法则在计算图上自动跑一遍。

## 直觉

链式法则处理的是**层层传导**。想象三个齿轮咬在一起:你转第一个齿轮 1 圈,它带第二个转 2 圈,第二个带第三个转 3 圈,那你转第一个 1 圈,第三个转几圈?$1\times2\times3=6$ 圈。**总传动比 = 各级传动比相乘**——这就是链式法则。

换个生活类比:汇率换算。人民币→美元汇率 $a$,美元→欧元汇率 $b$。那人民币→欧元的"边际兑换率"就是 $a\times b$。每加一层中转,就多乘一个本地兑换率。

放到求导上:$y$ 依赖 $u$,$u$ 又依赖 $x$。"$x$ 动一点 $y$ 动多少" = "$x$ 动一点 $u$ 动多少"($\frac{du}{dx}$)× "$u$ 动一点 $y$ 动多少"($\frac{dy}{du}$)。中间量 $u$ 的扰动被一层层放大/缩小地传到最后,所以是**连乘**。

这也解释了深度网络的两个老毛病:几十层的导数连乘,如果每层导数都 <1,乘到最后趋近 0(梯度消失);都 >1 则爆炸(梯度爆炸)——见 [[44 梯度消失、爆炸与梯度裁剪|梯度消失/爆炸]]。

## 例子

**单变量两层**。$y=(3x+1)^2$。拆成 $u=3x+1$,$y=u^2$。

- 内层:$\frac{du}{dx}=3$。
- 外层:$\frac{dy}{du}=2u$。
- 链起来:$\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}=2u\cdot3=6u=6(3x+1)$。

在 $x=1$:$u=4$,$\frac{dy}{dx}=6\cdot4=24$。验证:$y=(3x+1)^2=9x^2+6x+1$,直接求导 $18x+6$,$x=1$ 给 $24$。✓ 一致。

**三层链**。$y=\sin(e^{2x})$。设 $v=2x$,$u=e^v$,$y=\sin u$:

$$\frac{dy}{dx}=\underbrace{\cos u}_{dy/du}\cdot\underbrace{e^v}_{du/dv}\cdot\underbrace{2}_{dv/dx}=2e^{2x}\cos(e^{2x})$$

三个本地导数一条龙乘起来。

![[calc-链式法则链.png]]

**多元链(神经网络味)**。$L$ 依赖 $z$,$z=wx+b$。求 $\partial L/\partial w$:

$$\frac{\partial L}{\partial w}=\frac{\partial L}{\partial z}\cdot\frac{\partial z}{\partial w}=\frac{\partial L}{\partial z}\cdot x$$

这就是 [[20 反向传播的数学推导|反向传播]] 里"上游梯度 $\partial L/\partial z$ 乘本地导数 $x$"的原型:权重梯度 = 误差 × 输入。

**分叉(扇出)再算一个完整例子**。$L=u^2+uv$,其中 $u=x+1$、$v=2x$,$u,v$ 都依赖 $x$,$x$ 经两条路影响 $L$。多元链式法则要把路径相加:

$$\frac{\partial L}{\partial x}=\frac{\partial L}{\partial u}\frac{\partial u}{\partial x}+\frac{\partial L}{\partial v}\frac{\partial v}{\partial x}$$

逐项:$\partial L/\partial u=2u+v$,$\partial u/\partial x=1$;$\partial L/\partial v=u$,$\partial v/\partial x=2$。合起来 $\partial L/\partial x=(2u+v)\cdot1+u\cdot2=2u+v+2u=4u+v$。代 $x=1$:$u=2,v=2$,得 $4\cdot2+2=10$。**验证**:直接代入 $L=(x+1)^2+(x+1)(2x)=x^2+2x+1+2x^2+2x=3x^2+4x+1$,$L'=6x+4$,$x=1$ 给 $10$。✓ 路径相加无误。

**链式法则也能推出乘法法则**(统一视角)。$h(x)=f(x)g(x)$ 看成 $h=uv$、$u=f(x)$、$v=g(x)$,多元链式 $h'=\frac{\partial h}{\partial u}u'+\frac{\partial h}{\partial v}v'=v\cdot f'+u\cdot g'=f'g+fg'$——乘法法则就是分叉求和的特例。

## 原理

**单变量链式法则**。若 $y=f(u)$ 且 $u=g(x)$,则复合 $y=f(g(x))$ 可导且

$$\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}=f'(g(x))\,g'(x)$$

推广到 $n$ 层 $x\to u_1\to u_2\to\dots\to y$:

$$\frac{dy}{dx}=\frac{dy}{du_{n}}\cdot\frac{du_{n}}{du_{n-1}}\cdots\frac{du_1}{dx}$$

——**一串本地导数连乘**,这就是图里那条乘法链。

**多元链式法则**。若 $L$ 通过多个中间变量 $z_1,\dots,z_k$ 依赖 $x$,要把所有路径的贡献**加起来**:

$$\frac{\partial L}{\partial x}=\sum_{i=1}^{k}\frac{\partial L}{\partial z_i}\cdot\frac{\partial z_i}{\partial x}$$

"路径乘、分叉加"。在 [[18 计算图(前向)|计算图]] 里,一个节点若被多个下游用到(扇出),它收到的梯度就是各下游回传梯度之和——这正是这条求和公式的图形版。

**向量形式(反向传播核心)**。复合 $x\to y\to L$,$y$ 是向量、$L$ 是标量,上游梯度 $\partial L/\partial y$ 已知,则

$$\frac{\partial L}{\partial x}=\Big(\frac{\partial y}{\partial x}\Big)^{\!T}\frac{\partial L}{\partial y}=J^{T}\frac{\partial L}{\partial y}$$

用本层 [[17 雅可比与 Hessian|雅可比]] 的转置左乘上游梯度,再传给下游(推导见 [[12 矩阵求导|矩阵求导]])。反向传播每一层干的就是这个矩阵-向量乘。

**为什么这是 backprop 基础**:神经网络是一长串函数复合 $L=f_n(f_{n-1}(\dots f_1(x)))$。要 $\partial L/\partial$(每个参数),逐层套链式法则即可;而"先前向存值、再从 $L$ 反向把梯度连乘回传"的高效组织方式,就是 [[19 自动微分：前向 vs 反向模式|反向模式自动微分]]。

**梯度消失/爆炸的定量解释**。$n$ 层网络反传时,$\partial L/\partial x$ 含 $\prod_{\ell}\sigma'(z_\ell)\,W_\ell$ 的连乘。把每层"放大率"近似为常数 $r$:

- $r=0.5$、$n=20$ 层:$0.5^{20}\approx10^{-6}$ —— 梯度几乎消失,前层学不动。
- $r=1.5$、$n=20$ 层:$1.5^{20}\approx3300$ —— 梯度爆炸,训练发散。
- $r=1$:梯度量级稳定,这是 ResNet 残差连接(让 $r\approx1$)、归一化、合适初始化(让 $\sigma'\,W$ 接近 1)要达成的目标。

sigmoid 的 $\sigma'\le0.25$(见 [[14 导数与偏导数|导数表]]),深层堆叠极易消失,这正是 ReLU($\sigma'=1$ 在正区间)取代它的核心原因。详见 [[44 梯度消失、爆炸与梯度裁剪|梯度消失/爆炸]]。

## 代码

```python
import numpy as np

# y = sin(e^{2x}),解析链式法则导数 2 e^{2x} cos(e^{2x})
f = lambda x: np.sin(np.exp(2*x))
df_analytic = lambda x: 2*np.exp(2*x)*np.cos(np.exp(2*x))

# ❌ 朴素:复合函数直接"猜"导数,容易漏乘内层 du/dx
df_wrong = lambda x: np.cos(np.exp(2*x))         # 漏了 e^{2x} 和 2

# ✅ 正确:分层求本地导数再连乘(手写 backprop 雏形)
def df_chain(x):
    v = 2*x;        dv_dx = 2.0
    u = np.exp(v);  du_dv = np.exp(v)
    y = np.sin(u);  dy_du = np.cos(u)
    return dy_du * du_dv * dv_dx               # 连乘

# 用中心差分做"裁判"(见 21 数值梯度检验)
df_num = lambda x, e=1e-6: (f(x+e)-f(x-e))/(2*e)

x = 0.3
print("解析:", df_analytic(x))   # 与链式一致
print("链式:", df_chain(x))      # == 解析
print("数值:", df_num(x))        # ≈ 链式  → 验证正确
print("错误版:", df_wrong(x))    # 与数值差很多 → 漏乘内层被抓出

# 多元/分叉:L = (x*y) + (x+y),x 出现在两条路径,梯度要相加
def dL_dx(x, y):
    return y + 1     # ∂(xy)/∂x=y 加上 ∂(x+y)/∂x=1
print("分叉求和 dL/dx(2,3):", dL_dx(2., 3.))   # 3+1=4

# 分叉完整例:L=u²+uv, u=x+1, v=2x → dL/dx=4u+v
def dL_full(x):
    u, v = x+1, 2*x
    return (2*u + v)*1 + u*2          # 两条路径相加
L_direct = lambda x: 3*x**2 + 4*x + 1
dL_direct = lambda x, e=1e-6: (L_direct(x+e)-L_direct(x-e))/(2*e)
print("链式:", dL_full(1.), " 数值:", round(dL_direct(1.)))  # 10 10

# 梯度消失/爆炸:连乘放大率
for r in (0.5, 1.0, 1.5):
    print(f"r={r}, 20层连乘 = {r**20:.2e}")   # 1e-6 / 1 / 3.3e3
```

手算对照:链式法则结果与解析公式逐位相等,数值差分作裁判确认无误;"错误版"漏乘内层导数被数值梯度立刻揭穿;多路径例子里 $x$ 走两条边,梯度 $=y+1=4$,印证"分叉处梯度相加"。

## 面试高频

- **"链式法则一句话?"** 复合函数导数 = 外层导数 × 内层导数(多层就连乘);反向传播就是它在计算图上的自动化。
- **"多元链式法则和单变量差在哪?"** 多条路径要**求和**(分叉相加),单变量只有一条路径只需相乘。漏掉求和是经典 bug。
- **"链式法则怎么解释梯度消失/爆炸?"** 深层是大量本地导数连乘:都 <1 → 乘积 →0(消失),都 >1 → 爆炸。这是 ResNet 残差、归一化、梯度裁剪要解决的问题(见 [[44 梯度消失、爆炸与梯度裁剪|梯度消失/爆炸]])。
- **"反向传播为什么用雅可比转置?"** 向量链式法则 $\partial L/\partial x=J^T\partial L/\partial y$:上游梯度左乘本地雅可比转置再下传。
- **陷阱:别忘了乘"最内层"那一项。** 像 $\sin(e^{2x})$ 容易漏掉 $\cdot 2$ 这种最内层导数,数值检验能立刻抓出。
- **"为什么 backprop 比逐参数数值求导快?"** 链式法则让一次反向扫描就复用所有中间梯度,而数值法要对每个参数各扰动一次——这引出 [[19 自动微分：前向 vs 反向模式|反向模式 AD]]。
- **"乘法法则能用链式法则推吗?"** 能。$h=uv$、$u=f,v=g$,多元链式 $h'=v f'+u g'=f'g+fg'$,乘法法则是分叉求和的特例。
- **"梯度消失到什么程度算严重?"** 定量:放大率 $r<1$ 时 $r^n$ 指数衰减,$r=0.5$、20 层就 $\sim10^{-6}$;ResNet/归一化/ReLU 让 $r\approx1$。

## 关键事实

- 单变量与多元链式法则是微积分标准定理,见 James Stewart《Calculus》(8th ed., 2015)第 3.4 节(单变量)与 14.5 节(多元)。
- 反向传播 = 在计算图上系统化应用链式法则,由 Rumelhart, Hinton & Williams 在《Learning representations by back-propagating errors》(*Nature*, 1986)推广。
- 链式法则的向量形式 $\partial L/\partial x=J^T\partial L/\partial y$ 是现代自动微分框架的数学核心,见 Baydin et al., 《Automatic Differentiation in Machine Learning: a Survey》(JMLR, 2018)。
