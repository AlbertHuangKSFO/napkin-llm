[[12 矩阵求导|矩阵求导]]是把导数从"标量对标量"推广到"标量/向量/矩阵互相之间求导"的一套规则,核心是搞清**导数的形状**(梯度、雅可比)和**链式法则怎么连乘**。它是 [[20 反向传播的数学推导|反向传播]] 的数学底座——backprop 本质就是在 [[18 计算图(前向)|计算图]] 上反复套用矩阵链式法则。

## 直觉

普通导数 $\frac{dy}{dx}$ 回答"$x$ 动一点,$y$ 跟着动多少"。神经网络里 $x$、$y$ 常常是**一整组数**(向量、矩阵),"动一点"和"动多少"都得对每个分量分别算。

关键直觉:**导数的形状取决于谁对谁求导**。

- 标量 $L$ 对向量 $x$:每个分量 $\partial L/\partial x_i$ 排成跟 $x$ **同形**的向量,叫**梯度**——它指向 $L$ 上升最快的方向。
- 向量 $y$ 对向量 $x$:所有 $\partial y_i/\partial x_j$ 排成一个 $m\times n$ 的表,叫**雅可比矩阵**。
- 标量 $L$ 对矩阵 $W$:逐元素偏导排成跟 $W$ 同形的矩阵。

记住一句口诀:**对谁求导,结果就和谁同形(分子布局下转置一下)**。形状对不上,梯度就一定算错了。

## 例子

**标量对向量(最常用)**。设 $L=\|x\|^2=x^Tx=\sum_i x_i^2$。逐分量:$\partial L/\partial x_i=2x_i$,排起来:

$$\frac{\partial L}{\partial x}=2x$$

像一元的 $\frac{d}{dx}x^2=2x$,只是向量版。取 $x=(3,4)$,梯度 $=(6,8)$。

**线性层 $y=Wx$**。每个 $y_i=\sum_j W_{ij}x_j$,所以 $\partial y_i/\partial x_j=W_{ij}$,即雅可比

$$\frac{\partial y}{\partial x}=W$$

**二次型 $L=x^TAx$**。结论(必背):

$$\frac{\partial}{\partial x}(x^TAx)=(A+A^T)x\quad\xrightarrow{A\text{ 对称}}\quad 2Ax$$

手验 $A=I$:$L=x^Tx$,公式给 $2x$,与上面一致。✓

**链式法则小例**。$L=\|Wx-b\|^2$(线性回归损失)。令 $r=Wx-b$,$L=r^Tr$。逐层:$\partial L/\partial r=2r$,$\partial r/\partial x=W$,链起来 $\partial L/\partial x=W^T(2r)=2W^T(Wx-b)$。

**线性项 $a^\top x$ 手算**。$L=a^\top x=\sum_i a_ix_i$,$\partial L/\partial x_i=a_i$,排起来 $\partial L/\partial x=a$。取 $a=[2,5,3]$,梯度就是 $[2,5,3]$——线性函数的梯度是常向量(坡度处处一样)。

**softmax / 激活的逐元素雅可比(神经网络高频)**:

- **逐元素激活** $y_i=\sigma(x_i)$(如 ReLU、tanh):雅可比是**对角阵** $J=\mathrm{diag}(\sigma'(x_1),\dots,\sigma'(x_n))$。反向传播里它退化成逐元素乘 $\odot\sigma'$(见 [[20 反向传播的数学推导|反向传播]]),不用真的存矩阵。
- **softmax** $y_i=\frac{e^{x_i}}{\sum_j e^{x_j}}$:雅可比 $J_{ij}=y_i(\delta_{ij}-y_j)$,即 $J=\mathrm{diag}(y)-yy^\top$。这就是为什么 softmax + 交叉熵复合后梯度奇迹般化简成 $\hat y-y$(见 [[20 反向传播的数学推导|反向传播]])。

## 原理

**梯度(标量对向量)**。$L:\mathbb R^n\to\mathbb R$,

$$\nabla_x L=\frac{\partial L}{\partial x}=\Big(\frac{\partial L}{\partial x_1},\dots,\frac{\partial L}{\partial x_n}\Big)^T\in\mathbb R^n$$

**雅可比(向量对向量)**。$y:\mathbb R^n\to\mathbb R^m$,

$$J=\frac{\partial y}{\partial x}\in\mathbb R^{m\times n},\qquad J_{ij}=\frac{\partial y_i}{\partial x_j}$$

**链式法则(反向传播的发动机)**。复合 $x\to y\to L$,上游已知 $\partial L/\partial y$(标量对向量),则

$$\frac{\partial L}{\partial x}=\Big(\frac{\partial y}{\partial x}\Big)^T\frac{\partial L}{\partial y}=J^T\frac{\partial L}{\partial y}$$

**用雅可比转置左乘上游梯度**——这就是反向传播每一层干的事:本地算出雅可比 $J$,把上游传来的梯度左乘 $J^T$ 再传给下游。链式法则把各层雅可比连乘起来。

![[la-梯度雅可比链式.png]]

**常用结果速查表**(分母布局,结果与变量同形):

| 函数 $f$ | $\partial f/\partial x$ |
|---|---|
| $a^Tx$(线性) | $a$ |
| $x^Tx=\|x\|^2$ | $2x$ |
| $x^TAx$ | $(A+A^T)x$;$A$ 对称时 $2Ax$ |
| $Wx$(对 $x$) | $W$(雅可比) |
| $\|Wx-b\|^2$(对 $x$) | $2W^T(Wx-b)$ |

对矩阵参数:$L=\|Wx-b\|^2$ 对 $W$ 的梯度是 $\frac{\partial L}{\partial W}=2(Wx-b)x^T$——注意它跟 $W$ 同形,且形如"误差 $\times$ 输入转置",这正是 backprop 里权重梯度的通用形态。

**对矩阵求导的几个常用结果(Matrix Cookbook 高频条目)**:

| 函数 $f(W)$ | $\partial f/\partial W$ |
|---|---|
| $\mathrm{tr}(W)$ | $I$ |
| $\mathrm{tr}(AW)$ | $A^\top$ |
| $\mathrm{tr}(W^\top A)$ | $A$ |
| $a^\top W b$(标量) | $ab^\top$ |
| $\|W\|_F^2=\mathrm{tr}(W^\top W)$ | $2W$ |
| $\det(W)$ | $\det(W)\,(W^{-1})^\top$ |
| $\log\det(W)$ | $(W^{-1})^\top$ |

**两种布局约定(必须先声明,否则差一个转置)**。**分母布局**(本笔记用):$\partial(\text{标量})/\partial x$ 与 $x$ **同形**(列向量),雅可比是 $n\times m$。**分子布局**:梯度是行向量,雅可比是 $m\times n$。深度学习代码(PyTorch 的 `.grad`)统一用"梯度与参数同形",即分母布局——记住这个就不会在工程里翻车。链式法则在分母布局下写成 $\partial L/\partial x=J^\top\,\partial L/\partial y$(雅可比 $J=\partial y/\partial x$ 仍按 $J_{ij}=\partial y_i/\partial x_j$ 即 $m\times n$ 定义)。

**为什么这是 backprop 基础**:神经网络是一串函数复合 $L(f_n(\dots f_1(x)))$,要更新参数就要 $\partial L/\partial W_i$。在 [[18 计算图(前向)|计算图]] 上,前向算各节点的值,反向用上面这套矩阵链式法则把梯度从损失一路回传到每个参数,详见 [[20 反向传播的数学推导|反向传播的数学推导]] 与 [[19 自动微分：前向 vs 反向模式|自动微分]]。

## 代码

```python
import numpy as np

# 用数值梯度验证解析公式 ∂(x^T x)/∂x = 2x
def num_grad(f, x, eps=1e-6):
    g = np.zeros_like(x)
    for i in range(len(x)):
        e = np.zeros_like(x); e[i] = eps
        g[i] = (f(x + e) - f(x - e)) / (2 * eps)
    return g

x = np.array([3., 4.])
f = lambda v: v @ v                 # L = x^T x
print("解析 2x:", 2 * x)            # [6. 8.]
print("数值梯度:", num_grad(f, x))  # ≈ [6. 8.]

# 二次型 x^T A x,解析梯度 (A+A^T)x
A = np.array([[1., 2.],
              [0., 3.]])
g = lambda v: v @ A @ v
print("解析 (A+A^T)x:", (A + A.T) @ x)   # [22. 38.]
print("数值梯度:", num_grad(g, x))        # ≈ [22. 38.]

# 线性回归损失对 W 的梯度 2(Wx-b)x^T,与 W 同形
W = np.array([[1., 2.],
              [3., 4.]])
xv = np.array([1., 1.]); b = np.array([0., 0.])
r = W @ xv - b
gradW = 2 * np.outer(r, xv)
print("dL/dW 形状:", gradW.shape)   # (2,2),与 W 同形
```

```python
# softmax 雅可比 J = diag(y) - y y^T,数值验证
def softmax(x):
    e = np.exp(x - x.max()); return e / e.sum()
def softmax_jac(x):
    y = softmax(x)
    return np.diag(y) - np.outer(y, y)

x = np.array([1.0, 2.0, 0.5])
J_ana = softmax_jac(x)
# 数值雅可比
J_num = np.zeros((3,3)); eps=1e-6
for j in range(3):
    e = np.zeros(3); e[j]=eps
    J_num[:, j] = (softmax(x+e) - softmax(x-e)) / (2*eps)
print("softmax 雅可比解析≈数值:", np.allclose(J_ana, J_num, atol=1e-5))  # True

# tr(AW) 对 W 的梯度 = A^T,数值验证
A = np.array([[1.,2.],[3.,4.]]); W0 = np.random.randn(2,2)
f = lambda W: np.trace(A @ W)
G = np.zeros((2,2))
for i in range(2):
    for j in range(2):
        e = np.zeros((2,2)); e[i,j]=eps
        G[i,j] = (f(W0+e)-f(W0-e))/(2*eps)
print("d tr(AW)/dW == A^T:", np.allclose(G, A.T))  # True
```

手算对照:`2x=[6,8]` 与数值梯度一致;`(A+A^T)x` 解析值 `[22,38]` 与数值梯度一致(印证二次型公式);`dL/dW` 形状 $(2,2)$ 与 $W$ 同形,符合"梯度与被求导变量同形"的口诀;softmax 雅可比 $\mathrm{diag}(y)-yy^\top$ 与数值一致;$\partial\,\mathrm{tr}(AW)/\partial W=A^\top$ 验证通过。

## 面试高频

- **"$\partial(x^TAx)/\partial x$ 等于多少?"** $(A+A^T)x$,对称时 $2Ax$。这是矩阵求导第一送分题,务必背熟并能口算 $A=I$ 的特例 $2x$。
- **"梯度和雅可比什么区别?"** 梯度是标量对向量(与 $x$ 同形的向量);雅可比是向量对向量($m\times n$ 矩阵)。梯度是雅可比在 $m=1$ 时的(转置)特例。
- **"反向传播为什么用雅可比转置?"** 链式法则 $\partial L/\partial x=J^T\partial L/\partial y$:上游梯度左乘本地雅可比转置。把这句话和形状对齐讲清楚,直接体现你懂 backprop。
- **"为什么要关心导数的形状?"** 形状对不上 = 代码报维度错误 / 梯度算错。工程上 90% 的 backprop bug 是形状/转置写反。
- **陷阱:布局约定(分子 vs 分母)。** 不同教材梯度差一个转置。回答时声明"我用分母布局(梯度与变量同形)"避免歧义,显示专业。
- **"线性层权重梯度长什么样?"** $\partial L/\partial W=\delta\, x^T$(误差外积输入),与 $W$ 同形。能脱口而出说明真懂 backprop。
- **"softmax 的雅可比?"** $J=\mathrm{diag}(y)-yy^\top$;逐元素激活的雅可比是对角阵,反传时退化成 $\odot\sigma'$。
- **"$\partial\,\mathrm{tr}(AW)/\partial W$、$\partial\log\det W/\partial W$ 是多少?"** 分别是 $A^\top$、$(W^{-1})^\top$——Matrix Cookbook 常考条目。
- **"为什么实践里很少手推矩阵导数?"** 框架的自动微分(见 [[19 自动微分：前向 vs 反向模式]])帮你算;手推主要用于理解、写自定义算子、或数值检验。
