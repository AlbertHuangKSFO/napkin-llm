[[13 张量、广播与维度对齐|张量]]是带"阶"(轴数)的多维数字容器,标量是 0 阶、向量 1 阶、矩阵 2 阶、再往上就是高阶张量;[[13 张量、广播与维度对齐|广播]](broadcasting)是一套自动规则,让不同形状的张量在逐元素运算时"右对齐维度、把大小为 1 的维拉伸对齐"。维度对错是深度学习里报错的头号来源,这篇把规则讲死。

## 直觉

**张量** = "套娃版的数组"。标量是一个数,向量是一排数,矩阵是一张表,再往上是"一摞表""一柜子表"。**阶(rank / ndim)= 取出一个元素要几个下标**。神经网络里最常见的是 3 阶 `(batch, 序列长度, 特征维)` 和 4 阶图像 `(N, C, H, W)`。

**广播**像"自动配平"。你想给一批向量 `(batch, d)` 的每一行都加同一个偏置 `(d,)`,按理得把偏置复制 batch 份再相加。广播让你**直接写 `X + b`**,它在底层假装把 `b` 复制了 batch 行——但实际并不真复制数据,只是把那一维的"步长"设成 0,省内存还快。

类比**乘法口诀表**:一列数 `(3,1)` 和一行数 `(1,4)` 相加,自动铺成 $3\times4$ 的表格,每格 = 对应行值 + 列值。

**广播的两条规则(必须背)**:

1. **右对齐**:把两个形状右端对齐,缺的维在左边补 1。
2. **逐维兼容**:每一维要么相等,要么其中一个是 1;否则报错。结果每维取两者的 max。

**例子:列向量 + 行向量**。$a$ 是 `(3,1)`,$b$ 是 `(1,4)`:

```
a:  (3, 1)
b:  (1, 4)
对齐后每维取 max → (3, 4)
```

具体数值:$a=\begin{bmatrix}10\\20\\30\end{bmatrix}$,$b=\begin{bmatrix}1&2&3&4\end{bmatrix}$,广播相加得

$$a+b=\begin{bmatrix}11&12&13&14\\21&22&23&24\\31&32&33&34\end{bmatrix}$$

![[la-广播维度对齐.png]]

**再走两个三维广播例子(深度学习真实形状)**:

- **加偏置到一批序列**:`(B, T, d) + (d,)`。右对齐 `(B,T,d)` 与 `(1,1,d)`,缺维补 1,$b,t$ 维拉伸 → 结果 `(B,T,d)`。每个 `(b,t)` 位置都加同一个 $d$ 维偏置。
- **注意力打分加 mask**:`(B, H, T, T) + (1, 1, T, T)`。后者在 batch 和 head 维是 1,广播到所有 batch、所有 head。
- **逐通道缩放**:`(N, C, H, W) * (C, 1, 1)`。`(C,1,1)` 右对齐成 `(1,C,1,1)`?**不对**——`(C,1,1)` 是 3 维,右对齐到 4 维左补 1 成 `(1,C,1,1)`,正好按通道缩放。这就是为什么 BN 的 scale 参数常 reshape 成 `(1,C,1,1)`。

**批量矩阵乘法的广播(`@` / matmul)**:matmul 只对**最后两维**做矩阵乘,前面的维当 batch 广播。`(B, m, k) @ (B, k, n) -> (B, m, n)`;`(B, m, k) @ (k, n) -> (B, m, n)`(右操作数 batch 维广播)。这是注意力 $QK^\top$ 在多 batch、多 head 下一次算完的机制。

**反例(报错)**:`(3,)` 和 `(4,)` 右对齐后是 $3\ne4$ 且都不是 1 → 不能广播,直接报错。

## 原理

**形状(shape)与阶(ndim)**:shape 是各维长度的元组,如 `(2,3,4)`;阶 = `len(shape)` = 3。元素总数 = 各维乘积。

**广播算法**(NumPy / PyTorch / TensorFlow 通用):

1. 把两个 shape 右对齐,短的在左边补 $1$,补到等长。
2. 逐维检查:$\dim_A=\dim_B$,或其中一个为 $1$ → 兼容,结果维 $=\max$;否则抛错。
3. 大小为 $1$ 的维被"拉伸"到目标长度(逻辑上复制,物理上 stride=0 的视图,不占新内存)。

**维度对齐里的高频操作**:

- `reshape(...)`:改形状但**元素总数不变、底层内存顺序不变**。`-1` 表示自动推断该维。
- `transpose / permute`:交换轴的顺序,会让张量在内存里变"不连续"(可能要 `.contiguous()`)。
- `squeeze`(删大小为 1 的维)/ `unsqueeze`(插入大小为 1 的维,用来制造广播对齐)。
- `sum/mean(axis=k, keepdims=True)`:沿某轴归约,`keepdims=True` 保留长度为 1 的维,正好方便后续广播——这是 LayerNorm 等的常用写法。

**深度学习里的真实广播场景**:

- **加偏置**:`(batch, d) + (d,)`,偏置广播到每个样本。
- **归一化**:LayerNorm 对 `(B, T, d)` 沿最后一维算均值 `(B, T, 1)`,再广播相减(细节见 [[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|归一化]])。
- **注意力 mask**:`(B, 1, T, T)` 广播到多头维。
- **缩放**:`logits / temperature`,标量广播到整个张量。

**`einsum`:维度对齐的终极武器(显式写出每根轴)**。爱因斯坦求和约定用字母给每根轴命名,重复出现的字母被求和、不出现在输出的被消掉。一眼看清形状,杜绝广播歧义:

- 点积:`np.einsum('i,i->', a, b)`(两个 `i` 配对相乘再求和)。
- 矩阵乘:`np.einsum('ik,kj->ij', A, B)`(中间 `k` 被求和,正是 [[06 矩阵乘法的几何意义|内侧相等]])。
- 批量注意力打分:`np.einsum('bhqd,bhkd->bhqk', Q, K)`(对特征维 `d` 求和,得 query×key 分数)。
- 外积:`np.einsum('i,j->ij', a, b)`(无求和,升一维)。

**内存布局(C-order)与连续性**。numpy 默认按**行优先(C 顺序)**把多维数组铺平存在一段连续内存里;`reshape` 不改这段内存的顺序、只换"怎么解读"的步长(stride),所以很快;`transpose/permute` 只交换轴的步长、**不搬数据**,会让数组"非连续",某些操作前要 `.contiguous()`(PyTorch)/`np.ascontiguousarray`。这解释了为什么 `reshape` 后 `transpose` 再 `reshape` 有时报错——中间非连续。

**爱踩的坑**:`(N,1) + (N,)` 不会给 `(N,)`!右对齐后是 `(N,1)` 与 `(1,N)`,广播成 `(N,N)` 的方阵——很多 loss 算错就因为这个,务必用 `keepdims` 或 `reshape` 把形状对清楚。

## 代码

```python
import numpy as np

# 阶/形状
s = np.array(7.0)                 # 0 阶
v = np.array([1, 2, 3])           # 1 阶 (3,)
M = np.arange(6).reshape(2, 3)    # 2 阶 (2,3)
T = np.arange(24).reshape(2, 3, 4)# 3 阶 (2,3,4)
print(s.ndim, v.shape, M.shape, T.shape)

# 广播:列向量 + 行向量 → (3,4)
a = np.array([[10], [20], [30]])  # (3,1)
b = np.array([[1, 2, 3, 4]])      # (1,4)
print((a + b).shape)              # (3,4)
print(a + b)                      # 上面手算的那张表

# 加偏置:每行加同一个 bias
X = np.ones((5, 3))               # (batch=5, d=3)
bias = np.array([1., 2., 3.])     # (3,)
print((X + bias)[0])              # [2. 3. 4.],广播到每行

# keepdims 保证可广播(LayerNorm 式)
Z = np.random.randn(4, 6)
mu = Z.mean(axis=1, keepdims=True)        # (4,1) 而非 (4,)
print((Z - mu).shape)                     # (4,6),广播相减成功

# 经典陷阱:(N,1)+(N,) 会爆成 (N,N)
n1 = np.zeros((5, 1))
n0 = np.zeros((5,))
print((n1 + n0).shape)            # (5,5)!不是 (5,) —— 小心

# 不兼容会报错
try:
    np.zeros((3,)) + np.zeros((4,))
except ValueError as e:
    print("报错:", e)             # operands could not be broadcast
```

手算对照:`a+b` 输出与上面手算的 $3\times4$ 表 `[[11..14],[21..24],[31..34]]` 完全一致;`(N,1)+(N,)` 给出 `(5,5)` 印证那个著名陷阱;不兼容形状如期抛 `ValueError`。

```python
# einsum:显式写每根轴,杜绝广播歧义
a = np.array([1., 2., 3.]); b = np.array([4., 5., 6.])
print(np.einsum('i,i->', a, b))         # 32.0  点积
print(np.einsum('i,j->ij', a, b).shape) # (3,3) 外积
A = np.random.randn(2,3); B = np.random.randn(3,4)
print(np.allclose(np.einsum('ik,kj->ij', A, B), A @ B))   # True 矩阵乘

# 批量 matmul:只对最后两维做矩阵乘,前面 batch/head 维广播
Q = np.random.randn(2, 4, 8, 16)   # (B=2, H=4, T=8, d=16)
K = np.random.randn(2, 4, 8, 16)
scores = Q @ K.transpose(0, 1, 3, 2)   # (2,4,8,16)@(2,4,16,8)->(2,4,8,8)
print(scores.shape)                    # (2, 4, 8, 8)  注意力打分矩阵
print(np.allclose(scores, np.einsum('bhqd,bhkd->bhqk', Q, K)))  # True

# 内存连续性:transpose 只换 stride、不搬数据 → 变“非连续”
M = np.arange(6).reshape(2, 3)
print(M.flags['C_CONTIGUOUS'], M.T.flags['C_CONTIGUOUS'])  # True False
```

## 面试高频

- **"广播规则是什么?"** 标准答:右对齐 → 缺维补 1 → 每维要么相等要么有一个是 1,否则报错;大小为 1 的维被拉伸。能背两条规则直接过关。
- **"广播会复制数据吗?"** 不会。它用 stride=0 的视图逻辑复制,省内存。这是区分"会用"和"懂原理"的点。
- **"`(N,1)+(N,)` 得到什么形状?"** `(N,N)`——经典陷阱题,很多人答 `(N,)`。
- **"reshape 和 permute/transpose 区别?"** reshape 不改元素顺序只改形状(可能要连续内存);permute 换轴顺序,会让张量不连续。混用会出 bug。
- **"keepdims 有什么用?"** 归约后保留长度 1 的维,方便后续广播(LayerNorm/softmax 归一化都靠它)。
- **陷阱:广播的 bug 往往不报错只算错。** 形状凑巧能广播但语义错(如本想逐行却广播成方阵),结果数值不对却不抛异常——所以要养成打印 `.shape` 的习惯。
- **"einsum 有什么好处?"** 显式给每根轴命名,重复字母求和、缺席字母消去;一行表达点积/矩阵乘/批量注意力,杜绝广播歧义,常比手动 reshape+matmul 更清晰且不易错。
- **"batch matmul 怎么对齐?"** `@` 只对最后两维做矩阵乘(内侧相等),前面所有维当 batch 广播:`(B,H,m,k)@(B,H,k,n)->(B,H,m,n)`。
- **"transpose 后为什么要 contiguous?"** transpose/permute 只改 stride 不搬数据 → 非连续;某些算子(view、部分 CUDA kernel)要求连续内存,故需 `.contiguous()`。
- **"`(C,1,1)` 怎么广播到 `(N,C,H,W)`?"** 右对齐左补 1 成 `(1,C,1,1)`,按通道缩放——BN/逐通道仿射就这么写。

## 关键事实

- 广播语义(右对齐、维度为 1 时拉伸、stride=0 视图不复制数据)是 NumPy 的核心规则,见 NumPy 官方文档 "Broadcasting" 及 Harris et al., "Array programming with NumPy", *Nature* 585, 357–362(2020)。
- PyTorch / TensorFlow 沿用同一套广播规则,见各自官方 broadcasting semantics 文档。
- 张量(多维数组)作为深度学习数据容器的标准抽象,见 Goodfellow, Bengio & Courville《Deep Learning》(2016)第 2.1 节。
