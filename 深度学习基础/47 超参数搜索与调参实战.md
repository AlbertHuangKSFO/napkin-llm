[[47 超参数搜索与调参实战|超参数搜索]] 是系统地搜索那些"训练前要人为设定、梯度下降不会自动学"的参数(学习率、batch size、层数、正则强度等),用验证集评分选最优配置;主流策略有网格、随机、贝叶斯搜索,其中学习率最关键。

## 直觉

参数和超参数的区别像"厨师手艺"和"菜谱设定":

- **参数(weights)**:厨师在做菜过程中练出来的手感 —— 由训练数据通过 [[37 梯度下降：BGD、SGD、Mini-batch|梯度下降]] 自动学。
- **超参数**:你下厨前定的火候、用多少盐、炖多久 —— 训练前人为设定,模型自己不会调。

调参就是反复试不同"菜谱设定",每次拿**验证集**尝一口打分(见 [[46 训练、验证、测试与交叉验证|验证集]]),挑出最好吃的那套。难点:超参很多、组合爆炸、每次试验都要训一遍很贵。

**最反直觉的一条:学习率比其他超参重要一个量级**。学习率错一个数量级,模型要么纹丝不动、要么直接发散;而把层数从 4 调到 5 通常无关痛痒。

## 例子

**学习率的威力**。同一个网络,只改学习率:

- $\text{lr}=10$:第一步就把参数推飞,loss 变 NaN —— **发散**。
- $\text{lr}=10^{-6}$:每步几乎不动,训 100 个 epoch 才下降一点点 —— **太慢**。
- $\text{lr}=10^{-3}$:平稳快速收敛 —— **刚好**。

三个值跨了 7 个数量级却天差地别 —— 所以学习率要在**对数尺度**上搜(试 $10^{-4},10^{-3},10^{-2}$ 而非 $0.1,0.2,0.3$)。

**网格 vs 随机的关键差异**。假设要在 2 个超参上各试 3 个值。

- **网格搜索**:试全部 $3\times3=9$ 个组合。但因为是格点,**学习率只覆盖了 3 个不同值**。如果只有学习率重要,你实际只探索了 3 个有效点。
- **随机搜索**:同样 9 次,每次学习率独立随机抽 → **9 个不同的学习率值**。落进"好区间"的概率大得多。

Bergstra & Bengio(2012)证明:当只有少数超参真正重要时,**随机搜索在相同预算下通常优于网格搜索**。

**对数尺度采样的手算对照**。要在 $[10^{-4},10^{-1}]$ 搜学习率,采 4 个点。
- **线性均匀**采 $U(10^{-4},10^{-1})$:期望落点约 $0.025,0.05,0.075,0.1$ 这种,**99% 的概率落在 $[10^{-2},10^{-1}]$ 这一个量级**,$10^{-4}\sim10^{-3}$ 几乎采不到 —— 全浪费。
- **对数均匀**采 $u\sim U(-4,-1)$、$\text{lr}=10^u$:四个 $u$ 可能是 $-3.6,-2.8,-1.9,-1.2$,对应 $\text{lr}\approx2.5\times10^{-4},1.6\times10^{-3},1.3\times10^{-2},6.3\times10^{-2}$ —— **每个数量级都被覆盖**。结论:凡是"差一个数量级就天差地别"的超参(lr、weight decay、正则系数),一律对数尺度搜。

**随机搜索"命中好区间"的概率直觉**。若某超参只有 5% 的取值范围是"好的",随机采 $n$ 次至少命中一次的概率 $=1-0.95^n$:$n=10$ 约 40%,$n=30$ 约 79%,$n=60$ 约 95%。这给了一个实用经验:**60 次随机试验大概率能撞进任意单维度的前 5% 好区间**,无需穷举网格。

## 原理

**三种搜索策略**:

1. **网格搜索(Grid Search)**:为每个超参定一组候选值,穷举所有组合。简单、可复现,但组合数随维度**指数爆炸**($k$ 个超参各 $n$ 值 = $n^k$ 次),且格点浪费(重要维度被分辨率限制)。适合超参少($\le2$~$3$)。

2. **随机搜索(Random Search)**:在每个超参的范围内独立随机采样固定次数。同预算下对"重要维度"覆盖更密,**实践默认起点**。范围要按合适尺度采:学习率、weight decay 用**对数均匀**($\log U$),层数用整数均匀。

3. **贝叶斯优化(Bayesian Optimization)**:用代理模型(常是高斯过程或 TPE)拟合"超参 → 验证分数"的曲面,据此**主动挑下一个最可能更好的点**(平衡探索与利用,用采集函数如 EI)。样本效率高,适合每次试验很贵的场景(大模型)。工具:Optuna、Hyperopt、Ray Tune。

4. **进阶:Hyperband / ASHA**:给多组配置少量资源先跑,**早早砍掉表现差的**,把算力集中给有希望的(successive halving)。对深度学习极实用。

**调参优先级(经验法则)**:

- **第一档(最关键)**:学习率。对数尺度搜,$10^{-4}\sim10^{-1}$。
- **第二档**:batch size、[[40 学习率调度与 warmup、cosine|学习率调度]]、优化器选择(见 [[39 优化器(Momentum、RMSProp、Adam、AdamW)|优化器]])、网络宽度/深度、正则强度(weight decay、dropout)。
- **第三档(常用默认即可)**:Adam 的 $\beta_1,\beta_2,\epsilon$、初始化方式、激活函数细节。

**对数尺度采样的原理**。学习率从 $10^{-4}$ 到 $10^{-1}$,若按线性均匀采,绝大多数样本会挤在 $0.05\sim0.1$ 这一段,而 $10^{-4}\sim10^{-3}$ 几乎采不到。正确做法:在指数上均匀采 $u\sim U(-4,-1)$,取 $\text{lr}=10^{u}$,让每个数量级被等概率覆盖。

**学习率与 batch size 的耦合(高频)**。改了 batch size 必须同步调学习率,否则白调:
- **线性放大规则**(Goyal 2017):batch 放大 $k$ 倍,lr 也放大 $k$ 倍(大 batch 梯度估计更准、可迈大步)。如 batch 256 用 lr 0.1,batch 1024 用 lr 0.4,并配 warmup 防初期发散。
- **平方根规则**:另一派认为应按 $\sqrt k$ 放大(让梯度噪声尺度不变),Adam 类优化器有时更贴这条。
- 实践:大 batch + 线性放大 lr + warmup,是分布式训练的标配组合。

**早停轮数也是超参**:别让所有配置都训满 epoch;用 [[42 正则化(L2、Dropout、早停、标签平滑)|早停]] + 资源自适应(Hyperband/ASHA)早早砍掉烂配置,把算力让给有希望的。

**实战流程**:① 先用随机搜索在对数尺度粗扫学习率(其余固定为合理默认);② 锁定学习率量级后,粗调第二档超参;③ 在表现好的小区域精搜;④ 全程用**验证集/CV** 评分,**测试集只在最后跑一次**(见 [[46 训练、验证、测试与交叉验证|测试集铁律]])。每组配置记录种子以可复现。

**找学习率的快速 trick(LR range test,Smith 2017)**:让 lr 从极小($10^{-7}$)指数增长到极大,记录每步 loss,画 lr-loss 曲线;loss 开始稳定下降到即将反弹之间的那一段就是好 lr 区间,取下降最陡处的约 1/10。几十步就能定 lr 量级,比盲搜快得多。

```python
# 贝叶斯优化(Optuna):主动挑下一个最有希望的超参
import optuna

def objective(trial):
    lr = trial.suggest_float("lr", 1e-4, 1e-1, log=True)   # log=True 即对数尺度
    wd = trial.suggest_float("wd", 1e-6, 1e-2, log=True)
    bs = trial.suggest_categorical("batch_size", [32, 64, 128])
    # ... 按这组超参训练,返回验证集误差(越小越好)...
    val_loss = (np.log10(lr) + 3) ** 2 + 0.1   # 占位:在 lr≈1e-3 附近最优
    return val_loss

study = optuna.create_study(direction="minimize")
study.optimize(objective, n_trials=30)
print("最优超参:", study.best_params)   # 自动找到 lr≈1e-3 附近
```

```python
# Hyperband / ASHA 思想:多组配置先各跑少量资源,砍掉差的,把算力集中给好的
# Optuna 内置 pruner 实现 successive halving
import optuna
from optuna.pruners import SuccessiveHalvingPruner

def objective_pruned(trial):
    lr = trial.suggest_float("lr", 1e-4, 1e-1, log=True)
    for epoch in range(20):                     # 模拟逐 epoch 训练
        val = (np.log10(lr) + 3) ** 2 + 0.1 - epoch * 0.001
        trial.report(val, epoch)                # 上报中间结果
        if trial.should_prune():                # ✅ 差的配置提前砍掉,省算力
            raise optuna.TrialPruned()
    return val

study = optuna.create_study(direction="minimize", pruner=SuccessiveHalvingPruner())
# study.optimize(objective_pruned, n_trials=50)  # 烂配置早停,等价 Hyperband

base_bs, base_lr = 256, 0.1
for bs in [256, 512, 1024]:
```

## 面试高频

- **Q:参数和超参数的区别?**
  A:参数(权重、偏置)由训练数据经梯度下降自动学;超参数(学习率、层数、正则强度、batch size)训练前人为设定,梯度下降不会调它们,需另外搜索。
- **Q:网格搜索和随机搜索哪个好?为什么?**
  A:当只有少数超参真正重要时,随机搜索在相同预算下通常更好(Bergstra & Bengio 2012):它对重要维度采到更多不同值,而网格被格点分辨率限制、且组合数指数爆炸。
- **Q:最该先调哪个超参?学习率怎么搜?**
  A:学习率最关键,错一个数量级就训不动或发散。在**对数尺度**上搜($10^{-4}\sim10^{-1}$),先粗扫定量级再精调。
- **Q:贝叶斯优化比随机搜索强在哪?**
  A:它用代理模型拟合超参与分数的关系,主动挑最有希望的下一个点(平衡探索/利用),样本效率高,适合每次试验昂贵的大模型场景。
- **Q:改了 batch size 学习率怎么动?**
  A:线性放大规则(Goyal 2017):batch 放大 $k$ 倍,lr 也放大 $k$ 倍,并配 warmup 防初期发散;部分场景(尤其 Adam)用平方根规则。不调 lr 直接改 batch 是常见错误。
- **Q:Hyperband/ASHA 凭什么省算力?**
  A:successive halving——先给很多配置少量资源(几个 epoch)跑,按表现砍掉差的一半,把资源逐轮集中给幸存者。避免在烂配置上训满,深度学习里极实用。
- **Q:怎么快速定学习率量级?**
  A:LR range test(Smith 2017):lr 从极小指数增长记录 loss,画曲线,取下降最陡处约 1/10。几十步搞定,比盲搜快。
- **Q:贝叶斯优化的代理模型有哪些?采集函数是什么?**
  A:代理模型常用高斯过程(GP)或 TPE(树结构 Parzen 估计,Optuna/Hyperopt 默认);采集函数(如 EI 期望改进、UCB)平衡"探索未知区"与"利用已知好区",决定下一个采样点。
- **陷阱**:① 学习率用线性尺度搜 —— 几乎全采在大值,漏掉小 lr。② 用测试集挑超参 —— 数据泄漏。③ 一次性搜太多超参 —— 维度灾难,应先抓重要的。④ 改了 batch size 不同步调学习率(常见经验:lr 随 batch 近似线性放大)。⑤ 不固定随机种子,结果不可复现。⑥ 让所有配置都训满 epoch 而不用早停/剪枝,白烧算力。

## 关键事实

- 随机搜索优于网格搜索的经典论证:Bergstra & Bengio(2012,"Random Search for Hyper-Parameter Optimization",JMLR)。
- 贝叶斯优化用于 ML 调参:Snoek、Larochelle、Adams(2012,"Practical Bayesian Optimization of Machine Learning Algorithms",NeurIPS)。
- Hyperband(资源自适应早停):Li 等(2017,JMLR);其分布式版 ASHA(Li 等 2020)。
- 常用工具:Optuna、Ray Tune、Hyperopt、Weights & Biases Sweeps;TPE(Tree-structured Parzen Estimator)是 Optuna/Hyperopt 默认。
- 学习率与 batch 的经验关系:Goyal 等(2017,"Accurate, Large Minibatch SGD")提出"线性放大规则";平方根规则见 Krizhevsky(2014)、Hoffer et al.(2017)。
- **LR range test / 周期学习率**:Smith, *Cyclical Learning Rates for Training Neural Networks*(WACV 2017),给出快速定 lr 量级的方法。
- **GP 贝叶斯优化与采集函数(EI)**:Mockus(1978)、Snoek et al.(2012);**TPE**:Bergstra et al.(NeurIPS 2011)。
- 关联:搜索的评分依赖 [[46 训练、验证、测试与交叉验证|验证集/CV]];被搜对象含 [[40 学习率调度与 warmup、cosine|学习率调度]]、[[39 优化器(Momentum、RMSProp、Adam、AdamW)|优化器]]、[[42 正则化(L2、Dropout、早停、标签平滑)|正则强度]]。
