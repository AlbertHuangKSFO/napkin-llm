[[14 导数与偏导数|导数与偏导数]]是微积分量化"变量动一点、函数跟着动多少"的工具:**导数**管单变量,**偏导数**管多变量里"只动一个、其余钉死"。它们是 [[15 梯度、方向导数与等高线|梯度]]、[[16 链式法则|链式法则]] 直到 [[20 反向传播的数学推导|反向传播]] 这整条训练数学线的第一块砖。

## 直觉

导数回答一个特别朴素的问题:**"我把 $x$ 推一点点,$y$ 会涨还是跌、涨跌多快?"**

想象你在一条山路上走,$x$ 是你水平走的距离,$y=f(x)$ 是海拔。某一点的**导数 = 这一点路面的坡度**:坡度为正就是上坡,为负就是下坡,数值越大坡越陡。坡度不是"你走了一整段的平均",而是**脚下这一瞬间**的陡峭程度——这就是"瞬时变化率"。

几何上,导数 $f'(x)$ 就是函数曲线在该点**切线的斜率**。怎么得到切线?取曲线上两个点连一条**割线**(平均变化率 $\Delta y/\Delta x$),再让两点无限靠近,割线就转成切线——这个"无限靠近"就是极限。

**偏导数**只是把这件事搬到多变量。$f(x,y)$ 是一座山(两个水平方向),你想问"只往东走(动 $x$)坡多陡",那就**把往北的方向(y)钉死**,只让 $x$ 变——这条"切片"曲线的斜率就是偏导数 $\partial f/\partial x$。一次只盯一个变量,其它当常数,这是偏导的全部秘密。

## 例子

**单变量导数**。$f(x)=x^2$,求 $x=3$ 处的导数。先用"动一点"的定义手算,取 $\Delta x=0.001$:

$$\frac{f(3.001)-f(3)}{0.001}=\frac{9.006001-9}{0.001}=6.001\approx 6$$

再用幂法则 $\frac{d}{dx}x^n=nx^{n-1}$:$f'(x)=2x$,$f'(3)=6$。✓ 两者一致。坡度 6 意味着 $x$ 涨 1,$y$ 大约涨 6。

![[calc-导数切线斜率.svg]]

**偏导数**。$f(x,y)=x^2y+3y$。

- 求 $\partial f/\partial x$:把 $y$ 当常数。$x^2y$ 对 $x$ 求导得 $2xy$;$3y$ 对 $x$ 是常数,导数 0。所以 $\partial f/\partial x=2xy$。
- 求 $\partial f/\partial y$:把 $x$ 当常数。$x^2y$ 对 $y$ 求导得 $x^2$;$3y$ 对 $y$ 得 $3$。所以 $\partial f/\partial y=x^2+3$。

代入点 $(x,y)=(2,1)$:$\partial f/\partial x=2\cdot2\cdot1=4$,$\partial f/\partial y=4+3=7$。解读:在 $(2,1)$ 处,只推 $x$ 函数涨得慢些(斜率 4),只推 $y$ 涨得快些(斜率 7)。

![[calc-偏导数切片.svg]]

**用乘法/除法法则再练几个(深度学习常用函数)**:

- **乘法法则** $(fg)'=f'g+fg'$。例 $f(x)=x^2e^x$:$f'=2x\cdot e^x+x^2\cdot e^x=(2x+x^2)e^x$。
- **除法法则** $(f/g)'=\frac{f'g-fg'}{g^2}$。例 sigmoid 的雏形 $\frac{1}{1+e^{-x}}$ 见下。
- **sigmoid** $\sigma(x)=\frac{1}{1+e^{-x}}$,**导数极优美**:$\sigma'(x)=\sigma(x)(1-\sigma(x))$。推导:$\sigma=(1+e^{-x})^{-1}$,链式 $\sigma'=-(1+e^{-x})^{-2}\cdot(-e^{-x})=\frac{e^{-x}}{(1+e^{-x})^2}=\sigma\cdot\frac{e^{-x}}{1+e^{-x}}=\sigma(1-\sigma)$。在 $x=0$:$\sigma=0.5$,$\sigma'=0.25$(sigmoid 最大斜率,也是它两端梯度消失的根源)。
- **tanh** $\tanh'(x)=1-\tanh^2(x)$;**ReLU** $\max(0,x)$ 导数是 $x>0$ 取 1、$x<0$ 取 0、$x=0$ 处不可导(人为约定 0 或 1)。

**二阶导数(导数的导数)**。$f(x)=x^3$:$f'=3x^2$,$f''=6x$。二阶导符号:凸/凹的判据($f''>0$ 凸/碗朝上,$f''<0$ 凹)。多变量的二阶偏导排成 Hessian(见 [[17 雅可比与 Hessian|Hessian]])。混合偏导 $\frac{\partial^2 f}{\partial x\partial y}$:先对 $x$ 再对 $y$;连续时与求导顺序无关(克莱罗定理)。例 $f=x^2y$:$\partial f/\partial x=2xy$,再对 $y$ 得 $\partial^2f/\partial x\partial y=2x$;换序 $\partial f/\partial y=x^2$,再对 $x$ 得 $2x$,一致。

## 原理

**导数的极限定义**。函数 $f$ 在点 $x$ 的导数:

$$f'(x)=\frac{df}{dx}=\lim_{\Delta x\to 0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$$

分子是 $y$ 的变化 $\Delta y$,分母是 $x$ 的变化 $\Delta x$,比值是**平均变化率(割线斜率)**;取极限 $\Delta x\to 0$ 后变成**瞬时变化率(切线斜率)**。可导要求这个极限存在(左右极限相等),所以带尖角的函数(如 $|x|$ 在 0 点)不可导。

**常用求导法则**(必背):

| 函数 | 导数 |
|---|---|
| $x^n$ | $nx^{n-1}$(幂法则) |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $\sin x$ | $\cos x$ |
| 常数 $c$ | $0$ |

加法 $(f+g)'=f'+g'$;乘法 $(fg)'=f'g+fg'$;除法 $(f/g)'=\frac{f'g-fg'}{g^2}$;复合函数交给 [[16 链式法则|链式法则]]。

**深度学习常见函数导数补全(背)**:

| 函数 | 导数 | 备注 |
|---|---|---|
| $a^x$ | $a^x\ln a$ | $e^x$ 是 $a=e$ 特例 |
| $\log_a x$ | $1/(x\ln a)$ | $\ln x$ 是 $a=e$ 特例 |
| $\tanh x$ | $1-\tanh^2 x$ | 两端饱和 |
| $\sigma(x)=\frac1{1+e^{-x}}$ | $\sigma(1-\sigma)$ | 最大值 0.25 |
| $\mathrm{softplus}=\ln(1+e^x)$ | $\sigma(x)$ | ReLU 的光滑版 |
| $\sqrt{x}=x^{1/2}$ | $\frac{1}{2\sqrt x}$ | 幂法则 $n=1/2$ |
| $1/x=x^{-1}$ | $-1/x^2$ | 幂法则 $n=-1$ |

**偏导数定义**。对 $f(x_1,\dots,x_n)$,关于 $x_i$ 的偏导是"只让 $x_i$ 变、其余固定"的导数:

$$\frac{\partial f}{\partial x_i}=\lim_{h\to 0}\frac{f(\dots,x_i+h,\dots)-f(\dots,x_i,\dots)}{h}$$

注意符号从 $d$ 换成 $\partial$("偏"),提醒读者"还有别的变量被钉住了"。计算时**把其余变量全当常数**,套单变量法则即可。

把所有偏导排成一个向量,就得到 [[15 梯度、方向导数与等高线|梯度]] $\nabla f=(\partial f/\partial x_1,\dots,\partial f/\partial x_n)^T$,这正是神经网络要对每个参数求的东西。深度学习里 $f$ 是损失、变量是百万级参数,挨个求偏导不现实,于是有了 [[18 计算图(前向)|计算图]] + [[19 自动微分：前向 vs 反向模式|自动微分]] 自动批量算出全部偏导(见 [[12 矩阵求导|矩阵求导]] 的向量化形式)。

## 代码

```python
import numpy as np

# ❌ 朴素:手推公式但不验证,写错了也不知道
def f(x): return x**2
def df_wrong(x): return 2*x + 1   # 笔误:多了个 +1,看不出来

# ✅ 正确:用极限定义(数值导数)交叉验证解析公式
def df_analytic(x): return 2*x            # 幂法则 d/dx x^2 = 2x
def df_numeric(x, eps=1e-5):
    return (f(x + eps) - f(x - eps)) / (2 * eps)   # 中心差分,更准

x0 = 3.0
print("解析:", df_analytic(x0))   # 6.0
print("数值:", df_numeric(x0))    # ≈ 6.0000000...  与解析一致 → 公式对
print("错误版:", df_wrong(x0))    # 7.0  与数值 6 不符 → 立刻暴露 bug

# 偏导数:f(x,y) = x^2 * y + 3y,只扰动其中一个变量
def g(x, y): return x**2 * y + 3*y
def dg_dx(x, y, eps=1e-5): return (g(x+eps, y) - g(x-eps, y)) / (2*eps)
def dg_dy(x, y, eps=1e-5): return (g(x, y+eps) - g(x, y-eps)) / (2*eps)

print("∂f/∂x 解析 2xy:", 2*2*1, " 数值:", dg_dx(2., 1.))   # 4  ≈4
print("∂f/∂y 解析 x²+3:", 2**2+3, " 数值:", dg_dy(2., 1.))  # 7  ≈7
```

```python
# sigmoid 导数 σ(1-σ) 验证;ReLU 在 0 点不可导(左右导数不等)
sig = lambda x: 1/(1+np.exp(-x))
dsig_analytic = lambda x: sig(x)*(1-sig(x))
dsig_numeric  = lambda x, e=1e-6: (sig(x+e)-sig(x-e))/(2*e)
print(dsig_analytic(0.), dsig_numeric(0.))   # 0.25 ≈0.25

# |x| 在 0 点:左导数 -1、右导数 +1,不相等 → 不可导
f = lambda x: abs(x)
left  = (f(0) - f(0-1e-6)) / 1e-6     # ≈ -1
right = (f(0+1e-6) - f(0)) / 1e-6     # ≈ +1
print("左导:", round(left), " 右导:", round(right))  # -1 1 → 尖角不可导

# 二阶导:f=x^3, f''=6x
f3 = lambda x: x**3
d2 = lambda x, e=1e-4: (f3(x+e) - 2*f3(x) + f3(x-e)) / e**2  # 二阶中心差分
print("f''(2) 数值≈", round(d2(2.)), " 解析 6x=", 6*2)  # 12 12
```

手算对照:解析 $f'(3)=6$ 与数值 $6$ 一致,而笔误版给 $7$ 立刻被数值导数戳穿;偏导 $\partial f/\partial x=4$、$\partial f/\partial y=7$ 与数值结果吻合。"用数值导数验证解析导数"正是 [[21 数值梯度检验与调试|数值梯度检验]] 的雏形。

## 面试高频

- **"导数的定义是什么?"** 标准答:$f'(x)=\lim_{\Delta x\to0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$,几何上是切线斜率,物理上是瞬时变化率。能说出"割线取极限变切线"就到位。
- **"导数和偏导数有什么区别?"** 导数对单变量;偏导对多变量,"只动一个、其余当常数"。符号上 $d$ 对 $\partial$。
- **"为什么 $|x|$ 在 0 点不可导?"** 左导数 $-1$、右导数 $+1$,极限不存在(尖角)。这也是 ReLU 在 0 点导数要人为约定的原因(见 [[35 激活函数(Sigmoid、Tanh、ReLU、GELU、SwiGLU)|激活函数]])。
- **"$e^x$ 的导数为什么还是 $e^x$?"** $e$ 的定义就让 $e^x$ 自身的变化率等于自身,这是它在深度学习(softmax、指数族)里到处出现的根因。
- **陷阱:可导 ⇒ 连续,但连续 ≠ 可导。** 反例 $|x|$ 连续却在 0 点不可导。
- **"神经网络里我们对什么求导?"** 对损失关于每个参数求偏导(梯度),再用 [[37 梯度下降：BGD、SGD、Mini-batch|梯度下降]] 更新——这是面试想听的落点。
- **"sigmoid 的导数?"** $\sigma(1-\sigma)$,最大 0.25(在 $x=0$);两端趋 0 → 深层连乘导致梯度消失(见 [[16 链式法则]])。
- **"二阶导数表示什么?"** 曲率;$f''>0$ 凸(碗朝上)、$f''<0$ 凹;多变量推广为 Hessian(见 [[17 雅可比与 Hessian]])。
- **"混合偏导可以交换顺序吗?"** 二阶偏导连续时可以(克莱罗定理),$\partial^2f/\partial x\partial y=\partial^2f/\partial y\partial x$。

## 关键事实

- 导数的极限定义、求导法则与偏导数概念是单变量/多变量微积分的标准内容,见 James Stewart《Calculus》(8th ed., 2015)第 2 章与第 14 章。
- 神经网络训练 = 对标量损失关于参数求偏导(梯度)后做梯度下降,见 Goodfellow, Bengio & Courville《Deep Learning》(2016)第 4.3 节。
- 中心差分 $(f(x+\epsilon)-f(x-\epsilon))/2\epsilon$ 近似导数、误差 $O(\epsilon^2)$,是验证解析梯度的经典手段,见 Nocedal & Wright《Numerical Optimization》(2nd ed., 2006)第 8 章。
