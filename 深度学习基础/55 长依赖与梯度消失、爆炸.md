[[55 长依赖与梯度消失、爆炸|长依赖问题]]是 RNN 的命门:误差沿时间反向传播时要把每步的雅可比**连乘**,跨越的时间步一长,这串积就指数地塌成 0(消失)或炸上天(爆炸),于是远处的因果学不到。

## 直觉

句子"我在**法国**长大……所以我说一口流利的 ____",要填"法语"必须记住几十个词前的"法国"。这种**跨越长距离的依赖**对 RNN 极难——不是它不想记,而是梯度传不回去。

为什么?[[54 RNN 原理与 BPTT|BPTT]]里,从第 $t$ 步的损失要影响第 $k$ 步($k\ll t$)的参数,梯度必须经过 $t-k$ 个时间步,每经过一步就乘一次雅可比 $\frac{\partial h_j}{\partial h_{j-1}}$。一长串数相乘:
- 若这些数普遍 $<1$ → 连乘**指数趋 0**,远端梯度几乎为零 → **梯度消失**:网络只学得到近期依赖,长程因果被"遗忘"。
- 若普遍 $>1$ → 连乘**指数发散** → **梯度爆炸**:loss 突然 NaN、参数被一步巨大更新冲飞。

一句话:**深度(沿时间)= 连乘 = 指数行为**。这是结构性问题,不是调参能根治的。

## 例子

承接 [[54 RNN 原理与 BPTT]]的标量例子,雅可比 $\frac{\partial h_j}{\partial h_{j-1}}=(1-h_j^2)\,W_{hh}$,把它整体记作每步增益 $\lambda$。

**消失**:设 $\lambda=0.9$(比如 $W_{hh}$ 小、或 $\tanh$ 落在饱和区使 $1-h^2$ 小)。跨 100 步:
$$0.9^{100}\approx2.66\times10^{-5}$$
远端梯度只剩十万分之三——**等于没有梯度**。

**爆炸**:设 $\lambda=1.1$。跨 100 步:
$$1.1^{100}\approx1.38\times10^{4}$$
梯度放大一万多倍,一次更新就把参数打飞 → loss 变 NaN。

**临界点**:只有 $\lambda$ 恰好 $\approx 1$ 才不消失不爆炸,但 $\lambda=(1-h_j^2)W_{hh}$ 随时间变化,根本守不住——所以朴素 RNN 几乎必然遭遇其一。注意 $\tanh'=1-h^2\le 1$,**天然偏向消失**;爆炸多由 $W_{hh}$ 谱半径过大引起。

**消失"看不见"、爆炸"看得见"(为什么爆炸反而好治)**。把这两件事并排:
- **爆炸**:loss 突然飙到 NaN、梯度范数瞬间冲到 $10^4$ 以上——**症状明显、可监控**,梯度裁剪一招就压住(限模长不改方向)。
- **消失**:没有任何报错,loss 还在缓慢下降,只是**模型死活学不到长程依赖**——症状隐蔽,你以为模型在学,其实远端梯度早已是 $10^{-5}$ 量级、约等于没更新。这就是为什么消失更棘手:它不崩溃,只是"假装在学",必须靠改架构(LSTM/GRU)从根上给梯度一条不衰减的路。

**有效记忆长度的估算**。若每步增益 $\lambda=0.9$,梯度衰减到初始 $1/e\approx0.37$ 需要的步数 $k$ 满足 $0.9^k=0.37$,$k=\frac{\ln0.37}{\ln0.9}\approx9.4$ —— 也就是说这个 RNN 的"有效记忆"只有约 10 步,10 步之前的信息基本影响不到当前梯度。$\lambda=0.99$ 时 $k\approx99$,所以让 $\lambda$ 尽量贴近 1(正交初始化、门控)能直接拉长有效记忆。

## 原理

BPTT 中,损失对早期隐状态的梯度:
$$\frac{\partial \ell_t}{\partial h_k}=\frac{\partial \ell_t}{\partial h_t}\prod_{j=k+1}^{t}\frac{\partial h_j}{\partial h_{j-1}},\qquad \frac{\partial h_j}{\partial h_{j-1}}=\text{diag}(1-h_j^2)\,W_{hh}$$

对这串雅可比做谱分析:设 $W_{hh}$ 的最大奇异值(谱范数)为 $\sigma$,$\tanh'\le 1$,则每步增益上界 $\le\sigma$。于是
$$\Big\|\prod_{j=k+1}^{t}\frac{\partial h_j}{\partial h_{j-1}}\Big\|\ \lesssim\ \sigma^{\,t-k}$$
- $\sigma<1$:范数 $\le\sigma^{t-k}\to 0$,**必然消失**(充分条件,Pascanu 2013)。
- $\sigma>1$:范数有可能 $\sim\sigma^{t-k}\to\infty$,**爆炸的必要条件**。

**两种应对路线**:

1. **治标:梯度裁剪(应对爆炸)**。爆炸是"方向对、步子过大",裁剪保方向缩模长:若 $\|g\|>\theta$,令 $g\leftarrow \theta\,\dfrac{g}{\|g\|}$。详见 [[44 梯度消失、爆炸与梯度裁剪|梯度裁剪]]。裁剪**治不了消失**——消失是信息根本没传回来,无从裁起。

2. **治本:改架构(应对消失)**。给隐状态开一条**加性、近恒等**的"高速路",让梯度可以**不经反复乘 $W_{hh}$** 地穿过长程——这就是 [[56 LSTM 门控机制|LSTM]] 的 cell 状态(CEC)与 [[57 GRU 与变体|GRU]] 的更新门。后来的 [[52 残差连接与深度可训练性|残差连接]]、注意力也是同一思想:**用加法旁路替代连乘**。其他辅助手段:用 ReLU 类激活、正交初始化 $W_{hh}$([[41 权重初始化(Xavier、He、正交)|正交初始化]]让奇异值 $\approx1$)、[[43 归一化(BatchNorm、LayerNorm、RMSNorm、GroupNorm)|LayerNorm]]。

**为什么 ReLU 用在 RNN 里要小心**。ReLU 正区导数为 1(缓解消失),但它**无上界**,反复乘 $W_{hh}$ 时正区不再像 tanh 那样把值压回 $[-1,1]$,反而更容易让 $h$ 和梯度一起**爆炸**。所以朴素 RNN 用 ReLU 需配合精心初始化(如单位矩阵初始化 $W_{hh}=I$ 的 IRNN,Le 2015),否则不如门控结构稳。

**专门的正交/酉 RNN**:既然问题是 $\prod\frac{\partial h_j}{\partial h_{j-1}}$ 的范数失控,干脆**约束 $W_{hh}$ 始终接近正交/酉矩阵**(奇异值恒 $\approx1$),让连乘范数守恒。代表:uRNN(Arjovsky 2016,酉矩阵参数化)、其后续工作。理论优美,但实现复杂、实践不如 LSTM/GRU 普及。

**彻底的解法:去掉循环**。注意力 / Transformer 把"沿时间连乘"换成"任意两个位置一跳直连的加权和",**长程依赖的路径长度从 $O(T)$ 变成 $O(1)$**——根本不存在连乘,自然没有沿时间的指数消失。这是为何 Transformer 在长依赖上完胜 RNN(见 [[60 注意力机制的起源(Bahdanau、Luong)|注意力起源]])。

## 代码

```python
import numpy as np

# 模拟 BPTT 的雅可比连乘,看梯度随时间步的指数行为
def grad_norm_over_time(lam, T):
    """lam=每步增益(谱半径的代理),返回各时间跨度的梯度模长"""
    return [lam ** k for k in range(T)]

for lam in [0.9, 1.0, 1.1]:
    g = grad_norm_over_time(lam, 100)
    print(f"λ={lam}: 跨1步={g[1]:.3f}  跨50步={g[50]:.3e}  跨99步={g[99]:.3e}")
# λ=0.9 → 跨99步 ~1e-5(消失)；λ=1.1 → 跨99步 ~1e4(爆炸)；λ=1.0 才稳

# ❌ 错:以为调小学习率就能解决梯度消失 —— 消失是梯度信号本身≈0,缩放无济于事
# ✅ 对:爆炸 → 梯度裁剪;消失 → 换 LSTM/GRU 这种带加性记忆通道的结构
def clip(g, theta=5.0):                # 梯度裁剪:保方向、限模长
    n = np.linalg.norm(g)
    return g if n <= theta else g * (theta / n)

g = np.array([100., -80., 60.])       # 爆炸的梯度
print("裁剪前模长 =", round(np.linalg.norm(g), 1),
      " 裁剪后 =", round(np.linalg.norm(clip(g)), 1))   # 被压到 5.0,方向不变

# 有效记忆长度:梯度衰减到 1/e 需要多少步
for lam in [0.9, 0.99, 0.999]:
    k = np.log(1/np.e) / np.log(lam)
    print(f"λ={lam}: 有效记忆 ≈ {k:.0f} 步")   # 0.9→9, 0.99→99, 0.999→999

# 谱半径决定消失/爆炸:看 W_hh 最大奇异值
for scale in [0.5, 1.0, 2.0]:
    W = np.random.randn(8, 8) * scale
    sigma = np.linalg.svd(W, compute_uv=False)[0]   # 最大奇异值(谱范数)
    print(f"scale={scale}: 谱范数={sigma:.2f}",
          "→ 偏消失" if sigma < 1 else "→ 偏爆炸")
```

代码印证:$\lambda$ 差之毫厘(0.9 vs 1.1),跨百步后梯度差出**九个数量级**;裁剪只能救爆炸(限模长),救不了消失。

## 面试高频

- **"梯度消失/爆炸的根本原因?"** BPTT 把每步雅可比 $\text{diag}(1-h^2)W_{hh}$ 连乘 $t-k$ 次,指数级行为:谱范数 $<1$ 消失、$>1$ 爆炸。
- **"为什么 $\tanh$ 的 RNN 更容易梯度消失?"** $\tanh'=1-h^2\le1$,每步增益天然 $\le$ 谱范数,饱和区更小,长程连乘必然衰减。
- **"梯度裁剪能解决梯度消失吗?"** 不能。裁剪只限制过大梯度(治爆炸),消失是梯度近乎为零,无从裁起;消失要靠改架构。
- **"LSTM 为什么能缓解梯度消失?"** cell 状态是**加性**更新($c_t=f_t\odot c_{t-1}+\dots$),遗忘门接近 1 时梯度近似恒等流过,避免反复乘 $W_{hh}$ 的连乘衰减。
- **"还有哪些缓解手段?"** 正交/单位谱初始化 $W_{hh}$、ReLU 类激活、LayerNorm、残差/跳连、注意力(把连乘换成加权和)。
- **"为什么消失比爆炸更难处理?"** 爆炸症状明显(NaN、范数飙升)可监控可裁剪;消失无报错、loss 照降,只是学不到长程,隐蔽得多,必须改架构治本。
- **"为什么 ReLU 在 RNN 里反而可能更危险?"** ReLU 无上界,反复乘 $W_{hh}$ 时正区不被压回有界区间,更易让 $h$ 和梯度一起爆炸;需配单位矩阵初始化(IRNN)等技巧。
- **"Transformer 为什么没有沿时间的梯度消失?"** 注意力让任意两位置一跳直连(路径长度 $O(1)$),不存在沿时间的雅可比连乘,从结构上消除了该问题。
- **"谱半径和消失/爆炸的关系?"** $W_{hh}$ 最大奇异值 $\sigma<1$ 是消失的充分条件;$\sigma>1$ 是爆炸的必要条件。正交初始化让 $\sigma\approx1$,处在临界、最稳。

## 关键事实

- **首次系统分析**:Bengio, Simard & Frasconi, *Learning Long-Term Dependencies with Gradient Descent Is Difficult*,IEEE Trans. Neural Networks 5(2), 1994——证明长依赖下梯度要么消失要么爆炸。
- **谱半径判据与裁剪**:Pascanu, Mikolov & Bengio, *On the Difficulty of Training Recurrent Neural Networks*,ICML 2013——给出 $\sigma<1$ 必然消失的充分条件,并提出梯度裁剪。
- **加性记忆通道破局**:LSTM(Hochreiter & Schmidhuber 1997)的 Constant Error Carousel 让误差恒定流动,见 [[56 LSTM 门控机制]]。
- **正交/酉 RNN**:Arjovsky, Shah & Bengio, *Unitary Evolution Recurrent Neural Networks*(ICML 2016);IRNN(单位矩阵初始化 ReLU-RNN):Le, Jaitly & Hinton(2015)。
- **去循环的根本解**:Vaswani et al., *Attention Is All You Need*(2017)用注意力把长程路径降到 $O(1)$。
- 梯度裁剪的实现细节(按范数 vs 按值)见 [[44 梯度消失、爆炸与梯度裁剪]]。
