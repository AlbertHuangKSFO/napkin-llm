[[19 自动微分：前向 vs 反向模式|自动微分]](AD)是让计算机在 [[18 计算图(前向)|计算图]] 上**精确、自动**算导数的技术,既不是手推公式也不是数值近似。它有两种扫描方向:**前向模式**(跟着函数走,代价 ∝ 输入个数)和**反向模式**(逆着走,代价 ∝ 输出个数)。深度学习里损失是标量、参数上百万,所以反向模式完胜——它就是 [[20 反向传播的数学推导|反向传播]]。

## 直觉

先澄清:算导数有三条路,AD 是第三条且最优。

1. **手推符号微分**:人工算出导数公式。准确但易错、表达式会爆炸式膨胀(嵌套求导项越来越多)。
2. **数值微分**:用 $(f(x+\epsilon)-f(x-\epsilon))/2\epsilon$ 近似。简单但有截断误差、还要对**每个参数各扰动一次**——百万参数就跑百万次前向,慢且不准(见 [[21 数值梯度检验与调试|数值梯度检验]],它只配当"裁判"不配当主力)。
3. **自动微分**:把函数拆成原子运算,每个原子的导数是已知的,再用 [[16 链式法则|链式法则]] 把它们机械地乘起来。**没有近似误差(精确到机器精度),也不膨胀公式**——AD 算的是"在某个具体点的导数值",不是导数表达式。

AD 两种方向的直觉,用"传动比怎么算"来理解。链条 $x\to u\to v\to L$,你想知道总传动比 $dL/dx$:

- **前向模式**:从 $x$ 端出发,先算 $du/dx$,带着它往前推,顺手算 $dv/dx$、$dL/dx$。**一次推送 = 固定一个输入,得到它对所有输出的影响**。多输入就要推多次。
- **反向模式**:先正向把所有值算好存下,再从 $L$ 端出发往回走,算 $dL/dv$、$dL/du$、$dL/dx$。**一次回传 = 固定一个输出,得到所有输入对它的梯度**。多输出才要传多次。

深度学习的形状是"**一个标量损失 + 海量参数**",显然反向模式只需一遍回传就拿到全部参数梯度,前向模式却要按参数数目跑——这就是为什么 backprop 用反向模式。

## 例子

函数 $L=(a\cdot b)+\sin(a)$,在 $a=2,b=3$ 求 $\partial L/\partial a$ 和 $\partial L/\partial b$。先前向建图存值:$p=ab=6$,$q=\sin a\approx0.909$,$L=p+q\approx6.909$。

**反向模式(深度学习用的)**,从 $L$ 回传,每个节点把上游梯度乘本地导数:

- $\partial L/\partial L=1$。
- $\partial L/\partial p=1$(加法本地导数),$\partial L/\partial q=1$。
- $\partial L/\partial b=\partial L/\partial p\cdot\partial p/\partial b=1\cdot a=2$。
- $\partial L/\partial a$ 有**两条路径**(经 $p$、经 $q$),相加:$\underbrace{1\cdot b}_{\text{经 }p}+\underbrace{1\cdot\cos a}_{\text{经 }q}=3+\cos2\approx3-0.416=2.584$。

**一次反向扫描**同时得到 $\partial L/\partial a$ 和 $\partial L/\partial b$。

**前向模式**对比:要分别"播种"。求 $\partial L/\partial a$:设 $\dot a=1,\dot b=0$ 往前推($\dot p=\dot a b+a\dot b=3$,$\dot q=\cos a\cdot\dot a=\cos2$,$\dot L=\dot p+\dot q=3+\cos2$)。要 $\partial L/\partial b$ **得重来一遍**:$\dot a=0,\dot b=1$。两个输入 → 两遍前向。

![[calc-前向vs反向模式.png]]

这里只有 2 个输入差别不大;但神经网络有 $10^6$ 个参数、1 个损失,反向模式 1 遍 vs 前向模式 $10^6$ 遍——天壤之别。

**前向模式的实现:对偶数(dual number)**。把每个数扩成 $a+b\varepsilon$,其中 $\varepsilon^2=0$($\varepsilon$ 像"无穷小")。运算规则自动带出导数:$(a+b\varepsilon)(c+d\varepsilon)=ac+(ad+bc)\varepsilon$——实部是函数值,$\varepsilon$ 部就是导数!算 $f(x)=x^2+x$ 在 $x=3$ 的导数:代 $3+1\varepsilon$,$f=(3+\varepsilon)^2+(3+\varepsilon)=9+6\varepsilon+\varepsilon^2+3+\varepsilon=12+7\varepsilon$,读出 $f(3)=12$、$f'(3)=7$。验证 $f'=2x+1=7$。✓ 这就是前向模式"播一个种子 $\dot x=1$ 顺推"的代数实现,不用任何 $\epsilon$ 近似、精确到机器精度。

## 原理

**自动微分的本质**:任何复杂函数都由有限个**可微原子运算**(+、×、$\exp$、$\sin$、matmul、$\max$…)复合而成。每个原子的导数已知,AD 在 [[18 计算图(前向)|计算图]] 上用 [[16 链式法则|链式法则]] 把这些已知的本地导数按图结构组合,得到**精确的导数值**(非符号、非数值近似)。

**前向模式(tangent / JVP)**。给输入一个扰动方向(种子)$\dot x$,沿图正向传播"导数值"。每个节点 $v=g(u)$ 同时算值和切线 $\dot v=\frac{\partial g}{\partial u}\dot u$。一次正扫描得到 $J\dot x$(雅可比-向量积,JVP)。要得到完整雅可比的所有列,需对每个输入维各播一次种子 → 代价 $\propto n$(输入维数)。**输入少、输出多时高效**。

**反向模式(adjoint / VJP)**。先正向求值并缓存,再给输出一个种子 $\bar L$(标量损失取 1),沿图**逆向**传播"伴随量"$\bar v=\partial L/\partial v$。每个节点把上游 $\bar v$ 乘本地雅可比转置传给父节点:$\bar u=\big(\frac{\partial g}{\partial u}\big)^T\bar v$(向量-雅可比积,VJP)。一次反扫描得到 $J^T\bar L$,即损失对**所有输入**的梯度。代价 $\propto m$(输出维数)。**输出少($m=1$)、输入多时高效**。

![[nn-jvp-vjp方向.png]]

**为什么反向模式适合深度学习(必背)**:

- 训练的目标是**标量损失** $L$($m=1$),参数是**高维** $\theta\in\mathbb R^n$($n$ 上百万到上千亿)。
- 反向模式代价 $\propto m=1$:**一次反向扫描就拿到 $\nabla_\theta L$ 的全部 $n$ 个分量**,总代价约等于 1\~3 倍前向计算量,与 $n$ 无关。
- 前向模式代价 $\propto n$:要算全部参数梯度得跑 $n$ 遍,完全不可行。
- 代价就是**显存**:反向模式必须缓存前向的中间激活以备回传,而前向模式不用存图(边算边带导数)——这是反向模式唯一的"税",由 gradient checkpointing 等技术缓解(见 [[18 计算图(前向)|计算图]])。

口诀:**输入多用反向,输出多用前向;深度学习输出=标量损失,故用反向(= backprop)**。

**四种求导方法的总对照表(背)**:

| 方法 | 精度 | 求一个 $n$ 维梯度的代价 | 缺点 |
|---|---|---|---|
| 手推符号 | 精确 | 人工 | 易错、表达式爆炸 |
| 数值(差分) | 有 $O(\epsilon)$\~$O(\epsilon^2)$ 截断误差 | $\sim n$ 次前向 | 慢、不准,只配做裁判 |
| 前向模式 AD | 精确(机器精度) | $\sim n$ 次前向 | 输入多时贵 |
| **反向模式 AD** | 精确(机器精度) | **$\sim1$\~3 次前向** | 要缓存激活(吃显存) |

**反向模式的两点代价(常被追问)**:① 显存——必须存前向中间值供回传;② 必须先完整前向再反向,不能边算边丢。前向模式反而不用存图(边算边带切线),所以算 Hessian-向量积(前向套反向)等场景仍有它的位置。

**与数值/符号微分的界线**:AD ≠ 数值微分(无 $\epsilon$、无截断误差,精确到机器精度);AD ≠ 符号微分(不产生膨胀的导数表达式,只在给定点算数值)。数值微分退居二线,专门用来**检验** AD 实现对不对(见 [[21 数值梯度检验与调试|数值梯度检验]])。

## 代码

```python
import numpy as np

# 函数:L = a*b + sin(a),手搓两种模式对比,验证它们给同样的梯度
import math

# ❌ 数值微分(主力用它就错了):每个输入各扰动一次,慢且有误差
def numeric_grad(f, a, b, eps=1e-6):
    da = (f(a+eps, b) - f(a-eps, b)) / (2*eps)
    db = (f(a, b+eps) - f(a, b-eps)) / (2*eps)   # 每多一个参数就多一遍
    return da, db

# ✅ 反向模式 AD:前向存值,一次反向扫描得到所有梯度
def reverse_mode(a, b):
    # 前向(缓存)
    p = a * b
    q = math.sin(a)
    L = p + q
    # 反向(从 L 回传)
    dL = 1.0
    dp = dL * 1.0            # 加法本地导数
    dq = dL * 1.0
    db = dp * a              # ∂p/∂b = a
    da = dp * b + dq * math.cos(a)   # 两条路径相加
    return L, da, db

f = lambda a, b: a*b + math.sin(a)
L, da, db = reverse_mode(2., 3.)
print("反向模式: L=%.4f  dL/da=%.4f  dL/db=%.4f" % (L, da, db))  # 6.909, 2.584, 2
print("数值检验:", tuple(round(x,4) for x in numeric_grad(f, 2., 3.)))  # ≈(2.584, 2)

# 对照框架:一行 backward() 跑反向模式 AD,拿到全部参数梯度
import torch
a = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(3.0, requires_grad=True)
L = a*b + torch.sin(a)
L.backward()                       # 一次反向扫描
print("torch:", round(a.grad.item(),4), round(b.grad.item(),4))  # 2.584, 2.0
```

```python
# 前向模式 = 对偶数:实部是值, ε 部是导数(精确,无 ε 近似)
class Dual:
    def __init__(self, val, der=0.0): self.val, self.der = val, der
    def __add__(s, o): o=o if isinstance(o,Dual) else Dual(o); return Dual(s.val+o.val, s.der+o.der)
    def __mul__(s, o): o=o if isinstance(o,Dual) else Dual(o); return Dual(s.val*o.val, s.der*o.val+s.val*o.der)

x = Dual(3.0, 1.0)          # 播种 ẋ=1
f = x*x + x                 # f = x^2 + x
print("f(3)=", f.val, " f'(3)=", f.der)   # 12.0  7.0  (= 2x+1)
```

手算对照:反向模式一次扫描给出 $\partial L/\partial a\approx2.584$、$\partial L/\partial b=2$,与数值微分、PyTorch `backward()` 三方一致;前向模式对偶数给出 $f(3)=12,f'(3)=7$ 与解析 $2x+1$ 一致;注意数值微分要对 $a,b$ 各扰动一遍(参数越多越慢),而反向模式一遍全拿到——正是它在深度学习里的制胜点。

## 面试高频

- **"自动微分和数值/符号微分的区别?"** AD 把函数拆原子用链式法则,**精确(机器精度)且高效**;数值微分有 $\epsilon$ 截断误差、每参数扰动一次;符号微分会表达式膨胀。三者别混。
- **"前向模式 vs 反向模式,各适合什么?"** 前向代价 ∝ 输入数(JVP,适合输入少输出多);反向代价 ∝ 输出数(VJP,适合输入多输出少)。
- **"反向传播为什么用反向模式 AD?"(高频)** 损失是**标量**($m=1$),参数**海量**($n$ 巨大);反向模式一次扫描得全部参数梯度,代价与 $n$ 无关,前向模式要跑 $n$ 遍不可行。
- **"反向模式的代价/缺点?"** 必须缓存前向中间激活以备回传 → **显存开销大**;这是 activation/gradient checkpointing 要解决的。
- **"JVP 和 VJP 分别是什么?"** 前向给雅可比-向量积 $J v$(右乘),反向给向量-雅可比积 $v^T J$(左乘)。JAX 直接暴露这两个原语。
- **陷阱:AD ≠ 自动求"导数公式"。** 它求的是**给定点的导数值**,不输出符号表达式;别和符号微分搞混。
- **"为什么有时还要 forward-mode?"** 算 Hessian-向量积、雅可比某些结构,或输出维远大于输入维(少见于训练)时,前向模式更省。
- **"前向模式怎么实现的?"** 对偶数 $a+b\varepsilon$($\varepsilon^2=0$):运算后实部=值、$\varepsilon$ 部=导数,精确无近似。
- **"四种求导方法排个序?"** 符号(易爆)、数值(有误差只配裁判)、前向 AD(代价∝输入)、反向 AD(代价∝输出,深度学习首选)。
- **"反向模式的两个代价?"** 显存(缓存激活)+ 必须先完整前向;前向模式不用存图但代价∝输入数。

## 关键事实

- 自动微分两种模式(前向/反向)、JVP/VJP、与符号/数值微分的本质区别,见 Baydin et al., 《Automatic Differentiation in Machine Learning: a Survey》(JMLR, 2018)——AD 领域最常引用综述。
- 反向模式代价正比于输出维、前向模式正比于输入维;深度学习因损失为标量、参数高维而采用反向模式(即反向传播)。其反向需缓存中间值带来显存开销,见同综述及 Griewank & Walther《Evaluating Derivatives》(2nd ed., 2008)。
- 现代框架以反向模式 AD 为核心(PyTorch autograd、TensorFlow GradientTape、JAX grad/vjp/jvp),见 Paszke et al.(NeurIPS, 2019)与 Bradbury et al., JAX(2018)。
