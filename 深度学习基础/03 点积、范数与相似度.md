[[03 点积、范数与相似度|点积]]:把两个向量**逐分量相乘再求和**得到一个标量,它一次性编码了"两个向量有多同向"和"各自有多长";**范数**是向量自身的长度,**余弦相似度**则是去掉长度、只留方向的点积——这三者是衡量相似度、注意力打分、归一化的数学基础。

## 直觉

点积回答一个问题:**"这两个箭头有多大程度指向同一个方向?"**

- 两个向量越**同向**,点积越大(正);
- **垂直**时点积恰好为 0(互不相干);
- **反向**时点积为负。

生活类比:推一辆车。你用力 $\mathbf{F}$,车沿位移 $\mathbf{d}$ 移动,你做的功 $W = \mathbf{F}\cdot\mathbf{d}$ 就是点积——只有"沿位移方向的那部分力"才算数,垂直方向白使劲。物理里的"功"就是点积的原型。

**范数**是箭头本身的长度(从 [[01 标量、向量与几何直觉|向量]] 的勾股定理推广而来)。**余弦相似度**则像"只问方向、不问远近":两条都指向东北的箭头,不管一长一短,方向一致就算"相似"——这正是搜索引擎判断两段文本语义接近的方式。

## 例子

设 $\mathbf{a} = [4, 1]$,$\mathbf{b} = [1, 3]$。

**点积**(逐分量乘再加)——两步:先把对齐的分量相乘,再把所有乘积加起来:

$$\mathbf{a}\cdot\mathbf{b} = \underbrace{4\times 1}_{=4} + \underbrace{1\times 3}_{=3} = 4 + 3 = 7$$

结果为正 ⇒ 夹角小于 90°,大致同向。

**再用不同维度手算几个点积,把"乘了加"这步练熟**:

- 三维:$[1,2,3]\cdot[4,5,6]=1\cdot4+2\cdot5+3\cdot6=4+10+18=32$。
- 正交(垂直)例:$[1,0]\cdot[0,1]=1\cdot0+0\cdot1=0$。点积为 0 = 两向量垂直,这是**正交**的定义。
- 反向例:$[2,1]\cdot[-2,-1]=2\cdot(-2)+1\cdot(-1)=-4-1=-5<0$,负数 = 夹角钝角、大致反向。
- 自己点自己:$[3,4]\cdot[3,4]=9+16=25=\|[3,4]\|^2$。**向量点自己 = 长度的平方**,这是范数定义的来源。

![[la-点积投影.svg]]

**范数**(自己点自己再开方),逐步:先平方各分量、求和、再开根号:

$$\|\mathbf{a}\| = \sqrt{4^2 + 1^2}=\sqrt{16+1} = \sqrt{17}\approx 4.12,\qquad \|\mathbf{b}\| = \sqrt{1^2+3^2}=\sqrt{1+9}=\sqrt{10}\approx 3.16$$

**夹角(用点积的几何定义反解)**。把代数点积和几何点积联立 $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$,解出 $\cos\theta$:

$$\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|} = \frac{7}{\sqrt{17}\cdot\sqrt{10}} = \frac{7}{\sqrt{170}} \approx \frac{7}{13.04}\approx 0.537$$

夹角 $\theta = \arccos(0.537)\approx 57.5°$。这个 $\cos\theta$ 就是下面的**余弦相似度**(它本身就是夹角的余弦)。

![[la-余弦相似度三态.svg]]

**投影(把 a 压到 b 方向上的影子)**。这是点积最实用的几何用途。$\mathbf{a}$ 在 $\mathbf{b}$ 方向上的**标量投影**(影子长度)和**向量投影**(影子向量):

$$\text{标量投影 }=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{b}\|}=\frac{7}{\sqrt{10}}\approx2.21,\qquad \text{向量投影 }\mathrm{proj}_{\mathbf{b}}\mathbf{a}=\frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}\,\mathbf{b}=\frac{7}{10}[1,3]=[0.7,\,2.1]$$

逐步看向量投影:先求系数 $\frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}=\frac{7}{1^2+3^2}=\frac{7}{10}=0.7$,再把这个系数乘回 $\mathbf{b}=[1,3]$ 得 $[0.7,2.1]$。直觉:这是"$\mathbf{a}$ 里有多少分量是沿着 $\mathbf{b}$ 的"。

**单位化(normalize,把向量变成长度 1)**。除以自身范数:

$$\hat{\mathbf{a}}=\frac{\mathbf{a}}{\|\mathbf{a}\|}=\frac{[4,1]}{\sqrt{17}}=\Big[\tfrac{4}{\sqrt{17}},\tfrac{1}{\sqrt{17}}\Big]\approx[0.970,\,0.243]$$

验证它确实是单位向量:$0.970^2+0.243^2\approx0.941+0.059=1.0$。✓ 归一化后,两个单位向量的点积**直接就是余弦相似度**(因为分母 $\|\hat{\mathbf{a}}\|\|\hat{\mathbf{b}}\|=1$)。

**外积 / 张量积(outer product,两个向量"叉"出一个矩阵)**。和点积(内积,出标量)相反,外积 $\mathbf{a}\mathbf{b}^\top$ 输出一个矩阵,第 $(i,j)$ 元 = $a_i b_j$:

$$\mathbf{a}\otimes\mathbf{b}=\mathbf{a}\mathbf{b}^\top=\begin{bmatrix}4\\1\end{bmatrix}\begin{bmatrix}1&3\end{bmatrix}=\begin{bmatrix}4\cdot1 & 4\cdot3\\ 1\cdot1 & 1\cdot3\end{bmatrix}=\begin{bmatrix}4&12\\1&3\end{bmatrix}$$

每一行 = $\mathbf{b}$ 被对应的 $a_i$ 缩放;每一列 = $\mathbf{a}$ 被对应的 $b_j$ 缩放。外积出来的矩阵**秩恒为 1**(见 [[07 矩阵的秩、逆与转置|秩]]),它在反向传播里就是权重梯度 $\delta\,x^\top$ 的形态(见 [[20 反向传播的数学推导|反向传播]]),在 [[10 SVD 奇异值分解|SVD]] 里是 $\sigma_i u_i v_i^\top$ 的"秩 1 积木"。

> 一句话区分:**点积(内积)= 行 × 列 = 标量**;**外积 = 列 × 行 = 矩阵**。维度上 $(1\times n)(n\times1)\to(1\times1)$ vs $(n\times1)(1\times m)\to(n\times m)$。

## 原理

**点积的两个等价定义**(核心公式,务必记牢):

$$\mathbf{a}\cdot\mathbf{b} = \sum_{i=1}^{n} a_i b_i \;=\; \|\mathbf{a}\|\,\|\mathbf{b}\|\cos\theta$$

左边是代数(逐分量),右边是几何(长度×长度×夹角余弦)。两者相等正是点积威力的来源:**算的时候用左边(快),理解的时候用右边(直观)**。

**点积的代数性质**(都能从 $\sum a_i b_i$ 直接验证,面试常考):

- **交换律** $\mathbf{a}\cdot\mathbf{b}=\mathbf{b}\cdot\mathbf{a}$;
- **对加法分配** $\mathbf{a}\cdot(\mathbf{b}+\mathbf{c})=\mathbf{a}\cdot\mathbf{b}+\mathbf{a}\cdot\mathbf{c}$;
- **标量可提** $(c\mathbf{a})\cdot\mathbf{b}=c(\mathbf{a}\cdot\mathbf{b})$;
- **正定性** $\mathbf{v}\cdot\mathbf{v}=\|\mathbf{v}\|^2\ge0$,等于 0 当且仅当 $\mathbf{v}=\mathbf{0}$。

注意点积**不满足结合律**($(\mathbf{a}\cdot\mathbf{b})\mathbf{c}\ne\mathbf{a}(\mathbf{b}\cdot\mathbf{c})$,因为括号里是标量)。

**正交(垂直)**:$\mathbf{a}\cdot\mathbf{b}=0\iff\mathbf{a}\perp\mathbf{b}$(夹角 $90°$,$\cos90°=0$)。一组两两正交且都为单位长度的向量叫**标准正交基**(如标准基 $\mathbf{e}_1,\mathbf{e}_2$),是 [[09 特征值与特征向量|对称矩阵谱定理]]、[[11 主成分分析 PCA|PCA]] 的主角。

**范数**($\ell_2$ / 欧氏范数)就是向量与自身的点积开方:

$$\|\mathbf{v}\| = \sqrt{\mathbf{v}\cdot\mathbf{v}} = \sqrt{\sum_i v_i^2}$$

**三种最常用范数(L1 / L2 / L∞)对比,用 $\mathbf{v}=[3,-4]$ 手算一遍**:

$$\|\mathbf{v}\|_1=\sum_i|v_i|=|3|+|-4|=7\quad(\text{曼哈顿/出租车距离,沿格子走})$$
$$\|\mathbf{v}\|_2=\sqrt{\textstyle\sum_i v_i^2}=\sqrt{9+16}=\sqrt{25}=5\quad(\text{欧氏/直线距离})$$
$$\|\mathbf{v}\|_\infty=\max_i|v_i|=\max(3,4)=4\quad(\text{最大分量,切比雪夫距离})$$

它们都是 $\ell_p$ 范数 $\|\mathbf{v}\|_p=(\sum_i|v_i|^p)^{1/p}$ 在 $p=1,2,\infty$ 的特例。**为什么要分清**:L2 正则(weight decay)惩罚平方和、让权重平滑变小;**L1 正则惩罚绝对值和、会把一些权重精确压到 0(稀疏化)**——因为 L1 的"等高线"是带尖角的菱形,最优解容易卡在坐标轴上。这是面试高频的 L1/L2 区别题。

**两点间欧氏距离 = 差向量的 L2 范数**:$\mathrm{dist}(\mathbf{a},\mathbf{b})=\|\mathbf{a}-\mathbf{b}\|_2$。例 $\mathbf{a}=[4,1],\mathbf{b}=[1,3]$:$\mathbf{a}-\mathbf{b}=[3,-2]$,距离 $=\sqrt{9+4}=\sqrt{13}\approx3.61$。

**投影公式的推导**(为什么是 $\frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}\mathbf{b}$)。要找 $\mathbf{a}$ 在 $\mathbf{b}$ 方向的影子 $\mathbf{p}=t\mathbf{b}$,要求"残差" $\mathbf{a}-\mathbf{p}$ 与 $\mathbf{b}$ 垂直(影子的定义):

$$(\mathbf{a}-t\mathbf{b})\cdot\mathbf{b}=0\;\Rightarrow\;\mathbf{a}\cdot\mathbf{b}-t(\mathbf{b}\cdot\mathbf{b})=0\;\Rightarrow\;t=\frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}$$

所以 $\mathrm{proj}_{\mathbf{b}}\mathbf{a}=\frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}\mathbf{b}$。投影是最小二乘、Gram-Schmidt 正交化、PCA 投影的共同内核。

**余弦相似度**从几何定义反解 $\cos\theta$:

$$\text{cos\_sim}(\mathbf{a},\mathbf{b}) = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|} \in [-1, 1]$$

它对向量**长度不敏感**——把任一向量乘以正数,余弦相似度不变。这就是为什么 [[04 Embedding 与向量数据库|Embedding]] 检索里它比裸点积更稳健:不会因为某个向量"模长大"就被偏向。

**柯西-施瓦茨不等式**保证了这个比值落在 $[-1,1]$:

$$|\mathbf{a}\cdot\mathbf{b}| \le \|\mathbf{a}\|\,\|\mathbf{b}\|$$

等号当且仅当两向量共线(一个是另一个的缩放)。这正是"余弦绝对值不超过 1"的代数化身。

**为什么代数定义 $\sum a_ib_i$ 恰好等于几何定义 $\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$(用余弦定理证)**。考虑三角形三边 $\mathbf{a},\mathbf{b},\mathbf{a}-\mathbf{b}$,余弦定理:

$$\|\mathbf{a}-\mathbf{b}\|^2=\|\mathbf{a}\|^2+\|\mathbf{b}\|^2-2\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$$

而左边用代数展开 $\|\mathbf{a}-\mathbf{b}\|^2=(\mathbf{a}-\mathbf{b})\cdot(\mathbf{a}-\mathbf{b})=\|\mathbf{a}\|^2-2\,\mathbf{a}\cdot\mathbf{b}+\|\mathbf{b}\|^2$。两式相减,$\|\mathbf{a}\|^2,\|\mathbf{b}\|^2$ 消掉,得 $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$。两个定义就此焊死——这是点积一切几何直觉的根。

**归一化后点积 = 余弦,且 $\|\mathbf{a}-\mathbf{b}\|^2=2-2\cos\theta$**(单位向量上欧氏距离与余弦的换算,检索里常用)。把 $\|\mathbf{a}\|=\|\mathbf{b}\|=1$ 代入上面展开式:$\|\mathbf{a}-\mathbf{b}\|^2=1-2\cos\theta+1=2-2\cos\theta$。所以**单位球面上,余弦越大 ⟺ 欧氏距离越小**,二者单调对应——这是"用内积索引近似欧氏最近邻"的理论依据。

> 深度学习联系:**Transformer 自注意力**的打分 $\frac{QK^\top}{\sqrt{d}}$ 就是 query 与 key 的点积(再缩放),衡量 token 间相关性;**归一化**(L2 normalize)就是把向量除以范数变成单位长度,此后点积 = 余弦相似度。

## 代码

```python
import numpy as np

a = np.array([4, 1])
b = np.array([1, 3])

# 点积：三种等价写法
print(np.dot(a, b))     # 7
print(a @ b)            # 7   推荐：@ 运算符
print(np.sum(a * b))    # 7   逐元素乘再求和（暴露本质）

# 范数（L2）
print(np.linalg.norm(a))        # 4.123...
print(np.sqrt(a @ a))           # 同上：sqrt(自点积)
print(np.linalg.norm(a, ord=1)) # L1 范数 = 5

# 余弦相似度
cos = (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))
print(cos)              # 0.5369...
print(np.degrees(np.arccos(cos)))  # 57.5°  夹角
```

```python
# 三种范数 + 欧氏距离 + 单位化
v = np.array([3., -4.])
print(np.linalg.norm(v, 1))    # 7.0   L1 = |3|+|-4|
print(np.linalg.norm(v, 2))    # 5.0   L2 = sqrt(9+16)
print(np.linalg.norm(v, np.inf))  # 4.0 L∞ = max(|3|,|-4|)

a, b = np.array([4., 1.]), np.array([1., 3.])
print(np.linalg.norm(a - b))   # 3.605...  两点欧氏距离 = ||a-b||
print(a / np.linalg.norm(a))   # [0.970 0.243]  单位化(长度变 1)

# 投影:a 在 b 方向的向量投影
proj = (a @ b) / (b @ b) * b
print(proj)                    # [0.7 2.1]
print((a - proj) @ b)          # ≈0  残差与 b 正交,验证投影正确

# 外积:列 × 行 → 矩阵(对比点积:行 × 列 → 标量)
print(np.outer(a, b))          # [[4. 12.] [1. 3.]]  秩 1 矩阵
print(np.linalg.matrix_rank(np.outer(a, b)))  # 1
print(a @ b)                   # 7.0  内积(标量)
```

```python
# 单位向量上:点积 == 余弦,且 ||a-b||^2 == 2 - 2 cos(验证换算式)
ua = a / np.linalg.norm(a)
ub = b / np.linalg.norm(b)
print(ua @ ub)                          # 0.5369... == 余弦相似度
print(np.sum((ua - ub)**2), 2 - 2*(ua @ ub))  # 两者相等 → 0.926...
```

```python
# 批量余弦相似度（检索常见场景：query 对一批文档）
# ❌ 朴素：Python 循环逐条算，N 大时极慢
def cos_slow(q, docs):
    return [ (q @ d) / (np.linalg.norm(q)*np.linalg.norm(d)) for d in docs ]

# ✅ 向量化：先 L2 归一化，再一次矩阵乘法（点积=余弦）
def cos_fast(q, docs):
    qn = q / np.linalg.norm(q)
    dn = docs / np.linalg.norm(docs, axis=1, keepdims=True)  # 逐行归一化
    return dn @ qn        # (N, d) @ (d,) -> (N,)  每个文档一个相似度
```

## 面试高频

- **"点积、余弦相似度、欧氏距离怎么选?"** 标准答法:点积同时含方向+模长,适合 query/key 打分;余弦只看方向,对长度不变,适合语义检索;欧氏距离看绝对位置差。**单位向量上三者可互推**(归一化后 $\|a-b\|^2 = 2-2\cos\theta$)。
- **"自注意力为什么要除以 $\sqrt{d}$?"** 因为高维点积的方差随维度 $d$ 增大,值过大会把 softmax 推到饱和区、梯度消失;除以 $\sqrt{d}$ 把方差拉回 1 量级(Vaswani et al., 2017)。
- **陷阱:点积大 ≠ 一定相似。** 一个超长向量即使方向偏,点积也可能很大;所以"相似度"语义下通常先归一化(用余弦)。这是裸点积检索容易踩的坑。
- **陷阱:余弦相似度不是度量(metric)。** 它不满足三角不等式;"余弦距离" $1-\cos$ 也不是严格度量。需要真正距离时用欧氏。
- **"内积和外积区别?"** 内积(点积)行×列出标量,衡量相似;外积列×行出矩阵(秩 1),用于构造权重梯度 $\delta x^\top$、SVD 的 $\sigma uv^\top$。维度规则:$(1\times n)(n\times1)\to$ 标量 vs $(n\times1)(1\times m)\to n\times m$。
- **"L1 和 L2 正则有什么区别?(高频)"** L2 让权重平滑变小但很少到 0;L1 因菱形等高线尖角而把部分权重压到精确 0,产生稀疏(特征选择)。$\ell_2$ 平方处处可导、优化平滑;$\ell_1$ 在 0 点不可导(用次梯度)。
- **"两向量正交怎么判?"** 点积为 0。引申:正交向量线性无关;标准正交基让坐标变换变成简单的点积投影(无需求逆)。
- **陷阱:点积没有结合律。** $(\mathbf{a}\cdot\mathbf{b})\mathbf{c}\ne\mathbf{a}(\mathbf{b}\cdot\mathbf{c})$,左边是"标量乘 c",右边是"标量乘 a",维度都可能不同。

## 关键事实

- 点积双定义:$\mathbf{a}\cdot\mathbf{b}=\sum a_i b_i = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$,结果是标量。
- 范数 $\|\mathbf{v}\|=\sqrt{\mathbf{v}\cdot\mathbf{v}}$;L1 促稀疏,L2 最常用。
- 余弦相似度 $\in[-1,1]$,对正缩放不变;归一化后点积 = 余弦。
- 柯西-施瓦茨 $|\mathbf{a}\cdot\mathbf{b}|\le\|\mathbf{a}\|\|\mathbf{b}\|$,等号 ⟺ 共线,保证余弦不超过 1。
- 代数=几何两定义由余弦定理打通:$\mathbf{a}\cdot\mathbf{b}=\sum a_ib_i=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$。
- 正交 ⟺ 点积为 0;向量投影 $\mathrm{proj}_{\mathbf{b}}\mathbf{a}=\frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}\mathbf{b}$,残差与 $\mathbf{b}$ 垂直。
- L1/L2/L∞ 三范数:$\|\mathbf{v}\|_1=\sum|v_i|$ 促稀疏,$\|\mathbf{v}\|_2=\sqrt{\sum v_i^2}$ 最常用,$\|\mathbf{v}\|_\infty=\max|v_i|$;均为 $\ell_p$ 特例。
- 外积 $\mathbf{a}\mathbf{b}^\top$ 是秩 1 矩阵($(\mathbf{a}\mathbf{b}^\top)_{ij}=a_ib_j$),是反向传播权重梯度与 SVD 秩 1 分解的基本积木。
- 单位向量上 $\|\mathbf{a}-\mathbf{b}\|^2=2-2\cos\theta$,欧氏距离与余弦单调对应;范数与内积的标准论述见 Strang《Introduction to Linear Algebra》(第 6 版, 2023)第 1 章。
