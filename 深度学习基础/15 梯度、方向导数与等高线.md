[[15 梯度、方向导数与等高线|梯度]]是把一个多变量函数的所有 [[14 导数与偏导数|偏导数]] 打包成的向量,它**指向函数上升最快的方向**,大小就是那个方向的最陡坡度;**方向导数**量"沿任意指定方向走有多陡";**等高线**是函数取同一值的点连成的圈,梯度永远垂直于它。负梯度方向正是 [[37 梯度下降：BGD、SGD、Mini-batch|梯度下降]] 要走的下坡路。

## 直觉

站在一座山上,脚下每个方向坡度都不一样。**梯度 $\nabla f$ 就是一根箭头,指着"上山最快"的那个方向**,箭头越长说明那个方向越陡。这不是某一个偏导,而是把"往东多陡(∂f/∂x)""往北多陡(∂f/∂y)"两个分量合成出的**合方向**。

为什么是"最快上升"?因为偏导只告诉你沿坐标轴方向的坡度,而真正最陡的方向一般是斜的;把各方向的坡度按分量合起来,正好指向最陡上坡。

**等高线**就是地图上的"等海拔线"——同一条线上所有点函数值相同(高度一样)。沿等高线走,高度不变(坡度为 0);要改变高度最快,就得**垂直于等高线**走,而那正是梯度方向。所以记住一句话:**梯度 ⊥ 等高线,指向高处**。

**方向导数**回答"我偏不沿梯度,沿某个我指定的方向 $u$ 走,坡多陡?"答案是梯度在该方向上的投影 $\nabla f\cdot u$:正对梯度时最大,垂直时为 0(沿等高线),反向时最负(最陡下坡)。

## 例子

取碗状函数 $f(x,y)=x^2+y^2$(最小值在原点)。

**先求梯度**。$\partial f/\partial x=2x$,$\partial f/\partial y=2y$,所以

$$\nabla f=(2x,\,2y)$$

在点 $(3,4)$:$\nabla f=(6,8)$。这根箭头指向"远离原点"的方向——没错,$f$ 是个碗,越往外越高,上升最快当然是朝外。它的大小 $|\nabla f|=\sqrt{6^2+8^2}=10$,就是该点最陡坡度。

**方向导数**。在 $(3,4)$ 沿单位向量 $u=(1,0)$(正东)走:

$$D_u f=\nabla f\cdot u=(6,8)\cdot(1,0)=6$$

沿 $u=(0,1)$(正北):$D_u f=8$。沿与梯度同向的单位向量 $u=(0.6,0.8)$:$D_u f=6\cdot0.6+8\cdot0.8=3.6+6.4=10$——达到最大值,正好等于 $|\nabla f|$。✓ 沿垂直方向 $u=(0.8,-0.6)$:$D_u f=6\cdot0.8+8\cdot(-0.6)=4.8-4.8=0$,这是沿等高线方向。

![[calc-梯度等高线.png]]

**为什么下坡要用负梯度**。要最快减小 $f$(机器学习里的损失),就朝 $-\nabla f=(-6,-8)$ 走——指向原点(最小值),这就是 [[37 梯度下降：BGD、SGD、Mini-batch|梯度下降]] 的更新方向 $x\leftarrow x-\eta\nabla f$。

**再算一个非对称函数的梯度**(别只会圆碗)。$g(x,y)=x^2+3xy+2y^2$:$\partial g/\partial x=2x+3y$,$\partial g/\partial y=3x+4y$,即 $\nabla g=(2x+3y,\,3x+4y)$。在 $(1,1)$:$\nabla g=(5,7)$,模 $\sqrt{25+49}=\sqrt{74}\approx8.6$。这种交叉项 $3xy$ 让等高线是**斜椭圆**,梯度方向不再指向"远离原点"那么简单——它垂直于该点的斜椭圆切线。

**带交叉项时等高线是椭圆,梯度下降会"之字形震荡"**。当 Hessian 的两个特征值差很大(椭圆又长又窄,见 [[17 雅可比与 Hessian|条件数]]),负梯度并不直指谷底,而是来回横跳,收敛慢——这就是要做特征缩放/归一化、用动量优化器的几何原因。

![[calc-之字形震荡.png]]

## 原理

**梯度定义**。$f:\mathbb R^n\to\mathbb R$ 的梯度是偏导数排成的列向量:

$$\nabla f=\frac{\partial f}{\partial x}=\Big(\frac{\partial f}{\partial x_1},\dots,\frac{\partial f}{\partial x_n}\Big)^T$$

它与 $x$ **同形**(见 [[12 矩阵求导|矩阵求导]] 的"对谁求导就和谁同形")。

**方向导数**。沿单位向量 $u$($\|u\|=1$)的方向导数是梯度与 $u$ 的 [[03 点积、范数与相似度|点积]]:

$$D_u f=\nabla f\cdot u=\|\nabla f\|\,\|u\|\cos\theta=\|\nabla f\|\cos\theta$$

其中 $\theta$ 是 $\nabla f$ 与 $u$ 的夹角。由 $\cos\theta$ 的性质:

- $\theta=0$(沿梯度):$D_uf=\|\nabla f\|$,**最大上升**。
- $\theta=180°$(逆梯度):$D_uf=-\|\nabla f\|$,**最陡下降**——梯度下降走这。
- $\theta=90°$(垂直梯度):$D_uf=0$,**沿等高线**,高度不变。

这同时证明了三件事:**梯度指向最速上升、其模是最陡坡度、梯度垂直于等高线**。

**梯度⊥等高线的证明**。等高线上 $f=c$ 不变,沿等高线切向 $t$ 移动时 $D_t f=\nabla f\cdot t=0$,点积为 0 即 $\nabla f\perp t$。所以梯度处处垂直于等高线。

**一阶泰勒展开(梯度的"线性近似"身份)**。在 $\mathbf{x}_0$ 附近,$f(\mathbf{x}_0+\Delta)\approx f(\mathbf{x}_0)+\nabla f(\mathbf{x}_0)^\top\Delta$。这说明梯度是函数的**最佳线性近似系数**:沿 $\Delta$ 走一小步,$f$ 的变化约等于 $\nabla f\cdot\Delta$。最大化这个变化(固定步长)就要 $\Delta$ 与 $\nabla f$ 同向 —— 又一次推出"梯度=最速上升"。梯度下降正是用这个线性近似:朝 $-\nabla f$ 走步长 $\eta$,保证(足够小 $\eta$ 时)损失下降。

**梯度为零 ≠ 一定是最小值**。$\nabla f=\mathbf{0}$ 的点叫**临界点**,可能是极小、极大或鞍点;要靠二阶(Hessian 特征值)区分(见 [[17 雅可比与 Hessian|二阶判据]])。高维损失面上鞍点远多于局部极小,这是深度学习优化的关键事实。

![[calc-梯度等高线.png]]

**联系到训练**。损失曲面 $L(\theta)$ 在高维参数空间里也是这样一座"山",每步用 $-\nabla_\theta L$ 下坡。梯度怎么高效算出来?靠 [[18 计算图(前向)|计算图]] 上的 [[20 反向传播的数学推导|反向传播]];方向导数的概念还衍生出二阶方法(用 [[17 雅可比与 Hessian|Hessian]] 描述曲面弯曲)。

## 代码

```python
import numpy as np

f = lambda p: p[0]**2 + p[1]**2          # f(x,y)=x^2+y^2
grad = lambda p: np.array([2*p[0], 2*p[1]])

p = np.array([3., 4.])
g = grad(p)
print("梯度:", g, " 大小:", np.linalg.norm(g))   # [6 8]  10.0

# 方向导数 = 梯度·单位向量
def dir_deriv(g, u):
    u = u / np.linalg.norm(u)             # 务必归一化成单位向量
    return g @ u

print("沿东 (1,0):", dir_deriv(g, np.array([1., 0.])))   # 6
print("沿梯度方向:", dir_deriv(g, g))                     # 10 = |∇f| 最大
print("沿等高线(垂直):", dir_deriv(g, np.array([8., -6.])))  # ≈0

# ❌ 朴素:把负梯度方向当"步长固定的方向",忘了归一化/学习率,容易发散
# ✅ 正确:梯度下降一步 = x - η ∇f
eta = 0.1
for _ in range(20):
    p = p - eta * grad(p)                 # 朝 -∇f 下坡
print("下降后 ≈原点:", np.round(p, 4))    # 趋向 [0,0] 最小值
```

```python
# 非对称函数:等高线斜椭圆,梯度不直指谷底
g  = lambda p: p[0]**2 + 3*p[0]*p[1] + 2*p[1]**2
gg = lambda p: np.array([2*p[0]+3*p[1], 3*p[0]+4*p[1]])
print("∇g(1,1)=", gg(np.array([1.,1.])))   # [5 7]

# 一阶泰勒近似 vs 真实:小步长时几乎相等
x0 = np.array([1., 1.]); d = np.array([0.01, -0.02])
approx = g(x0) + gg(x0) @ d
print("泰勒近似:", round(approx,5), " 真实:", round(g(x0+d),5))  # 很接近

# 条件数大的“峡谷”:梯度下降之字震荡(λ 差距大)
H = lambda p: np.array([100*p[0], 1*p[1]])   # ∇ of 50x²+0.5y², κ=100
q = np.array([1., 1.]); eta = 0.018
traj = [q.copy()]
for _ in range(8):
    q = q - eta * H(q); traj.append(q.copy())
print("x 分量来回变号(震荡):", np.array(traj)[:,0].round(3))
```

手算对照:梯度 $(6,8)$、模 $10$ 与上面一致;沿梯度方向的方向导数恰为 $10$(理论最大),沿垂直方向 $\approx0$(等高线);迭代后参数趋向 $(0,0)$ 即 $f$ 的最小值。

## 面试高频

- **"梯度指向什么方向?"** 函数**上升最快**的方向;模长是该点最陡坡度。注意是"上升",下降要取负梯度——这是高频混淆点。
- **"为什么梯度垂直于等高线?"** 沿等高线 $f$ 不变 ⇒ 方向导数 $\nabla f\cdot t=0$ ⇒ 梯度垂直切向。一句话证明,显功底。
- **"方向导数公式?"** $D_uf=\nabla f\cdot u$($u$ 为单位向量),最大值 $=\|\nabla f\|$(沿梯度)。陷阱:$u$ **必须归一化**,否则数值错。
- **"梯度和偏导的关系?"** 梯度是所有偏导打包成的向量;单个偏导只是沿某坐标轴的方向导数。
- **"梯度下降为什么用负梯度?"** 负梯度是最陡下降方向,使损失下降最快——是局部最优方向,不保证全局,所以才有动量、自适应等优化器(见 [[39 优化器(Momentum、RMSProp、Adam、AdamW)|优化器]])。
- **陷阱:梯度只给方向,步长由学习率定。** 步子太大会越过最小值甚至发散,这引出 [[40 学习率调度与 warmup、cosine|学习率调度]]。
- **"梯度和一阶泰勒展开什么关系?"** $f(\mathbf{x}_0+\Delta)\approx f+\nabla f^\top\Delta$,梯度是最佳线性近似系数;梯度下降就用这个近似选下降方向。
- **"$\nabla f=0$ 一定是最小值吗?"** 不,是临界点(极小/极大/鞍点),要看 Hessian 特征值区分(见 [[17 雅可比与 Hessian]])。
- **"为什么梯度下降会震荡?"** 等高线又长又窄(Hessian 条件数大),负梯度不直指谷底而横跳;归一化/动量缓解。

## 关键事实

- 梯度指向最速上升方向、垂直于等高线、方向导数 $=\nabla f\cdot u$,是多元微积分标准结论,见 James Stewart《Calculus》(8th ed., 2015)第 14.6 节。
- 负梯度方向作为最速下降方向是梯度下降法的理论基础,见 Boyd & Vandenberghe《Convex Optimization》(2004)第 9.3 节。
- 损失曲面上沿负梯度迭代是神经网络训练的核心,见 Goodfellow, Bengio & Courville《Deep Learning》(2016)第 4.3 节与第 8 章。
