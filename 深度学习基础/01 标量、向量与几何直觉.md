[[01 标量、向量与几何直觉|标量与向量]]:**标量**是只有大小的单个数(如温度 36.5),**向量**是一串有序的数,既代表空间里一个带方向的箭头,也代表一条数据样本——它是深度学习里一切张量运算的最小积木。

## 直觉

想象你在地图上描述"从家到公司怎么走"。

- 只说"走 5 公里"——这是**标量**:一个大小,没有方向。光知道 5 公里,你可能走到了任何方向。
- 说"向东走 3 公里、再向北走 4 公里"——这是**向量**:它同时锁定了**大小**(总位移)和**方向**。写成 `[3, 4]`,两个数分别是沿东西轴、南北轴走的距离。

向量的关键在于:**几个数捆在一起、顺序固定、整体当一个对象来用**。在机器学习里,一张图片、一段文字、一个用户,最后都会被压成一个向量。所以"看懂向量"= 看懂 AI 眼里的世界长什么样。

![[la-向量三种视角.png]]

为什么需要它?因为模型不理解"猫"这个字,只理解数。把"猫"变成一个 768 维向量(每一维是一个被学出来的特征),模型就能用[[03 点积、范数与相似度|点积]]去比较"猫"和"狗"有多像。这就是 [[04 Embedding 与向量数据库|Embedding]] 的核心思想。

## 例子

取二维向量 $v = [3, 4]$,在坐标系里它是从原点 $O=(0,0)$ 指向点 $(3,4)$ 的箭头。

- **第 1 个分量 3** = 沿 x 轴(横)走 3 格。
- **第 2 个分量 4** = 沿 y 轴(纵)走 4 格。
- 箭头的**长度**(到原点的距离)用勾股定理:$\sqrt{3^2 + 4^2} = \sqrt{9+16} = \sqrt{25} = 5$。这个长度就是它的[[03 点积、范数与相似度|范数]]。

再取 $w = [5, 1]$:沿 x 走 5、沿 y 走 1,是一个更"扁平"、更偏横向的箭头。两个向量虽然都在同一平面,方向却不同——这点在后面比"相似度"时至关重要。

![[la-向量几何直觉.png]]

注意:向量 $[3,4]$ 和 $[4,3]$ **不是**同一个向量,顺序变了方向就变了。这跟标量集合 $\{3,4\}$(无序)是两码事。

**再多看几个不同维度的例子,把"有序+方向"刻进脑子**:

- **一维** $v=[7]$:就是数轴上从 0 指向 7 的箭头。它和标量 $7$ 都只用一个数来描述,所以数值上很像;但 $7\in\mathbb R$ 是 0 阶标量,而 $[7]\in\mathbb R^1$ 是带一个分量的 1 阶向量,不能在形状和运算规则上直接画等号。
- **三维** $v=[1,2,2]$:从原点指向 $(1,2,2)$,长度 $\sqrt{1^2+2^2+2^2}=\sqrt{1+4+4}=\sqrt9=3$。注意这是把勾股定理从平面推到了空间——先算底面对角线 $\sqrt{1^2+2^2}=\sqrt5$,再和高 $2$ 凑直角三角形 $\sqrt{(\sqrt5)^2+2^2}=\sqrt{5+4}=3$。
- **四维** $v=[1,1,1,1]$:画不出来,但长度照样是 $\sqrt{1+1+1+1}=\sqrt4=2$。**你画不出箭头,公式照样成立**——这正是后面所有高维 Embedding 的底气。
- **零向量** $\mathbf{0}=[0,0]$:长度为 0、没有方向的特殊向量,是加法的"原点"(见 [[02 向量运算：加法、缩放与线性组合|加法单位元]])。

**坐标 = 各轴上的"投影长度"**。$v=[3,4]$ 的第 1 个分量 3,正是把箭头"压"到 x 轴上的影子长度;第 2 个分量 4 是压到 y 轴的影子。这个"投影"视角在 [[03 点积、范数与相似度|点积]] 里会变成核心工具。

## 原理

一个 $n$ 维向量是 $n$ 个实数构成的有序组,记作

$$\mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix} \in \mathbb{R}^n$$

其中 $\mathbb{R}^n$ 读作"n 维实数空间",就是所有长度为 $n$ 的实数列表的集合。约定上**默认向量是列向量**(竖着排),写成横排时常加转置 $\mathbf{v}^\top = [v_1, v_2, \dots, v_n]$。

- 标量是 0 阶张量,$s\in\mathbb R$;向量是 1 阶张量,$\mathbf v\in\mathbb R^n$。当 $n=1$ 时,$[s]\in\mathbb R^1$ 与标量 $s$ 可以自然对应,但前者仍有一个分量/一个轴,不是同一个对象。
- 第 $i$ 个数 $v_i$ 叫第 $i$ 个**分量 / 坐标**,它是 $\mathbf{v}$ 在第 $i$ 个坐标轴上的投影长度。
- 几何视角:$\mathbf{v}$ 是从原点出发的箭头;代数视角:$\mathbf{v}$ 是一列数;数据视角:$\mathbf{v}$ 是一条样本的特征。三者完全等价,这种"一物三看"是线性代数威力的来源。

> 微妙处:几何箭头只在 2D、3D 能画出来,但代数定义对任意 $n$ 都成立。深度学习里向量动辄几千维——你画不出来,但所有公式照样用,这正是抽象的价值。

**行向量 vs 列向量(必须分清,否则矩阵乘法处处踩雷)**。同一组数有两种摆法:

$$\text{列向量 } \mathbf{v}=\begin{bmatrix}3\\4\end{bmatrix}\ (\text{形状 }2\times1),\qquad \text{行向量 } \mathbf{v}^\top=\begin{bmatrix}3&4\end{bmatrix}\ (\text{形状 }1\times2)$$

数学上**默认列向量**;写 $A\mathbf{x}$、$W\mathbf{x}$ 时 $\mathbf{x}$ 都是列。转置 $\top$ 在行列之间切换。numpy 的"一维数组" `shape=(2,)` 两者都不是(没有第二根轴),广播时常出意外,要列向量就 `.reshape(-1,1)`,要行向量就 `.reshape(1,-1)`。

**单位向量 / 标准基向量**。长度恰为 1 的向量叫单位向量;沿坐标轴的单位向量 $\mathbf{e}_1=[1,0]$、$\mathbf{e}_2=[0,1]$ 叫**标准基**(见 [[04 向量空间、基与维度|基]])。任何向量都能写成基向量的配比:$[3,4]=3\mathbf{e}_1+4\mathbf{e}_2$,坐标就是这些配比系数。把一个向量除以自己的长度,就得到同方向的单位向量(**单位化 / normalize**),这是 [[03 点积、范数与相似度|余弦相似度]] 的前置操作。

**向量相等的判据**:两个向量相等 ⟺ **维数相同且逐分量相等**。$[3,4]\ne[3,4,0]$(维数不同),$[3,4]\ne[4,3]$(分量错位)。这听着废话,但 90% 的"形状不匹配"报错就栽在这。

## 代码

```python
import numpy as np

# 标量:就是一个 Python 数;numpy 里是 0 维数组
s = np.array(3.5)
print(s.shape)        # ()   —— 没有维度

# 向量:1 维数组
v = np.array([3, 4])
w = np.array([5, 1])
print(v.shape)        # (2,)  —— 长度 2 的一维
print(v[0], v[1])     # 3 4   —— 按下标取分量(从 0 开始)

# 向量长度(范数 / 模):勾股定理的推广
print(np.linalg.norm(v))   # 5.0   = sqrt(3^2 + 4^2)

# 顺序敏感:[3,4] != [4,3]
print(np.array_equal(np.array([3, 4]), np.array([4, 3])))  # False
```

```python
# ❌ 朴素:用 Python list 当向量,逐元素手写循环,慢且易错
a = [3, 4]; b = [5, 1]
out = [a[i] + b[i] for i in range(len(a))]   # 能跑,但 1000 维就开始拖

# ✅ 正确:用 numpy 数组,运算向量化、底层走 C,快几十倍
a = np.array([3, 4]); b = np.array([5, 1])
out = a + b           # array([8, 5])
```

```python
# 行/列向量与一维数组的区别(高频踩坑)
v1d = np.array([3, 4])          # shape (2,)   ——“纯一维”,没有行列
print(v1d.T.shape)              # (2,)         ——转置对一维无效！还是它自己
col = v1d.reshape(-1, 1)        # shape (2,1)  ——显式列向量
row = v1d.reshape(1, -1)        # shape (1,2)  ——显式行向量
print(col.shape, row.shape)     # (2, 1) (1, 2)
print(col.T.shape)              # (1, 2)       ——这下转置才有效

# 单位化:除以自身长度 → 同方向、长度 1 的单位向量
v = np.array([3., 4.])
u = v / np.linalg.norm(v)       # [0.6 0.8]
print(u, np.linalg.norm(u))     # [0.6 0.8]  1.0  ——长度恰好为 1

# 三维向量的长度(勾股定理的推广)
w = np.array([1., 2., 2.])
print(np.linalg.norm(w))        # 3.0  = sqrt(1+4+4)
```

## 面试高频

- **"标量、向量、矩阵、张量有什么关系?"** 标准答法:它们是同一概念按维度(阶 / rank)递进——标量是 0 维,向量 1 维,矩阵 2 维,张量是 $\ge 3$ 维的统称(其实标量/向量/矩阵都是张量的特例)。详见 [[13 张量、广播与维度对齐]]。
- **"为什么深度学习里万物皆向量?"** 因为神经网络只会做线性变换 + 非线性激活,而线性变换的输入输出都是向量;把图像/文本编码成向量后,才能喂进矩阵乘法。
- **陷阱:行向量 vs 列向量。** 面试白板写 $A\mathbf{x}$ 时,$\mathbf{x}$ 默认是列向量,形状 $(n,1)$;搞反会导致维度对不上。numpy 里 `shape=(2,)` 的一维数组没有行列之分,广播时容易踩坑,必要时用 `.reshape(-1,1)` 显式变列。
- **陷阱:`v.shape` 是 `(2,)` 不是 `(2,1)`。** 一维数组和列向量在 numpy 里不等价,转置 `v.T` 对一维数组**无效**(还是它自己)。
- **"一个 768 维向量到底存了什么?"** 每一维是一个被模型学出来的(通常不可解释的)特征坐标;它不是"第 5 维 = 颜色"这种人为含义,而是训练后涌现的分布式表示。追问"维度越高越好吗"——不,见 [[04 向量空间、基与维度|维数灾难]]:维度高表达力强但更难训、更稀疏、更耗算力。
- **"为什么向量要有序?换成集合行不行?"** 不行。神经网络第 $i$ 个权重永远对齐第 $i$ 个分量,顺序一乱整个映射就错位;集合 $\{3,4\}$ 丢掉了"哪个数在哪根轴"的信息。

## 关键事实

- 向量 $\in \mathbb{R}^n$ 是 $n$ 个有序实数(1 阶);标量 $\in\mathbb R$ 是单个数(0 阶)。$[s]\in\mathbb R^1$ 与 $s$ 数值可对应,但形状不同。
- 三种等价视角:几何箭头、代数数组、数据特征。
- 向量长度(范数)由勾股定理推广而来:$\|\mathbf{v}\| = \sqrt{\sum_i v_i^2}$。
- 约定默认列向量;numpy 一维数组 `shape=(n,)` 无行列之分,转置不改变它。
- 单位向量长度为 1;单位化 = 向量除以其范数,余弦相似度的前置步骤。
- 标准基 $\mathbf{e}_1,\dots,\mathbf{e}_n$ 中 $\mathbf{e}_i$ 只有第 $i$ 维为 1、其余为 0;任意向量 = 基向量按坐标加权(见 [[04 向量空间、基与维度]])。
- 向量相等 ⟺ 维数相同且逐分量相等;顺序敏感($[3,4]\ne[4,3]$)。
- 现代 ML 里的 Embedding(如 OpenAI text-embedding-3 输出 1536/3072 维,2024)本质就是高维向量。
- 阶(rank/ndim)递进:标量 0 阶、向量 1 阶、矩阵 2 阶、张量 ≥3 阶(见 [[13 张量、广播与维度对齐]]);标准教材如 Strang《Introduction to Linear Algebra》(第 6 版, 2023)第 1 章。
