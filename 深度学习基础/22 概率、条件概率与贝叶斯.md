[[22 概率、条件概率与贝叶斯|概率]]是对"事件发生可能性"的度量(0 到 1),**条件概率** $P(A\mid B)$ 是"已知 $B$ 发生后 $A$ 的概率",而**贝叶斯定理**把 $P(A\mid B)$ 和 $P(B\mid A)$ 互相换算——它是机器学习里"从数据反推参数""从证据更新信念"的总开关。

## 直觉

概率回答"长期重复下,某事占多大比例"。掷骰子出 6 的概率 $1/6$,意思是掷很多次大约 $1/6$ 的次数是 6。

**两种概率观(零基础先分清)**:
- **频率派(frequentist)**:概率 = 长期重复试验里的相对频率。"硬币正面概率 0.5"指抛无穷多次正面占一半。参数 $\theta$ 是个固定但未知的常数,数据是随机的。[[25 最大似然估计 MLE|MLE]] 是这一派。
- **贝叶斯派(Bayesian)**:概率 = 对命题的**信念强度**(可对"只发生一次的事"谈概率,如"明天下雨概率 70%")。参数 $\theta$ 本身是随机变量、有分布(先验),数据来了就更新它。[[26 最大后验 MAP 与正则化的概率解释|MAP]] 与贝叶斯推断属这一派。
两派算出的很多公式一致,但哲学不同——面试偶尔会问"频率派和贝叶斯派的区别",要能讲清这一点。

**条件概率**是"缩小样本空间后再数比例"。本来在全部可能里看 $A$,现在已经知道 $B$ 成立,就只在"$B$ 发生"这块里看 $A$ 占多少。直观图像:整张样本空间是一块地,$B$ 把地圈小,$P(A\mid B)$ 是"在圈里 $A$ 占的比例",分母从 $P(\Omega)=1$ 换成了 $P(B)$。

**贝叶斯定理**的直觉是**信念更新**:你心里先有个猜测(先验),看到新证据后,按证据的"指向性"把猜测调一调,得到更新后的猜测(后验)。医生看到化验阳性,不会直接说"你 99% 有病"——还要乘上这个病本来有多罕见(先验)。先验罕见时,即便检验很准,阳性也可能多半是误报。这就是贝叶斯反直觉的地方。

**"自然频率"破解贝叶斯反直觉**:把概率换成"想象 10 万人"的整数,基率谬误立刻消失。后面例子里会用这招把"约 2%"算得肉眼可见。

## 例子

**条件概率手算**。一副去掉大小王的 52 张牌,抽一张。$A$=抽到 K,$B$=抽到红色牌。红牌 26 张,其中红 K 有 2 张(红桃 K、方块 K),所以

$$P(A\mid B)=\frac{\text{红 K 张数}}{\text{红牌张数}}=\frac{2}{26}=\frac{1}{13}$$

**贝叶斯定理(经典疾病检测题)**。某病患病率 $P(D)=0.001$(千分之一,先验很罕见)。检验灵敏度 $P(+\mid D)=0.99$,假阳性率 $P(+\mid\neg D)=0.05$。问:化验阳性,真有病的概率 $P(D\mid +)$?

先算阳性的总概率(全概率公式):

$$P(+)=P(+\mid D)P(D)+P(+\mid\neg D)P(\neg D)=0.99\times0.001+0.05\times0.999=0.00099+0.04995=0.05094$$

代入贝叶斯:

$$P(D\mid +)=\frac{P(+\mid D)P(D)}{P(+)}=\frac{0.00099}{0.05094}\approx0.0194$$

**只有约 1.9%!** 即便检验很准,因为病太罕见,阳性里绝大多数是健康人的假阳性。这就是为什么不能只看检验准确率。

**用自然频率重算同一题(零基础最直观)**。设想 10 万人:
- 真病人 $100000\times0.001=100$ 人,其中阳性 $100\times0.99\approx99$ 人(真阳)。
- 健康人 $99900$ 人,其中阳性 $99900\times0.05\approx4995$ 人(假阳)。
- 阳性总人数 $99+4995=5094$,真有病的 $\dfrac{99}{5094}\approx0.0194$。

**4995 个假阳 vs 只有 99 个真阳**——一眼看出"阳性里绝大多数是健康人"。整数化是讲清基率谬误最快的方式。

![[prob-自然频率树.png]]

**第二次检验(信念可累积)**。若第一次阳性后再独立检一次又阳性,把第一次的后验 $0.0194$ 当**新的先验**代入贝叶斯:
$$P(D\mid ++)=\frac{0.99\times0.0194}{0.99\times0.0194+0.05\times0.9806}=\frac{0.0192}{0.0192+0.0490}\approx0.28$$
两次阳性把患病概率从 $1.9\%$ 拉到 $28\%$——**贝叶斯更新可以反复叠加**,这正是"序贯更新"的威力(也是为什么医生会复检)。

![[prob-贝叶斯先验后验.png]]

**赔率形式(odds form)的贝叶斯**——比例式更省事。定义赔率 $O=\frac{P(D)}{P(\neg D)}$、**似然比** $\Lambda=\frac{P(+\mid D)}{P(+\mid\neg D)}$,则
$$\underbrace{\frac{P(D\mid+)}{P(\neg D\mid+)}}_{\text{后验赔率}}=\underbrace{\frac{P(D)}{P(\neg D)}}_{\text{先验赔率}}\times\underbrace{\frac{P(+\mid D)}{P(+\mid\neg D)}}_{\text{似然比}}$$
代入:先验赔率 $\frac{0.001}{0.999}\approx0.001$,似然比 $\frac{0.99}{0.05}=19.8$,后验赔率 $\approx0.001\times19.8=0.0198$,换回概率 $\frac{0.0198}{1.0198}\approx0.0194$,与上面一致。**后验赔率 = 先验赔率 × 似然比**这一句话是贝叶斯最精炼的记法。

## 原理

**概率公理(Kolmogorov, 1933)**。对样本空间 $\Omega$ 上的事件:$P(A)\ge0$;$P(\Omega)=1$;互斥事件 $P(A\cup B)=P(A)+P(B)$。

**联合与条件**。两事件同时发生 $P(A,B)$,定义条件概率(当 $P(B)&gt;0$):

$$P(A\mid B)=\frac{P(A,B)}{P(B)}\quad\Longrightarrow\quad P(A,B)=P(A\mid B)\,P(B)$$

把右边对称地写两遍($P(A,B)=P(B\mid A)P(A)$),令两式相等,就得到

$$\boxed{P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}}\qquad\text{贝叶斯定理}$$

各部分有名字:$P(A)$ **先验**(prior,看证据前的信念)、$P(B\mid A)$ **似然**(likelihood,假设 $A$ 成立时证据 $B$ 有多可能)、$P(A\mid B)$ **后验**(posterior,更新后的信念)、$P(B)$ **证据/归一化常数**。一句话:

$$\text{后验}\propto\text{似然}\times\text{先验}$$

分母 $P(B)$ 用**全概率公式**展开($A_i$ 是一组互斥且穷尽的假设):

$$P(B)=\sum_i P(B\mid A_i)\,P(A_i)$$

**链式法则(乘法法则的推广)**。把联合概率拆成一串条件概率的连乘——这是几乎所有概率模型(语言模型、贝叶斯网络)的基石:
$$P(x_1,x_2,\dots,x_n)=P(x_1)\,P(x_2\mid x_1)\,P(x_3\mid x_1,x_2)\cdots P(x_n\mid x_1,\dots,x_{n-1})=\prod_{i=1}^n P(x_i\mid x_{<i})$$
自回归语言模型(GPT)正是直接建模这条链:每一步预测 $P(x_i\mid x_{<i})$,连乘得到整句概率。这也是 [[32 困惑度 Perplexity|困惑度]] 的概率根。

![[nn-链式法则自回归.png]]

**独立性**。若 $P(A,B)=P(A)P(B)$,则 $A,B$ **独立**,此时 $P(A\mid B)=P(A)$(知道 $B$ 不改变对 $A$ 的判断)。

**条件独立**(更微妙、面试常考):$A,B$ 在给定 $C$ 时条件独立,记 $A\perp B\mid C$,即 $P(A,B\mid C)=P(A\mid C)P(B\mid C)$。**条件独立和边际独立互不蕴含**:两个变量可能边际相关、但给定第三个变量后独立(如"冰淇淋销量"与"溺水数"边际正相关,但给定"气温"后独立);也可能边际独立、给定某变量后变相关。朴素贝叶斯分类器就假设各特征**给定类别时条件独立**,把高维联合拆成连乘以便估计:
$$P(y\mid x_1,\dots,x_d)\propto P(y)\prod_{j=1}^d P(x_j\mid y)$$
"朴素"二字就指这个(往往不成立但很好用)的条件独立假设。

**全概率公式 + 贝叶斯的多假设版**。$A_i$ 是一组互斥且穷尽的假设(如多分类的各类别):
$$P(A_k\mid B)=\frac{P(B\mid A_k)P(A_k)}{\sum_i P(B\mid A_i)P(A_i)}$$
这正是 [[27 Softmax 与温度|softmax]] 分类的概率形态:分子是某类的"似然 × 先验",分母是全体归一化——**softmax 本质上就是离散贝叶斯后验**。

这套"先验 × 似然 → 后验"正是 [[26 最大后验 MAP 与正则化的概率解释|MAP]] 的出发点,也是把损失函数从概率推出来的根(见 [[25 最大似然估计 MLE|MLE]])。

## 代码

```python
import numpy as np

# 贝叶斯:疾病检测,阳性后真患病概率
P_D     = 0.001          # 先验:患病率
P_pos_D = 0.99           # 似然:有病时阳性(灵敏度)
P_pos_nD= 0.05           # 假阳性率

# ❌ 错误直觉:阳性 → "检验 99% 准,所以 99% 有病"
wrong = P_pos_D
print("❌ 错误估计:", wrong)            # 0.99

# ✅ 正确:贝叶斯定理,先乘先验再归一化
P_pos = P_pos_D * P_D + P_pos_nD * (1 - P_D)   # 全概率
post  = P_pos_D * P_D / P_pos                   # 后验
print("✅ 贝叶斯后验 P(D|+):", round(post, 4))  # 0.0194

# 用大量模拟验证(频率派视角)
rng = np.random.default_rng(0)
N = 2_000_000
disease = rng.random(N) < P_D
positive = np.where(disease, rng.random(N) < P_pos_D,
                             rng.random(N) < P_pos_nD)
print("模拟 P(D|+):", round(disease[positive].mean(), 4))  # ≈ 0.0194
```

`❌` 把"检验准确率"当成"患病概率",忽略了罕见先验;`✅` 乘上先验并归一化,模拟值与解析值都约 $0.019$,印证手算。

```python
# 朴素贝叶斯小例:给定类别,特征条件独立 → 联合拆连乘
import numpy as np
# 两类先验,两个二值特征在各类下的 P(feature=1|class)
prior = {0: 0.5, 1: 0.5}
lik   = {0: [0.2, 0.8], 1: [0.7, 0.3]}    # P(xj=1 | class)
def nb_posterior(x):                        # x: 观测到的特征向量(0/1)
    scores = {}
    for c in (0, 1):
        s = prior[c]
        for j, xj in enumerate(x):
            p1 = lik[c][j]
            s *= p1 if xj == 1 else (1 - p1)  # 条件独立 → 连乘
        scores[c] = s
    Z = sum(scores.values())
    return {c: round(v / Z, 3) for c, v in scores.items()}   # 归一化成后验
print(nb_posterior([1, 0]))     # 后验,分母即全概率(softmax 形)
```

朴素贝叶斯把高维联合 $P(x_1,\dots,x_d\mid y)$ 近似成各特征条件概率的连乘,再乘先验、归一化——这与多类 softmax 的"似然 × 先验 / 归一化"是同一结构。

## 面试高频

- **"贝叶斯定理写出来,各项叫什么?"** $P(\theta\mid D)=\frac{P(D\mid\theta)P(\theta)}{P(D)}$:先验、似然、后验、证据。能脱口而出是底线。
- **"千分之一患病率、99% 灵敏度、5% 假阳,阳性后真患病概率?"** 约 2%。必须当场用全概率公式算分母,讲清"罕见先验拉低后验"的反直觉点;若想又快又稳,用自然频率(10 万人:99 真阳 vs 4995 假阳)直接秒出。
- **"再检一次还阳性怎么办?"** 把上一次后验当新先验序贯更新;两次阳性 $\approx28\%$。能讲"贝叶斯更新可叠加"是加分。
- **"条件概率和联合概率的关系?"** $P(A,B)=P(A\mid B)P(B)$,这条乘法链是一切推导起点;推广到 $n$ 维就是链式法则 $\prod_i P(x_i\mid x_{<i})$,正是自回归语言模型的建模对象。
- **"独立和互斥的区别?"** 互斥是不能同时发生($P(A,B)=0$);独立是发生与否互不影响($P(A,B)=P(A)P(B)$)。两个正概率事件若互斥则必不独立——常见陷阱。
- **"边际独立 vs 条件独立?"** 互不蕴含。可能边际相关而条件独立(冰淇淋–溺水,给定气温后独立),反之亦然。朴素贝叶斯赌的就是"给定类别条件独立"。
- **"似然比 / 赔率形式的贝叶斯?"** 后验赔率 = 先验赔率 × 似然比。似然比 $>1$ 的证据把信念往该假设推,$<1$ 往反方向推。
- **"频率派和贝叶斯派区别?"** 频率派把 $\theta$ 当固定常数、概率是频率(MLE);贝叶斯派把 $\theta$ 当随机变量、有先验,数据来了更新成后验(MAP / 贝叶斯推断)。
- **陷阱:把 $P(A\mid B)$ 当成 $P(B\mid A)$(检察官谬误)。** "无辜却匹配的概率小" $\ne$ "匹配却无辜的概率小",必须乘先验。

## 关键事实

- 概率公理化体系由 Kolmogorov 在《概率论基础》(*Grundbegriffe der Wahrscheinlichkeitsrechnung*, 1933)建立,是现代概率论标准基础。
- 贝叶斯定理出自 Thomas Bayes 遗作,经 Richard Price 于 1763 年整理发表;Laplace 独立给出一般形式(约 1774)。
- 疾病检测的"低患病率使后验远低于灵敏度"是基率谬误(base rate fallacy)的标准案例,见 Kahneman & Tversky 的判断与决策研究。
