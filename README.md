# napkin-llm

> 在餐巾纸上把 LLM 讲明白 —— 从一根向量到一座推理集群。
> *From a single vector to a whole inference cluster, explained on a napkin.*

一套**中文、手绘、面试向**的大模型知识库。零 AI 基础起步,一路铺到「能从头写出 LLM」「能把 LLM 部署上生产」。每个概念一张原子笔记,配**亲手画的图**(精确布局手写 SVG 绘制,不是 Mermaid、不是截图),用生活类比 + 小数字手算讲透「是什么、为什么这样设计」。

**394 篇原子笔记 · 764 张手绘图 · 6 大领域**,全部 web 核验出处(带年份 / arXiv)。

> 🐛 **发现错了 / 看不懂?** 开 [issue](../../issues/new/choose) —— 有「内容纠错(公式·数字·出处·代码·图)」和「看不懂·求补类比」两个模板,欢迎报错与提问。

## 为什么是「napkin」

好的解释应该能画在一张餐巾纸上。这库的灵魂是 **764 张手绘图**:Roofline 画成水管 vs 水泵、PagedAttention 画成停车场、Tensor Core 画成矩阵冲压机、投机解码画成「实习生写草稿主管批」。看图秒懂,再读公式。

## 怎么用

1. 用 **[Obsidian](https://obsidian.md)** 打开本仓库根目录(当作 vault)。
2. 从每个领域的 **MOC(地图)** 文件进:它只放定位 + `[[双链]]`,顺着链子走。
3. 图为 PNG(带水印),静态原生渲染无需插件;笔记里 `![[图名.png]]` 直接显示。
4. 不用 Obsidian 也能读:`.md` 是纯文本,GitHub 上直接看(双链不可点,但内容全在)。

> ✅ 文件名跨平台安全:冒号用全角 `：`、不含 `/` 等非法字符,Windows / macOS / Linux 均可正常 `git clone`。

## 学习路线

```
零基础                                                          能上生产
  │                                                                │
  ▼                                                                ▼
深度学习基础 ──► LLM(原理+从零实现 tiny GPT)──► LLM Infra(推理部署)
                    │                                  ▲
                    └──► Agent / RAG / AI 安全 ◄────────┘
                         (应用层,任意切入)
```

- **想搞懂 LLM 怎么来**:深度学习基础 → LLM。
- **想把模型跑起来扛并发**:LLM Infra(可独立读,前置背景深链回 LLM)。
- **MLE / Infra 面试**:每篇都有 `## 面试高频`(常问什么 + 标准答 + 陷阱)+ `## 关键事实`(出处带年份)。

## 每篇笔记长啥样(7 段)

① 本质开场(一句话定义) → ② 直觉 / 生活类比 → ③ 小数字手算例子 → ④ 公式推导(KaTeX,不跳步) → ⑤ 手绘 SVG → ⑥ 可运行代码/配置(`❌ 朴素 vs ✅ 高效` 对照) → ⑦ `## 面试高频` + `## 关键事实`。

## 设计约定

- **一张网,不是一棵树**:层级靠 MOC + `[[双链]]`,文件夹只一层。
- **原子笔记**:一文一概念,便于被多个 MOC 复用。
- **手写 SVG 非 Mermaid**:精确布局、固定五色调色板、信息密。
- **编号前缀**:`LLM/`、`LLM Infra/` 用三位(`001`…),其余两位(`01`…),保文件管理器有序。
